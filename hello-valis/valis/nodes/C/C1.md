## ロジック

`doGet` は `HtmlService.createHtmlOutputFromFile('Index')` から HtmlOutput を返す。
GAS の addMetaTag によりモバイル向け viewport を設定する。
Index.html は外部依存のない HTML / CSS / JavaScript とし、黒×マゼンタのネオン画面を構成する。
CSS でグリッドと光を動かし、ボタンで一括停止する。prefers-reduced-motion を尊重する。
GAS が HtmlOutput をブラウザ向け応答として提供する。
主見出しの固定文字列 `Hello, VALIS` と HtmlOutput の返却は意味保存に必要な要素である。
HTML の組み立て方法、配色、装飾、アニメーションはユーザー指定に沿った可変部とする。
命名やコメントは可変部とし、追加の認証・保存・外部通信は実装しない。
