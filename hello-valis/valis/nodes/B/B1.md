# B1:（A1 / 挨拶表示機能）［草案］

## 構成（要素・関係）

ブラウザからの GET と、固定の挨拶を含む HTML 応答からなる表示機能。
A1 に由来し、C1 が実装し、D1 が確認する。
画面は黒×マゼンタのネオン調とし、発光、動くグリッド、浮遊する光を持つ。

## ロジック

利用者は URL を開くだけで `Hello, VALIS` を読める。
入力フォーム、追加操作、画面遷移は必要としない。
アニメーションは任意の停止操作で一括停止できる。
端末の「動きを減らす」設定を尊重し、初期表示から動きを止める。
スマホでも挨拶と停止操作が表示範囲に収まり、挨拶は動作の有無によらず読める。
