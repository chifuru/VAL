# A1.4:（A1 / 1000行較正の三相進化・系統分岐・成熟仕様）［承認済み］

構成（要素・関係）:
	主所属: A層。parent_id: A1（同一層）。
	対象: 全体成長尺度、萌生/変容/異相、14系統、継承と成熟。具体化: B1.4/B1.4.1/B1.4.2。関連: A1.3/A1.5/A1.6/A1.8。

ロジック:
	全1000行の標準栄養列をenergyQuarters=1801（rawEnergy=450.25）として100Pへ較正する。P=min(100,100×energyQuarters/1801)。
	P<28は第一相・萌生、28<=P<62は第二相・変容、62<=P<100は第三相・異相、100Pは第三相の完全成熟。相判定は表示丸めでなく整数energyQuarters×100と1801×閾値の比較で行う。
	標準列の第二相は280行目（505quarters）、第三相は621行目（1117quarters）、成熟は1000行目（1801quarters）。Nによる閾値短縮やDNAによる全体成熟の前倒しを行わない。
	出生時は系統未分化。第二/第三相入口で、当該相の環境履歴と最近のenergyに基づいて14系統から選び、その相内の系統を固定する。前系統を次の分岐の固定加点・制約にしない。
	DNA素質は身体と各部位の成長感受性に作用する。既に獲得したすべての器官を次相へ継承し、アンカーを現身体の変換に追従させる。
	成熟時の形態・体色・体積・模様・器官状態を固定する。小さいNは到達済み相の途中結果として完走し、最終相へ強制しない。

制約:
	正式相は3つ。全系統を一律の陸生/宇宙全身へ交換しない。第四相は未解放候補名のみ。
	同Nと同環境操作列は同終端。先頭3器官等の切捨てで継承情報を失わない。成熟後のenergy集計とFizzBuzz再生は継続。
