# A1:（ / Windows FizzBuzz生物育成アプリ統合仕様）［草案］

構成（要素・関係）:
	主所属: A層。起点ノード、parent_idなし。
	子仕様: A1.1（出力）、A1.2（同期再生）、A1.3（4energy）、A1.4（成長・系統）、A1.5（部位と画面）、A1.6（DNA）、A1.7（desktop配布）、A1.8（実個体記録）。
	意味接続: B1へ具体化し、C1/D1に実装・検証を接続する。層間parent_idは持たない。

ロジック:
	Windows 10/11 x64で、同梱実行体とローカル画像だけから起動する生物育成アプリとする。
	入力N全体から未分化の水棲幼体と不変6軸DNAを生成し、1..NのFizzBuzz各行を4種類のenergyに排他対応させて摂取する。
	energyQuartersの蓄積を全1000行基準1801で正規化し、28/62/100Pで変容・異相・完全成熟へ進む。小さいNを最終相へ強制しない。
	環境と最近のenergyから相入口で14系統を選択し、DNAを身体形状・部位感受性に接続する。全獲得器官を継承し、頭・胴・眼・尾・付属肢・表皮と系統器官の発達を実描画に反映する。
	実行開始から実個体をrun単位で保存し、通常画面に架空見本を置かず実際に生まれた個体を再閲覧する。

制約:
	FizzBuzzの順序・表記・N件を保持する。出生時系統は未分化、正式相は萌生/変容/異相の3相、第四相は候補名のみ。
	生物・摂取・成熟の説明を出力本文へ混ぜない。承認済み仕様であることと、製品完成・美術受入・Windows実機成功を混同しない。

実態:
	状態: 草案。定義版: desktop-contract-proposal-2026-10-14。仕様・機能の採用判定と製品実装の検証は別に扱う。
	成立条件: 8子仕様が同じ入力・実個体・成長・出力契約を共有し、B/C/Dへの対応が追跡できる。
	未実施: この定義に対応するdesktop実装・画像品質受入・Windows10/11実機確認。既存E20は移行前の適合監査でありdesktopの成功証跡ではない。
