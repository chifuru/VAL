## 保持方針

1. **最新版を選んでも旧案は残す**。削除・上書きせず、新しい図案を別名の版として追加する。
2. **個体の継承を優先する**。頭・目・胴体比率・尾の根元・基本色を優先維持し、接続位置と器官が蓄積で成長/派生する。
3. **4枚だけを仕様と誤認しない**。過去9枚の良い部分を素材・器官デザインへ取り込む。
4. **原本と縮小見本を区別する**。配布ZIPの `originals/` は原PNGのまま、`thumbnails/` は閲覧用で、`manifest.json` に各原本のSHA-256がある。
5. **設計資料と実装証跡は別**。ここにある図案は視覚的な比較と作画目標であり、Canvasの現行描画/パーツアセットが画像品質に到達済みという証明ではない。

公開・GASデプロイ・承認済み既存ノードの状態変更はこの目録追加に含まれない。
