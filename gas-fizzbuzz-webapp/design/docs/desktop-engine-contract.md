# ENGINE 2 — 数値入力と進化の契約

実装: src/composite/creature-engine.js / lineage-definitions.js。検証: tests/desktop-growth.test.cjs。全VALISノードは草案。

N=1..1000、出力は元の1..N。inputイベント中に出生前DNA/姿/体色を変え、600ms安定後に自動出生する。入力途中は保存しない。育成中の切替は前runを保存し、保存失敗は通知して出生を止める。

栄養5/4/3quarters、数字調節の次回栄養1回消費は従来通り。全1000行=1801quarters。表示Pは100で上限、rawP=100q/1801を成熟判定に使う。第二相20P=201行、第三相58P=580行。成熟は88+12(1-aptitude)+8(1-sensitivity)P（88..108P）。N927は好条件の900前後成熟例。小Nの進化期間を圧縮しない。同Nの運/素質は決定的で、再実行も同じ進化。

環境はN%15と(N%15+floor(N/15)%15)%15で2配分を選び、3/5/15分類の15行周期から配分内の環境を事前計算する。環境配分は14ニッチと均等配分。相入口の実曝露90%/直近12行10%、直近餌による小加点から14系統を選ぶ。未来系統をユーザーが指定する操作はない。

組織はDNA親和性.84+.32traitと調節1+.18*sensitivity*modifierで成長する。部位growth=(.55P/100+.45tissue/1801)*rate、rateは胴1/頭1.1/眼1.4/尾1.15/ひれ1.3/肢1.2/殻1.05。素材Lv1..4と連続倍率を併用。DNAの胴X=.65+.90body/Y=1.35-.65body、頭X=.65+.70senses、尾X=.55+1.10appendageなど広い出生差を表す。

器官XP増分=(.7+.8*(環境一致+餌一致))*ID親和性*調節発現倍率。LvはXP1/55/160、growth=.1+.9*(1-exp(-XP/110))。獲得済みの全系統器官に成長を継続し、相入口スナップショットはその時点を保持する。繊維/首/腕/眼/衛片等はLv/DNAにより数と分枝が増える。眼は倍率/素材/数/光・暗視・系統特有の感覚で変化する。これは架空生物の感覚表現であり外部認識機能ではない。

色はskin由来0..360度の出生色相、bodyによる明暗、系統パレット/実摂取/成長で変わる。Canvasで明暗と輪郭を保ちPNG部位を配色する。14系統は5解剖族と独自の75器官を持つ。体積の立方根を寸法へ1回適用し、ソケットは実PNG領域/根元/倍率から投影する。

成熟到達時にfinalAppearance/maturedAtを保存し、以後は形態を固定しながらN行まで摂取/ログを継続する。engineVersion2の保存はschema1に追加。旧engineVersion1はlegacy-engine.jsで当時の状態を解釈し、保存肖像を再生成/上書きしない。
