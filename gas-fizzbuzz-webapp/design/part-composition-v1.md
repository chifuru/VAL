# 高解像度ドット・パーツ合成進化 — 実装便1（試作・未承認）

更新: 2026-10-13。主所属は設計資料（Node Fileではない）。正規責務: A1.4/A1.5、B1.4.2/B1.5、C1.4.3/C1.5/C1.6、D1.2/D1.3。

## この便で実装した範囲

既存64×64ドット基盤と12系統を維持したまま、共通個体コア・接続アンカー・パーツ経験値・Lv1〜3・2系統の異形パーツ描画・図鑑を導入。14系統で同じ環境選択方式を使う。全系統の128×128高解像度スプライトを生成済みという意味ではない。静的画像素材への差し替えと128×128アトラス化は次便。

### 固定コア

`coreFor(dna)` は出生時に `headRatio / eyeSpacing / torsoRatio / tailRatio / hueBias` を確定し、次相や環境変更で置換しない。`socketsFor(core)` はコアから整数のドット座標に変換し、左右対称の拘束ではなく共通の身体参照点を提供する。コアとソケット座標は凍結したオブジェクト。

| ソケットID | 主な結合対象 |
|---|---|
| head | 頭冠・顔面・受信角 |
| eye | 単眼/複眼・観測焦点 |
| mouth | 口器・口触手 |
| dorsal | 背びれ・受信膜・抹消冠 |
| shoulder | 翼腕・前肩装甲 |
| flank | 側腹の索・触肢 |
| chest | 生体核・光核 |
| forelimb | 腕・翼・触腕 |
| hindlimb | 脚・後肢 |
| tailBase | 付け根・器官派生元 |
| tailTip | 欠章尾・信号尾 |
| outerOrbit | 浮遊衛片・体外観測器官 |

ソケット座標は論理64×64の暫定値。128×128画像アトラス移行時は比率で再配置する。**元の顔・眼・胴・尾の基礎位置を固定し、器官だけ結合規則で派生する**。

### パーツ経験値と育成

`PARTS` に `id,label,anchor,food,environment,variants[3],thresholds[1,6,16]` を定義。
`partXp` に `lineageId:partId` ごとの累積スコアを持つ。

- 当該系統での育成中に、選択環境がパーツの `environment` と合えば +1。
- 餌の種類が `food` と合えば +1。同じ行で環境も餌も一致したら +2。
- 合計1以上でLv1、6以上でLv2、16以上でLv3。進化時の一斉全パーツLvアップではない。
- 進化先の選択は引き続きその相の環境比率と餌で決定。初期Nは身体素質であり、種族を確定させない。
- 獲得済みの `partXp` は別の系統に移っても保持。さらに前段階の外見に存在したLv付きパーツは `heritage[].parts` にスナップショットされ、別系統の体にも描画される。
- P=100以降は既存どおり外見を固定。再生はN行完走。

### 第一優先: 反記銘生命（∅）

系統候補名: 第二相 `ノル＝メム`、第三相 `レテグラフ`。第4相候補名 `アネムネシス` は表示用で解放条件未実装。著作物に由来する要素を直接転用しないオリジナル造語。

| パーツ | ソケット | Lv1 → Lv2 → Lv3 |
|---|---|---|
| 忘却面 | head | 顔の暗斑 → 非連続の額紋 → 欠落を縁取る面 |
| 不在眼 | eye | 二重瞳 → 観測欠線 → 断絶する側眼 |
| 抹消冠 | dorsal | 背びれ切れ目 → 断続冠 → 外部消失環 |
| 記憶吸糸 | flank | 短い触索 → 枝分かれする吸糸 → 断片状の長い吸糸 |
| 欠章尾 | tailTip | 尾端斑 → 欠節尾 → 遠位に分離した尾片 |

基本造形: 元の目/顔/尾を残したまま、器官が「認識しづらい欠落」へ派生する。騒がしいノイズを主役にはしない。

### 第一優先: VALIS異化通信生命（⌁）

系統候補名: 第二相 `ノオフィラ`、第三相 `アイオ＝レイ`。第4相候補名 `ヴェイル＝シオン` は名前のみ。原作のVALISの直接の造形再現ではない。

| パーツ | ソケット | Lv1 → Lv2 → Lv3 |
|---|---|---|
| 受信冠 | head | 片側受信角 → 非対称の開冠 → 外部衛片への分岐 |
| 観測焦点 | eye | 二重観測眼 → 外縁の観測点 → 体外にずれる眼群 |
| 受信膜 | dorsal | 背部の光膜 → 片側に裂けた受信面 → 符号模様の不均衡な大膜 |
| 偏在光核 | chest | 胸部の微小核 → 偏在した双核 → 生体から浮く第三核 |
| 漂遊衛片 | outerOrbit | 離れた光片 → 接続索を持つ衛片 → 複数の異常衛片 |
| 符号尾 | tailTip | 尾端信号斑 → 分岐したデータ尾 → 断続する伝送束 |

基本造形: 啓示侵食を主、通信異常を副。左右非対称、外部衛片、観測の増殖を重視し、単なる神聖な対称光輪にしない。身体コアは同じ個体として維持。

## 第一便の確認境界

- 実装: パーツデータと育成への蓄積、2新系統のドット器官、継承、図鑑への追加。
- 未実装: 参照モックそのものからのパーツPNG切り出し、128×128スプライトアトラス、すべての系統でこのパーツレベル方式を用いること、第四相の本実装。
- 描画方式: 既存の64×64生成ドットに、名前付きソケットを持つ拡張パーツを重ねて試作。最終的な128×128パーツ素材との入替が可能なインターフェースを最初に固める狙い。
- 検証: Node/V8互換DOM/Canvasモック80件（旧9+65に6件追加）。実ブラウザ・GAS実通信・画質評価ではない。
- ユーザー確認候補: LV3の忘却面を「静かな暗斑」寄りにするか、「輪郭を侵食する穴」寄りにするか。VALISの漂遊衛片の密度を高めるかどうか。今回は前者は静かな不在感、後者は3片までを採用。
