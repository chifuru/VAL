# B1.3:（A1.3 / FizzBuzz分類と3種餌蓄積・比率計算機能）［草案］

構成（要素・関係）:
	主所属: B層。parent_id: B1。
	derived_from: A1.3。入力はB1.2の再生行、出力は餌種別・種類別累積数・総数・比率。
	意味接続: B1.4（餌由来の成長・進化判定）、B1.5（色彩や演出）。

ロジック:
	Fizz→fizz（青系）、Buzz→buzz（黄系）、FizzBuzz→fizzbuzz（紫系）。数字は餌なし。
	各行を最大1つの餌に分類し、FizzBuzzをFizz/Buzzへ重複計上しない。
	種類別数と総数を累積し、合計が1以上のときの餌比率を計算可能にする。0個時の比率・基準色は未定義のままにせず後続で決める。
	再生時はその行の餌を追加。スキップ時は全配列から同じ最終値を再集計する。
	餌履歴・比率は見た目の生成に使うが、FizzBuzzの出力テキストを加工しない。
	色の混合規則、体積の増加式、細部変化はB1.4/B1.5と次工程で具体化する。

実態:
	状態: 草案。従来の排他的集計に餌バランス・比率を追加。
	確定: 3種餌の集計と比率が成長状態に供給される。
	未確定: 0個時の扱い、数値型・正規化方式、色彩合成式。
	既存C1.4のtally()は種類別累積・総数のみを実装。比率連動は未実装。
	次FLOW候補: FLOW-04 / FLOW-07。
