# B1.3:（A1.3 / FizzBuzz分類と4種餌・調節因子集計機能）［草案］

構成（要素・関係）:
	主所属: B層。parent_id: B1。
	derived_from: A1.3。入力はB1.2の再生行。出力は3種栄養餌の累積・比率、通常数字由来の調節餌の促進/抑制履歴。
	意味接続: B1.4（餌由来の成長・進化判定）、B1.5（色彩や演出）。

ロジック:
	Fizz→fizz（青系栄養餌）、Buzz→buzz（黄系栄養餌）、FizzBuzz→fizzbuzz（紫系栄養餌）、通常数字→number（第4種の調節餌）。FizzBuzzの出力配列・文字列自体は不変。
	各行を4種のうち厳密に1つの餌に分類する。FizzBuzzをFizz/Buzzへ重複計上しない。通常数字は調節餌として必ず処理する。
	栄養餌3種の数と栄養総数を別管理して比率を算出する。0個時は基準色を中立とする。通常数字の促進/抑制数は栄養総数へ加えず、調節履歴として記録する。
	通常数字nのr3=n mod 3、r5=n mod 5から促進/抑制の向きを決める仮規則を使用する。促進条件は(r3=1かつr5<=2)または(r3=2かつr5>=3)、それ以外は抑制。素数による強度差は追加候補であり未確定。
	調節餌は以後の栄養餌の成長効率および遺伝子発現の度合いを調整し、過去の成長を減算しない。調節の強さ・持続時間・重ね合わせの規則は未確定。
	再生中は各行の順番どおり4種餌を処理する。スキップ時も同じ順序の調節履歴を再計算して最終状態の一致を保証する。色・体積の写像はB1.4/B1.5で扱い、FizzBuzz出力を変更しない。

実態:
	状態: 草案。旧版の数字→餌なしを置き換え、4種餌の排他的分類と数字餌の調節機能を定義。
	確定: 3種栄養餌の比率と通常数字の調節餌の促進/抑制をB1.4へ供給する。
	仮規則: 3/5の剰余による促進・抑制。未確定: 調節の持続・強度、素数判定の追加有無、色彩合成式。
	既存C1.4は通常数字を餌にしない旧実装。4種餌・促進/抑制・新しい成長集計は未実装。
