# B1.3:（A1.3 / FizzBuzz分類と餌カウント機能）［草案］

構成（要素・関係）:
	主所属: B層。parent_id: B1。
	derived_from: A1.3。入力はB1.2の再生行、出力は餌種別・種類別計数・累積計数。
	意味接続: B1.4（進化判定）、B1.5（視覚演出）。

ロジック:
	Fizz→fizz（青）、Buzz→buzz（黄）、FizzBuzz→fizzbuzz（紫）。その他→餌なし。
	各行の餌を最大1つに分類し、FizzBuzzをFizz/Buzzへ二重計上しない。
	再生時は餌数をインクリメントする。スキップ時は全配列から最終餌数を再計算する。
	餌の種類と数量は結果の表示テキストとは別に表示する。

実態:
	状態: 草案。分割元: B1の分類・餌カウント機能。
	検証観点: 排他的分類、累積の整合、スキップ同値性。
	残存処理フラグ: 餌の演出表現は次の検討対象。
	次FLOW候補: FLOW-04 / FLOW-08。
