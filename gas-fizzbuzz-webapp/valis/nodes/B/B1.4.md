# B1.4:（A1.4 / DNAと餌蓄積による3段階・形態分岐判定機能）［草案］

構成（要素・関係）:
	主所属: B層。parent_id: B1。統合機能ノード。子: B1.4.1（成長P・調節）、B1.4.2（段階・形態・成熟）。
	子Node File: valis/nodes/B/B1.4.1.md / valis/nodes/B/B1.4.2.md。
	derived_from: A1.4（段階と分岐）、関連: A1.3（餌と連続成長）、A1.6（DNA）。
	入力: B1.6の初期DNA、B1.3の3種栄養餌数・比率・数字調節餌の促進/抑制履歴。
	出力: 成長ポイントP、進化段階（魚/陸生動物/宇宙生物）、段階内の具体形態、色・体積・細部の状態、完全成熟フラグ・固定済みの外見。
	表示先: B1.5。B1.2の再生制御とは独立して判定する。

ロジック:
	段階は「魚→陸生動物→宇宙生物」の正確に3段階。初期は魚。調節因子の効果を反映した有効成長ポイントPの仮閾値10/35で第2/第3段階へ遷移する。入力Nが小さくPが不足すると魚や陸生のまま終了する。
	各段階の具体形態候補から、初期DNAと現在の栄養餌比率・累積、数字餌による遺伝子発現調節を組み合わせて姿を決定する。
	Lispエイリアンは宇宙生物の具体的な形態候補の1つとして扱う。割り当て条件や他の種族は未定。
	色彩は3栄養餌の比率、体積と模様・部位の発達は有効栄養成長量PとDNA感受性に基づく。数字餌の促進/抑制は次の栄養餌効率と遺伝子発現強度に作用するが、過去のPを減算しない。倍率は抑制0.75、通常1.0、促進1.25を仮値とし、時系列処理と正確な係数は未確定。
	P>=100（仮値）の時点を完全成熟と定義し、その時点の具体形態・体色・体積・模様・器官を固定する。上限到達以降は餌カウンターを集計するが外見は変化させない。完全成熟は第4段階ではなく第3段階の完成状態。
	完全成熟後もB1.2のFizzBuzz自動再生は止めずN行すべてを表示する。スキップ・低モーションでは通常の1行ずつの時系列処理と同じ最終成長状態・成熟時外見を再計算する。旧4形態のstageFor()は今後置換する。

実態:
	状態: 草案。4種餌、Pによる3段階の閾値と成熟時外見固定の入出力契約を追加。
	確定: DNA+4種餌履歴で形態分岐、3段階、栄養比率で色・有効成長で体積、完全成熟以降は外見固定、再生はNまで継続。
	仮値: P=10/35/100を段階2/段階3/完全成熟の境界とする。未確定: Pの計算式、調節の持続・重み、分岐一覧・混色/体積/部位の写像。
	処理フラグ: C1.4再設計（4種餌・3段階・成熟固定）=必要、D1検証更新=必要、新証跡=未作成。
