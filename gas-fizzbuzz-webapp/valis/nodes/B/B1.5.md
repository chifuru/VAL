# B1.5:（A1.5 / ピクセル生物・成長形態の視覚フィードバック機能）［草案］

構成（要素・関係）:
	主所属: B層。parent_id: B1。
	derived_from: A1.5。初期DNA入力: B1.6、成長状態と具体形態: B1.4、餌イベント: B1.3。
	対象: 3段階の生物のピクセル表現、餌の飛来、食事反応、蓄積に応じた色・体積・部位、進化演出、カウンター。

ロジック:
	B1.6とB1.4から受けた遺伝子・具体的な形態情報をピクセルのパーツや形状に写像する。
	魚/陸生動物/宇宙生物の3段階で基本シルエットが大きく変化し、初期DNAに由来する識別できる特徴を継承する。
	同一段階中でも、餌バランスに応じて色が変化し、餌の総量に応じて体積が増加し、蓄積に応じて模様・部位等が変わる。
	Fizz/Buzz/FizzBuzzに対応する餌取得を演出する。通常数字は餌を増やさない。
	結果のテキスト表示へ演出情報を書き込まず、低モーション環境では最終形態を動きなしで示せる。
	Canvasによる整数ピクセル、部品組合せを描画実装候補とする。具体ドット絵・パレット・サイズは未確定。

実態:
	状態: 草案。DNA継承・3段階シルエット・蓄積変化の表示機能を明記。
	未確定: スプライト部品定義、描画アルゴリズム、各進化先の姿、補間とレイアウト。
	旧C1.5のCanvasスプライトは旧LV.0～3の版で、新仕様に適合したとはみなさない。
	処理フラグ: C1.5更新=必要、実ブラウザ・GAS描画確認=必要。
	次FLOW候補: FLOW-04 / FLOW-06 / FLOW-07。
