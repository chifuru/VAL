# B1.5:（A1.5 / ピクセル生物・成長形態の視覚フィードバック機能）［草案］

構成（要素・関係）:
	主所属: B層。parent_id: B1。
	derived_from: A1.5。初期DNA入力: B1.6、成長状態と具体形態: B1.4、餌イベント: B1.3。
	対象: 3段階と完全成熟のピクセル表現、4種餌の飛来、食事反応、蓄積に応じた色・体積・部位、進化演出、カウンター。

ロジック:
	B1.6とB1.4から受けた遺伝子・具体的な形態情報をピクセルのパーツや形状に写像する。
	魚/陸生動物/宇宙生物の3段階で基本シルエットが大きく変化し、初期DNAに由来する識別できる特徴を継承する。
	同一段階中でも3種栄養餌の比率に応じて色が変化し、調節後の有効成長Pに応じて体積が増加し、蓄積に応じて模様・部位が変わる。
	Fizz/Buzz/FizzBuzzは3栄養餌、通常数字は第4種の調節餌として表示する。促進/抑制の視覚表現を添えてよいが、FizzBuzz出力欄の文字列は変更しない。
	B1.4から完全成熟の状態を受け取った後は、体色・体積・器官・模様・種族などの外見パラメータを固定し、餌カウンターの更新とNまでの再生は継続する。結果のテキスト表示へ演出情報を書き込まない。
	低モーション環境では逐次処理と同値の最終形態（未進化でも可）を動きなしで表示する。Canvasによる整数ピクセル、部品組合せを候補とし、具体ドット絵・パレット・サイズは未確定。

実態:
	状態: 草案。DNA継承・3段階シルエット・4種餌の効果・完全成熟後の外見固定を表示機能へ追加。
	未確定: スプライト部品定義、4種目の餌の表示、成熟時の外見キャプチャ、各進化先の姿、補間とレイアウト。
	旧C1.5のCanvasスプライトは旧LV.0～3の版で、新仕様に適合したとはみなさない。
	処理フラグ: C1.5更新（新4種餌・成熟後の外見固定）=必要、実ブラウザ・GAS描画確認=必要。
	次FLOW候補: FLOW-04 / FLOW-06 / FLOW-07。
