# B1.5:（A1.5 / ピクセル生物・成長形態の視覚フィードバック機能）［承認済み］

構成（要素・関係）:
	主所属: B層。parent_id: B1。
	derived_from: A1.5。初期DNA入力: B1.6、成長状態と具体形態: B1.4、餌イベント: B1.3。
	対象: 3段階と完全成熟のピクセル表現、4種餌の飛来、食事反応、蓄積に応じた色・体積・部位、進化演出、カウンター。

ロジック:
	B1.6とB1.4から受けた遺伝子・具体的な形態情報をピクセルのパーツや形状に写像する。
	流線/装甲/知性の3系統を各段階で分岐させ、魚は尾やえら/甲殻/感覚器、陸生は滑空膜/装甲殻/直立体、宇宙では翼/装甲躯体/大頭エイリアンに大きく分けて描く。魚/陸生動物/宇宙生物の3段階で基本シルエットが大きく変化し、初期DNAに由来する識別できる特徴を継承する。
	同一段階中でも3種栄養餌の比率に応じて色が変化し、調節後の有効成長Pに応じて体積が増加し、蓄積に応じて模様・部位が変わる。
	Fizz/Buzz/FizzBuzzは3栄養餌、通常数字は第4種の調節餌として表示する。促進/抑制の視覚表現を添えてよいが、FizzBuzz出力欄の文字列は変更しない。
	B1.4から完全成熟の状態を受け取った後は、体色・体積・器官・模様・種族などの外見パラメータを固定し、餌カウンターの更新とNまでの再生は継続する。結果のテキスト表示へ演出情報を書き込まない。
	生き物の描画は32×32の整数ピクセル領域と、段階別の器官パーツ/輪郭/陰影を共通レンダラで組み立てる。再生中は動きと餌の効果を付与し、結果カードの個体肖像は同じappearanceを使って静止描画する。
	再生終了イベントで育成パネルよりゲーム結果画面を優先表示する。表彰台風の肖像演出・称号・個体番号・種族・到達段階・P・色・4種餌を表示し、未成熟ならRUN COMPLETE、成熟ならEVOLUTION COMPLETEを明示する。結果画面ではログ表示を切り替えられ、再育成操作を提供する。
	低モーションとスキップでは逐次処理と同じ最終形態を直接表示する。結果カードをFizzBuzz出力テキストに混入させない。

実態:
	状態: 承認済み。DNA継承・3段階シルエット・4種餌の効果・完全成熟後の外見固定を表示機能へ追加。
