# B1:（A1 / FizzBuzz算出・再生・生き物機能群）［草案］

構成（要素・関係）:
	主所属: B層。上位仕様A1を機能群として具体化する起点ノード。
	B1.1: 入力とGAS計算通信 → valis/nodes/B/B1.1.md（derived_from: A1.1）
	B1.2: 1行ずつの再生・操作 → valis/nodes/B/B1.2.md（derived_from: A1.2）
	B1.3: 出力による餌分類・カウント → valis/nodes/B/B1.3.md（derived_from: A1.3）
	B1.4: 段階成長の判定 → valis/nodes/B/B1.4.md（derived_from: A1.4）
	B1.5: 中央生き物の視覚フィードバック → valis/nodes/B/B1.5.md（derived_from: A1.5）
	各B1.xの parent_id は同一層の B1 のみ。A層のノードは意味参照で接続する。

ロジック:
	B1.1が検証済みのサーバー出力を受け、B1.2がその文字列を改変せず再生する。
	B1.3が餌を排他的に数え、B1.4が段階成長を判定し、B1.5がその状態を表示する。
	エラー時は成功結果を偽装しない。低モーション環境には自動再生の代替手段を提供する。
	サーバー出力の契約、再生、餌、進化、描画は個別に更新・検証できる。

実態:
	状態: 草案。分割元B1の機能責務を同一層の子ノード5件へ整理。
	進化閾値と描画表現は現行実装値を記録しており、後続対話で見直す。
	残存処理フラグ: 進化機能=要検討、描画機能=要検討、実機確認=必要。
	次FLOW候補: FLOW-04 / FLOW-06 / FLOW-08。
