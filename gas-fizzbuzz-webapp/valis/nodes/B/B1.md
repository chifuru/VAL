# B1:（A1 / FizzBuzz算出・再生・生き物機能群）［草案］

構成（要素・関係）:
	主所属: B層。上位仕様A1を機能群として具体化する起点ノード。
	B1.1: 入力とGAS計算通信 → valis/nodes/B/B1.1.md（derived_from: A1.1）
	B1.2: 1行ずつの再生・操作 → valis/nodes/B/B1.2.md（derived_from: A1.2）
	B1.3: 出力による4種餌分類・栄養蓄積・調節因子 → valis/nodes/B/B1.3.md（derived_from: A1.3）
	B1.4: DNA＋餌で3段階・形態分岐と完全成熟を判定 → valis/nodes/B/B1.4.md（derived_from: A1.4、関連: A1.3）
	B1.4の下位機能: B1.4.1 成長P・調節、B1.4.2 段階/種別/成熟判定（いずれもparent_id: B1.4）。
	B1.5: 成長・完全成熟を表示するピクセル生物描画 → valis/nodes/B/B1.5.md（derived_from: A1.5）
	B1.6: 入力値全体による決定的DNAと初期の魚の構築 → valis/nodes/B/B1.6.md（derived_from: A1.6）
	B1.xの親子関係は同一層B1のみに設ける。A層への依存はderived_from等の意味参照で表す。

ロジック:
	B1.1が妥当なNと計算応答を扱い、B1.6はN全体から個体DNAと初期魚の特徴を決める。
	B1.2はFizzBuzzの文字列を一切加工せず自動再生し、B1.3はFizz/Buzz/FizzBuzzの栄養餌と通常数字の調節餌を排他的に分類する。
	B1.4は初期DNA・栄養餌・促進/抑制因子から有効成長ポイントを求め、魚→陸生動物→宇宙生物の段階・具体形態を判定し、成熟上限到達時に外見を固定する。
	B1.5はDNA、現在の進化形態、3種栄養餌比率からの色、有効栄養成長量からの体積、調節された細部の蓄積状態をピクセル表現へ変換する。
	完全成熟がFizzBuzz再生より先に発生しても、出力は従来どおりN件すべてを再生し、出力文字列へ生き物情報を混ぜない。Nが小さく途中段階で終了しても最終段階を強制しない。

実態:
	状態: 草案。A1.6に対応するB1.6を追加し、B1.3～B1.5の機能契約を更新。
	確定した役割: 初期DNA / 食事蓄積 / 3段階と形態分岐 / 視覚描画の独立。
	運用仮値: 有効成長P=10/35/100で陸生/宇宙/完全成熟、促進/抑制時の栄養効率1.25/0.75。未確定: DNA生成式、数字餌の正確な効力と持続、成長ポイント計算式、種族分岐、ピクセルパーツ。
	C層・D層・E層は旧版の内容を保持しており、新仕様の実装・新検証は未実施。
	処理フラグ: 4種餌・成熟上限のC層設計/実装更新=必要、D層計画更新=必要、GAS実機確認=必要。
