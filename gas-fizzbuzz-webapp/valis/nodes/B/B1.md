# B1:（A1 / FizzBuzz算出・再生・生き物機能群）［草案］

構成（要素・関係）:
	主所属: B層。上位仕様A1を機能群として具体化する起点ノード。
	B1.1: 入力とGAS計算通信 → valis/nodes/B/B1.1.md（derived_from: A1.1）
	B1.2: 1行ずつの再生・操作 → valis/nodes/B/B1.2.md（derived_from: A1.2）
	B1.3: 出力による3種餌分類・蓄積・比率 → valis/nodes/B/B1.3.md（derived_from: A1.3）
	B1.4: 餌成長状態とDNAを組み合わせた3段階・形態分岐判定 → valis/nodes/B/B1.4.md（derived_from: A1.4、関連: A1.3）
	B1.5: ピクセル生き物の色・体積・形態・食事の描画 → valis/nodes/B/B1.5.md（derived_from: A1.5）
	B1.6: 入力値全体による決定的DNAと初期の魚の構築 → valis/nodes/B/B1.6.md（derived_from: A1.6）
	B1.xの親子関係は同一層B1のみに設ける。A層への依存はderived_from等の意味参照で表す。

ロジック:
	B1.1が妥当なNと計算応答を扱い、B1.6はN全体から個体DNAと初期魚の特徴を決める。
	B1.2はFizzBuzzの文字列を一切加工せず自動再生し、B1.3は餌を排他的に集計する。
	B1.4は初期DNA+累積餌の比率・総量から、魚→陸生動物→宇宙生物の段階・具体形態を判定する。
	B1.5はDNA、現在の進化形態、餌比率からの色、総量からの体積、細部の蓄積状態をピクセル表現へ変換する。
	FizzBuzz出力は従来のN件配列であり、演出用の成長データで変更しない。
