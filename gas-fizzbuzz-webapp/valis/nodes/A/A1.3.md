# A1.3:（A1 / 4種energyの摂取・調節・色彩と体積仕様）［承認済み］

構成（要素・関係）:
	主所属: A層。parent_id: A1（同一層）。
	対象: FizzBuzz由来の4energy、排他分類、栄養と数字調節。具体化: B1.3/B1.4.1。関連: A1.2/A1.4/A1.5/A1.6。

ロジック:
	Fizzは青、Buzzは金、FizzBuzzは紫の栄養energy、通常数字は調節energyとする。各行は厳密に1種類を摂取し、FizzBuzzをFizz/Buzzへ重複計上しない。
	3栄養energyの種類別数と総数、数字調節の数と促進/抑制を分けて管理する。摂取の飛来・吸収・反応を当該行に同期して表示する。
	通常数字nのr3=n%3、r5=n%5に対し、(r3=1かつr5<=2)または(r3=2かつr5>=3)を促進、その他を抑制とする。
	最新数字の調節を次の栄養摂取1回だけに適用する。次の数字で上書きし、栄養摂取後は中立へ戻す。栄養の有効量は促進1.25/中立1/抑制0.75、四分単位5/4/3で蓄積する。
	栄養比率を体色へ、有効栄養量を体積と部位発達へ接続し、数字調節はDNA感受性に応じた部位発現にも作用する。出生時は栄養0・調節中立・基準体積1.0。

制約:
	数字は第4の栄養原色や栄養個数として加算しない。調節で過去の成長を減算しない。任意の追加クリックで元列と別の栄養を増やさない。
	成熟後も摂取件数と出力は継続するが、固定済み形態は変更しない。
