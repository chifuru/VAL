# A1.3:（A1 / 3種餌の蓄積・色彩と体積への影響仕様）［草案］

構成（要素・関係）:
	主所属: A層。parent_id: A1。
	対象: 出力の種類に対応する3種の餌、種類別累積・総量・比率、連続的な外観変化。
	参照: A1.1（出力契約）、A1.4（段階進化への成長入力）、A1.5（表示）、A1.6（DNA）。
	具体化: B1.3（排他的分類・集計）、B1.4（成長状態への変換）。

ロジック:
	Fizz→青系の餌、Buzz→黄系の餌、FizzBuzz→紫系の特別な餌、通常数字→餌なし。
	各行は最大1種の餌に対応する。FizzBuzzをFizz/Buzzに重複計上せず、種類別の数と総数を蓄積する。
	餌の種類別「比率・バランス」に応じて体色が連続的に変化する。0個時の基準色、混色規則、飽和度や色の変化速度は未確定。
	餌の「総量」に応じて体積が増える。上限、初期体積、増加曲線、ピクセル占有数への写像は未確定。
	その他、模様・部位の成長など、蓄積に応じて滑らかにまたは小刻みに変化する特徴を持てる。具体的な対象部位は未確定。
	蓄積の変化とA1.4の3段階の大きな形態変化は異なる制御軸として扱う。
	再生行に対応して餌を取得し、スキップ後も全行を処理したのと等価な最終累積状態にする。

実態:
	状態: 草案。現行の3種餌契約を維持し、色彩・体積の仕様を追加。
	確定: 色=餌バランス、体積=餌総量、餌は排他的に蓄積。
	未確定: 混色・体積増加・細部成長の具体式。
	既存実装には新しい色/体積連続変化は未反映。
	処理フラグ: B1.3/B1.4具体化済み、C層実装=未着手、検証計画=要更新。
	次FLOW候補: FLOW-04 / FLOW-06 / FLOW-07。
