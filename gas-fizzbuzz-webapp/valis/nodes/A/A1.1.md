# A1.1:（A1 / FizzBuzz入力と出力契約）［草案］

構成（要素・関係）:
	主所属: A層。parent_id: A1（同一層の内部分解）。
	対象: GASへの入力条件とFizzBuzz算出結果の意味。B1.1、C1.1、C1.2へ制約として接続する。
	関連: A1.6は同じ入力値N全体を初期個体DNAのシードにも用いる。入力欄を増やす要件ではない。

ロジック:
	安全な整数 N を1～1000で受け取り、1からNまでを昇順に扱う（1000は既存の暫定上限）。
	15の倍数→FizzBuzz、3の倍数→Fizz、5の倍数→Buzz、その他→数字の文字列。
	GASの結果配列はN件。出力に別の説明文や装飾を混入させず、従来の表記・順序を保持する。
	入力値NはFizzBuzz計算の上限であると同時に、DNAを決めるひとまとまりの数値である。先頭桁やFizzBuzz出力の1に置き換えない。
	不正入力は拒否し、通信・応答エラーを正常結果として扱わない。

実態:
	状態: 草案。入力値の用途をA1.6へ意味参照として追加。算出・返却契約は変更しない。
	成立条件: 計算値、順序、件数、文字列形式の不変性。
	残存処理フラグ: GAS実環境確認=必要。
