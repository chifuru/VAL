# A1:（/ FizzBuzz GAS Webアプリ仕様）［草案］

構成（要素・関係）:
	Google Apps Script ウェブアプリとして、整数 N を入力し、1..N の FizzBuzz テキストを従来と同じ1行1結果で表示する。
	出力に同期して中央のレトロゲーム風（ピクセルアート）の生き物が反応し、3種類の餌を食べて成長する。
	意味参照: B1（機能）、C1（実装）、D1（検証計画）、E1（検証証跡）。層間 parent_id を設けない。

ロジック:
	GAS の calculateFizzBuzz(N) は N 件の文字列配列（Fizz / Buzz / FizzBuzz / 数字）を返す。配列・順序・表記は変更しない。
	画面は配列を1行ずつ自動再生してテキスト欄へ追記する。再生終了後の全文は従来と同じ lines.join('\\n')。
	Fizz = 青い餌、Buzz = 黄色い餌、FizzBuzz = 特別な紫の餌。普通の数字は餌を増やさない。
	餌を食べた累積回数が 3 / 7 / 15 に達したら、それぞれ成長段階1 / 2 / 3へ進化（初期段階0）。計4形態。
	再生は自動開始。操作性のため一時停止・再開・スキップ・速度変更を許容するが、出力文字列には影響させない。
	安全な整数 1～1000（上限は既存の暫定仕様）。入力不正や通信失敗時はエラー表示、成功結果を偽装しない。
	外部公開・権限変更・実環境デプロイは明示承認の対象として保留する。

実態:
	状態: 草案。今回の仕様指示に基づく草案更新であり、承認済み状態には遷移しない。
	成立条件: 計算内容が不変、出力が行単位で一致、アニメーションと成長が連動、演出が表示形式を汚染しない。
	確認待ち: GAS 実機表示・非同期通信・デプロイの承認。
