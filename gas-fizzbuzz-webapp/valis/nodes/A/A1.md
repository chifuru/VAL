# A1:（/ FizzBuzz GAS Webアプリ仕様）［草案］

構成（要素・関係）:
	主所属: A層。上位仕様の統合ノード。同一層の子ノードに成立条件を委ねる。
	A1.1: 入力条件とFizzBuzz出力契約 → valis/nodes/A/A1.1.md
	A1.2: 出力に同期する自動再生 → valis/nodes/A/A1.2.md
	A1.3: 3種類の餌・累積成長入力・色と体積への影響 → valis/nodes/A/A1.3.md
	A1.4: 魚→陸生動物→宇宙生物の3段階進化・具体的な姿の分岐 → valis/nodes/A/A1.4.md
	A1.5: ピクセル生物の視覚表現・継承される特徴 → valis/nodes/A/A1.5.md
	A1.6: 入力値全体Nに基づく初期DNAと初期魚の生成 → valis/nodes/A/A1.6.md
	意味参照: B1（機能）、C1（既存実装）、D1（既存検証計画）、E1（既存証跡）。層間の親子関係は作らない。

ロジック:
	Google Apps Script ウェブアプリとして N=1～1000（暫定上限）のFizzBuzz文字列配列を返し、1行1結果の順序と表記は変更しない。
	N全体から決定的なDNAを生成して魚型の初期個体を構成し、そのDNAを進化後も保持する。
	Fizz/Buzz/FizzBuzzの3種餌は排他的に蓄積され、餌の比率は体色、総量は体積、蓄積は細部の成長へ反映される。
	大きな形態段階は魚→陸生動物→宇宙生物の3段階。具体的な進化形態はDNAと餌による成長結果の組合せで決まる。
	中央キャラクターはピクセル表現を基本方針とし、結果欄への演出情報の混入を禁止する。
	自動再生・制御は従来の仕様を保持する。GAS実環境の公開・権限変更・デプロイは明示承認対象。

	保留: DNA算出式、色混合法、体積曲線、3段階の到達閾値、具体的な分岐系統、Lispエイリアンの条件。
