# C1.3:（B1.2 / 出力再生状態機械と表示実装）［草案］

構成（要素・関係）:
	主所属: C層。parent_id: C1。
	implements: B1.2、参照仕様: A1.2。
	実装: src/Index.html の state、nextLine()、finish()、showFinalResult()、再生操作ハンドラ。

ロジック:
	サーバーから受け取った配列を1行ずつtextarea.valueへ追加する。
	再生時に現在行を分類へ渡し、演出と同期させる。出力文字列は変更しない。
	一時停止ではタイマーを止め、再開時に残りの行を進め、スキップ時は元配列join('\\n')を表示する。
	再生速度変更時にはタイマーを張り替え、別実行時は状態と出力を初期化する。
	低モーション指定はスキップ相当の最終表示とする。

	再生完了契約: finish() はタイマー停止・UI再生終了とともに presentFinal() を呼び出す。setMode('result')で育成部を隠し結果画面を最優先表示し、setLogOpen()で結果を改変せずログの開閉を行う。retryButtonはresetState()で育成モードに戻り、前回の表示を初期化する。スキップと低モーションは showFinalResult()→finish()を共有して同じカードを表示する。再実行時は final-cardを非表示へ戻す。FizzBuzzテキストへの混入は禁止。

	残存処理フラグ: 実ブラウザでの再生/停止/スキップ/結果モード/ログ開閉/再育成の確認=必要。
