# C1.5:（B1.5 / ピクセル生物・餌・進化エフェクト描画実装）［草案］

構成（要素・関係）:
	主所属: C層。parent_id: C1。
	implements: B1.5。参照仕様: A1.5。
	実装: src/Index.html の canvas、sprite()、drawFood()、draw()、frame()、餌数UIと進捗ゲージ。魚の尾/ひれ、陸生の四肢/尾、宇宙の触角をDNA由来で描画し、栄養比率で混色、Pで体格変化。

ロジック:
	Canvasコンテキストを使用し、pixel / blockで整数グリッドのピクセル生き物を描く。
	出力が餌に対応する場合は食事反応、進化段階が変わる場合はエフェクトを描画する。
	Canvasの視覚情報、餌カウンター、進化段階ラベルは計算結果テキストとは分離する。
	src/Index.html に魚・陸生・宇宙のパーツ別ピクセル描画、DNA形質継承、成長による体格/体色、数字餌演出、成熟時の外見固定を実装した。
	初期外観: 入力N編集中にDNAプレビューを更新し、初期魚の胴体径・尾長・目の大きさ・感覚器を数ピクセル以上変える。段階内発達: tier=0..3に応じて身体寸法・ヒレ/腕/翼の発達・模様密度を目に見える単位で変化させ、成長時エフェクトを付与する。
	改良実装: src/Index.html に pixel/block/ellipse/polygon/marks/eye の部品描画、stage別 sprite（魚の横向き胴体・尾・ひれ、陸生動物の四肢・頭・尾、宇宙生物の頭・触角・腕・触手）と、共通の renderScene を実装。流線/装甲/知性で主たる輪郭と器官（魚は尾/甲殻/額の感覚器、陸生は滑空翼/殻/二足歩行、宇宙は大翼/装甲/大きな頭）に明確な差を持たせる。
	新しい final-creature Canvas は再生中の同じappearanceを使用して静止描画。画面をゲーム結果の舞台・光輪・表彰台風に再配置し、種族名と進化到達状態を主役にする。育成中は大型の生物アリーナと簡潔な餌HUDを表示する。描画処理でFizzBuzzの出力文字列を変更しない。
	GASの本番画面・視覚的な造形品質の確認は未実施。
