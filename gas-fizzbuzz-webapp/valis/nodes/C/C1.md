# C1:（B1 / GAS HTMLサービスとピクセル生き物の実装）［草案］

構成（要素・関係）:
	サーバー: src/Code.gs（doGet / calculateFizzBuzz）は既存の返却形式を維持する。
	ブラウザ: src/Index.html（入力、結果textarea、Canvasのピクセル描画、成長、再生制御）。
	設定: src/appsscript.json。意味参照: B1。親子IDによる層間リンクは禁止。

ロジック:
	Fizz / Buzz / FizzBuzz を分類する純粋関数と stageFor(totalFoods) をブラウザに実装する。
	形態の切り替え閾値: 3 / 7 / 15。餌の種類別カウントは排他的（FizzBuzzをFizz/Buzzへ二重計上しない）。
	Google Apps Script 側の算出配列を再生タイマーで1件ずつ結果欄に追記する。完了時は厳密に lines.join('\\n')。
	Canvas 描画はピクセル整数座標・imageSmoothingEnabled=false で行い、餌の飛来、口の開閉、進化時のエフェクトを表現する。
	一時停止時は出力の進行を止める。スキップ時は全文と最終カウントへ直接移る。
	入力値・返却値を検証し、文字列配列以外の値を結果欄に挿入しない。
	textContent / textarea.value を用い、返却値をHTMLとして実行しない。

実態:
	状態: 草案。
	実装中核: FizzBuzz結果の不変性、排他的分類、段階成長、再生競合防止、表示のエスケープ。
	可変要素: 配色、スプライト、BGMなしの演出、タイミング。
	対象: src/Index.html。Code.gs は原則無変更。
	未確認: GAS実機描画と通信。次FLOW候補: FLOW-08。
