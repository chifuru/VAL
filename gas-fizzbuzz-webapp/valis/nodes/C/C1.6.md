# C1.6:（B1.6 / 入力Nからの決定的DNA生成実装）［草案］
構成（要素・関係）:
	主所属: C層。parent_id: C1。implements: B1.6。参照仕様: A1.6。実装: src/Index.html 内の dnaFor。
ロジック:
	N全体を非暗号学的決定的疑似乱数のシードにし、6軸DNA（体形/器官/感覚器/表皮/進化適性/調節感受性）の0～1値へ写像する。
	同じNのDNAは同じ、成長中は不変。先頭桁ではなくN全体を利用する。体積の基準1.0、色の中立基準を保持。
実態:
	状態: 草案。新規の独立した実装単位。src/Index.html の dnaFor(seed) は Murmur型の32bit拡散混合（(N xor 0x9e3779b9)に0x85ebca6bと0xc2b2ae35をMath.imulで適用）後のxorshift32を使い、6回の値でbody/appendage/senses/skin/aptitude/sensitivityを生成。近い整数Nでも軸の値が相関しにくくなる。処理途中のDNAは変更しない。入力N変更時に初期生物をプレビューする。
