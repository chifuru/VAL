# VALIS — FizzBuzz生物育成（Windowsデスクトップ版）

Windows 10 / 11 x64向け。入力した数値N（1〜1000）から不変の初期DNAを生成し、FizzBuzzの各出力をエネルギーとして摂取する生物育成アプリです。

## ダウンロード・起動

[確認済み v1.6.0 のWindows配布](https://github.com/chifuru/VAL/actions/runs/38727120662)のArtifactsから `VALIS-Windows-x64` をダウンロードします。外側の成果物ZIP、その中の `VALIS-Windows-x64.zip` をすべて展開し、`VALIS.exe` をダブルクリックしてください。DLL・resources・localesも同じフォルダに必要です。Node.js、npm、GAS、インターネット接続は利用時に不要です。

成果物は30日保存。ソースZIPにはElectron実行体を含めません。配布物は署名していません。Windows 10/11の利用者実機での表示・操作の受入は別確認です。

## 育成

- N全体から決まるDNA6軸が、胴・頭・眼・尾・ひれ・付属肢・表皮と器官成長へ作用します。
- Fizzは生命、Buzzは鉱物、FizzBuzzは情報、数字は促進/抑制の調節エネルギー。各出力1行に1回の摂取が対応します。
- 数字入力 →「① 読み込み」でDNA・初期形態・環境を準備 →「② スタート」で育成開始。入力や読み込みだけでは実行しません。第二段階は201回、第三段階は580回、第三形態以降の器官発達・系統別の餌配合・環境適応が揃うと独立した第四段階・覚醒（最終形態）へ進みます。Nが小さいと、実際に到達した途中の姿で終了します。
- 環境は数値とFizzBuzzの周期から事前決定され、その実履歴から20系統へ分岐し、獲得した全器官を継承します。系統ごとに4〜6の器官群、計99群（新24群は既存素材を明示再利用）があります。
- 通常0.1秒/行、ゆっくり0.2秒/行、速い0.05秒/行で、原文を1行ずつ表示します。DNAとFizzBuzz出力は常時表示です。一時停止・再開・速度・最後まで進めるを使用できます。任意の追加給餌で原FizzBuzz列とは別の成長を増やしません。
- 「図鑑」は育成を最後まで実行した最終結果だけを表示します。未成熟の完走も実際の結果として残し、途中保存や出生前プレビューは掲載しません。同じNでも別実行は別個体。記録の閲覧で現在の育成内容は変わりません。

保存先はElectronのWindowsユーザーデータ領域（通常 `%APPDATA%/VALIS/specimens/history.json`）。実形態・DNA・相履歴・PNG肖像を保存します。保存失敗や破損は画面に表示し、元記録とバックアップを保全します。通常再生中は25行ごと、相遷移・一時停止・完走・通常終了時にも保存します。電源断など通常終了できない場合は最後の保存位置までになります。

v1.6.0では生態世界の美術を強化しました。深海の珊瑚・海藻、熱圏の玄武岩・赤銅色の植物、情報域の真珠質の扇葉・結晶花、虚空の銀枝・黒曜石の花を追加しています。遠景の柔らかな方向光、中景の累積群生、前景の地形で奥行きを作ります。20系統それぞれの明暗・彩度・縁の反射と身体型ごとの動きを調整し、環境の光を一体の身体に反映します。生命餌は4種×2姿勢の全8領域を使い、底生・群泳・漂泳の行動と、滑らかな旋回・奥行きを持ちます。新しい演出は元の成長・分岐・覚醒計算を変えません。

v1.5.1では停止しやすい処理と演出の違和感を修正しました。反応用Canvasを再利用し、静的背景・皮膚・発光をバイト上限付きキャッシュへ保持します。高倍率でも観測Canvasは最大約200万画素・1.5倍に抑え、文字や操作部は通常の表示倍率を維持します。DNA・器官カードを再利用し、肖像を一度だけ非同期PNG化します。25行ごとの保存は行再生を止めず、停止・完走・終了では保存キューを待ちます。保存失敗は表示し再生を停止します。

口腔や唇を描き足す演出を外し、元画像の口先だけを小さく動かします。生物の型に応じて口先の動きや口元の収縮を分け、実眼を保護します。生命は初回と以後4回ごと（0.9秒）、鉱物は初回と以後2回ごと（1.1秒）、情報は毎回（1.4秒）、一周期でゆっくり立ち上がり落ち着きます。鉱物は地面への拡散反射、情報は元画像の明るい器官の弱い発光です。人工的な光筋・光球・突然出る結晶や直接の取り込みはありません。数字は背景だけを変え、元の調節計算は保持します。

8種類の群生は生息地の色温度・彩度・明るさへ合わせ、根元のフェード・接地影・大気の色で背景へなじませます。大小・速度・位相の異なる生命の群れと控えめな情報粒子が周囲を漂います。4種類の餌による背景の蓄積は、停止・完走・再起動でも保持します。20系統×8コマ・DNA・段階内成長・条件覚醒は維持し、保存済みの肖像は再生成しません。図鑑と保存肖像は静止します。

## 開発・検証

Node.js 22.12以上（CIは24）。リポジトリ内で実行します。

```sh
cd gas-fizzbuzz-webapp
npm ci
npm run check:assets
npm test
npm start
npm run package:windows
```

画像は `src/assets/creatures/*.png`・`src/assets/food/*.png`・`src/assets/environments/*.png` のローカルファイルです。設定変更時は `npm run build:assets`。画面検証は `src/` をローカルHTTPの8766で配信し `npm run test:browser`。運動検証は `npm run test:motion`。性能・保存遅延の検証は `npm run test:performance`。20系統×4生息地と旧版材質の画像比較は `npm run test:art`。Electron検証は `npm run test:desktop`、パッケージ検証は `node tests/electron-smoke.cjs --exe ./dist/VALIS-Windows-x64/VALIS.exe`。各スモークは専用の一時保存領域を使用します。

## 配置

| パス | 内容 |
|---|---|
| `src/` | 実装に必要なHTML・CSS・JS・ホスト・PNG・画像設定だけ |
| `tests/` | 現行の計算・画像・永続化・画面・起動検証 |
| `tools/` | 画像設定生成、SHA検証付きWindows配布生成 |
| `valis/` | 標準core、A/B/C/D/Eの責務・検証・状態、Project Summary Manifest |
| `design/` | 原モック、派生画像の設計・根元/領域・出典、旧GAS資産 |
| `operations/` | 承認根拠・工程・検証証跡・旧定義の保存 |
| `dist/` | ローカル配布生成物（Git対象外、CIからダウンロード） |

原モックのバイトは保全しています。新規個体は20系統それぞれ8コマの身体素材を持ち、主器官を身体へ一体化しています。DNA・組織成長・皮膚模様・体色・系統ごとの生体運動を反映します。旧ENGINE1/2/3/4と既存の肖像は当時の解釈で保持します。新しい画像は原モックを参考にした派生素材で、原画の切抜きではありません。全FizzBuzzノードは草案です。動作検証と画像品質の利用者受入を区別します。

最終形態は第三形態以降、器官・餌・環境の条件が揃ったときの第四段階です。未達条件の進み具合も表示します。詳しい係数と造形/生態の契約は[ecology-appearance-contract.md](design/docs/ecology-appearance-contract.md)を参照してください。観測・餌・進化履歴・環境を一画面に表示し、図鑑からは上部の「現在の育成に戻る」またはEscで復帰します。
