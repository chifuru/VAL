# VALIS — FizzBuzz生物育成（Windowsデスクトップ版）

Windows 10 / 11 x64向け。入力した数値N（1〜1000）から不変の初期DNAを生成し、FizzBuzzの各出力をエネルギーとして摂取する生物育成アプリです。

## ダウンロード・起動

[確認済み v1.3.2 のWindows配布](https://github.com/chifuru/VAL/actions/runs/38655161064)（または[配布ワークフロー](https://github.com/chifuru/VAL/actions/workflows/valis-windows.yml)の成功した実行）のArtifactsから `VALIS-Windows-x64` をダウンロードします。外側の成果物ZIP、その中の `VALIS-Windows-x64.zip` をすべて展開し、`VALIS.exe` をダブルクリックしてください。DLL・resources・localesも同じフォルダに必要です。Node.js、npm、GAS、インターネット接続は利用時に不要です。

成果物は30日保存。ソースZIPにはElectron実行体を含めません。配布物は署名していません。Windows 10/11の利用者実機での表示・操作の受入は別確認です。

## 育成

- N全体から決まるDNA6軸が、胴・頭・眼・尾・ひれ・付属肢・表皮と器官成長へ作用します。
- Fizzは生命、Buzzは鉱物、FizzBuzzは情報、数字は促進/抑制の調節エネルギー。各出力1行に1回の摂取が対応します。
- 数字入力 →「① 読み込み」でDNA・初期形態・環境を準備 →「② スタート」で育成開始。入力や読み込みだけでは実行しません。第二段階は201回、第三段階は580回、900回以上で素質条件を満たすと独立した第四段階・覚醒（最終形態）へ進みます。Nが小さいと、実際に到達した途中の姿で終了します。
- 環境は数値とFizzBuzzの周期から事前決定され、その実履歴から20系統へ分岐し、獲得した全器官を継承します。系統ごとに4〜6の器官群、計99群（新24群は既存素材を明示再利用）があります。
- 一時停止・再開・速度・最後まで進める・低モーションを使用できます。任意の追加給餌で原FizzBuzz列とは別の成長を増やしません。
- 「図鑑」は育成を最後まで実行した最終結果だけを表示します。未成熟の完走も実際の結果として残し、途中保存や出生前プレビューは掲載しません。同じNでも別実行は別個体。記録の閲覧で現在の育成内容は変わりません。

保存先はElectronのWindowsユーザーデータ領域（通常 `%APPDATA%/VALIS/specimens/history.json`）。実形態・DNA・相履歴・PNG肖像を保存します。保存失敗や破損は画面に表示し、元記録とバックアップを保全します。通常再生中は25行ごと、相遷移・一時停止・完走・通常終了時にも保存します。電源断など通常終了できない場合は最後の保存位置までになります。

系統ごとの遊泳・傘の収縮・翼・触腕・葉・関節の動きと、エネルギー摂取への反応を追加しています（v1.3.2）。低モーションや読み込みプレビュー、図鑑と保存肖像は静止します。静止の姿と成長条件は保持しています。

## 開発・検証

Node.js 22.12以上（CIは24）。リポジトリ内で実行します。

```sh
cd gas-fizzbuzz-webapp
npm ci
npm run check:assets
npm test
npm start
npm run package:windows
```

画像は `src/assets/creatures/*.png` のローカルファイルです。設定変更時は `npm run build:assets`。画面検証は `src/` をローカルHTTPの8766で配信し `npm run test:browser`。運動検証は `npm run test:motion`。Electron検証は `npm run test:desktop`、パッケージ検証は `node tests/electron-smoke.cjs --exe ./dist/VALIS-Windows-x64/VALIS.exe`。各スモークは専用の一時保存領域を使用します。

## 配置

| パス | 内容 |
|---|---|
| `src/` | 実装に必要なHTML・CSS・JS・ホスト・PNG・画像設定だけ |
| `tests/` | 現行の計算・画像・永続化・画面・起動検証 |
| `tools/` | 画像設定生成、SHA検証付きWindows配布生成 |
| `valis/` | 標準core、A/B/C/D/Eの責務・検証・状態、Project Summary Manifest |
| `design/` | 原モック、派生画像の設計・根元/領域・出典、旧GAS資産 |
| `operations/` | 承認根拠・工程・検証証跡・旧定義の保存 |
| `dist/` | ローカル配布生成物（Git対象外、CIからダウンロード） |

原モックのバイトは保全しています。12種の解剖ごとに専用の四段階素材を用意し、植物の花冠・根、節足類の背甲・多脚、鯨の胴・尾などをDNAに沿って変形・接続して表示します。20系統すべてに第四段階へ到達できる入力が存在しますが、到達は900回以降の素質条件によります。旧engine1/2/3の状態と素材は当時の解釈で保持します。v1.3.1の新規個体は系統別の輪郭と主器官の大小、眼窩・付け根の組織色を改善した外見revision2を使います。既存engine4の個体は当時の外見revision1と保存肖像を保持します。現在の器官PNGは原モックを参照した透過派生素材で、原画のそのままの切抜きではありません。全FizzBuzzノードは草案です。動作検証と画像品質の利用者受入を区別します。最終形態は第四段階です。第三段階の完走とは区別します（例: N=900は第三段階、N=927は909回目に第四段階）。観測・餌・進化履歴・環境を一画面で表示し、図鑑からは上部の「現在の育成に戻る」またはEscで復帰します。旧版の個体記録と肖像も保持します。
