# VALIS — FizzBuzz生物育成（Windowsデスクトップ版）

Windows 10 / 11 x64向け。入力N（1〜1000）からDNAと生息環境を定め、FizzBuzzの出力ごとに生物が成長します。

## ダウンロード・起動

[確認済み v1.9.0 のWindows配布](https://github.com/chifuru/VAL/actions/runs/38740083540)のArtifactsから `VALIS-Windows-x64` を取得してください。外側の成果物ZIPと、中の `VALIS-Windows-x64.zip` をすべて展開し、`VALIS.exe` をダブルクリックします。DLL・resources・localesも同じフォルダに必要です。利用時にNode.js・npm・GAS・インターネット接続は不要です。

v1.9.0の配布/実exe起動/次起動図鑑リセットをCIで照合しています。成果物は30日保存。ソースZIPには実行体を含みません。Windows利用者実機での表示・FPS・美術受入は別確認です。

## 操作と図鑑

数字を入力 → **① 読み込み**でDNA・姿・環境を準備 → **② スタート**で育成を始めます。入力や読み込みだけでは実行しません。読み込み/開始中は先に処理中表示を描き、開始/一時停止を図鑑の保存処理から分離しています。「最後まで」は処理を小分けにして進めます。

DNAとFizzBuzz出力は常時表示です。通常0.1秒/行、ゆっくり0.2秒/行、速い0.05秒/行。一時停止・再開ができます。図鑑からは上部の「現在の育成に戻る」またはEscで復帰します。

**図鑑は今回アプリを起動してから閉じるまでの記録です。** 完走した最終結果だけを記録し、次の起動では空になります。同じNを育て直すと別個体です。途中の育成や出生前プレビューは図鑑へ登録しません。旧版のhistory.json・バックアップは読み込み・書き込み・削除しません。

起動時に過去の図鑑を処理せず、育成中の定期保存も行いません。完走時だけ最終肖像1枚と状態をメモリ内へ登録します。図鑑を閉じると画像カードを解放し、開くと30件ずつ、必要な画像から読み込みます。記録処理に失敗した場合は画面に表示します。

## 成長と描写

v1.9.0では4生息地に固有の小生物12種・24姿勢を追加しました。実画像の足元を支点にして呼吸・摂取・成長中の脚の滑りを抑え、粒子も環境ごとの形と滑らかな循環にしています。模様を残す3色の全身反応と20系統の一体身体を保持し、配布物と実exe起動もCIで照合しました。

- DNA6軸が胴・頭・眼・尾・ひれ・付属肢・表皮へ作用し、20系統へ分岐します。系統の主器官と身体は一体の源PNGです。
- Fizz＝生命、Buzz＝鉱物、FizzBuzz＝情報。数字は促進/抑制の調節と背景の変化に使い、生物の発光イベントを起こしません。各出力は元列どおり一回ずつ作用します。
- 生命は緑系の全身発光と収縮・口先、鉱物は琥珀色と重心が沈む動き、情報は青紫とゆっくりした波動です。元の陰影/輪郭を残し、同時反応の光量を制限します。移動する餌を口へ引き込む演出は行いません。
- 実際の進化には緩い伸張、部位レベル上昇には該当部位の小さな拍動を加えます。演出は栄養/分岐/覚醒条件を変更せず、静止肖像へ含めません。
- 第二段階は201回、第三段階は580回。第三形態以降、器官発達・系統別の餌配合・環境適応が揃うと第四段階の最終形態へ覚醒します。Nが小さい場合は到達した途中の姿で終了します。
- 深海/熱圏/情報域/虚空の背景・植生・光と、生命/鉱物/情報/数字の景観が同じ育成中に蓄積します。生命餌は8姿勢と底生/群泳/漂泳の行動を持ちます。

背景・素材は有界キャッシュで再利用し、高倍率の主役Canvasは約200万画素・最大DPR1.5に抑えます。初回の素材準備には短い負荷が残ります。詳しい条件は[描写契約](design/docs/ecology-appearance-contract.md)を参照してください。

## 開発・検証

Node.js 22.12以上（CIは24）。

```sh
cd gas-fizzbuzz-webapp
npm ci
npm run check:assets
npm test
npm start
npm run package:windows
```

`src/` をローカルHTTPの8766で配信して、`npm run test:browser`（観測UI）、`test:motion`（摂取/成長/旧画素）、`test:performance`（描画/完走登録）、`test:art`（20系統×4生息地）、`test:interaction`（実クリック/201件図鑑）、`test:finish`（接地/環境流/仕上げ実画面）を実行します。`npm run test:desktop` は実Electronを2プロセスで起動し、図鑑リセットと旧ファイル不変も検査します。配布実体は `node tests/electron-smoke.cjs --exe ./dist/VALIS-Windows-x64/VALIS.exe` で検査します。

| パス | 内容 |
|---|---|
| `src/` | 実装に必要なHTML・CSS・JS・ホスト・PNG・画像設定 |
| `tests/` | 現行検証と、過去版に限定した回帰用実装 |
| `tools/` | 画像設定生成、SHA照合付きWindows配布生成 |
| `valis/` | 不変core、草案Node、Project Summary Manifest |
| `design/` | 原モック、画像の出典・領域、描写契約 |
| `operations/` | 計画・検証証跡・旧定義 |
| `dist/` | 配布生成物（Git対象外、CIから取得） |

全FizzBuzzノードは草案です。原モック・既存源PNG・旧1..4描画を保全し、旧保存ファイルの肖像を再生成しません。
