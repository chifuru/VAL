# FizzBuzz Creature — レトロピクセル育成ゲーム × GAS

Google Apps Script の HTML サービスを利用した FizzBuzz ウェブアプリです。入力した整数 `N` について `1` から `N` まで計算し、中央にいるレトロゲーム風の生き物が **Fizz / Buzz / FizzBuzz に同期して餌を食べ、段階進化**します。

## 従来の出力形式を維持

サーバー側 `src/Code.gs` の `calculateFizzBuzz(limit)` は変更していません。返却値は従来通りの文字列配列です。画面側 `src/Index.html` は配列の内容を **1行ずつ自動的に** 結果欄へ追記します。完了後の出力は従来と厳密に同じ `lines.join('\n')` です。

```text
1
2
Fizz
4
Buzz
Fizz
...
14
FizzBuzz
```

- 3 の倍数は `Fizz`、5 の倍数は `Buzz`、15 の倍数は `FizzBuzz`、他は数字
- 画面・サーバーで 1〜1000 の安全な整数のみ受け付ける
- 餌や進化の情報、再生位置は **出力テキストには挿入しない**

## 生き物との連動ルール

| 出力 | 餌の種類 | 効果 |
|---|---|---|
| 数字 | なし | 待機アニメーションのみ |
| `Fizz` | 青 | 青い餌が飛来し、食べる |
| `Buzz` | 黄 | 黄色い餌が飛来し、食べる |
| `FizzBuzz` | 紫 | 特別な餌が飛来し、食べる |

餌は種類ごとに **排他的に** 計上します。`FizzBuzz` は Fizz と Buzz の両方には加算しません。

**累積餌数による段階進化**

| 食べた餌の累積数 | 形態 |
|---|---|
| 0〜2個 | LV.0 ちび |
| 3〜6個 | LV.1 こども |
| 7〜14個 | LV.2 おとな |
| 15個以上 | LV.3 レジェンド |

生き物は外部画像や音声の読み込みなしで、Canvas 上のピクセル描画として表示します。画面はレスポンシブです。

## 再生と操作

- **スタート**: GAS で計算後、結果を1行ずつ自動再生します。
- **一時停止 / 再開**: 行の進行を停止・再開します。
- **速度**: 1×、2×、4× を選択できます。
- **スキップ**: 全行をテキストで表示し、最後まで食べた場合と同じ最終形態へ移行します。
- OSで「動きを減らす」が指定されている場合、アニメーションを省いて完成した結果を表示します。

計算ロジックと画面演出を分離しているため、画面の演出を変更してもサーバーの返却形式には影響しません。

## Google Apps Scriptへの導入（未デプロイ）

1. [Google Apps Script](https://script.google.com/) でスタンドアロンプロジェクトを作成します。
2. `src/Code.gs` の全文を `Code.gs` にコピーします。
3. HTML ファイルを「Index」の名前で作成し、`src/Index.html` の全文をコピーします。
4. 必要ならマニフェスト編集を有効にして `src/appsscript.json` の設定を適用します。
5. アクセス権と実行ユーザーを確認した上で、希望する場合に限り **デプロイ → 新しいデプロイ → ウェブアプリ** を行います。

**注意:** GitHub への実装コミットは GAS 上のデプロイではありません。Google Apps Script の本番実行、ブラウザでの通信、公開範囲・権限は未確認です。

## テスト

Node.js 18 以降で以下を実行します。

```sh
npm test
```

`tests/fizzbuzz.test.cjs` は GAS サーバーの計算・doGet をモック環境で検証します。`tests/creature.test.cjs` は画面スクリプトの純粋な計算関数、3種類の餌、進化閾値、1行ずつの出力、一時停止・スキップ・無効入力・低モーション環境の挙動を検証します。GAS 実機の Web App 表示は別途検証が必要です。
