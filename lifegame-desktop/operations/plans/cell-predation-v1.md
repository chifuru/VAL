# CR06：同マスの直接捕食

起点 `9dc3a38`。正本 `design/specification/cell-reorganization-v1.md` の2/7/8/10節、既存食性・量機・P/Q仕様、C/D契約 `design/implementation/cell-reorganization-v1.md` を適用する。FLOW-04/05、既存C7/C7.2/C7.3/C7.5/C8.2、D7/D8/D8.1/D8.2 → E5へ接続。既存責務内で行い、新Node・分割・正式状態/Graph変更・初期登録は行わない。

1. 実際に成立した戦闘の参加者を内部接合用に保持する。描画イベントから生態判断を逆算せず、射程攻撃と所在マスの栄養取得を分ける。
2. 低次動物の捕獲は、そのマスの全小集団から既存食性/食料評価で選ぶ。通常食料と比較し、一捕食者の一度の捕獲で実在1個体を抽出する比較実装とする。複数捕食者の希望は安定hashで調停、実人数以上を抜かない。同系統の主生物や通常植物の捕食行動は追加しない。
3. 小集団の損失は整数人数と実コホートB/自由E/M/身体Mに従う。生存群の栄養・P/Qを複製せず、残った実人数へ保持上限・維持を接続する。
4. 同マスの実撃破者と実捕獲者に限り、倒した身体への当Tの直接取得資格を与える。物理在庫は一つだけ。取得は既存の同マス配分・合計採食上限を共有し、食べ残しは新死骸として次Tへ。一般の新死骸/出生体の即時採食・遠隔栄養取得は許可しない。
5. 摂食経路によるP移行・曝露を実消費割合へ接続。成熟/適合/遺伝/抵抗/成功率・次T定着を維持し、失敗時も残る有限保持者を追えるようにする。死骸経由と直接経由を重複させない。
6. 自律Qの被食も同マス・相IV・開始時に生きていた個体に限定する。既存の有償回避/一度の成功、実E/Bの分配と死亡を使い、当T羽化体を捕食資源にしない。寄生中Qは直接対象にしない。
7. 少数の境界fixtureで人数/E/M、複数同居ID、実攻撃と同時死、同系統/隣接/新生除外、実比率P/Q所有・Q回避、生成元/生成物・Worker/JSON・旧4T/再生を確認する。該当する既存回帰だけを使い、全件・500T・性能/UI/Windows・画像生成・配布は行わない。

Core/A/B本文・採用係数・61Nodeの正式状態/階層/参照・UI/画像・製品4.2.77を維持する。光合成系主生物の共有光、水系専用値/淡水生活、群落移動の対象種/再生枝、観測/設定/表示/保存の開放、CR07代表長期は後続。通常ターン/新方式保存ガードを解除しない。
