# 設定画面：再生成の基準と下層リセット

基点 main 4a1ce12 / app4.2.74。継続確認で見つかった2件を利用者へ先に共有し、既存設定UIの範囲で修正する。FLOW-04→05→08、A1/B5/C8/D9/E6内。新規Node・分割・正式状態変更なし。

問題: 生成後の設定復帰では入力が実効値、内部generationBaseが生成前基準となるため、欄の「基準値」説明が不一致。下層リセットは入力だけを戻し、generationBaseの下層値が残って次回生成に再使用される。

修正: 自動欄へ実際の次回基準を単位付き表示。下層リセット時は該当下層の保持基準だけを破棄し、入力の基準を使う。主生物/地形・個別指定有無・現在世界/記録/供給/優遇は維持。生態計算/readConfig本体/保存形式は変更しない。

D9: 旧mainと現コードを同じ小世界fixtureで照合し、容量40→生成60の説明、リセット20の次回採用、主/地形基準保持、指定/自動往復、下層個別指定保持、分布/情報/年齢割合等の単位、取消時世界保持を限定確認。既存setup-intentの代表35項目を回帰確認。全件/長期/Windows/配布は行わない。証跡はoperations/evidence/setup-basis-v1/README.md。

結果: 旧mainで2件を再現。修正後17項目＋既存設定UI35項目が成功。限定範囲と残る未実測は証跡参照。
