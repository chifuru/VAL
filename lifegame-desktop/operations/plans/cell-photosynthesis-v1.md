# CR06：植物共生体の共有光接続

起点 `76d5f0f`。FLOW-04/05、既存C7/C7.2/C7.4/C8.2、D7/D8/D8.1 → 実測後E5。上位は `design/specification/cell-reorganization-v1.md` 4/10節、既存混合栄養は `ab-system-specification-v1.3.md` 5節、食性はA1.7のA/B v2.5確定差分に従う。新Node・分割・正式状態/Graph・Core/A/Bの変更や初期登録は行わず、既存Manifestへ現在状態を反映する。

## 実行・検証契約

1. `kelp` は主生物のまま、最終所在マスの共有光と有限水分で光合成する。既存の基礎1.5と相係数1/1.1/1.2/1.3、年齢の光係数を一度だけ使う。通常植物の維持・成長・繁殖表へ置換しない。
2. 固有の高さ/葉面積係数は未選定。今回の比較接続は既存受光面積1を使い、専用の高さ優位を付けない基底受光帯0に置く。光の上限・環境倍率はマスの共有予算に従い、旧供給モデルの無料補填を追加しない。専用造形から吸収係数を捏造しない。
3. 光の捕捉と利用を分け、水1/光E2.6を実利用だけに請求する。植物用の温度/pHは光合成利用に限って作用し、採食・主生物の維持へ一律に掛けない。土壌からの新しい直接M吸収は追加せず、既存の有限な動物食/鉱物由来のMを使う。
4. 光と採食は同じE不足を満たす。M不足による必要な採食を妨げず、光だけの二重要求・容量超過分のための水消費を避ける。実光Eを光イベント/当T記録へ一度だけ接続し、既存E1→G1条件と相/年齢の独立を維持する。
5. 新方式の食料要求で植物共生体が植物/菌を食べられる漏れを修正する。候補評価・自動要求・直接要求の入口をそろえ、光合成＋小型動物食と鉱物利用を保持する。通常植物を捕食者にしない。他系統の食性全般は変更しない。
6. 少数の境界fixtureで同マスの光競争、水不足/遮光、相と年齢、移動後の所在、食性、光＋採食の同時予算、光成長、当T出生体除外・二重実行拒否、E/M収支を確認する。生成元/生成物・Worker/JSON、旧4T/再生と公開ガードを必要範囲で確認する。全件・500T・画像/UI/性能/Windows・配布は行わない。

水系の専用値/淡水生活、群落移動の対象種/再生枝、観測/設定/表示/保存と通常ターン公開、CR07代表長期は後続。未選定の水系値を陸上値で埋めない。製品4.2.77と通常ターン/新方式保存ガードを維持する。

## 結果・追加発見

新境界13＋必要回帰64の計77項目が成功。共有光/水、相・年齢、食性、光と採食のE/M需要、実移動先、光成長、利用時点を限定確認。光/採食の2T、生成元/生成物・Worker/JSON、旧4T/再生を照合。証跡は `operations/evidence/cell-photosynthesis-v1/README.md`。

共有光の環境補正が蓄えの不足量にだけ掛かり、受光上限より不足量が大きいと温度/pH低下が光合成量に反映されない場合を追加発見した。実受光量へ環境上限を掛け、半活性/ゼロ活性を確認。採食への同じ補正は追加しない。

生態結果が変わるのは明示された新方式のみ。旧方式には従来の光・採食を維持する。通常ターン/新方式保存の公開、水系値・淡水生活、自然長期循環は未完のまま。
