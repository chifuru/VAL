# CR06：グラフ・記録の単位接続

起点 `5ea17f3`。FLOW-04/05。既存C8/C8.2、D9 → 実測後E6。正本 `design/specification/cell-reorganization-v1.md` 12節、C/D契約6/7節。新Node/分割・Core/A/B・正式61Node/Graphは変更しない。Manifestは既存登録の現在状態を反映する。

## 実行契約

1. `cell-reorganization/1` の観測だけを新しい集計契約へ接続する。旧記録の定義・指標値・CSV/復元結果を変更しない。未知の版・欠測・不整合を旧値や0で埋めない。
2. 生産者/分解者は群落、独立植物/主生物は個体、低次動物は内部人数、P/Qは生存群体を人口単位とする。量機の3枠×3体を9個体として集計。低次動物の群数・各層の占有単位/マス数・定住の枠数/人数・移動人数は別の観測値とする。感染量/卵を生存数へ加算しない。
3. 新定義 `cell-occupancy-observed/1` に、実生物から読む層/種の管理単位数、人口数、B/基部/可食部/E/M/身体M、量機の枠内同居、既知水量/未解決水域数・土壌M・有機物と次T待ちの集計を保持する。毎Tの全ID/全マスのスナップショットは追加しない。旧下層/量機の1マス1群落・3体上限を新記録へ流用しない。
4. 相/年齢/雌雄は実状態へ接続。混合小集団はコホート人数、株の年齢を持たない群落は年齢/雌雄非適用。空間層を分類UI/食性/情報役割へ流用しない。生物量は実Bで一度だけ加算し、人口や枠数から換算しない。
5. 既存3グラフ/構成/ピラミッド/関係図の配置と選択・全期間・表示軽減を維持。必要な新単位だけをメタデータ/CSV/読取専用観測スナップショットに明示し、表示用読み取りで生態世界や乱数を変更しない。
6. 観測スナップショットの新定義を往復させ、既存図鑑の通常保存/新方式進行ガードを維持する。今回の観測復元を、ゲーム全体の図鑑保存・公開完了とは扱わない。

## 最小検証

最大/混合収容の代表マスで人口/群数/枠/層・相/年齢/雌雄・実B・次T待ちを照合。新方式の少数ターンで観測/全期間系列/JSON/CSVを往復し、欠測/不整合拒否と既存行の非破壊を確認。旧量機/下層観測の必要回帰と既存スナップショット/CSVの固定ハッシュを限定確認。Linux画面では各グラフ/対象選択と単位を確認。多数シード/500T/性能/Windowsは実行しない。

実効設定/説明の全経路、ゲーム図鑑保存/再生と公開条件、樹冠/移動対象種/再生枝、CR07は後続。生態ソース/生成物/署名・素材/製品4.2.77は変更しない。
