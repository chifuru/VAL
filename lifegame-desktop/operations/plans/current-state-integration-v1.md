# CS07：Worker・観測・画面・保存への全接続

起点34b6f57。標準配置Operation→Summary→Flow、current-state/1の9節、CS02〜06と現行Worker/観測/図鑑を読む。既存責務内のFLOW-05で段階接合する。新Node・分割・正式状態変更は不要。

## 今回の実行契約：CS07前半

- 目的：現在の型参照/場所情報/資源状態をWorkerで正しく受け渡し、全Tのネイティブ観測と新しい記録形式を保存・初期条件再生へ接続する。
- 前提：現在状態の集約は内部比較として接続済み。C7が確定/Worker、C8が観測、C8.2が保存境界、D7/D9が接合確認、E5/E6が実測を担当する。
- 作成：新しい場所情報の識別キー、現在状態の差分メタ転送、新形式の最終状態/全T観測の図鑑記録と検証、必要なtests/証跡。
- 維持：主生物/宿主内P/Qの実ID、有限量/現在時計、全T観測、確定と途中表示の分離、停止/再開と取消、旧記録の原bytes。旧結果との同値を新規則に登録しない。
- 新保存：実効初期条件・生態署名・最終の現在状態/必要な代表例・全Tの集計を保持する。毎Tの世界スナップショットを蓄積しない。結果の読取では計算を進めず、再計算は初期条件からのみ。同じ署名に対応しない再計算を明示的に拒否する。再生だけで保存せず、再保存は新IDとする。
- 転送：同じマスの異なる局所情報を識別する。固定地形/設定を毎フレーム送らず、現在状態の大きな配列・オブジェクトも変更分を扱う。新方式と従来方式の境界を保つ。
- 変更しないもの：Core/A/B Node、61Nodeの草案/階層/層間参照、画像/UI配置・既定モード・製品4.2.77/配布。新形式を旧図鑑形式へ偽装しない。
- 検査：同マス情報の共存/差分更新、3段階/一括/最終のみWorker、確定状態/取消・再開、保存/読取/初期条件再生・再保存・版違い/破損拒否、従来の記録/原bytes。
- 作業結果照合後に既存Node/E/Manifestを同期しmainへ統合する。自然500T/総合性能/Windowsを今回の成功へ含めない。

## 後半への接続

新形式を既存3グラフ/サマリ・手動個体詳細・資源/残骸表示へ投影し、明示のマス方式で新規作成から通常画面を接続する。CSV/結果図鑑の画面参照と説明を揃え、必要な画面確認を行う。画面構成/素材の再設計や既定モードの無断変更はしない。前半だけの成功でCS07全完了とは報告しない。
