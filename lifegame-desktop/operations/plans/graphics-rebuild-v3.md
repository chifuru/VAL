# グラフィック全面置換 / app 3.0

## 前提フィードバック・FLOW接続

利用者の「各種モックに徹底的に近づける。既存グラフィックは全廃可」を入力とする。project-local core のOperation（出力前ゲート・Manifest反映）、Summary（構造要約）、Flow（FLOW-04）を実読。採用資料は `design/specification/ab-visual-reference-v1.md` から画面v4・素材v1・分岐v1・特殊生物v5へ接続する。

FLOW-04を既存 B5.3 → C8/C8.1 → D9 → E6 の内側で適用する。責務・ノード分割・正式状態・生態計算を変更しない。新しい系統や植物の数値仕様は追加しない。FLOW-08相当の実測をE6に記録し、現在のManifest該当構造へ反映、出力前ゲートで実体と照合する。今回の契約の終了は、描画置換・Linuxの機能検査・実画面撮影・現在Manifest・main統合であり、利用者による見た目の承認やWindows実機合格を代行しない。

## 実装単位と受入

- 投影：回転した斜め俯瞰、実地形に由来する浅い起伏、共有頂点と逆選択。高低は表示専用で保存・通行条件を増やさない。
- 地表：実タイルから連続材質を生成し、起伏へ貼る。遠景のキャッシュと近景の画面解像度キャッシュを使う。水際の曲線化は描画補間で、実セル中心と地形判定は保持する。
- 地物：実際の茂み・岩塊・倒木・壁から立像を配置。低い花草と水際の泡は装飾で、餌・資源・障害物を新設しない。遠景では装飾を岩などの意味記号に変換しない。
- 生物：全21主系統83相、餌6系統12枠、P/Q3系統9枠の専用新作画へ置換。日輪と浮遊傘はIIIの3枝・IVの6枝を専用画へ接続。他系統の全18枝専用原画は今回の対象に含めない。
- 差分：相と年齢は独立、幼体の付属器比率・老齢の表面、雄の長い外形・雌の広い胴を表示変換する。P/Qの3造形は生活環を増やさない表示対応で、自由遊泳する新個体として盤面に置かない。
- 描画順：地表→資源→奥行き順の生物/地物→選択。前景が個体に重なる場合の地物透過。主/餌をセル内でずらし、P/Qは宿主バッジ、詳細は選択欄へ接続。
- 動き：確定した移動の補間、攻撃の傾き、採食の収縮と作用粒、成長/防衛等の短い作用。生態から切り離した架空の採食・攻撃は発生させない。補間は最大128ID、一体4件。遠景の生物を間引かない。
- 画面：近景240px/セル、上限480px。開始時は観察表示へ移り、設定を戻せる。操作バーを盤面上へ配置。図鑑の再生条件・記録抑制は維持する。

D9：投影単体検査、全素材SHA/領域、全30種と全83主相、代表分岐、実際のポインタ選択、全個体位置、重複/P/Q、年齢、図鑑再生、画面例外を検査。静止画は通常配置と明示的な作画比較配置を分ける。機能検査の成功をモックとの完全一致と呼ばない。
