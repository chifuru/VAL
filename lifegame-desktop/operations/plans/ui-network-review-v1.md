## 反映と照合

1. Aの意味定義、Bの機能要件・後続フラグを更新する。
2. 詳細仕様とモックの参照を各Nodeへ接続する。模式画像の誤記/誤接続は仕様本文を優先する。
3. Manifestへ現在の適用状態・正本参照・未実装・次FLOWを必要最小限で反映する。履歴を追加しない。
4. NodeのID/状態/親/参照、ファイル実在、Manifestとの対応、上1/下4、50T指標と100T図の区別、P/QのB欠測、最大軽減の非記号化を文書照合する。
5. Git差分で許可範囲だけの変更と確認する。ゲーム動作/性能/Windowsを新規検証済みとは報告しない。
6. 利用者の継続指示に従いmainへ反映する。競合や他者差分は破棄しない。
