# CS05：環境感染量・共有遺伝型・微小残留の終了

起点c373ceb。標準配置Operation→Summary→Flow、current-state/1の7節と現行P/Q・卵・土壌・情報を入力とし、FLOW-05で既存責務へ接合する。

## 実行契約

- 目的：環境中で感染の挙動が同じものを現在量へ集約し、長い遺伝定義と由来連結IDの反復保持を減らす。抵抗の丸め端数の永久存続を終える。
- 前提：現在状態への集約と旧結果との差は許可済み。C7/C7.1/C7.5・C8.2、D7/D8.2/D9、E5/E6内の更新で、新Node/分割/正式状態変更は不要。
- 作成：current-infectionsの補助処理、同条件量の集約/参照型/解放・短い実ID、卵付着時の実量分割、微小抵抗の終了、必要なtestsと証跡。
- 保持：マス・寄生系統・遺伝適応・経路・成熟/生活段階・期限・必要な直接親/宿主参照。侵入/付着済み、実P/Qと一匹移行の状態は無差別に混ぜない。通常の寿命・初期量・宿主適合/侵入失敗/定着翌T・Q感染窓/羽化と有限収支を維持する。
- 境界：確定した世界は遺伝型参照と量を保持する。既存の感染処理中だけ必要な型を展開し、確定前に再集約/未参照型を解放する。異なる期限の合算や延命はしない。
- 卵：同条件の自由卵を量で保持する。付着は実量だけを取り出して宿主別の状態へ移す。移動/拡散でも量を複製しない。量に応じた分割は本接合の明示的な集約規則であり、旧一レコード一卵の結果一致を要求しない。
- 抵抗：既存の半減/費用を保ち、新方式だけ未丸め現在量を減衰させ、0.000001以下で失活する。CS02のQ残留30T/半減10Tも確認し、過去Q列を復活させない。
- 変更しないもの：Core/A/B Node、61Nodeの草案/階層/層間参照、画像・UI配置・既定モード・製品4.2.77・配布。新方式は内部比較のみ。通常画面/Worker/図鑑全接合はCS07。
- 検証：同条件多数→量在庫/型共有・期限/遺伝/親/宿主/移行の分離、参照型解放、実量/収支、自由卵→付着→侵入→定着の成功/失敗・水域分散、微小抵抗終了・Q残留期限、短期生成元/生成物/取消と既存経路の最小比較。
- 作業結果照合：検査後のみE/Manifestを同期しmainへ統合する。自然500T/総合性能/新画面/Windowsの成功を報告しない。次はCS06の更新対象と時間処理。
