# 期限優先の観察版への接続

利用者の最新指示、A/B observation-first-v2.8、producer-pyramid-v2.7、producer-support-v2.7実測を入力とする。既存A/B/C/D/E責務を用いる。新Node分割/承認状態変更なし。R1〜R6を消去せず、暫定R0と分ける。

直近の完了単位は、生産者供給の私有実装/2004状態/境界検査の証跡確定、最新A/BとManifestの反映。製品への接続にはC7群（3枠/環境供給/収支/出生・寄生）、既存C8群（状態転送/描画/選択）、既存C4（Windows接続）の既存分割を使う。コード変更前に該当NodeとD計画を読み直す。

製品接続時は供給ヘルパーを既存のNode/browser両方で利用できる形式へ移し、private source transformationに依存しない本体を作る。Workerと3段階turnの全状態転送、追加world項目、選択/同マスの3枠、外部入力台帳/世代/環境発生、保存署名と記録を同時に整合させる。旧データは保持し、旧署名の記録を新生態の再生として実行しない。旧比較ツールが旧source hashを拒否する場合は旧証跡を書き換えず、新製品用の基準を別に作る。

初期量・資源量は既定条件と手動調整を分け、合法枠/初期源/実際の配置量を検査。設定/マップ再生成/取消・再試行/観察/終了/初期画面への遷移を確認する。通常ポップアップへ戻さない。

画面調整は遠景記号と採用済み近景画を維持。近景主生物の周囲枠を可読性の手段にせず、接地影/明度・彩度・環境光と背景の立体感を代表実画面で比較する。全体UI再設計、新規の生物画一式、空中層分離を先に作らない。表現確認後に細かなバランスを行う。

R0確認: 既定湖で500T/出生と次世代/生産者供給/採食・競争・遺体利用を確認し、少なくとも消費者の一系統が残る。データと残差/同枠重複、操作/再生成、表示・保存再生の不整合は許容しない。各設定の実測範囲と高次寄生等の未達を明示し、全系統存続率や全特殊生活環の完成へ拡大解釈しない。実行環境別の未確認も残す。

自由モードへの追加接続契約:
- 供給方式を地形/配置モードから分離し、自由モードでも初期設定で有無を選択する。新規の観察用既定値は供給あり、旧記録は当時の条件を保持する。表示/Worker/設定保存/再生で同じ設定を渡す。
- 下層の生産・世代更新の余力を優先して確保する。自由条件の水游虫途絶を、供給不足・採食・繁殖資格・出生先・被食の診断へ分ける。一律倍率の増大や動物補充を先に実装しない。
- 湖と自由の供給あり/なしを比較し、手動設定・旧記録互換・上限と速度を検査する。追加の長期試験/製品変更は未実施。既存C/Dの責務内で接続し新Nodeは追加しない。
