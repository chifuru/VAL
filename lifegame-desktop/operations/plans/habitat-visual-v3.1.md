# 背景景観の再制作 / 3.1

利用者は生物造形を維持し、背景を採用モックへ徹底的に近づけることを指示。見た目を最優先の受入条件にする。coreのOperation（出力前ゲート/Manifest）、Summary（構造要約）、Flow（FLOW-04）を実読し、C8.1の既存描画責務内で修正する。新ノード・正式状態変更・新生態条件は作らない。

前提フィードバック：3.0は色とノイズの地表、均一な水面、孤立した地物と楕円影に留まり、採用モックの詳細な川床/波/苔/落葉/岸辺/光を再現できていない。機能検査の成功でこの不足を解消済みにしない。

FLOW-04実行契約：B5.3を満たすC8.1の地表・水面・景観合成を置換。素材はdesign/visual-alignment-v4/near.pngとdesign/asset-mock-v1/01-terrain.pngを主参照として専用制作する。地形分類/被覆/壁/セル座標は維持。生物・生態・保存を変更しない。D9で視覚比較と機能を分け、E6へ実画面と対象SHAを記録、現在Manifestへ反映し、出力前ゲート後にmainへ統合する。

受入：近景の地面は描き込んだ素材を十分な解像度で合成する。水面に川床/反射/細かな波と深浅差、岸に砂礫/苔/根の連続感を出す。岩/植生は景観の層として接地し、浮く楕円台座・泡の影・広範囲の幽霊状透過をやめる。遠景は全位置の記号を残しながら自然な地勢を示す。生物の可視性・選択と同一状態を維持する。採用モックとの比較画像を作り、実際の近景を見て修正する。

検査：素材の実読/領域/SHA、視野に応じた高解像度、実際の固定地形との対応、全個体/資源の描画対象、選択と生態不変、地物遮蔽、キャッシュ/大盤面の負荷。通常配置と比較配置を明示し、静止図を生態成績やWindows実機の証拠にしない。
