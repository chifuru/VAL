- 目的：明示のマス方式で、新規作成→観測→既存3グラフ/サマリ→手動詳細→形式4保存/読取/初期条件再生まで接続する。

- グラフ：個体数/相・雌雄・年齢/実作用の全期間と現在サマリを維持する。栄養段階4成分＋不明と食性上の5分類を混同しない。食性別Bは観測側の直近50Tの系統別実同化構成で配分し、未観測を補完しない。関係面は実作用と現存する付随関係の意味を分ける。

- 記録：形式4の結果を既存図鑑画面へ接続。再生だけでは保存せず、再保存は新ID。CSVはWorker/代替経路とも同じ原値を分割出力する。旧記録にない値は推定しない。
