# I04 量機の実行契約

基準main `04b7bf6`、開発版4.2.35から4.2.36へ進む。利用者の継続指示と[実装12単位](implementation-sequence-v1.md)のI04に基づく。主FLOWはFLOW-05、限定検証の記録はFLOW-08。プロジェクト内のOperationを先行制御とし、実行契約/分割判断/Manifest保持範囲と関連仕様・C/D/Eを実読する。

## 採用と比較値

正本は `ryouki/3`、通常I/II・相変異2区分と採用された通常III三枝/IV六枝。未採用の旧9区画や筒状案を使用しない。新案を作らず、採用原画と透過編集による実行素材を区別する。

攻撃0.45/防御0.60/最大HP0.80の標準主生物比は利用者採用済みの比較開始値。その他は `implementation-start/2` 第2節を今回の版付き比較値に選ぶ。寿命180、成体I実効維持0.48E/T、歩行基準0.39E/歩、感知1/2/3/4、採食上限2B/変異2.4B、繁殖待機8T、母18E/.75M＋父6E/.25M→子16E+B6/M1＋散逸2E。比較値を最適値や個別承認済み値にしない。

## 対応する構造と変更範囲

既存C7/C7.1〜C7.5、C8/C8.1/C8.2、D7/D8/D8.1/D8.2/D9、E5/E6に、状態/索引、行動/競合、成長/出生、寄生の対象ID境界、観察/素材/保存、計画/証跡を接続する。既存の責務・実装単位・検証観点を利用し、新Node/分割/初期登録は不要。全Nodeの正式状態/階層/層間参照、A/B採否、coreを変更せず、Project Summary Manifestの現在要約を反映する。

- `ryoukiModel:'ryouki/1'` と `ryouki-parameters/1` を明示して有効化する。旧D.species31/D.main21と独立植物3は保持し、D.ryoukiを別登録。世界別activeSpecies/activeMainだけへ追加する。旧31/I03の34を無断で32/35へ変換しない。
- 初期配置は既存の主総数/系統選択/重み配分を利用する。新しい量機専用初期数や主全体の直接個体数UIは作らない。選択除外/対応可能な重み0は初期だけの指定で、開始後の合法出生を永久禁止しない。量機を入れるために他の手動指定を無断で減らさない。
- `o.ryouki.version='ryouki-state/1'` に相変異・高低密度カウンタ・有限窓/最近セルを保持し、相/枝/年齢/ID/Gとは分ける。新モデルでは年齢成熟を有効な版で保存する。
- ターン開始時の同セル＋近傍8セルにいる同系統他個体6以上を3T継続で変異。2以下を6T継続し自セルが本人だけなら解除。中間密度では状態を保ち、各継続条件を外れたカウンタを0へ戻す。同居中は解除待ちとし、強制移動/死亡/個体消失で空きを作らない。
- 新モデルだけ `mainByCell` と共通 `mainAt(m,cell)` / `mainRoom(w,o,cell,m)` を接続する。代表mainとbyIdを残し、変異量機同士だけ最大3、通常/他系統は1。移動は各歩の通行/実費/残容量を予約し、途中で止まった場合は実歩だけ確定する。通常1/2/3/4、変異全相3。占有・壁・不通セルを飛び越えず、実pathから描画する。
- 草本/苔等の有限可食部と小型一次消費者を利用する。移動歩数で攻撃/採食機会を増やさず、光合成/情報栄養/無償補充を追加しない。全同居者の食事在庫は共通で、一体分を複製しない。弱い攻防と年齢/相の共通成長は各一回適用する。
- 繁殖は両親の年齢成熟/本人最大HP70%/待機、母30E/.75M・父12E/.25M以上の資格と実費/合法な通常空セルを通す。子はI/年齢0/G0/通常型。相変異4の準備候補評価1.5倍は繁殖率/出生数/待機倍率にしない。
- 経験20/60/140、IIIの保持M2/IV4。実維持・吸収・合法移動だけから最大2/T。分岐32T窓、最近16Tの通過セル最大64件。III探索/周辺/踏破とIV各二枝は実績条件を通し、不足ならIIIで待つ。高位能力がなければ達成不能な循環条件を作らない。
- 攻撃/捕食/清掃/寄生/P→Qは実対象IDへ接続。P新生活環/遺伝/宿主表そのものはI05へ残す。同居死亡の死骸/栄養/PQを同セルという理由でまとめて消さない。
- 横詳細・系統樹・全ターン観測/CSV・Worker・図鑑/再生へ、通常/変異と実個体数/占有セル数を渡す。`ryouki-observed/1` は全確定T必須で欠測/未知版を0補完しない。旧署名で新量機を再生しない。
- 通常11＋相変異早期1/IV1の13形態。近景の既存絵柄/遠景記号を保ち、新量機の専用記号と同居者の個別アンカー/ヒット/追跡を追加する。透過編集/静的pack/原図crop/hashを記録し、実行中の背景除去や囲みカードを追加しない。全方向/全年齢/最終発光縁等はI10へ分ける。

## 検証と完了条件

1. 新flag/旧記録、主選択/初期分配/同居容量・開始時同時判定・解除待ちを確認する。
2. 全相の歩数/各歩実費/部分確定/同時競合、有限採食/攻防/ID別作用/複数死骸、成熟出生/実績分岐/有限窓を検査する。
3. 旧無指定/I02/I03は基準mainと世界/指紋/CSVを照合し、新規則は静的/動的の8優遇設定と実Worker・保存再生で照合する。
4. 固定条件の世代更新/相変異・同居・成長/実捕食を観測し、必要な実画面で原画対応/遠近/同居選択/詳細/グラフ/再生を確認する。未達を隠さず、500T/R1〜R6・全端末性能/新Windows配布まで認定しない。
5. C/D/E・Manifest・実体・証跡を照合し、出力前ゲートを通してmainへ統合する。次はI05「一次寄生P」。意味/系統数/可逆性/新Node分割等の変更が必要な場合だけ具体案を確認する。
