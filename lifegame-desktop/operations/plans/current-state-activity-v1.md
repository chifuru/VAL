# CS06：更新対象と時間処理

起点0f7d320。Operation→Summary→Flow、current-state/1の8節と、現行の水分/養分/土壌/時計を読み、FLOW-05で既存責務へ接合する。

## 実行契約

- 目的：全盤面の反復更新を、変化する水分・正の養分入力・実在する土壌在庫・実際に空きが生じた還元先へ絞る。
- 前提：CS01〜05は採用/内部比較接続済み。既存C7/C7.1/C7.2/C8.2、D7/D8/D9、E5/E6内の更新。新Node/分割/正式状態変更は不要。
- 水分：固定条件の一段更新と各フローを維持。非平衡マスは生物がいなくても処理し、平衡マスは固定フローを合計値で保持する。実消費で再開する。配列の現在値は常に確定Tと一致し、参照による時刻進行を作らない。
- 養分：正の固定入力を持つマスだけ更新する。保持待ちは実際の取り出し/空き/有効な流入で再試行し、満杯のまま毎T同じ試行をしない。有限量・次T還元・外部入力の台帳を維持する。
- 背景：有機物をマスごとに扱い、乾燥/静的な不適環境では在庫を処理しない。水分の回復で再開する。腐敗負荷は現在/直前の該当マスだけ更新し、消失した場所を0へ戻す。
- 時計：更新対象は現在の在庫/変更状態から管理する。生物の移動/出生/消失や情報/卵の期限は既存の現在状態処理を継続し、空マスであることだけを理由に残存対象を凍結しない。新しい気候変化・時間飛ばしは導入しない。
- 作成：current-activity補助処理、必要な書込通知と現行処理への接続、対象範囲/フロー/有限量/取消/短期同期のtests・証跡。
- 維持：Core/A/B Node、61Nodeの草案/階層/層間参照、UI/画像/既定モード・製品4.2.77/配布。新方式は明示current-state/1の内部比較のみ。通常画面/Worker/図鑑全接合はCS07。
- 確認：密な基準計算との水分/フロー照合、平衡→消費→再開、空所の雨/後進入、正の養分入力/次T還元、満杯待機/新しい空き、乾燥→湿潤、腐敗負荷消失、生成元/生成物・取消、従来経路の短期比較。自然500T/総合速度は対象外。
- 結果照合後にE/Manifestを同期してmainへ統合する。次はCS07のWorker/画面/保存への全接続。
