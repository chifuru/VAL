# 地形・開始設定・再生の実装契約 v2.4

利用者の「進めてください」を、決定稿の第1項（開始条件・地形）から実装する指示として受領。project-local Operation→Summary→Flowの関連節とA1.2/B5/B5.4/C7.1/C8/C8.2/D7/D8/D9、現行コードを照合し、FLOW-04/05/07/08へ接続する。既存責務内で吸収し、新規Node分割・正式状態変更は行わない。

製品を2.4.0へ更新し、蛇行河川・湖沼・湿地・岩地・疎林平原・盆地を事前データ化する。40×28、80×56、160×112のセルデータを制作時にそれぞれ確定し、実行時に引き延ばさない。作者用ツールは静的な輪郭・地形場をセルへ書き出すためのもので、実行時の全域ランダム地形生成には使わない。36地形への増量は今回行わない。

開始時の変動は事前の候補セルと有限パターン（空き・茂み・倒木・岩塊）だけ。主要陸路・水路をデータで宣言し、確定後に通行と水域連続を照合する。不成立の候補は安全な基底配置へ戻し、UIと保存条件へ明示する。基底も不成立なら停止。宣言外の孤立域や全環境の均等配置を矯正せず、生存救済をしない。

地形用初期値はマップのおまかせ選択と候補配置、生態用初期値は初期個体・資源と生態計算に使う。空欄の地形初期値は読み込み時の生態初期値を引き継ぐ。確定後は両方を表示/保存し、地形名・版・寸法・指紋を表示する。編集中のフォームは読み込みまで世界へ反映しない。

最終保存のconfigへ集合版・解決済みID/版・寸法・データ指紋・候補列・既定配置利用・初期地形指紋を含める。再生は保存されたIDから同じ版を復元し、指紋不一致を拒否する。旧計算の記録は上書きせず、計算版不一致として再生拒否する。再生終了/中断/反復は記録しない条件を維持する。

変更対象は世界初期化、地形データ/ローダー、設定UI、記録再生、計算指紋、検査・証跡・関連Node/Manifest。生物カタログ、採食・戦闘・繁殖・寄生の係数、採用造形の実装用画像は変更しない。旧試作のソース差替え位置だけを新しい世界初期化の境界へ合わせ、その試作ルールを製品へ採用しない。

検査は6地形×3寸法の主要接続、二つの初期値の独立、候補以外の不変、既定配置/停止、版・指紋・寸法の拒否、再生の終端一致/非記録、既存単体、実ブラウザのフォーム/6地形/拡大/狭い表示/外部通信を対象とする。E5は世界条件の新しい検査範囲、E6はLinuxの実画面、E7はWindows実exeを分ける。新地形の長期生存率をこの検査の合格へ含めない。

証跡の入口はoperations/evidence/map-ui-v2.4/README.md。対象ソースと実行環境を固定し、古いEの成功を新コードへ無条件に流用しない。出力前に実体・Node・Manifest・検査・未達を照合してmainへ統合する。全体のUI/バランス完成、年齢能力、新植物、採用生物の描画接続は後続作業として残す。
