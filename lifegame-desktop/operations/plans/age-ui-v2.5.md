# 年齢・能力・観測UIの実装契約 v2.5

利用者の継続指示に従い、決定稿v1.7/v1.8の年齢部分を既存責務内で接続する。project-localのOperation（出力前ゲート・Manifest）、Summary（記述規則）、Flow（修正フロー）を読み込み、FLOW-04/05/07/08へ接続する。新規ノード・責務分割・正式状態変更は行わない。第零次前提・Identity Kernel・前提フィードバックを維持し、範囲を超える造形や長期生存率を成功としない。

出生時の第一相基準寿命L0を固定し、幼体/成体/老齢を進化相とは独立して判定する。通常の成熟はceil(.10 L0)、早成はceil(.03 L0)、餌生物は既定maturity、老齢はmax(成熟+1,floor(.75 L0))。寿命そのものの進化相補正は従来どおりで、年齢境界だけをL0へ固定する。P/Qは個体の年齢ではなくコロニー生活環を維持する。

開始時の年齢能力を攻防・移動消費・維持・回復・光入力・繁殖資格/出生後待機へ接合する。射程・感知・移動歩数は変えない。幼体は第三相でも繁殖できず、老齢は他の資格が揃えば可能。成熟時の最大HP増加で回復せず、老齢時の上限低下は戦闘損害/経験に数えない。確定した出生期限は年齢変化や第四相到達で再計算しない。二親の有限費用・出生I相/年齢0/幼体を維持する。

新規UI世界はconfig.ageModel="life/1"を明示する。エンジンの無指定は旧比較モデルを維持する。旧記録は新しい計算指紋と一致せず再生拒否し、変換や上書きをしない。新記録は年齢モデルを含むconfigから再計算し、再記録しない。

描画は既存アトラスから幼体の丸い比率、老齢の表面の筋を作り、遠近両方へ年齢の印を重ねる初期接続。個体欄に出生L0・境界・年齢補正・実効値を表示し、ゲーム内で二軸を説明する。餌生物の年齢は印と能力表示へ接続するが、専用の年齢体形素材は未制作。採用した新造形、雌雄の全面接続、独立四相植物、背景仕上げの完成は今回含めない。

対応はA1.1/A1.3/A1.6→B4/B4.1/B4.3/B4.4およびB5.2/B5.3→C7系列/C8系列→D7/D8/D8.1/D9→E5/E6。既存仕様を変更せず実装状態のみ更新する。検査は全年齢×全相、境界、早成、出生・待機、有限光/回復、複数自然初期値の短期再現性、実画面・観測独立・保存再生。自然試行と表示用fixtureを区別し、長期300〜500の存続率・Windows実exeは別検証とする。
