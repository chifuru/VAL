# I01 共通基盤の実行契約

対象main `e8488a4`、基準製品4.2.32。利用者の実装着手指示により、実装12単位のI01を進める。Operationを先行制御としてプロジェクト内3coreの実行契約/分割/Manifest保持範囲を実読する。主FLOWはFLOW-05、必要な修正・検証計画・証跡記録を同じ作業単位へ含める。

## 範囲

- 読む：現行A/B索引、実装順/最適化調査、C7/C7.1/C8、D7/D9、E5/E6、関連src/testsと比較モデルの生成経路。
- 実装：engineが指定する同期区間内だけの共有索引。通常のS.mapsは従来の新規構築を維持し、移動/採食削除/死亡/出生/供給の境界を跨ぐ古い索引を使わない。共有区間はfinallyで解除し、公開worldや保存へ索引を入れない。
- 実装：Worker受信のepoch/連続turn/段階順/要求数/予約込み6件上限を検査し、異常通知を確定状態へ適用しない。既存の途中取消→確定worldで再initを維持する。appの画面構成/生態規則/保存形式は変更しない。
- 接続契約：ID/セル/分類の所在と所有権、将来の同居予約、経験/由来/Q痕跡/変更記録の追加口を明示する。新生態の空フィールドを全個体へ先に増設せず、量機/植物/PQ/情報の実働はI02以降へ分ける。
- 更新：必要なsrc/tests、静的生成物、C7/C7.1/C8・D7/D9・E5/E6、Project Summary Manifestの短い現在要約、実装順の現在位置、版付き検証証跡。
- 版：開発版4.2.33として識別し、最新配布済みWindows版4.2.32とは分ける。生態ソースの再生成で署名が変わるためreplay-versionを更新し、旧版との同値を確認した署名だけを明示互換にする。必要なarchive/C8.2・関連検査を含め、全ての未知署名を許可しない。新Windows配布は今回行わない。
- 変更しない：A/Bの意味・採否、3core、画像/絵柄、Node正式状態・親子/層間関係。新Node/分割は不要。既存構造内の索引/同期制御/検査/証跡責務で吸収し、Manifest初期登録なし・参照/実装/検査要約のManifest反映あり。

## 確認と完了条件

1. 共有外のMap独立性、共有内の再利用、例外/区間終了時の破棄、移動・採食除去・死亡・出生・供給後の新しい所在を確認する。
2. 旧規則・全8優遇条件で共有ON/OFFの世界/指紋/観測/CSVと有限収支を照合する。通常/比較/Workerで生成物が一致することを確認する。
3. 現epochの非連続/重複turn、欠損/重複/逆順phase、要求外通知、6件上限、旧epoch無視、途中停止からの再初期化を確認する。
4. 関連単体検査から全単体検査へ進み、実ブラウザの段階表示・停止再開/選択の必要範囲を検査する。必要な失敗反例を残し、未測定の速度向上・新生態・Windows起動を合格扱いしない。
5. 対象/環境/実行結果/未達と生成元の版を証跡へ保存し、C/D/E/Manifestと実体を照合してmainへ統合する。次はI02。

現在の計数・相/年齢・同居の意味は現行A/Bを正とする。将来の新しい状態/定義版は各実装単位で保存/転送まで接続し、I01だけで量機の実働や新保存スキーマの完成を認定しない。

## 状態・更新口の接続契約

- 公開/保存するworldは独立した確定状態。索引スコープ、Workerのepoch/予約/次受信T、変更比較器の私有コピーはworldへ直列化しない。Workerの先行worldを停止後の確定worldとして流用しない。
- 所在は実在する`organisms[].id/cell/slot`を正とする。今回の`main/food/prey`の代表Mapは従来の意味を維持し、`byId`は同セルでも全独立IDを保持する。I04の複数占有は、同セルID集合と予約容量を実装時に接続し、代表Mapの値を個体融合に読み替えない。
- 同期スコープの開始/終了が今回の索引更新口。移動/採食削除/死亡/出生/資源供給を跨いでキャッシュを持ち越さない。全面的なdirty追跡は今回の完成範囲にせず、後続の状態更新口で必要な領域へ追加する。既存の完全差分比較器は維持する。
- 本人経験/由来/場所/元経験時刻/Q痕跡は各機能の成立イベントから記録する。個体ID・情報由来ID・寄生群体IDを混同せず、表示/保存は同じ確定レコードを参照する。新しい未使用の空配列を全個体へ先に追加せず、I02〜I07の状態版で導入する。
- 状態/計算/保存の版は既存の`config`・観測定義・再生署名を入口とする。I01では既存形式を保持し、署名と検証対象ソースを対応させる。後続の新生態の版は旧記録の暗黙変換に使わない。
