# CS08：現在状態の肥大化・性能を限定確認

起点6349562。標準配置のOperation→Summary→Flow、current-state/1、CS07の接合と既存D7/D8/D9・E5/E6を読む。FLOW-05で既存責務内の検査/実測参照を追記し、新規Nodeや正式状態・階層・層間参照は変えない。

- 目的：死骸に限らず、情報・感染・土壌・要求・世界複製・全T観測・転送・描画を初期/進行後で測る。
- 代表1条件：既存の実フォーム由来の小40×28/河川/84体/多層/淡水比較へcurrent-state/1を明示。旧500T世界は新仕様の終盤へ流用しない。自然進行は最大500T、初回は壁時計4分を上限にして到達範囲を明示する。停止・例外も結果とする。条件総当たり/生存率再認定はしない。
- 計算：ターン開始/3段階/情報/共有要求・配分/土壌/生体進行、現在状態の規模と全T観測appendを別々に記録する。内包時間は加算しない。先頭のJIT/冷キャッシュと暖機後を混同しない。
- 状態：本人発信/受信/加算分、旧履歴の不在、場所情報、残骸の有限在庫、感染の型/担体、現在の活動対象を把握する。全T観測は生態の世界と分け、必要な記録の増加を生態の無制限肥大化と呼ばない。
- 転送：代表境界の実3段階をencode/clone/applyし、復元世界と原世界を照合する。転送JSON量はJSヒープや実ブラウザの通信時間ではない。
- 画面：保持した新方式の初期/到達世界を同じrenderer/寸法で読む。遠景/近景の暖機描画と初回準備を分け、既存画面構成/素材/遠景記号を保つ。長期グラフは保持した全T行を使い、データのない過去を捏造しない。
- 問題：新しい不具合が見つかった場合は先に利用者へ伝え、原因が明確なものへ修正範囲を絞る。生態ルールやバランス・マップ可視化の追加は行わない。
- 終了：計測範囲/結果/残件をE5/E6・Manifestへ反映し、mainへ統合する。性能の万能保証・全条件/Windows/配布の完了とはしない。
