# CR06：水域の有限資源と下層生活の接続

起点 `294d1b6`。FLOW-04/05、既存C7/C7.1/C7.2/C8.2、D7/D8 → 実測後E5。正本 `design/specification/cell-reorganization-v1.md` 3/4/9/10/13.3節と、既存の生産者/小集団/分解者を適用する。13.3節が委ねる実装上の数値比較として専用プロファイルを明示する。A/Bの採用値・意味・正式状態/Graph・Coreを変更しない。新Node・分割・初期登録は不要、既存Node/Manifestへ現在状態を反映する。

## 専用の比較設定

`cellSettings.aquaticProfile: freshwater-comparison/1` を明示した新方式だけに適用する。未指定の世界は従来の未解決状態を保持し、旧記録や陸のプロファイルへ自動適用しない。

| 項目 | 水域の比較値 | 理由・限界 |
| --- | --- | --- |
| 水分保持上限 / 初期量 | 40 / 32 | 入力量の5T分 / 4T分に相当する有限の緩衝。在庫は無限化しない |
| 局所の水分入力 | 8/T × 雨倍率 | 共通光15.6Eの最大利用6水分＋最大6分解群の処理約0.3＋基準蒸発0.5より余裕を持つ。生物を見て補充量を変えない |
| 蒸発 | 20℃で0.5/T、既存温度応答 | 同じ比較単位の表面蒸発。光合成/分解の実利用と別計上 |
| 底質の利用可能M（乏しい） | 初期4 / 上限16 | 有限の物質在庫。新しい供給源ではない |
| 同（標準） | 初期8 / 上限32 | 最大低次6群の基準取得0.3/Tの約27T分。再循環なしの規模比較で、生存保証ではない |
| 同（豊か） | 初期16 / 上限64 | 全水域を無制限に富栄養化せず、既存の豊富さ設定を使う |

底質M上限には共通土壌の質を適用する。水域の水分量を土壌保水量として扱わず、水分40/32は土壌の質から独立させる。Mの外部入力は既存の明示設定のみ、標準は0。光は既存の所在光量と共有予算、気温/pH・生物別の応答は既存の対応を維持する。水の入力は局所の境界条件で、隣接マスからの流体計算・養分遠隔取得・気候変化を追加しない。

これはC/D上の比較開始プロファイルであり、A/Bへの新しい正式採用や配布版既定化ではない。陸の水分/底質値を黙ってコピーせず、参照元・導出・適用版を保存する。

## 実行と最小検証

1. 世界作成時に固定値を解決し、動的な水分/唯一の土壌M所有者を初期化する。明示した版だけが有限水域を使えること、未知の版を拒否することを確認する。
2. 水域入力・排水・蒸発・実利用を既存の一回限りのターン処理へ接続する。雨由来の入力と水域境界の入力を固定フィールドで区別し、同じ水を二重加算しない。
3. 同マスの微藻/水生植物→水游虫等の小集団→死骸→分解/翌TのM還元を既存生活処理へ接続する。植物に動物食を付けず、植物/菌を無料補充しない。
4. 明暗/水分/底質不足、在庫競合、余剰保持、隣接取得0、E/Mと水の収支、少数Tの結合、生成元/生成物・Worker/JSON・旧4T/再生・公開ガードを絞って確認する。無関係な全件/500T/画像/性能/Windows/配布は実施しない。

淡水光合成体は既存の独立四相・年齢・主生物側占有/移動を維持し、今回その生活表を定着高次植物へコピーしない。専用生活接続は次の工程。通常ターン/新方式保存の公開ガードと製品4.2.77を維持する。
