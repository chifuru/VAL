# I09 観測UI・グラフ・操作の実行契約

基準main `e09132c` / 開発版4.2.40、対象4.2.41。主FLOW-05、証跡FLOW-08。利用者の「次に進んでください」と採用済みA/Bに接続する。project-local Operationを先に読み、Summary/Flowに従って進める。第零次前提・Identity Kernel・前提フィードバックを維持する。

## 対象と構造

正本は `observation-ui/12`、`relationship-network/2`、`display-load-reduction/2`、`observation-state-contract/1`。既存C7/C8/C8.1/C8.2、D7/D9、E5/E6の8責務で扱う。既存A/Bは採用済みの意味を維持し、新Node・分割・初期登録・正式状態遷移は行わない。実装/検査対応と現在Manifestを更新する。

- 開始/一時停止をマップ右上へ一本化。同画面の選択/所在強調/詳細/追跡/表示設定/グラフ対象は進行を維持する。説明/図鑑/設定へ移る間だけ停止し、同世界への復帰では最初の進行意図を戻す。手動停止・新世界・終了・区間終了・エラー・遅延応答を分ける。描画/UI失敗からの復旧で確定ターン/観測を二重適用しない。
- 不要な通常画面のCSV/集計説明、全個体一覧、詳細専用停止を撤去。全期間3パネルを開閉なしで常設し、相/雌雄/年齢を同時に実数軸で表示。マップ/グラフ/独立横詳細、上部の一体サマリを保持する。作成画面ではライブグラフを隠す。
- 円の解像度/面積を増やし、内側「生物グループ」と外側「系統」を同じ分母で明示。サマリは総括と関係面→Bピラミッド→円の一体構造。100T上1大図/下4小図で500Tを担当し、継続時は次の500T区切りを表示する。盤面の記号/固有色・系統の基準位置・同作用の共通縮尺・線幅と単位付き値を使用する。
- 3面は採食/分解、戦闘/支援、寄生/情報。実同化E、実損害HP、支援/除去件数、定着群体T、由来付き非ゼロ情報作用を区別する。不足は未記録、ゼロ/未観測と分け、因果/勝利/情報の真実を推定しない。系統別B/数は区間末の確定値を保持し、絶滅した過去を現在値で上書きしない。
- 表示軽減は通常/最大/個別。補間、追加演出、行動マーク、既存名札、状態札、グラフ更新頻度、操作中背景簡略化を独立操作する。最大でも近景を記号化せず、選択/停止時は最新確定値を示す。格子・幼体/老齢マークも採用済み意味の範囲で識別を改善する。

## 実装・互換と負荷

`relationshipModel:network/1`の版付き観測追加だけを新経路で有効にする。engineの表示用テレメトリは演出件数制限前に取得し、生態判断/乱数/収支へ読ませない。旧無指定経路と旧観測原値・旧再生を保持する。新記録は任意の関係図定義/区間集計/境界値を保存し、旧記録の欠測を補完しない。全個体の毎T完全履歴、全個体対比較、毎フレームの力学配置は追加しない。区間集計と固定配置を再利用する。

対象はapp/Index/styles、rendererの表示設定、engineの観測出口、observations/関係図、archiveの署名/定義接続と対応tests。原画・採用造形・遠景記号・近景絵柄・生態規則・A/B・3coreは変更しない。全盤面への毎フレーム暗色マスクは追加しない。描画更新頻度と全T記録頻度を分離する。

## 検査・完了条件

1. 単体：100/101/400/500/501T境界、0T/途中/全滅/続行/欠測、対別量/方向/同単位縮尺・区間末Bと重複なし、全T保存/復元と旧版互換。
2. 操作：進行/手動停止/準備/計算待ち/三段階途中と別画面・取消・ネスト・遅延応答。選択中も進行し、表示例外から二重確定なく復旧する。
3. 実画面：標準/狭幅、独立詳細、常設3パネル/相雌雄年齢3本、円の内外、上1下4関係面、作成画面非表示。保存結果とライブ値を混ぜない。
4. 通常/最大/個別で生態世界指紋・全ターン原値一致。旧経路/新経路とWorker/保存を必要な範囲で照合する。表示処理の時間は測った条件だけを記載し、速度向上や全PC性能を推定で保証しない。
5. 証跡 `operations/evidence/i09-observation-interface-v1/`、対象ソースSHA、既存8Node/Manifest/実体/実行契約を照合し、出力前ゲート後mainへ統合する。

意味や責務に未採用の変更、新Node分割が必要な場合だけ具体案を確認する。実装上の選択は委任済み範囲で進める。次はI10描画/素材/行動表示。P/Q自然長期循環・500T/R1〜R6/全端末性能はI11未達、新Windows/ZIPはI12。現Windows配布4.2.32は更新しない。
