# 採用モックへ向けた地表・地物・観察画面 v2.7

利用者の明示した画面実装指示を受領。project-localのOperation出力前ゲート、Summary記述規則、Flow修正フローを実読し、FLOW-04/05/07/08をB5.3/C8/C8.1/D9/E6内で接続する。59ノードの責務・分割・正式状態は維持し、追加分割を行わない。

採用したvisual-alignment-v4の遠近およびasset-mock-v1の地形を基準に、実装用の地表8材質と透過地物8区画を新規制作し、素材を盤面へ接続する。背景の完成絵を盤面へ貼らず、地表は実際の環境・地形、岩/茂み/倒木/崖は実際の被覆・岩地・壁から描く。材質の花や苔は装飾であり、新たな可食生物・通行障害を発生させない。

水際は実セル中心の水域値を双線形補間した輪郭で描き、中心の水陸分類を保つ。深浅の表現だけ滑らかにし、地形・環境・通行を変更しない。描画素材と可視範囲の処理はscenery.jsへ置くが、既存C8.1の一責務内で扱う。詳細生物の円形台座を接地影へ替え、近景は320px/セルまで拡大可能にする。採用した全生物の全差分の新規作画まで完了とはしない。

観察に集中する操作で設定/導入を隠し、盤面を広げる。戻せること。全体ボタンは画面寸法に関係なく記号モード、近景ボタンは同じ選択セルの96px詳細へ接続し、通常拡大は縮尺に応じて切替える。モード・焦点・素材・拡大を生態指紋へ入れない。設定フォームと記録再生の動作を維持する。

検査は素材の読込/透過/区画/地物接続、全体が高解像度でも記号、近景/集中操作の生態独立、選択中心・狭幅・全体へ復帰、遠景/年齢/既存画面/記録再生の回帰。通常配置の実画面と明示配置の表示fixtureを区別し、同じ世界の遠近を保存する。素材のSHAと由来、旧生態との同一性、未達を記録し、Manifest現在状態と照合してmainへ統合する。最終的な見た目の利用者承認・長期バランス・Windows実exeは別対象。
