# I03 独立植物3系統の実行契約

基準main `66bfd0d` / 開発版4.2.34から4.2.35へ進む。利用者の継続指示と実装12単位のI03に基づく。主FLOWはFLOW-05、検証証跡はFLOW-08。プロジェクト内Operationを先行制御とし、実行契約/分割判断/Manifest保持範囲と関連A/B・既存C/D/Eを実読する。

## 採用仕様と比較開始値

正本は `appearance-correspondence/1`、`producer-renewal/1`、`initial-comparison/1`、`observation-state-contract/1`。森冠/星冠/移動する淡水光合成体は独立3系統。旧光樹・植物共生体・基底群落を黙って置換しない。機械IDは `forestcrown / starcrown / freshwaterlight`。新しい海/塩分/海流を追加しない。

専用寿命/維持/光/容量/出生費等は `implementation-start/2` 第3節から比較開始値を選ぶ。追加比較値は相成長の支出II/III/IV=2/4/6E、陸の適地和集合2%を二種へ分配/水適地2%の自動初期数、初期I相/年齢比0/E容量比50%。これらを未実測最適値や利用者の個別数値採用へ読み替えない。全実効設定・定義/係数版を保存する。

## 構造と変更範囲

既存C7とC7.1〜C7.5、C8/C8.1/C8.2、D7/D8/D8.1/D9、E5/E6で、状態・有限収支・行動・成長繁殖・寄生境界・観察描画・検査証跡を分担する。既存の責務/変更単位/検証観点を使い、新Node/分割は不要。A/B採否、3core、全Nodeの正式状態・親子/層間関係は変更しない。Manifest初期登録なし、現在要約の反映あり。

- `largePlantModel:'independent/1'` は群落版 `producerModel:'colony/1'` と明示して有効化する。旧無指定/I02の世界は従来の有効31系統と計算/保存を維持し、新世界だけ34系統とする。`D.independentPlants` と世界別の `S.activeSpecies(w)` により旧カタログの無条件拡張を避ける。
- `group:'plant' / kind:'independent' / slot:'producer'`。三種合計一個体/セル、基底群落/主生物/一次消費者とは別の有限枠。同じIDを複数枠やグラフへ二重加算しない。本体2Bと有限可食部、E/M、本人年齢/出生時寿命基準、相/枝/経験を分離する。
- セルの光は、実在する各生産者の最大個別上限を一度だけ計上し、受光面積比と各容量上限で配分する。土壌Mは同じ確定在庫から調停する。再生E1.2/B・M0.02/B、維持/移動/出生/成長/準備費を実支出にし、無料供給や処理分割による二重再生を作らない。
- 森冠/星冠は不動。淡水はI相から局所1マスを有償移動できる。合法な移動先/空きproducer枠/予算を通し、滑る位置変化で表す。移動だけで栄養や成功経験を生成せず、通常植物に捕食/攻撃を付けない。
- 繁殖は本人の年齢成熟と有限予算/待機/近隣8セルの適地/空き枠/調停を通す。I/IIでも成熟すれば可能、幼体の上位相だけでは不可。子は新ID/I/年齢0/可食0。親の相・実績・後天状態を丸ごと継承しない。
- 経験は実維持/純生産/被食後再生/子の定着成果から最大1/T、II12/III36/IV80。III三枝→IV各二枝を実配分から決める。IIIまでにしか出来ない行動をIII到達の必須条件にせず、IV準備も本人Eを支払って記録し、到達前にIV能力は発効しない。
- 可食0と本体死亡、同ID回復と新ID出生、年齢と進化、基底群落と独立個体を、Worker・横詳細・系統樹・全ターン観測/CSV・図鑑保存で統一する。未知版/欠測を0で補完しない。旧署名で新植物を再生しない。
- 遠景の既存記号表現へ三種専用記号を追加し、近景とportraitは保存済み採用画へ対応させる。背景/文字等の除去が必要な素材は画像編集ツールで透明な派生アトラスを用意し、原図・採用区画・派生結果を区別する。毎フレームのマスク加工や盤面への囲みカードは追加しない。I10の全方向/全年齢/全密集状態の素材完成とは区別する。

## 検証と完了条件

1. 三種の初期設定/直接0/適地/producer占有と、群落・主・一次消費者との同セル共存を確認する。初期数の0は初期のみで、無効群/不適地を無断補完しない。
2. 本体残存/有限在庫の競合/再生費/共有光・M/死亡還元、成熟I繁殖/幼体禁止/子I0、経験/枝の到達と年齢独立、全相の淡水移動と定着型不動を検査する。
3. 無指定とI02旧条件は旧mainの世界/指紋/全CSVと照合。新条件は動的・静的全優遇設定と実Worker/同期を照合し、保存/再生で再抽選しない。
4. 固定条件の循環・成長/子の定着と未達を記録し、必要な実画面で三種/重なり/選択・詳細/系統樹/グラフ/再生成を確認する。最終500T生存率・R1〜R6・全端末性能やWindows新配布は今回認定しない。
5. 対象source/採用画/生成物・C/D/E・Manifest・証跡を照合し、出力前ゲート後mainへ統合する。次はI04「量機」。採用の意味/枝数/可逆性や新Node分割が必要になった場合だけ具体案を確認する。
