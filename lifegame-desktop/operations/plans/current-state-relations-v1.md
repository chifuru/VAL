# CS04：関係・摂取構成・過去統計の分離

起点 `884e2a0`。FLOW-05で既存C/Dへ接合し、限定確認後EとManifestを同期する。標準配置のOperation→Summary→Flow、current-state/1の6節、CS02/03と現行観測/有限取得を入力とする。

## 実行契約

- 目的：個体ペアの過去列、過去世代の累積表、採食明細の再走査を生態の次T入力から外す。
- 前提：現在状態への集約・旧結果の差・工程ごとのmain統合は許可済み。新Node/正式状態変更/分割は不要。既存C7/C7.1/C7.2/C7.3/C7.4/C7.5が現在値と実作用、C8が外部観測、C8.2が保存境界を所有する。
- 作成：固定5成分の摂取状態、当該Tの接触/作用・世代差分を扱う補助コード、全Tの内部観測保管/CSV、検証と証跡。D7/D8/D9を更新してからtestsを作る。
- 維持：マス/有限資源・同T/次T境界、直接の親子/養育/宿主関係、現在の世代/成熟/繁殖待ち、造形/UI・既定条件・製品4.2.77/配布。Core/A/B Node・正式61Nodeの草案/階層/層間参照を変更しない。
- 新方式はcurrent-state/1の内部比較のみ。通常画面/Worker/図鑑の新形式全接合はCS07。旧保存を新規則へ黙って変換せず、既存の新状態保存拒否を維持する。

## 実施と確認

1. 実際に同化したEのみを5成分へ加算し、半減期20Tで現在量を更新する。光は生産者成分、食物は取得時の源構成を一段上へ、不明は不明へ渡す。表示の参照では時計を進めない。
2. 身体/土壌・捕獲・P/Qの実栄養移転へ同じ境界を接続する。同時取得では源構成を開始時に固定し、配分/加算順で食物源を塗り替えない。小集団の分割は現在の要約を比例分割し、過去明細やP/Qを複製しない。
3. 接触は当該Tだけ個体ペアを重複除外し、系統別の接触回数/接触Tへ集約する。「過去に初めて会った」を復元しない。接触だけで成立作用の多様性を増やさない。
4. 実際の採食/損傷/防衛/支援/感染/情報作用と現在の付随関係を集計する。匿名の土壌/場は分類と不明を明示し、架空の源個体や系統を補完しない。
5. 生態から渡す世代統計は当該Tの差分だけ。観測側が全T行・世代累積・50T関係/完了10T区間を保持する。現在の世代/直接の親参照を消さない。
6. 最小検査：5成分/半減/不明/読取不変/実同化、同時取得/土壌/寄生/分割、全同居者の接触重複と作用分離、世代差分・全T/CSV/読取専用復元、短期生成元/生成物と取消を確認する。
7. 変更していない従来経路は短期の起点比較と署名条件を照合する。新方式の旧互換を登録しない。生成物・証跡・Manifestの現在要約を揃えてmainへ統合する。

卵/活動マス/新画面全接合・自然500T・総合性能の認定は本工程へ混ぜない。新しい別件を修正する場合は先に範囲を伝える。

既存責務内へ接合。新方式16・関連32・既存観測12・通常7成功、従来3条件×T0〜T2一致。代表1条件の新方式4Tで生成元/生成物一致と取消保護を確認した。全T観測の合成62行を確認したが、自然62/500Tや総合性能は未測定。[実装契約](../../design/implementation/current-state-relations-v1.md) / [証跡](../evidence/current-state-relations-v1/README.md)。新画面/図鑑全接合はCS07、次はCS05。
