# 初期適地と動く餌の更新経路

FLOW-04/05。A/B v2.5 23節の初期適地配分/有償出生に接続。既存C7.1/C7.2/C7.4、D7/D8、E5内で扱い、新Node/分割/正式状態変更なし。

初期の餌総数・群別数と地形/主生物初期数を維持し、餌枠の配置を植物→菌→動く餌の順から全種のラウンド配分へ変更する候補を比較する。適地が狭い種へ順番に一枠ずつ配り、広い種は競合の少ない場所を優先する。適地不足の残りだけ同群の他種へ再配分。水生餌だけを後から追加せず、藻類と水生餌の双方に実際の適地を残す。

次の単独候補は動く餌の出生E条件12→8（出生費8、子E6+B2は維持）。前段の留保/近傍出生との組合せは固定3条件で比較し、寿命/主生物繁殖/PQは変えない。途中補充/遠隔繁殖を追加しない。

作成対象: design/renewal-screen-v2/、tools/screen-prey-routes.cjs、tests/prey-route-screen.test.cjs、operations/evidence/prey-route-screen-v4.1/。製品src/core/UI/素材と旧試行版は変更しない。前段のモデルと同じ補正だけなら全ターン一致を照合し、新しい配置では初期個体構成が変わることを明示する。解決済み地形と群別初期数、費用の有限収支、適地/枠/決定性を確認して500Tの3条件比較を行う。

評価: 水生餌が適地に初期配置されるか、動く餌の世代更新/150〜250T/末尾50T/500Tの存続、非光合成主生物の出生と子孫再繁殖、P/Q、植物の維持。三事例の改善をR1〜R6合格と混同しない。有望案がない場合は失敗理由を残して次の単独要因へ進む。

切り分け用に自由設定の同じ地形/初期値/餌条件で主生物とP/Qだけを無効にした補助条件も確認する。固定3モードとは別集計とし、光や餌倍率を変えず、捕食/寄生がなくても動く餌が更新できるかを見る。tools/diagnose-food-only.cjsと全ターン原値を保存し、この補助条件の存続を混合競争の達成件数に加算しない。

追加の接合確認: 栄養側の「繁殖場所あり」判定が旧出生近傍2〜3に残っていた。近傍出生1〜5と繁殖用E8留保の判定を揃えるbirthReserve候補を追加し、alignedReserve/同preyGateを3条件で比較する。元の試行は判定不一致を含む実行結果として保持し、未実行の訂正版の結果へ読み替えない。先行の実行モデル/ツールをアーカイブしてhashで区別する。
