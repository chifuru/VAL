# CR06前半：実宿主・寄生・情報の内部接合

正本は `design/specification/cell-reorganization-v1.md` 10〜12節、既存P/Qは `parasite-cohorts-v1.md` / `primary-eggs-v1.md`、情報は `information-cycle-v1.md`。C/D契約は `design/implementation/cell-reorganization-v1.md`。

- FLOW-04/05で既存C7/C7.2/C7.4/C7.5/C8.2の接合、FLOW-07/08でD7/D8/D8.1/D8.2 → E5の限定確認・証跡。既存責務内の作業単位で、新規Node・分割・初期登録なし。既存Manifestの現在要約を反映する。
- 今回はCR06の内部境界を一まとまりとして実施する。全体の主生物生活・Q自律採食/探索、初期画面・複数ID表示/選択/単位・グラフ・通常ターン/保存公開は後続であり、CR06全体の完了としない。
- 開始時に既存の有限感染体期限・P/Q維持/発育、情報追跡と有限予算からの情報受容を接続。情報を栄養にせず、採食予定から受容費を前借りしない。新方式の実維持額を受容費の基準とする。
- 同マス全占有層・実IDを既存の適合判定へ渡し、代表一体だけで同居者を隠さない。実際に記録された移動途中の接触は既存の有償移動候補に接続する。既存感染率・窓・卵数・通過減衰・費用は変えない。
- 実際に食べた旧植物/旧死骸の割合を既存の摂食曝露へ渡す。新死骸は死亡Tに利用しない。直接採食と死骸経由を重複させない。
- 部分死亡は新生活型の実世代/身体を抽出し、成熟P/Qを実死骸へ一度だけ移す。付着伝播体は既存フックに従い、可食部伝播体の死骸への付替えと、生存宿主を失った侵入体/付着卵の失敗を区別する。未成熟Pの死亡・除外も既存規則へ戻し、無期限の待機体を避難先にしない。
- 分群は出生と区別し、移ったP/Qの実オブジェクト/hostIdを情報追跡も参照する。同Tの再行動・再移動や、分群を子の成立実績として加算することを防ぐ。
- 実維持・採食/分解・植物形成の結果を情報経験へ渡し、役割分類を空間層番号へ変更しない。死亡の決定は一回、新情報は次Tから。
- 少数fixtureで全同居ID/量機実宿主、部分死/分群の所有・E/M、感染性期限と物質期限、新旧資源の曝露、情報費/役割/経験/新情報、生成元/Worker・旧方式の必要回帰を照合する。全件・500T・画像生成・配布は行わない。
- Core/A/Bの意味・採用数値・61Nodeの正式状態とGraph・UI/画像・製品4.2.77・配布を不変。通常進行と新図鑑保存のガードを維持し、未選定の水系専用値等を推定補完しない。結果と限界を記録してmainへ統合する。
