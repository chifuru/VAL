# CS01のA/B反映記録

対象は `current-state/1`。文書反映の記録であり、ゲームの動作/性能検証証跡ではない。実行契約は [CS01](../plans/current-state-ab-v1.md)、詳細正本は [現在状態への集約](../../design/specification/current-state-aggregation-v1.md)。

## 範囲と判断

標準配置のOperationを先行して関連節を再読し、SummaryのNode/Manifest保持規則、Flowの差分更新契約、現行Manifest・関連A/Bを読む。既存の情報・環境資源・生活・観測の責務へ反映できるため、新Node/分割なし。Manifest初期登録ではなく、既存19Nodeの内容要約を反映する。

利用者の指示は、過去の全情報ではなく現在状態を引き継ぐこと、初期値＋a、発信情報/受信情報の集約、死骸由来を土壌へ統合すること、対象のある場所の処理、長過ぎる存続/不要残存の見直し、旧結果への影響を制約にしないこと。後続候補の具体化と工程1の反映を受け、慣れ/失効区間/土壌の鮮度/分解等を比較開始式へ落とした。数値の採用は実測による確定ではない。
