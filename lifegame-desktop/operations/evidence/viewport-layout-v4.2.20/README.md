# 観察配置の一画面化（4.2.20）

## 結果と範囲

マップ＋基本3グラフ＋現在像サマリを、代表の1920×1080・1366×768で同時表示する。個体数推移、相/雌雄/年齢の集団構成、生態関係の3パネルを維持。現在構成の円、総括と広がり/多様さ/持続性の文章・薄い根拠数値、関係図、生物量ピラミッドの情報は残す。関係図とピラミッドは従来どおり生態関係パネルへ接続し、別の第4時系列へ数え替えない。

承認済みの原画・記号・背景・生態source・乱数を変更せず、ヘッダー/余白/カード密度/グラフの描画枠と説明の配置だけを調整。上部の詳細な観測条件は展開、名札・資源・記号の説明も既存凡例内の展開へ整理した。名札5群は既定OFFを維持し、主と選択対象の名前は従来どおり。所在強調解除と縮尺警告は常に到達可能な位置に置く。分類一覧は横スクロールで全系統へ到達する。

情報内訳・集計限界・単位と凡例の詳細は「観測値・CSV・集計の説明」に保持。原値や全ターン履歴を減らしていない。通常配置/狭幅は縦スクロールを許容し、説明を展開した時と個体詳細の長文もスクロールできる。ページ全体をoverflow:hiddenで隠して通過とはしない。

## 反例の修正

4.2.19の画面レビューでは1920幅でもマップ下端1224.5px、1366幅の右欄内容989pxだった。今回は既定の3パネルが右欄内に収まること、盤面/サマリ/関係図/ピラミッドの矩形が画面内にあることをui-report.jsonで機械照合。far-1920.png/far-1366.png/near.pngは実3T河川世界の製品描画であり、画像生成モックではない。

併せて、盤面サイズが変わっても遠景の縮尺が追従せず切れる問題をResizeObserverで修正。全体表示は再fit、近景/拡大表示は前の表示中心を維持する。画面操作で別個体へ選択を切り替えたり、生態指紋を書き換えたりしない。
