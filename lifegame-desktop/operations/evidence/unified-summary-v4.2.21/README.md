# 現在像サマリの統合（4.2.21）

## 訂正した構成

前版は現在の関係図・ピラミッドを右の生態関係パネルへ分散していた。ユーザー訂正に従い、上部の同じサマリ枠へ「現在構成」「総括と広がり/多様さ/持続性の文章・薄い根拠数値」「成立した関係図」「生物量ピラミッド」を統合した。右側は全期間の「個体数」「集団構成（相/雌雄/年齢）」「生態関係」の3パネルだけ。

サマリは最新確定ターンを読む。現在の特徴を導く直近50Tの評価窓は保持する。右の過去参照/対象変更ではサマリを巻き戻さず、個体詳細が右のグラフを置換している間も現在像を更新する。図鑑の分析では記録の最終サマリと全期間3パネルを一緒に表示し、閉じると元の世界の最新サマリへ戻す。ドーナツの母数・栄養B・生産同化E・作用の定義や保存スキーマは変えない。

絵柄・素材・遠景記号・生態sourceは不変。通常配置/狭幅は上部サマリを保った縦配置。詳しい説明/CSVは既存展開欄。現在像を4つの別カードへ分散させず、基本3グラフも数え替えない。
