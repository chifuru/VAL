# UI・バランス完成前の現行製品計測

対象：製品2.3の生態コード、Linux/Node（版はbalance.json）、UIと同じwatershed。40×28、主80体、初期値で5系統、補充保証なし。10固定初期値、各500ターン。製品コード・係数は変更していない。

## 結果

全5000ターンで既存の有限収支・占有等の不変条件を通過し、観測した主出生は第一相/G0を満たした。既存npm testは11テストファイル成功。これはUI完成や新モデルの検証ではない。

10条件中2条件で500ターンまでに主生物が全滅した（443、485ターン）。500時点の主個体数は条件順で1、0、1、0、5、23、2、6、47、3。終端の存続集合は空集合を含み9通りで、全条件が同一勝者ではないが、少数個体の残存を安定繁殖と呼ばない。

500時点の一次/高次寄生は全条件で0。現在の調整では宿主・食物網の維持と寄生の接続の両方が残課題。複数時点のP/Q数はbalance.jsonを参照。集計死因には餌生物も含まれるため、総死因だけから主生物の死因や原因を断定しない。

## 再実行と有効範囲

`node tools/measure-ui-balance-baseline.cjs`。固定した10初期値と条件を使う。source-hashes.jsonは実測対象の生態・UI・計測ツールを固定する。balance.jsonに解決済み条件、初期個体数、最初の系統消失、出生、300〜500の毎ターン存続、100/300/500時点、最終指紋を保存する。

新しい地形方式、年齢能力、独立植物、採用造形の製品反映は未実施。旧E5/E6/E7をこの範囲外へ拡張しない。後続のバランス調整は開発条件と未使用の確認条件を分け、無償補充や強制的な生存保証で合格させない。
