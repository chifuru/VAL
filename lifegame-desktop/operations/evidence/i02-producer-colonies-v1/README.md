# I02 基底群落と陸水の生産基盤

基準main `aafc614`（開発版4.2.33）に対する4.2.34の実装・限定検証。実行主体はVALIS/Codex、Linux x64 / Node v24.19.0 / Chromium。[実行契約](../../plans/i02-producer-colonies-v1.md)に従い既存C/D/Eを更新する。全61 Nodeの正式状態・構造、A/B採否、原画/絵柄/グラフ配置を維持し、新Node登録はない。配布済みWindows版4.2.32と今回の開発版を区別する。

## 接続した規則と比較値

- 新規UI世界へ `producerModel:'colony/1'` を明示。草本/苔/藻/浮遊微藻は一セル一群落で、内部株の個別計算を増やさない。状態は `colony-state/1`、係数は `colony-parameters/1`、全実効値を初期条件へ保存する。
- 可食容量20B（標準採食2Bの10回分）・初期可食14B・非可食基部2B。最大再生は容量10%/T。自動占有率は適地に対し陸20%/水15%。数・容量・初期割合・再生を分け、固定モードの初期量増は群落容量側へ適用する。
- q=2B、1B再生へE1.2/M0.02を使う値は実装開始案から選んだ比較値。B1はEから移し、差E0.2は散逸、Mは実土壌から同じ群落へ移す。利用者採用済み最適値とは扱わない。光・E・有限M・活性・残容量が足りなければ増やさない。
- 同IDの部分採食と再生では経過/由来/感染等を保持。可食0でも基部を残し、葉の再生を出生に数えない。群落へ内部株の寿命一斉死や架空の年齢/雌雄分布を付けない。完全消失後の合法定着は新ID・新状態となる。
- 陸水の占有上限、局所出生の親負担・適地・空き枠を調停する。直接数は初期配置を優先し、種別0も既存契約どおり初期0。供給ONでの開始後の合法定着まで永久禁止しない。群無効化、占有率0、初期保証との矛盾は迂回しない。
- 供給ONもBを直接補充せず、不足E/Mの明示入力と有償再生へ分ける。供給欄の再生倍率も容量10%/Tの範囲で作用する。供給OFFに外部入力や消費者救済を追加しない。散在/集落の配置差も実際に適用する。

## 部分採食と既存Pの境界

可食感染量を有限備蓄として親Pの実Eから作り、実採食B/採食直前可食Bの比率だけ取り出す。備蓄のEを全体収支に含め、失効/不適合/死亡時の残量も一度だけ散逸する。元P/QのID・宿主を一口で分割/複製せず、既存適合先への娘Pに新IDと実際の備蓄Eを与える。

これはI02の在庫境界。侵入/定着の多段判定、経路遺伝、獲得抵抗の新機構、P/Q自身のBや新Q生活環はI05/I06で接続する。現段階の既存適合処理を新P生活環全体の完成とは報告しない。

## 観測・保存・画面

`producer-colony-observed/1` として全確定Tに地域別の群落数/B/基部/可食量/E・M蓄え/活性/占有面積と分母/光入力E/生産B/被食後再生B/消費Bを残す。生産Bのうち被食補充分が再生Bであり、合算して二重計上しない。CSVは群落と個体を単位で区別し、適地0の割合は未定義として残す。欠測や未知定義を0で補完せず、保存・復元を拒否して既存記録を保護する。

横詳細に成立後経過、基部/可食部/容量、蓄え、活性、直近再生を表示。既存の遠景記号/近景絵柄を維持し、量による描写の分母だけ新容量に合わせた。群落の状態マークは群落と示す。グラフやマップの配置は変えていない。

生態署名は `29d8a966b7f9dcf86b26c5f40bd11967633dc9d8c52971720e584e8f0f7e23d5`。旧4.2.32/I01の記録は群落指定のない旧計算経路だけ再生互換にし、新群落を旧署名で再生させない。新記録は全実効条件・全期間指標・最終指紋を保存し、再生で再抽選/自動記録しない。
