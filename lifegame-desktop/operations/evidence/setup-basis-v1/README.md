## 再現と修正

旧mainで、小世界の生成前容量40→高生産の生成後60となる条件を作成。設定へ戻ると入力60を「基準値」と説明するが、次回生成は40を基準としていた。さらに下層をリセットすると表示20、内部の次回基準40となった。

自動欄には実際の次回基準を単位付きで表示。保持された基準がある場合に、前回の生成値を基準と説明しない。下層リセットは下層の保持基準だけを消し、既存の入力復帰値を次回生成へ渡す。主/地形・個別指定有無・供給/優遇・現世界/記録は保持する。
