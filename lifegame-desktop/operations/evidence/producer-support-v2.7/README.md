## 実装した範囲

- 既存の基底/小型動物/主の3枠を用い、生産者だけへ外部E/Mと上限付き可食B再生を供給する。capacityは環境支援地点の割合であり、全個体数の厳密な上限ではない。
- 実投入したE/BをproducerE、MをproducerMへ記録する。旧initialE/M/solarは変更せず、開放系の収支式へ明示した外部入力を追加する。2004状態でE/M残差はすべて0。
- 空き基底枠への環境定着は新ID/環境由来/親なしとして保存し、通常の繁殖数と別に数える。生体個体数/構成/接触観測には実個体として含める。動物/P/Qの救済補充はしない。
- 供給停止は生産者の外部入力/光入力/養分取得/成長/繁殖を抑制し、栄養猶予の消費後に衰弱する。供給回復時は新IDから環境定着する。診断用の固定スケジュールであり、稀なランダム攪乱の発生器は未実装。
- 無効時は新しい状態を追加しない。初期設定後の供給条件の直接再設定は拒否する。

初期比較値は陸水ともnutrition=1/capacity=.35/regrowth=1、環境発芽率.1、維持E目標8/M目標.5、停止猶予20T。settings/設定スケジュールはworld.config.producerSupportへ保存する。これらは私有比較の初期値であり、全環境の調整完了値ではない。土壌/水域に由来する設定を変えた条件であることを製品のモード説明にも接続する必要がある。
