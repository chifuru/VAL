# I05 一次寄生Pの限定検証

対象は開発版4.2.37、基準main `3167a2d` / 4.2.36。[実行契約](../../plans/i05-primary-parasites-v1.md)のFLOW-05/08。Node正式状態は草案で、採用仕様・接続実測・未達を区別する。

## 接続範囲

`primaryParasiteModel:'primary/1'` と `primary-parameters/1` による明示世界だけ新Pを使う。旧無指定/群落/独立植物/量機の世界は旧定義を保持する。P二系統・三相、本人齢/出生時計/実Bと宿主段階、A/B/C固定形態、遺伝適応と宿主選好、後天抵抗を別に保存する。

有限曝露→適合→侵入→翌T別定着。同源・同形質・同経路・同宿主の微量だけ元期限内で蓄積し、量0/不適合/占有/不足を成功へ補完しない。曝露中/侵入済と、生体P/移行中P/死骸上Pを分ける。同じPの宿主移行でも別定着を通し、同じID/Q/齢/栄養を保持。失敗でP/Qが失われ、娘PへQをコピーしない。

実食の割合だけ付着量を移し、全経路共有の有料放出、同期水拡散20%以下、期限制限とE+B収支を通す。体外感染量から生体数を捏造せず、末期に隠れた補充をしない。維持/発育/誘導は相別の有限費用で、誘導は可視な手掛かり/合法候補へだけ作用する。宿主適応を相手の内部状態を知る力へ転用しない。

初期自動Pだけ40/40/20配分。手動正数は適合第一宿主全数、明示0/無効を優先し、不足は報告または既存の直接数エラーで止める。初期状態を開始後成功実績に数えない。

## 観察と保存

P本人相/成立後経過と宿主stage、好み/適応/抵抗/直近実費・不足を横詳細へ接続。体外量・曝露蓄積・侵入済・移行中の数/量/期限/由来は現在状態から参照する。全ターンは `primary-parasite-observed/1` / `primary-parasite-flow/1` のstock/flow原値を保存し、毎Tの全個体映像・全感染体履歴は追加しない。新定義を旧記録へ0補完せず、旧署名が新Pを再生することを拒否する。

新P本人相を既存原画へ渡し、実定着/移行完了/排除だけ短い既存マークへ渡す。曝露/侵入/移行準備・失敗を感染成功の演出にしない。遠景記号/近景絵柄/常設3グラフ配置を維持する。
