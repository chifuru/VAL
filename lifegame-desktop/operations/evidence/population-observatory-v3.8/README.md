## 何を変えたか

繁殖準備のできた同系統の異性への、視界内の接近/隣接滞在に有限の評価を加える。双方III以上・成体/老齢・HP70以上・系統固有E閾値以上・M4以上・待機終了が必要。接近0.65×距離改善（2マス正規化）、隣接の非移動0.2、可視危険度で減衰。近づかない移動への追加罰なし。群体は除外して社会性を保持する。自動交配や優先行動の強制ではない。

実際の出生B2/3、同系統二親、費用、健康、待機、I相/幼体、寿命・供給/戦闘の式は維持。無償回復・生体再投入はない。視界外の配偶相手へ誘導しない。既定の全20系統を保ち、5系統へ一律変更する案は不採用。

候補評価の同じ個体/view内で不変な危険度/近傍を再利用。UIの閉じた一覧/順位/収支は生成更新せず、開くと現在値を表示し、進行しても開閉を保つ。記号凡例も個体数が変わらなければ再作成しない。表示操作は生態を変えない。

## 検査・性能の範囲

unit.log: 最終実装122回帰。繁殖誘引の資源/待機/健康境界、世界とDNAへの読取独立を含む。browser-report.jsonは既存46、population-ui-report.jsonは専用23項目。閉じた三パネルの12ターンのDOM書込み0、開いた際の最新性/継続中の開閉維持、表示操作の計算独立、狭幅・初期化を実ブラウザで検査。Windows CIにも専用UI検査を接続。

optimization-candidate.jsonは繁殖調整前に最適化だけを分離した予備計測。2入力×100ターンの終端指紋は前版と完全一致。計算時間は7646→6959ms、6411→5325ms。共有環境の単発値であり、最終3.8の速度保証や全端末FPSとして扱わない。再測定にはbeforeCommitの二つの展開先の片方へcache-only.patchを適用し、LIFEGAME_BASE_ROOT/LIFEGAME_OPT_ROOTを各srcに指定してmeasure-cache.cjsを実行する。optimization-metadata.jsonが比較対象のbehaviorを特定する。

source-hashes.jsonは実装・検査・依存・契約・CIを特定。対象変更時は該当証跡を失効させ再検証する。visual-identity.jsonで描画/原画保持を照合。
