# 所在強調・名札の確認/1・限定証跡

基点main 3a58660 / 4.2.72。2026-10-23 UTC、Linux Chromium。契約: `design/specification/presence-controls-v1.md`、計画: `operations/plans/presence-controls-v1.md`、D9検査: `tests/presence-controls-ui.cjs`。

## 原因と修正

従来の所在強調は主に生体宿主内と自立Qを拾い、死骸内/移行待ちで生存するP/Qを拾っていなかった。`baseline/preflight.json` では、期限内の死骸内と移行待ちの両セルが強調されなかった。

現行モデルの `PrimaryParasite.entries` を正として、生存Pと付随Qの現在セルを補う。現在描画世界の候補へキャッシュし、選択がP/Qに関わる時だけ構築する。期限や定着を独自判定せず、感染量を個体へ数えない。画像/配色/名札/型の表示や生態計算は変更していない。

## 限定結果

`report.json` の14項目が成功。期限内の死骸内/移行待ちでP/Qの2系統を個別色で強調し、期限切れの搬送個体は強調しない。淡い分類色との重ね合わせ、全解除、分類一括チェック/部分選択も確認した。落ち着いた同一描画世界の再描画3回では、生存Pの再列挙は0回だった。性能倍率や実時間短縮を示す測定ではない。

近景は主生物の名称を維持し、未選択の下層/P/Qは初期状態で非表示、チェックで表示し、解除で戻った。新しい正常世界での実Worker進行中も、名札/分類色の操作は観測を止めなかった。通常の起動画面は即時1ターンボタン/旧配置ボタンを隠し、smokeモードだけの検査用露出と区別した。ブラウザ例外0。

搬送ケースは通常配置したP/Qを元に複製/付随させ、期限内の死骸/移行待ち/期限切れへ置いた明示的な表示fixture。実際の自然死・接触移行・感染成功や個体数の整合を検証したとはしない。実Workerはこのfixtureを破棄して新世界で確認した。

一般の型名は通常の盤面名札や選択個体の相/雌雄/年齢欄へ追加されていない。系統樹の正しい通常/相変異の説明、Pの形態、真社会性の役割は別の意味を持つため維持した。0体の一覧項目を隠す既存処理はソース確認のみで、今回その消滅過程の新しい実測はしていない。

## 残件と限界

fixture準備中、潮環6群体を直接指定した組合せで「指定6/配置可能5・第一宿主の適合枠不足」となり、8候補以内で生成できないケースを観測した。完全な地形初期値は保存しておらず、同条件を必ず再現する記録ではない。一般化した上限を今回推定せず、初期数と適合宿主枠の事前制約/案内の残件として記録する。今回の確定検査は葉環4・潮環2・Q2を基にしている。

格子/年齢強調/背景判読性、旗なし旧世界の宿主外強調、感染量や資源/地形の新たな選択UI、全条件/長期生態/Windows/配布は対象外。中断中の速度変更は反映しない。
