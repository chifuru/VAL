採用済みの上部現在像（左ドーナツ、右の総括/3ラベル文章と薄い根拠値）を維持。右側へ個体数・集団構成・生態関係を配置し、個体/系統詳細を閉じるとグラフへ戻る。既定主生物、全体/群/系統対象。相/雌雄/年齢は同じ母数の実数時系列で同時表示し、非該当と無性別を区別。個体数は系統色と凡例。全ターン原値を保持し、通常は最新へ自動追従する。

生態関係は実際の作用が関与する系統数・作用種類・継続関係の別尺度3レーン。固定関係図の栄養矢印は50T内の同化E、宿主→P→Qは現在の有効定着数で別尺度。生産/生きた動物の捕食/現在の定着を役割別に注記。無機養分放出は未計測のため破線。情報餌を栄養経路へ混ぜない。

`trophic-observed/1` は直近50Tの栄養取得で生体Bを配分。既知の非捕食生産者は基底。光合成は第1段、採食は供給元の前ターン配分から1段上、4段以上は集約。未観測は不明へ残す。雑食も全配分の和はB。分解者/死骸q/P-Qは別枠。生産は総光入力E、同化は実吸収Eであり、Bへ混ぜない。これはモデル内の観測推定で、現実の栄養段階の正確な測定を意味しない。
