## 原因と切り分け

85983fdで追加した4.1の隣接生体植物採食は食性制限を迂回し、通常植物にも隣接植物を供給していた。植物は土壌Mより植物摂食を優先し、吸収できない有機Eを失いながら生産者を消費した。収支保存だけでは食性の誤りを検出できない。

before-investigation.jsonは修正前6245483の現行旧処理/4.1を履歴3.4のtrial0と同じconfigで実行した結果。旧処理は当時そのものの復元ではなく、3.4の最終指紋とは一致しない。旧処理の500Tは主68/food521/草走虫57、欠陥4.1は主0/food0/草走虫0。元の3.4記録はoperations/evidence/colony-survival-v3.4/mixed-after.jsonのtrials[0]で、food548/草走虫54。

guard-only-investigation.jsonは私有モジュール内で隣接植物採食の食性制限だけを追加した診断。500Tは主113/food599/草走虫63。この条件にkelpが含まれないため、最終製品のhistorical-inputの指紋と一致した。通常植物の誤摂食が崩壊の主要因だったことを切り分ける。旧調整試行は欠陥モデルの診断記録として維持し、採用根拠として流用しない。
