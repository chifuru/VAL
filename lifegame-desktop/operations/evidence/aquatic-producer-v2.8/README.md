## 既存微藻の確認と新生物

既存微藻は基部B2を残し、光由来Eを可食Bへ変換する。水游虫は同セル/隣接の生葉を食べられる。境界検査で実移転/被食後再生と有限収支を確認した。経路が存在することと、多数個体が必要量を継続取得できることは別。

浮遊微藻は明るい浅深水の生産者/基底枠/無性別/二相。初期値life80/維持.1/待機2、初期E6/B8/M.5/HP6、容量20/16/2/6、光係数8（既存植物4）。光→E→B、有限土壌M取得と有償出生/枯死/還元へ既存経路を使う。相進行は実取得光Eの累計4、年齢成熟とは別。局所分裂は同種近傍B123、親の成熟/E8/B3/M.2、支払E8/M.2と空き適地を維持する。人工E/M入力・環境由来再発生・流体移流・水生植物・他種の繁殖変更は追加していない。

植物総量を4種へ配分し、初期総生物数は旧対照と同じ（河川/疎林food533、湖537）。河川81/湖114/疎林48の浮遊微藻を含む。旧草本の一部等が再配分され、初期総E/Mと配置は新種なし対照と異なるため各jsonにreferenceInitial/initialLedgerDifferenceを記録した。単独と併用の初期世界は一致する。
