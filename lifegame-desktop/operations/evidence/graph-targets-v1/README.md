## 結果

`report.json` の15項目が成功。全生物/既存6分類の対象候補がカタログの所属に一致し、分類を選ぶと分類全体、次に個別系統を選べる。初期対象は主生物全体。個別系統の集計と凡例、全体数の一致を確認。

実際のWorker進行中に分類を変更しても停止/エラーにならず、既存の選択個体詳細は固定された。停止中の変更は世界指紋と停止意図を保持。実際に図鑑へ保存し、結果分析で対象を変更した後にライブ画面へ戻ると、元の個別系統と分類を復元した。ブラウザ例外0。

320px幅のパネルfixtureで対象欄と選択肢の実幅を確認。実際の狭幅画面全体の適合ではない。`narrow-controls.png` は対象欄だけの切り抜き。狭幅画面全体の配置や既存ヘッダの見やすさを認定するものではない。

## 限界

生態関係の系列は従来どおり全生物の関係。対象選択が適用される個体数/集団構成との違いを欄に表示した。新たな関係指標や図の再設計は行っていない。

生態規則/画像素材/グラフ配置/保存形式/正式状態は変更なし。長期/全条件/Windows/配布/中断中の速度変更は対象外。包括的回帰は実行していない。
