# 現在の残件と次の順序

## 確認できている範囲

マス再編の通常進行/有限生活・保存再生へ接続し、代表1条件の自然500Tで主7体が存続した。取得/配分と情報受信には同値の軽減を採用し、単純な複製置換は効果不足で採用していない。今回、現行の通常観察で実画面22項目と遠景/近景を確認した。

## 残るもの

| 対象 | 現在の境界と後続の扱い |
| --- | --- |
| 重い終端の計算時間 | 生体/死骸と学習済み情報が増えた世界では、情報軽減後も1T全体平均約4.72秒の限定実測がある。実画面の短期成功を、500T全体の所要時間や約1秒/Tの保証にしない。次の軽減は実測で支配的な処理を絞り、収支/順序/学習内容を変える近似を無断で入れない。 |
| 新方式の既定化 | 現在は従来が既定、多層/水域は明示比較。専用樹冠係数、群落移動対象種/再生枝、水域比較値のA/B正式採用など未選定部分を、既存正本と照合して整理する。推測で数値を追加しない。 |
| 生態の観察範囲 | 新版の自然P/Q多世代・全系統/R1〜R6は未認定。以前の目標は残すが、利用者が緩和した「1条件で生存例があればよい」を多数条件の再試験へ戻さない。現在のP/Q自然循環を成功済みとも扱わない。 |
| 画面の配置/細部 | 今回は現行配置と絵柄を維持した代表確認。利用者が実稼働で調整するとした画面構成、全系統/状態・狭い画面での細部は別工程。未指摘の全面改装やモック再生成を始めない。 |
| Windowsと配布 | 今回はLinux Chromiumの確認であり、変更後のWindows起動・梱包/配布物は未作成。配布する段階で現行ソース/生成物/保存版と梱包内容を合わせ、必要な起動確認を行う。過去の配布URLを最新版として案内しない。 |

## 次の順序

1. 完了範囲・未選定条件と残る負荷を照合し、一旦完成の対象を確定する。今回の結果を全条件完成へ拡大しない。
2. 実稼働の指摘または実測で必要な箇所だけを調整する。見つかった別件は先に内容を伝える。
3. 配布する場合は変更後のWindows/梱包確認へ接続し、その実体からダウンロード版を作る。今回の作業では配布しない。
