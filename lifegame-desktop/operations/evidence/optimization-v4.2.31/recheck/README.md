## コード照合：導入済みと残る処理

導入済み: 4096整数の乱数表、段階ストリームと変更フィールド通信、固定地形の複製削減、既存近傍キャッシュ、系列の増分キャッシュ、事前生成した影、背景余白キャッシュ、変更のないフレームの描画省略。

残る処理:

1. **背景の準備待ち中にも同期生成が走る。** 上記で反例を実測。完成前に使える背景も事前準備・再利用することが最優先。
2. **遠景でも毎描画、世界の個体を走査し、表示対象を並べ替え、記号を描き直す。** 記号はPath2Dを共有するが、完成した記号画像や静止した個体層の再利用まではしていない。大盤面の遠景負荷を実測したが、各処理の寄与率は未分離。
3. **画像加工は初回表示にも残る。** 主生物の初期準備だけでなく、下層・地物・新しい外観差分の準備時期を見直す余地がある。元画像の省略やデザイン変更は必要ない。
4. **差分通信は全変更の追跡ではない。** transport.encoderは各段階で全行のフィールドを比較し、入れ子データをJSON文字列化する。applyも変更行がある配列を走査する。beginTurnは可変世界を深く複製する。
5. **生態関係の直近50Tは毎ターン集計し直す部分が残る。** 栄養フレームの容量計算と系列キャッシュは増分化済みだが、observations.current/trophic/appendの全処理が増分化されたわけではない。
6. **CSVとJSON出力は一括生成。** 全履歴を維持する要件は満たすが、大きい結果の出力はまだ独立した軽量化対象。

次の修正順は 1 → 2・3 → 4 → 実測に応じて5・6。集団化・個体やターンの間引き・画質低下・生態パラメータ変更を性能対策の前提にしない。GPU/WASMなど大きな書き換えが必要だと、この結果だけで判断しない。
