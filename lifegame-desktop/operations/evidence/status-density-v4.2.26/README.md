## 変更と実画面

状態マークに「主＋選択」（既定）/「全生物」を追加。主＋選択は主生物と実際に選んだ個体の札だけを表示する。同じマスの他の個体は選択扱いにしない。全生物は従来の下層の札も確認できる。状態OFFは全体に優先し、対象設定を保持する。名札・所在強調・生態計算からは独立する。生物の絵/記号/位置/選択範囲/統計を省略しない。

代表の河川40×28自然配置に、同じマスの主/植物/一次消費者とP/Qを加えた私有表示fixtureで確認。描画余白を含む診断上の状態札は全生物時56体分（主15/基底36/一次5）、既定では主15体分。near-main.png / near-all.png / separated-main.pngは同じ盤面の実画面。状態対象は主・植物・一次消費者の相/雌雄/年齢の札で、P/Qの名称/宿主段階表示は従来の分類別名札・姿・選択詳細を維持する。

20項目通過（report.json）。名札のみON、選択した下層だけ表示、選択解除、状態OFF/再ON、近景記号、相分離、狭幅、生態指紋不変を限定照合。「全生物」の近景と遠景の盤面画素は旧rendererと同じカメラ/寸法で完全一致。表示対象の切替で視野内の生体描画数も変わらない。
