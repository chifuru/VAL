# 修正後基準での適地配分・繁殖材料比較

実行契約: operations/plans/foodweb-recovery-screen-v4.1.2.md。製品基準main55a9fb1 / 4.1.2。通常植物は非捕食、菌は非生物有機物/死骸の分解、植物共生体は食虫植物型のまま。旧欠陥モデルの試行結果は採用根拠に使用しない。

## 比較条件

履歴と同じ入力・自由・湖の3固定条件。モデルはdesign/renewal-screen-v2/model.cjsを現在の4.1.2生態ソースで私有コンパイルする。baselineは無変更、allocationは共同適地配分のみ、reserveは生体刈取り後の既存Mを最大0.25残すのみ、allocationReserveはその組合せ。留保はMを追加せず、Mが0.25未満でも増やさない。主/餌/植物/菌の群別初期数、地形、光、寿命、費用、出生近傍、感染率、Qの窓は変更しない。配分候補では種別数と個体位置が変わり得る。

無補正501状態はfoodweb-diagnosis-v4.1.2/afterの保存指紋へ全ターン照合し、不一致なら停止する。各候補も収支/占有等を全ターン検査。指紋/個体数/群別数/世代/台帳/累積出生/世代別再繁殖を各json.gzへ保存し、概要は同名json。JSONのconfigだけで製品の再生を行える試行ではなく、私有モデル/flags/実行ソースハッシュを合わせた診断記録である。

parasiteStagesは各一次寄生IDが到達した生活環区間別の延べID数、matureWindowsは生存宿主上で有効な成熟移行窓を観測できた一次ID数、attachedQは生存宿主の一次寄生へ実際に定着した高次寄生の一意ID数。探索Qが盤面に残るだけでは定着成功に数えない。主生物の150〜250T存続と世代交代、餌の最終数/最後の生存ターン/子の再繁殖も別々に記録する。

## 現時点の判断

全候補とも製品には未採用。無補正は3条件すべて全ターン一致、第一段階12試行と追加2試行は各501状態で収支/占有検査を通過。追加1案は483Tで停止（同条件の再実行は新しいパラメータ試行に数えない）。M留保0.25の一律採用と出生条件の単純な緩和は行わない。現在の製品は4.1.2を維持し、UI/地形/画像/配布物も変更しない。

次は候補の収支停止を切り分ける。そのうえで、新しい係数の網羅探索ではなく、生き残った餌が捕食へ吸い上げられる速さ、到達できる可食部、出生後の世代更新の重なりを対象にする。餌の総数だけを増やす/寿命だけ延ばす/無償補充/感染窓の無条件拡大は採用しない。適地配分で水系生活環とQ実定着が生じることは確認できたため、この経路は長期維持の次候補の基盤として残す。


再現検査でも483Tの同じENERGY:0.002006で停止。partialは0〜482Tの483行。failure-residual-trend.jsonでは残差が100T:0.000057、200T:0.000237、300T:0.000595、400T:0.001467と蓄積し、保存範囲の最大1ターン差は0.000019。急激な一括増加は観測されていないが、これだけで丸め誤差と認定しない。段階別の移転/量子化の照合を次の検査とする。

最終の専用/既存モデル14検査はすべて合格（tests-final.log）。Manifest構造検査はstructure.log。各実行ハッシュと原文対応の照合はvalidation.json。第一段階13検査の旧ログtests.logは当時の記録として保持する。製品src/版/再生署名は本作業で変更していないため、UI/Worker/Windows等を新たに検証済みとは報告しない。
