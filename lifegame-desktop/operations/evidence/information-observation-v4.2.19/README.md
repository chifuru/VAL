# 情報の由来・適用・Q媒介の限定観測（4.2.19）

基準d025202（4.2.18）。プロジェクト内coreをOperation→Summary→Flowの順で関連節を読み、既存B5.5/C7群/C8・D8/D9・E5/E6のFLOW-04/05へ接続。新Node・正式状態変更なし。

## 接続したもの

成功した情報生成/増量、実取得、情報による直接重み差を一時ctxへ記録し、確定観測で集計。Q操作が支払われた生成、媒介印を持つ取得/非ゼロ適用を分ける。発信イベントID→系統を観測側で元時刻+20Tまで保持し、死亡した発信者の由来も既知範囲で復元。再送/再観測による期限延長なし。

情報の実関係は既知由来かつ非ゼロ重み変更だけに限定し、取得＝作用という旧集計を補正。出所不明は推測せず数を残す。生態関係パネル内に今T内訳を短く表示し、全ターン原値/CSV/保存/結果分析へ接続。追加定義information-observed/1を保持。旧欠測は未記録、旧情報関係は取得基準と注記。

## 限界と後続

直接重み差は次の移動/攻撃の変化を保証しない。Q媒介印の適用はQがなかった場合との差分を証明しない。途中から入った由来不明情報を推測で補わず、消費後に死亡して適用されない取得もあり得る。旧記録は書換えない。

情報生成/取得/適用の条件別頻度や長期の創発は未認定。要所保持の実効利益/時系列、陸水の長期世代循環、最終描画/性能/500T結合運転・実Windowsは後続へ保持。
