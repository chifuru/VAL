# 次期地形・友好・存続の限定実測

製品2.2.0は変更していない。対象はdesign/ecosystem-nextの分離モデル。Linux/Nodeで実行。旧版の証跡を今回の合格根拠にしない。

## 固定5系統・10初期値・500ターン

40×28、主役80（各16）、固定5系統、同じ10初期値で比較。全更新で有限収支等のinvariantsを確認。系統や初期値を結果を見て差し替えていない。

|系統|300〜500連続存続|同区間に出生した試行|
|---|---:|---:|
|日輪|9/10|9/10|
|植物共生|10/10|10/10|
|浮遊傘|10/10|10/10|
|深淵触手|10/10|8/10|
|星晶|10/10|3/10|

連続存続だけで繁殖集団が安定したとは認定しない。星晶は残存と世代交代の差を引き続き調整する。出生件数も最終の繁殖可能な組の証明にはならない。

## 検査範囲

- generation-check.json：10初期値の地形生成と二重実行20ターンの再現性、配置主役80、状態整合。
- rules.log：友好の双方向攻撃候補拒否、古い攻撃意図の確定拒否、別系統への捕食攻撃維持。2検査。
- structure.log：Node階層・実体・参照・草案・coreハッシュの照合。
- source-hashes.json：今回の計算対象を再識別するハッシュ。
