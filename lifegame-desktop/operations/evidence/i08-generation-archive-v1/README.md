## 再生の境界

新しい一覧ヘッダは軽量な射影だけを持ち、候補記録/全初期配置を複製しない。UIは `await get(id)` で実本文を読み、`replayRecord(body)` で検証した後に置換する。永続ストアのヘッダだけを使う同期 `replay(id)` は本文検証を省略できないため拒否する。本文を持つ旧インメモリschema1/2の同期経路は維持する。

解決条件のダイジェストは再現/取り違え検査であり、外部改ざんに対する認証ではない。外側で適用される優遇設定は解決条件のconfigHashから除外し、モデル側の整合検査で照合する。再生時は全実効条件と実配置を再確認する。

全体検査/構造照合の最終件数は `verification-summary.json` と `final-structure-check.json`。P/Qの自然長期循環、500Tの生存/創発と性能、I09のUI全体、I10の素材、I12のWindows新配布は本検査の完了範囲に含めない。

最終単体検査は **75ファイル成功・失敗0**（約264秒）。Nodeは61件を維持し、既存9件の本文/対応参照のみ更新。3,718参照、ソース46件、資料リンク53件の照合が成功し、core/A/B・正式状態/階層・採用原画は変更していない。出力前の照合結果は `output-gate.json`。
