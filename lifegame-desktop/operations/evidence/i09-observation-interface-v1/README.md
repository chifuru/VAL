# I09 観測UI・グラフ・操作の限定検証

基準main e09132c、対象開発版4.2.41。実行契約は operations/plans/i09-observation-interface-v1.md。最終検証集計/対象SHA/構造照合を別ファイルへ記録する。

UIの判読性・停止復帰・観測原値/保存互換を対象とし、生態規則や採用原画は変更しない。P/Q自然長期循環・500T/R1〜R6/全端末性能はI11、新素材I10、Windows/新ZIPはI12の後続範囲。配布版4.2.32を維持する。

## 実装と検査の範囲

- 新しい `relationshipModel:network/1` だけ、演出の上限前に実損害HP・支援/除去・討取りを観測する。生態判断はこの追加データを参照しない。採食E・有効寄生の群体T・由来付き情報作用・区間末B/数も別尺度で保持する。
- 100T区間の上1/下4を一体サマリへ接続。各面/区間で同じ記号・系統位置・縮尺を使い、未出現種の空枠を除いて過去の消失系統を残す。生物量Bは台座面積で示し、P/Qへ宿主Bを付けない。全経路の数値と過去500T区切りは図鑑分析から参照する。
- 全Tの新原値をCSV、100T集計/境界値をJSONへ保存。旧無指定の世界/CSV/記録は保持し、欠測を現在値で補完しない。schema3の本文/定義/区間集計不整合を拒否し、新旧署名を経路で区別する。
- 操作は右上の開始/一時停止へ一本化。別画面の停止・同世界復帰/手動停止保持・世代と遅延応答を保護し、描画/確定UI/観測記録の失敗を区別する。故障注入で二重確定なく復旧できることを確認した（利用者の症状の原因を再現したという断定ではない）。
- 常設3パネル、集団構成の相/雌雄/年齢3本、独立横詳細、内外リングの説明へ接続。通常のCSV/集計説明、全個体一覧、詳細専用停止を撤去した。表示軽減は補間/追加演出/行動マーク/名札/状態/グラフ更新/操作中背景へ限定し、近景を強制記号化しない。
