## 変更した表示

- 潮環/葉環/抑環の既存9原画を近景へ接続。原画PNGは変更せず、9枠の参照矩形を完全な身体へ合わせ、切れ/隣接画混入を修正。
- P: firstは1、middle/extraは2、terminalはcounter8未満が2、8以上が3。Qはphase1〜3、探索中も実phaseを使う。宿主の性別・年齢補正を寄生群へ流用しない。
- 近景P/Qを別位置へ表示。QからPへの短い接続線で関係を示し、両方を選択可能。表示位置と選択/追跡位置をdisplay-planeで共通化。通常/相分離の双方に追従。
- 死骸は系統の第一相の基本輪郭を伏せ、低彩度・接地影・陸水の色調を適用。残存qで大きさ/外周欠損、経過時間で退色/表面差。3つの由来枠は別位置と奥行き順で表示し、セルの既存詳細へ接続。
- 生体・遠景/簡略記号、原画35PNG、生態計算/計算版/記録形式は維持。死骸を生体数へ加算しない。

死亡時の相/枝/性/年齢を保存するスナップショットは未実装です。第一相の輪郭を使うことは、死んだ個体が第一相だったという意味ではありません。死骸内の感染は既存詳細で確認でき、今回は死骸上の専用寄生原画まで追加していません。遠景死骸の専用輪郭も残件（既存×印維持）です。生態や感染能力の追加はありません。
