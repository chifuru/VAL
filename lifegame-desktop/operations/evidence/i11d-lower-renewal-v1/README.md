## 絶滅の原因

**被食が主因になる条件は多いが、生物・環境によって異なる。** `harvest` は身体を食べ尽くされた死、`combat` は戦闘死で、捕食されたことまで保証しない。個体の死因割合と、出生・摂取が死者を補えず系統が消える原因は分けて解釈する。

旧個体菌膜は高密度40×28/主160の3条件150Tで全滅。旧基準版の死亡中、被食35/40＝87.5%（河川）、37/43＝86.0%（湖）、34/34＝100%（疎林）。ただし別の40×28/主80の固定2条件を500Tまで見ると、菌膜は河川で被食20・寿命17・飢餓8、湖で被食36・寿命18・飢餓3。寿命と摂取/出生不足も無視できない。

草棲虫は旧500T湖で寿命61・戦闘20・飢餓1、河川で戦闘45・被食11・寿命27・飢餓4。全ての生物の絶滅を「食べられたから」と一括しない。[原データ](long/baseline-river-0-T500.json)、[湖](long/baseline-lake-1-T500.json)、[短期原因表](cause-table.json)。

## 菌膜の群落化と500T実測

利用者指示で、既存A1.2/A1.7・B4.3/B4.4/B5.2/B5.5/B5.6へ菌膜1マス1群落を採用。群落は基部1Bと有限の可食部/蓄えを持ち、通常採食で食べ尽くされない。既存有機物の実分解からEを得て、1.2E/Bを払って再生する。光合成/無条件補充はなく、維持不足が12T続けば消滅する。個体寿命80Tは適用せず、成立後Tと実績を持つ。再生は同ID、新群落は既存CA・出生費で別ID/親/世代を持つ。初期総E/B/M・初期群落数と明示0を増やしていない。

[製品モデル実行器](colonies.cjs)で同じ主80の固定2条件を50→150→500T。前半の草棲虫係数は入れず、各再実行の先頭原値は完全一致した。[全結果](colonies/comparison.json)、[河川500T](colonies/river-0-T500.json)、[湖500T](colonies/lake-1-T500.json)。個体と群落は異なる単位であり、この数を個体の生存確率へ読み替えない。

群落のフロー値は各T終端に生存する群落の実績合計で、死亡群落の直前分まで含む全体収支の総量ではない。全体のE/B/M保存は別途台帳・不変条件で照合した。

空の基部の残存だけでなく、後半450〜500Tも河川では同化222.67E・再生107.86B、湖では同化875.28E・再生648.71Bが実測された。新群落の死は河川31・湖39で全て維持不足の飢餓。死なない群落への変更ではない。湖終端は78群落中65群落が可食部0であり、群落数だけで餌在庫が十分とは判定しない。河川の草棲虫0は未解決。

新4の6実行で1,406状態の有限収支/不変条件異常0（先頭区間の再実行を含む）。主生物は河川152・湖209が終端に存在したが、全22系統/全初期値の生存・R1〜R6合格は認定しない。
