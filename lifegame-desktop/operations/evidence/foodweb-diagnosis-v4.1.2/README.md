# 修正後の食物網診断と分解者の食性修正 4.1.2

実行契約: operations/plans/foodweb-diagnosis-v4.1.1.md。基準main7282f14、通常植物/植物共生体の食性修正後から開始。R1〜R6、全体バランス完成の認定とは別。

## 計測と切り分け

before/lake-full.jsonは4.1.1の湖条件、0〜500Tの501状態について保存済み指紋と完全一致、不変条件エラー0。追加計測は世界/乱数/収支を変更していない。生体からの有機取得、光、支出、材料、死因、植物/小型餌の繁殖資格と近傍条件を集計した。birthGatesは各ターンの個体状態数で、阻害理由は重複する。確率や互いに独立の原因率ではない。

before/lake-food-only.jsonは同じ生成済みの湖から主生物/P/Qを除き、有限台帳を残存ストックに合わせた対照。地形と各餌の位置/E/Mは維持。製品プリセットや再生入力ではなく、この対照をR1〜R6の成功例に数えない。500Tで草本383、微藻60、菌膜175、草棲虫212が残った。本番の全餌消失を餌側だけの繁殖障害とは断定できない。

湖本番では草棲虫の死因は戦闘650/寿命546/栄養不足6。草本と微藻の最終死因は寿命で、世代更新が消費圧に追いつかない。草本の繁殖資格がある個体状態32978に対し、合法な近傍出生先も同時にある状態は1037。資格と空間条件の重なりを分けて扱う。菌膜には草本由来6213口・微藻由来156口の取得があり、現行の生体/死骸双方を含むためこの数だけを生体摂食数とは解釈しない。専用再現例と取得候補のコードで生体刈取りの仕様違反を確認した。

## 製品修正と検証範囲

v1.4で菌は「非生物有機物・死骸、光/生体刈取りなし」。4.1の隣接生体刈取りから菌を除外し、強制harvestも遮断。非生物有機物/死骸の隣接分解は維持する。吸収/光量/寿命/出生費/初期配分などの係数変更なし。4.1.2と生態再生署名を更新した。旧記録は削除せず署名違いの再生拒否を維持する。

tools/diagnose-foodweb.cjsの同期観測フックはfinallyで復元する。観測あり/なしの世界全体が一致すること、例外時の復元、対照の初期餌/地形/有限台帳保護をtests/foodweb-diagnosis.test.cjsで検査。tests/feeding-regression.test.cjsは菌の生体拒否と死骸/有機物利用、有限収支を追加。targeted.logは計8検査合格。

before/diagnose-source.cjs.txtは4.1.1観測時のツール原文（保管用）。before/source-hashes.jsonはその実行時点の製品/ツールのハッシュ。after/は4.1.2の新基準であり、4.1.1との指紋一致を主張しない。CLI --new-baselineを明示し、通常実行では旧指紋との差を検知して停止する。

## 初期生活環と次の候補

全3条件で水游虫が初期0。潮系一次寄生は微藻→水游虫→適合主生物の順に移るため、中間宿主が欠ける初期条件ではその生活環もQの成熟移行窓も成立しない。陸系一次寄生は別経路であり、P総数が多いことは水系経路の成立を意味しない。Qの窓を広げたり初期数だけ増やしたりする前に、中間宿主の実配置/存続を整える。

initial-placement-feasibility.jsonは既存の共同適地配分候補を4.1.2の入力へ適用した初期配置だけの診断。総food数と主生物数を増やさず、水游虫は履歴/自由の0→46、湖の0→71となる。植物と餌の種別配分は変わる。対応するrunnerとモデル/割当原文/状態コードのハッシュを保存。長期生存はここでは未計測、製品にも未採用。次はこの候補と、生産者の有限M留保/出生近傍の整合を個別に少数条件で比較する。修正前の旧23試行を採用根拠に再利用しない。

全体unitは166/166合格（unit.log）。今回の専用8検査も合格（targeted.log）、Manifest参照/階層/実在の構造確認も合格（structure.log）。正式Node状態は草案のまま。UI/Windowsの新しい合格認定は行わない。
