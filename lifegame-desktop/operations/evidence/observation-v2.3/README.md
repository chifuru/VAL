# 観測版2.3の限定検証

[遠景](overview.png)・[同じ世界/同じ90ターンの近景](detail.png)・[結果図鑑](results.png)は実装画面。近景は96px/マス、元モックの生物アトラスを使用。手描き景観の完成形ではない。

観測13項目、既存ブラウザ45項目、保存/再生3検査を実施。正確な件数はvalidation.jsonと各ログを参照。再生終端指紋一致・反復と中断で記録数不変・再読込永続化を実測。ソースはsource-hashes.json。通常実行の一時停止では保存しない。

Windowsの実exe検証、全系統の安定生存、1000ターンの勝者多様性は含まない。
