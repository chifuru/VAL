## 変更と有効条件

- 役割/対応軸・種別・所在環境は受信個体ごとに一度解決する。役割集合は直前のentries列挙から受け、空間占有層へ置き換えない。P/Qの相や個体の感受性・親/養育者・費用/予算の違いを保持する。
- 到達/視認できる近傍を所在マスごとに再利用する。受信中は個体が移動せず地形も変わらない。近傍順と拒否/読取の計上順は維持する。
- 内容キー/鮮度は内容オブジェクトの同一性で再利用する。同じ由来/内容IDでも普通の保持情報と死亡情報、歪曲/根拠が異なる別オブジェクトを混同しない。量・環境一致・伝達倍率を含めた受信強度は個別に計算し、乗算順を変えない。
- 学習済み由来の期限検索は由来→内容の一時Mapへ結果なしも含めて記憶する。検索元の `originId+"|"+contentId` 形式とactive索引をそのまま使い、期限更新の意味を変えない。学習済み検索は先頭一致を保つMapへ移し、追加・期限・64由来上限・2由来/T・同じ内容の再学習拒否を維持する。
- すべて受信走査1回に閉じた一時データ。世界/保存/Workerへ追加せず、次ターン・別世界・受信後の新生成情報へ持ち越さない。候補ソート・同点判定、費用支払・拒否/学習記録、演算/丸め・乱数を変更しない。既存のplace索引/作用は変更しない。
