## 確認した境界

- 開始時追跡→感染期限処理→P/Q維持と宿主からの有限徴収→徴収後Eの予算→一度だけ情報受容。費用は新方式の実維持額の1%。後の採食から前借りせず、同マスの別IDも独立して支払う。
- 1次6群＋2次3体、相変異量機9体の各実IDへ既存曝露条件を適用。代表1件だけに限定しない。卵も他の同居者が占有済みの場合に残る合法な宿主を選べる。
- 移動で記録した実接触pairを既存の有償宿主間移動候補へ加える。接触後に離れた相手にもその接触を根拠に一度試行できる。再呼出しで再支払・再試行しない。感染成功を保証したものではない。
- 新死骸・新生宿主・新分群保持者・移行中の待機保持者を同T感染行動へ使わない。旧植物の直接採食と、死亡Tに利用不可の新死骸を区別する。
- 同時に決めた採食量を実移転するとき、直前の残可食量を分母として曝露する。固定の初期割合を残感染体Eへ順次掛けて過少曝露しない。実消費量と実同化量は別に保持する。
- 部分死亡の実身体と成熟P/Qは一つの有限死骸へ移る。PのhostIdは死骸ID、QのhostIdはPのID。未成熟Pは既存の死亡・除外規則へ接続し、無期限の待機体へ逃がさない。群の残存個体と情報状態は同IDを維持する。
- 定着植物の全死亡も物理残存物へ接続。残存量と翌T利用を保持し、感染期限だけで栄養を消さない。
- 分群では同じP/Qオブジェクトを一度だけ移し、情報追跡も現所有者を参照。分群を後日「子の定着」として繁殖成果へ加算しない。群の身体成長や菌の再生を生産者成果にしない。
- 実採食・実分解・植物の実形成・E/M双方を満たす維持を情報経験へ渡す。役割分類を0〜5次の空間占有層へ置換しない。
- 死亡の情報生成判断は一回。開始時索引は固定し、末尾生成を同Tに受容しない。元経験・期限・役割・Q痕跡の意味を維持する。
- 小さな3T寄生/情報結合の生成元/生成物一致、Worker用差分/JSON往復を確認。実Workerの通常再生や500Tの開放結果ではない。
