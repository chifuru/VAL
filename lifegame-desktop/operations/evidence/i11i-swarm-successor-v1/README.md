# I11i 群体節足の後継群れ調整 / 4.2.54

既存記録では群体節足が長期7条件で残らず、後継繁殖型の不足が目立った。新規世界限定の後継モデルを追加し、繁殖型の娘、同群接近、低維持費、実貯精後の低費用出生、働育個体の有限給餌を接続した。他の主生物と旧無指定世界の生態係数は変更しない。

調整中の代表条件は40×28・河川・主160・5系統・菌密度.03・P/Q無効・供給有効・`survival/4`。後継娘確率.45、維持費.55倍、同群接近E25/補正.75、貯精後出生費40Eの段階では、群体節足は0T 32体、100T 44体、200T 23体、300T 6体、400T 1体、500T 1体（子孫の繁殖型）。同じ条件で出生費を30Eへ下げた段階は500Tで0体。費用単独の効果を成功として扱わない。

追加の試行条件は40×28・河川・主160・3系統 `swarm/solar/kelp`・菌密度.12・P/Q無効・供給有効・`survival/4`。女王の出生費30E、働育個体の2E給餌から最大1.5Eの移転を加えた段階では、100T 73体（子孫22）、200T 68体（子孫45）を観測した。利用者の指示により200Tで試行を中断した。この中間値は500T存続の証明ではない。

その後、利用者の指示に沿って、繁殖型娘確率.55、維持費.45倍、同群接近E20/補正.85へさらに優遇した。これが4.2.54の最終設定であり、最終設定の長期試行と追加テストは実施していない。先行段階では繁殖/有限収支・旧記録の再生境界について関連テスト4ファイルが通過したが、その結果を最終設定の検証済み報告に転用しない。生成観測モデルと再生署名は最終ソースに合わせて更新した。全系統の生存率、最終設定の500T群体節足存続、Windows配布、画面性能は未認定。
