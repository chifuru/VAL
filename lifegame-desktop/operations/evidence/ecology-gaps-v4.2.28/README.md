# 情報・菌膜・水中生産者の切り分け（製品4.2.28）

## 確認できたこと

生態処理を変更せず、既存の供給OFF/ON各500Tのcohortを再集計し、同じ代表河川の120Tを監視した。監視あり/なしの最終生態指紋は一致。不変条件を120状態で確認。8Tの追加診断は情報生成の入口だけを観測した。全条件の発生率や安定生存率は評価していない。

菌膜は動かない分解者であり、植物のような光E供給や生体捕食を追加して救済しない。生産者の被食耐性は利用者の採用方針として維持する。現在の水系基盤は存続しており、孫がないことだけを理由とする係数増は行わない。

## 次の修正順序

1. 情報の私有比較：内容なし粒子の成長時に近傍経験を参照する経路と、消滅後にも局所経験を足場としてCAが再始動する経路を分ける。B3/S23等の近傍更新、有限E費用、鮮度/文脈、撹乱、Qの媒介、DNAを変えない延長された表現型の方針を保持する。複数初期値で生成→取得→実適用が成立し、無限発生/情報への一極集中がないことを確認してから製品へ反映する。
2. 菌膜の私有比較：死骸/非生物有機物に到達できる範囲、可食部を保つ最低基体、寿命と出生可能期間、局所出生先を個別比較。捕食者不在対照を使い、飢餓・被食・自然死を区別する。全個体不死化・隠れた補充を避ける。
3. 水中生産者：まず局所の親が自然死した空きで、成熟子が有償出生できることを限定ケースで確認。環境枯渇/供給OFFも分ける。長寿基盤を500T内に無理に世代更新させる変更は優先しない。

## 記録と限界

- `report.json`: 既存OFF/ON各501状態のcohort要約、現行120Tの合計、指紋一致。

- `info-bootstrap.json`: 初期8Tの内容なし成長候補の検査。
- `source-scope.json`: 監視した製品sourceのhashと基準commit。
