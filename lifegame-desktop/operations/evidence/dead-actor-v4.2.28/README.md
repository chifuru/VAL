# 死亡済み行為者 — 4.2.28

## 原因と修正

行動段階では移動・戦闘・採食後に死亡判定があり、その段階のプレビューでは死亡済み個体が生存一覧から除去される。描画が生存一覧だけから行動を拾うため、実際に実行した行動まで消えていた。

同じ世界の直前状態と死亡イベントが揃う個体だけ、近景の既存モーション時間内に半透明の原画残像と確定行動を表示する。生存体と共通の行動効果処理を使う。元の個体数・命中/軽減・経路・採食結果には触れず、生体への復活・生存数/札/寄生/選択対象への追加はしない。モーションOFF・終了後・遠景・異なる世界では残像なし。128行為者/各4種類の既存描画上限は維持する。

## 限定照合

`node tests/dead-actor-ui.cjs`: 39項目。私有ケースで攻撃、防御、採食、除去、移動の死亡行為者を描画し、各行動の保持、生存数不変、選択対象外、名札なし、世界状態不変を確認。遠景/モーションOFF/終了後/世界変更を確認した。

実Workerでは健康だが寿命を超えた初期個体を検証用に設定し、採食後に寿命死する記録を取得。通常再生の行動段階に残像が現れ、最終生態指紋は同じ初期値の一括計算と一致した。自然発生率や長期生存バランスを検証した試験ではない。

`tests/death-motion-ui.cjs`: 既存37項目を通過。生存体の攻撃/命中/防御/採食/屍肉食/除去/成長/繁殖等、死亡時の雌雄・年齢表示、優先順、モーションOFF、生態状態不変を回帰確認。`living-regression/`に保存。

`departed-attack.png`は死亡行為者の半透明原画と攻撃を確認する私有描画ケース。死骸は地面に残り、生存相手だけに名札が付く。通常の全盤面外観承認とは区別する。`worker.json`/`report.json`は実測。
