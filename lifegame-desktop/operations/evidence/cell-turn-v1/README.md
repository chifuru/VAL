## 接続と照合

- 明示した新方式だけを既存の同期3段階へ接続した。第1段階は資源・寄生・情報の開始、第2段階は移動/交戦と共有取得/維持、第3段階は成長/出生・還元と確定。内部 `cellLife` と段階実行の処理順を揃え、旧CA供給や旧生活処理を重ねない。
- 生成元/静的生成物、直接の内部接合/一括/3段階、Workerのbatch/stream/final-onlyで同じ3Tを照合した。固定環境を読取共有し、動的在庫・身体・占有は私有する。段階途中の取消/失敗とプレビュー変更は元世界/確定観測へ漏れない。未解決水域、未知版、身体/生活状態の不足は推測補完せず拒否する。
- 実画面の作成条件で、水游虫の初期身体量を上限へ制限する前に内部コホートへ配っていた不整合を発見した。`CellLife.attach` の配分を制限後へ移し、B・内部コホートB合計・身体Mを一致させた。能力・上限・初期総数は増やしていない。
- 設定01に「従来のマス構造 / 多層のマス構造（比較用）」を追加した。従来が既定。新方式は設定04の「淡水の固定条件（比較用）」を明示選択して作成する。未選定は作成を非活性化し、旧セット/自動調整/支援補充を流用しない。戻る/切替/リセット/取消ではモデル・明示水域条件と観察中の世界を保つ。水域係数は引き続きC/D比較値である。
- 実フォームから河川40×28・主84体・少数系統の世界を生成した。自動生成された実効設定は [initial-config.json](initial-config.json)。この同じ条件を12T進めて保存し、通常/2倍/最速で再生した。すべてT12の生態指紋、T0〜T12の13行全原値が一致。最速の10T表示は最後の端数もT12へ反映した。個体選択/表示変更で継続し、停止中は確定T/行数を保ち、再開できた。
- 再生だけでは既存1記録から保存数が増えない。保存6項目は本文検査、初期条件からの再計算、明示保存だけの別ID、破損/保存失敗時の保護を今回の署名でも照合した。
- 500T停止境界は時計を499へ設定した2Tだけで検査した。500T自然進行の試験ではない。既存の500T単位、主生物全滅の終了条件、速度/全T集計の意味は変えない。

最終生態署名は `c7b6198bf4f96dabd400a3b131a50859210ca21b8618183228712407d16a6721`。旧方式だけ、直接一致を確認した起点の再生署名へ接続する。以前の内部新方式の署名を、新しい自動行動の再生へ別名接続しない。既存記録の閲覧と異版の再生拒否を区別する。
