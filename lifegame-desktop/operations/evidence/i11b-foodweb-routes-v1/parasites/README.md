# I11b P/Q初期成立・経路・局所判断

基準main `1b248aa` / 4.2.43。契約 `operations/plans/i11b-foodweb-routes-v1.md` と既存A1.5/B4.2/C7.5/D8.2へ接続した。project-local core3の前提・実行/報告制御、寄生生活環/比較開始値を実読した。Node/core/A/Bの編集、系統/食性/生活環の追加は行っていない。

本資料は50T以内の原因診断と局所境界であり、自然長期循環の合格ではない。v2の初期年齢はroot担当のsource変更をFactoryから読み、生成済み8モデル/最終署名の照合前に診断した。JSONの `generatedProductsNotYetBuilt: true` とsource SHAを保持する。旧生成物の署名95b740…をv2採用版の署名として扱わない。採用版の生成/署名検査はroot側へ接続する。

## 初期未配置と維持失敗の分離

同じ固定生成条件を、初期後の個体追加/編集なしで比較した。陸はwoodland・主80（precocial/solar）・草棲虫80・P初期比率.5。水はlake・主80（jelly/whale）・藻80/淡水光合成20/水游虫80・同比率.5。初期直接数/供給/優遇/seed/不足理由をJSONへ保存した。

| 陸 | 82 / 4 | 103 / 7 | 寄生2・自立5 | 13 |

## 宿主内の消失理由

`attached-trace.json` はv2初期attached Qだけを15T追跡した。陸の2群体は両方T2にPがgroom除去され、水の1群体はT11にPがimmunity除去された。いずれもHはHP100・十分なEで生存していた。陸では同Tの複数仲間のgroomが加算され得る。今回この対処能力を制限/変更していない。

Pの任意放出は次T留保を持たず、観測した陸PはT1放出後E.07/.08まで下がった。一方、その直後のQ消失はgroomと判明したため、放出費を原因と断定しない。満額要求でのP III収支は `.10-.06-.01-.04=-.01 E/T` だが、実装はQ税を実残高まで切る。即P餓死という意味ではなく、P放出余力やQ発育/羽化留保の不足候補である。

## 今回の採用差分：満腹Qの資源固着

旧scoreは満腹でも資源利得係数.5が残り、資源上の滞在利得.5→隣接移動.25の損失が、安全な可視宿主へ近づく利得約.15を上回った。`forage-priority.json` の8T局所fixtureで、E1のQは資源があると距離2のまま8T滞在し、同配置で資源がなければ1T後距離1、2T後同セルへ進んだ。これは修正前の診断結果である。保持したrunnerを現在sourceで再実行すると修正後を測る。

`survival/2` だけ、資源利得を以下に制限した。

- 卵1回＋既存4T維持に必要な有限Eの不足。十分に蓄えていれば資源利得0。
- 実資源/死骸量、既存採食上限、同化率で取得可能なE。情報や視界外の資源を含めない。
- 可視宿主cue、実際の捕食者、移動費は既存条件を維持する。内部成熟時計/遺伝適合を透視せず、窓外や費用不足を突破しない。

`unit.log` は新5件＋従来6件の11件成功。空腹採食/必要量確保後の接近、満腹時の接近、有限収支、情報/遠方除外、窓外拒否と有料卵を検査した。版なしとsurvival/1それぞれ8Tの全world/RNGを `1b248aa` の旧parasite APIと完全一致確認した。既存6境界の挙動も保持する。

## 未採用の比較候補

Q初期E.35、P III徴収.12、可食曝露8Tを診断overrideで組み合わせたが、両条件のQ新定着/羽化は0のままだった。第一→中間定着も一様には改善しない。各係数の独立した因果効果を確認した比較ではなく、既定値に採用しない。

P徴収.12でも遺伝費factor1.25では満額の支出予算を賄えず、宿主負担も増える。Q初期E増は初期自立群体の猶予だけで、娘Qの成立時Eは.08のまま。放出の次T留保・有限な自立予備を蓄えてからの羽化・groom/排除の強さは、今回の実消失理由や実会計を踏まえた後続候補とし、今回変更していない。

窓延長、娘PへのQ自動継承、救済spawn、寿命だけの延長、隠れた宿主/資源追加は採用していない。後続では同じ固定条件の宿主継続・実窓と接触・有償羽化・同QIVと子の定着を結合して測る。今回の局所成功/初期Q残存をR5達成として扱わない。
