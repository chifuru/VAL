# 未選定・未接続・既定化の照合

対象 `2f877a2`。今回の照合ではA/Bの意味・数値・対象種・枝や既定モードを変更していない。以下は現行正本/実装/既存証跡の区別である。

| 対象 | 現在成立しているもの | 残っているもの | 明示比較の利用を止めるか |
| --- | --- | --- | --- |
| 海生光合成系kelpの樹冠 | 面積1/高さ帯0と既存の相・年齢・光係数で有限な共有光へ接続 | 専用の高さ・面積・生産優位の係数 | 止めない。比較用の接続が既に明示されている。造形から数値を推定しない。 |
| 移動する淡水光合成体の樹冠 | 高さ帯0、相別の既存面積/受光・年齢・実残存膜で光の捕捉を制限 | 専用の樹冠係数 | 止めない。4次の移動個体/生産者という扱いを維持する。 |
| 低次植物の稀な群落移動 | 現行は定着・繁殖・衰退を処理。上位仕様でも移動は任意で、移動できる種類に限定 | 移動可能な種の指定と全群落移動の接続 | 止めない。任意の移動機能が完成したとは言わず、帳尻合わせで全植物を動かさない。 |
| 定着する高次植物の再生枝 | 表現型には既存の1.2係数を保持。通常の有限な形成/再生は動作 | 新しい固定合計形成上限の下で、その再生枝の専用効果を接続すること | 止めない。ただし枝の効果は未接続。数値そのものが無いという意味の「未選定」と区別し、上限へ単純に乗算しない。 |
| 淡水光合成体の再生枝 | 既存の1.2係数を専用の有限形成で使用している | 専用樹冠等の後続項目とは別 | 止めない。定着植物の未接続と混同しない。 |

| 既定モード | 従来方式が既定、多層方式は利用者が明示選択 | 既定変更の採否 | 現行の限定比較を止めない。今回、既定を勝手に切り替えない。 |

根拠：

- [マス仕様4.2](../../../design/specification/cell-reorganization-v1.md)：専用係数・戦略は後続。5.3は群落の移動を任意・適格種に限定する。
- [C/D契約5.3〜5.5・6.1](../../../design/implementation/cell-reorganization-v1.md)：kelp/淡水の比較接続、明示水域選択と通常進行の範囲。8節は実装前の独立したゲーム仕様確認が現時点で不要とする。
- [CR04証跡](../cell-life-v1/README.md)：高次植物の再生係数を保持しつつ、新しい固定合計形成上限への作用は未接続と明記。
- [state.js](../../../src/ecology/state.js)：CellLifeの再生係数とLargePlantの再生係数。[reproduction.js](../../../src/ecology/reproduction.js)：前者の形成式はage.productionを使い、後者の淡水専用形成ではregenerationFactorを使用。[nutrition.js](../../../src/ecology/nutrition.js)：共有光への接続。[behavior.js](../../../src/ecology/behavior.js)：現行の移動接合は3/4次を対象とする。
- [水域比較契約](../../plans/cell-aquatic-resources-v1.md)：有限値と導出を持つC/D比較版であり、A/B正式採用や配布版既定化ではない。

現行の限定比較を継続するための追加質問はない。専用係数・種の指定・枝効果の接続/固定上限との整合・A/B正式採用/既定化は、それぞれの後続課題として保持する。過去の生存目標は残し、今回の照合を多数条件の生存試験へ広げない。
