# 選択詳細の切り抜き表示/1・限定証跡

基点main 222bcfd / 4.2.72。2026-10-23 UTC、Linux Chromium。契約: `design/specification/inspector-cutouts-v1.md`、計画: `operations/plans/inspector-cutouts-v1.md`、D9検査: `tests/inspector-cutouts-ui.cjs`。

## 原因・対応

P/Q・独立植物・量機の盤面には透明アトラスがある一方、詳細/系統樹の多くは背景/文字付きの参照図を直接切り出していた。`baseline/preflight.json` の68状態中65状態は、描いた範囲がほぼ不透明な矩形だった。QのI〜IIIは既存の透明経路が機能していた。

既存アトラスと全身境界bodyBoundsを読み、透明な全身だけを詳細/系統樹へ描く。実行時の背景判定/画素走査/新規マスクは追加しない。採用図や相/枝の割当、盤面関数、生態規則、保存形式を変更しない。旧参照図も削除しない。

## 限定結果

`report.json` の12項目が成功。P18（2系統×3形態×3相）、Q4相、植物33（3系統×11相枝）、量機13（通常11＋相変異2）の計68状態が表示され、全てに透明な輪郭と外縁余白がある。背景矩形のままの状態は0。68画像は区別され、描画入力は不変。

実際に配置したP/Qを選んで画像と本人相を確認した。PをIII相/第一宿主とする表示fixtureで本人IIIを確認し、宿主段階だけ終宿主へ変えても画像は同じだった。詳細の手動更新が指紋を変えず、P三相/Q四相の系統樹も維持された。検査の一部は表示fixtureであり、自然な相進化/感染成功/羽化の実測ではない。ブラウザ例外0。

`examples.png` は代表18画像。`baseline/examples.png` は同じ状態の修正前。背景比較用の資料であり、ゲームのUI画面そのものではない。

## 変更を限定した根拠

`report.json` に、producer/ryouki/parasiteの盤面関数とparasitePhase/parasiteIndexの基点との同一性、7枚のアトラスのSHAを保持。素材と盤面関数のバイトは変えていない。盤面の全条件ピクセル回帰を実施したとはしない。

従来の3つの素材確認テストは、背景付き原図の一致を期待していた部分だけ透明アトラスの全身切り出しへ更新し、構文検査を通した。これら3本の全実行は行っていない。今回の実行範囲は上の新規12項目/68状態であり、以前の証跡は各対象版の範囲を維持する。

## 限界

主生物全系統/全餌/全地形素材の再生成・全検査、画像読込失敗の全経路、高DPI/Windows/長期生態/配布は対象外。本人相の表記と既存の相対応は機能していたため、相や型の追加実装はしていない。中断中の速度変更は反映しない。
