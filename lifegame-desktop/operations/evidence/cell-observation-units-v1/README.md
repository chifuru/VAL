## 記録契約と有効条件

新方式は `cell-occupancy-observed/1` と種別の `populationUnits` を明示する。既存の旧下層/量機の観測定義を、新方式の上限や容量へ読み替えない。新記録では層/種の管理数・人口・占有マス、定住人数/枠・移動、実B/基部/可食部/E/M/身体M、集計在庫と利用待ちを保持する。毎Tの全ID/全マス状態は新規記録しない。

`source-hashes.json` に一致する実装/検査入口に対する限定証跡。集計・分類/単位・入力状態・構成・Bの読取元・定義版・CSV/復元条件を変更した場合は該当検査を再実行する。正式状態は草案。前工程の描画/選択証跡と生態の71項目は、それぞれの対象版/範囲に限定し、今回再実行したと扱わない。

これは小規模fixtureの観測接続である。初期設定/説明の全経路、ゲーム図鑑保存・初期条件再生、通常観察公開、連続操作/全速度、自然多世代循環・500T・性能/Windows/配布の完了ではない。未選定の樹冠・群落移動対象種/再生枝とCR07も後続。
