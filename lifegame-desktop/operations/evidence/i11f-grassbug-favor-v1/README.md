# I11f 草棲虫の水游虫相当優遇 — 限定証跡

対象: 4.2.48、`consumer-group-parameters/2`。固定条件は `i11d-lower-renewal-v1/check-cases.json` の河川0・湖1。`compare.cjs` は各ターンの不変条件を照合し、同一設定の人数・集団数・出生/損失を `*-T*.json` に保存する。

| 条件 | T0 草棲虫 | T50 草棲虫 | T50 水游虫 | T500 草棲虫 | T500 水游虫 |
|---|---:|---:|---:|---:|---:|
| 河川0 | 33 | 112 | 118 | 未確認 | 未確認 |
| 湖1 | 33 | 193 | 114 | 1526 | 405 |

前版4.2.47では河川T40、湖T269までに草棲虫が消滅した。今回の限定比較では両地形で存続し、湖ではT500まで維持された。一方、湖の草棲虫は最大1530体、終端1526体まで増えた。生息域の広さが水游虫と異なるため、同じ生存能力値でも生態系内の個体数は一致しない。過密と描画/計算負荷の懸念があり、「バランス完成」「性能達成」とは判定しない。河川500T、全系統の存続率、R1〜R6、自然P/Q循環、Windows実行は今回の検査範囲外。

`tests/consumer-groups.test.cjs` で新版の実効値、設定版1の旧値、有限収支、旧保存署名からの再生を検査した。既存ブラウザ集団表示の限定検査は16項目成功、例外0。旧I11eの証跡は元の版のまま保持する。
