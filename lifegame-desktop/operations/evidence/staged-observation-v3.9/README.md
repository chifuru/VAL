## 基準速度と三段階

自動観察の基準は一つ、1ターン約2秒。資源更新→移動/採食/戦闘→成長/繁殖/供給の三段階でイベントループへ制御を返し、プレビューを描く。餌の集団を先に優先決着させる変更はしていない。元の同期・競合調停・全個体の計算順を保存する。段階表示は最低180msずつ露出させ、負荷超過時は減速する。生物やターンは間引かない。手動の1ターンは即時確定で、同じ段階処理を一括実行する。

未確定世界は私的コピー。個体数・ターン番号・推移・図鑑は確定後に更新する。途中プレビューを明記して詳細選択を止める。停止/リセット/再設定/終了は未確定分を破棄し、最後に確定した世界へ戻る。世代トークンとジョブ同一性で古いタイマーの確定を拒否する。表示用コピーを書き換えても確定結果へ影響しない。
