## 実装と比較開始式

`state.CellLife` に菌の生活型・身体上限を接続し、`nutrition.CellResources` が要求・取得・死骸・背景分解を管理する。`reproduction.CellLife` が実費形成/出生/不足を確定する。`engine.cellLife` は支払→死亡確定→取得→維持→生活→背景の内部入口であり、未接続の主生物維持を無償0に補わない。

採用数値を保ったうえで、以下を比較開始式として具体化した。A/Bで新しい保証や気候変動を採用したものではない。

- 菌の維持と処理能力は実B/4に比例する。当Tに形成した組織を処理能力へ即時利用しない。
- 菌用気温係数は −10℃=0、5℃=0.2、20〜30℃=1、45℃=0。菌用pH係数は2=0、4=0.6、6.5=1、8=0.7、11=0の区分線形。範囲外は端点値。共通の土壌の質を一回掛け、実水分は保持上限半分で十分とする。
- 生物分解の共有水分費は身体換算1あたり0.05。Bのない有機物も `max(E, M/0.02)` を有限処理単位とし、無償の無機化を作らない。実源のE/M濃度から要求充足を評価し、1B=1Eを一律に仮定しない。
- 背景分解は残存物の0.001/T×上記環境係数。Eは熱、Mは次Tの0次へ一度だけ移す。容量不足のMは元の有機物へ保持する。菌の維持Mは次Tの有機物へ戻す。
- 腐敗負荷は同マスの残存有機E×環境係数の合計から `clamp((合計−40)/160,0,1)`。経過時間そのものによる罰ではない。無機質だけの骨等にE由来の負荷を付けない。
- 取得時の丸めは過剰移転を防ぐ切り下げ、共有水の支払は合計後に最小単位へ切り上げる。細かな残量も物質会計へ残す。
