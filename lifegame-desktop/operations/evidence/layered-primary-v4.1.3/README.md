契約: operations/plans/layered-primary-v4.1.3.md。製品4.1.3は変更しない。design/layered-primary/model.cjsは現行ソースを私有コンパイルし、既存の共同適地配分/適地移動を基準に、植物・菌のfood枠と動く餌のprey枠を分ける。主生物はmain枠。各枠1個体を維持する。

水游虫は全条件で500Tに0。草棲虫は混合の両条件で子孫が再繁殖し500Tへ残ったが、主/P/Qを除いた下層対照は最終的に生産者/一次消費者とも途絶えた。混合と下層は寄生系の有無も異なるため、この差を捕食者だけの因果効果と断定しない。湖の主生物は89→26であり、餌の存続改善だけを総合改善として扱わない。

追加の「植物/菌のみ」対照は、自由960体（植物541）、湖951体（植物563）が500Tへ存続した。同じ地形/基底初期生物/資源を用いて動く餌も除き、残存ストックで台帳を開始する派生条件。これらの植物数は微藻/草本等の合算で、水域だけの数とは異なる。主/P/Qなし下層との違いは動く一次消費者の有無であり、生産者の内因性更新だけでは説明できない結合上の問題を示す。単に光や初期数を増やす調整へは進まない。

## 判定と残件

- 占有分離は実装可能で、植物上の採食・出生・捕食/寄生接触を維持できた。草棲虫の混合存続には改善例がある。
- 生産者と動く一次消費者の長期更新、特に水系の経路は未達。生産者の可食部再生/被食後の出生資格・材料と、一次消費者の消費・出生による圧力を分けて次に測る。
- 現行の動く餌はMの吸収/子への割当が0。肉を経由した材料移転も、エネルギー移転とは別に確認が必要（nutrition.efficiency/reproduction.child）。今回の占有分離に便乗して変えていない。
- 製品の描画/選択/保存・再生/Workerへの3枠接続、全体検査と署名変更は未実施。今回は製品未採用。新しい浮遊微藻/水生植物や死骸の詳細描画も未実装。
- R1〜R6や固定10+別3条件の認定ではない。基底の自立と、草食動物を含む下層だけの常時安定、全体の安定を区別し、対照の崩壊も結果として保持する。
