# グラフとピラミッドの判読性/1・限定証跡

基点main 5f3dd88 / 4.2.72。2026-10-23 UTC、Linux Chromium、DPR1、40×28/主24の実Worker。契約: `design/specification/graph-readability-v1.md`。計画: `operations/plans/graph-readability-v1.md`。D9検査: `tests/graph-readability-ui.cjs`。

## 反例と修正

`baseline/preflight.json` と2画像は修正前のレイアウト測定。停止中に1460×1030から1280×800へ変更すると、集団構成の表示幅は200.59pxになったが、bitmap幅は265pxのままだった。ターン/対象が同じだとグラフ描画が省略され、CSSだけで旧画像を縮めていた。

グラフの4つのcanvasの実寸をResizeObserverで監視し、寸法/DPRが変わった時だけ1フレームへまとめて再描画する。ウィンドウサイズ変更と図鑑分析への移動を対象にし、世界の進行/選択詳細/停止意図は変更しない。1280×800で構成bitmapは201×44、個体数bitmapは230×120へ更新された。最大の縦横比誤差は1.464から0.0093未満へ低下（ピクセル丸めを含む）。性能倍率ではない。

既存の微量層の8px最小幅と五層/0の区別は既に機能していたため、作り直していない。ただし0.001 Bは従来の小数2桁表記で0へ丸められるため、正の0.01未満は「<0.01」とし、titleへ実数Bを保持する。

## 限定結果

`report.json` の13項目が成功。1460×1030/1280×800の3カード横並びとピラミッド左の配置、水平はみ出しなし、停止中の再描画と原値/指紋/停止意図の不変を確認。レイアウトが落ち着いた停止中200msに継続的なグラフ再描画がないことも確認した。

五層の表示fixture `[1e8, 1e4, 10, .001, 0]` は、0を0幅、正の微量を8px以上、0.001を「<0.01」/正確なtitleとして確認するためのもの。自然な食物網や生態バランスの結果ではない。保存前に実データへ戻している。

実際の図鑑へ保存・結果分析・画面サイズ変更・ライブ復帰でもcanvasが実寸へ一致。再開後のサイズ変更でもWorkerが進行し、ブラウザ例外0。画像は `summary-initial.png`、`summary-resized.png`、`archive-graphs.png`。測定と撮影はレイアウトの比較であり、別実行間の生態結果の一致を主張しない。

## 限界

既存配置/図の意味/グラフの原値/生態計算/画像素材/保存形式/正式状態は維持。全件回帰・長期生存・Windows・配布は実施していない。狭幅画面全体/高DPI/全端末の判読性や、既存の全凡例の網羅的な表示は認定しない。3速度/10T表示の中断案は反映していない。
