# 作成条件全体復帰/1・限定証跡

基点main ced3a7b / 4.2.72。2026-10-23 UTC、Linux Chromium。契約は `design/specification/setup-defaults-v1.md`、計画は `operations/plans/setup-defaults-v1.md`、D9の検査は `tests/setup-defaults-ui.cjs`。

## 対象と結果

設定画面上部の全体復帰ボタンから、フォームの起動時デフォルトへ戻す。生成ロックと内部の生成基準値を消去し、供給入力の非活性状態、モード、最低人数、入力エラーを同期する。下層だけの復帰操作は維持する。現在の世界や描画設定を初期化しない。

`report.json` の13項目が成功。起動直後と復帰後の作成条件、チェック値と非活性状態を比較。固定モード/変更済み条件/不正入力からの復帰、ロック解除と再作成可能な状態、世界指紋・観測行数・図鑑件数・世界世代の保持、表示設定の保持、取消後の元世界の進行再開を確認した。

保持確認には40×28/主24の実生成世界を使用。高生産の自動生成で解決済みの内部基準値を持つ状態から戻している。最後にデフォルト条件で実際に標準80×56の新世界を作り、観測画面へ移ることを確認。ブラウザ例外0。

## 限界

生態規則/画像素材/正式状態は変更しない。既存生成/観測復帰の全件試験、長期観察、Windows、配布物、速度変更の中断案は対象外。全条件の生存や性能は認定しない。版番号は据置。
