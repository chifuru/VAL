# I03 独立植物3系統の限定検証

対象は開発版4.2.35、基準main `66bfd0d` / 4.2.34。[実行契約](../../plans/i03-independent-plants-v1.md)に従うFLOW-05/08の記録。Nodeの正式状態は草案のままで、I03の接続と実測範囲を示す。

## 実装対象

森冠 `forestcrown`、星冠 `starcrown`、移動する淡水光合成体 `freshwaterlight` を独立した生産者として追加。三種合計で一セル一個体の `producer` 枠とし、主生物・基底群落・一次消費者と共存できる。本体2B、有限可食部、E/M、年齢、相、枝、実績を区別する。通常被食は可食部を移転し、本体が生存して予算を満たせば同じIDで再生する。

成熟したI/II相にも有償繁殖を認め、子は新ID・I相・年齢0・可食0。経験は実維持・生産・被食後再生・子の定着から最大1/Tを得る。III三枝、IV各二枝は32Tの実支出配分から選び、到達前に能力を発効させない。森冠/星冠は定着、淡水は全相で合法な局所1歩を有償移動する。新P宿主経路や海の環境は追加しない。

`largePlantModel:'independent/1'` と `producerModel:'colony/1'` を明示した世界にだけ有効化する。旧カタログ31種を変更せず、新世界は世界別カタログ34種を使う。光は同セルの一つの有限予算を分け、土壌Mも同じ在庫から支払う。比較開始値の採用は最適値の認定ではない。

## 検証の入口

- [経路照合](model/paths.json)：旧モデル/I02の8優遇設定それぞれ、計16条件112状態で世界・指紋・全CSVを基準mainと照合。新モデル8条件40状態で静的生成と動的生成を照合。
- [循環記録](model/circulation.json)：河川自由/湖沼自由/河川供給の3条件各180T、計543状態。不変条件と有限収支を検査し、全確定ターンのCSVを同ディレクトリへ圧縮保存。3植物すべてで生産・被食後再生・出生・IV到達を確認。
- `tests/independent-plants.test.cjs`：占有/初期0、有限光/再生/採食、成熟/出生費、経験/全9枝の優勢選択、準備費、死亡、淡水の全相移動等。
- `tests/independent-plants-flow.test.cjs`：全ターン観測・図鑑保存/再生・欠測拒否、旧署名の新植物拒否、旧31種互換、実Workerの3段階と確定後再開。
- `tests/independent-plant-observation.test.cjs`：個体/群落の単位、全ターン原値/CSV、復元、未知版/欠測、旧snapshot/CSVのbyte一致。
- `tests/independent-plants-ui.cjs`：初期設定、個体横詳細、11形態の系統樹、グラフ/保存分析/再生、同セル選択、旧世界表示、狭幅。画面・結果は `ui/`、最終の実行結果と対象hashは `verification-summary.json` / `source-hashes.json` を参照。

全単体60ファイルが成功。画面は新規50＋群落23＋供給24の計97項目、既存遠景の回帰15項目、描画専用9項目（33形態/原画portrait一致/透過/年齢差/4枠選択/生態不変）で、合計121項目が成功し、ブラウザ例外/画像読み込みエラー0。素材照合は [描画記録](graphics/graphics-report.json)、既存遠景は [遠景記録](overview/report.json)へ分離した。同セルを作った選択用fixtureは自然発生の生存試験と区別する。

検査中に、共通維持費が省資源枝だけへ帰属する誤りと、蓄え満杯の受光0を暗所と見なす誤りを修正。共通費と枝専用準備費を分け、容量制限前の有限な受光機会で判断する。明所/暗所の境界検査と、修正後の全経路・循環を確認した。個体別の全索引再構築/親探索を確定索引1回へまとめた最適化は、修正前の543状態と全結果が一致（`model/index-parity.json`）。枝の意味修正による結果変化とは区別する。

## 観測・保存と素材

定義は `independent-plant-state/1` / `independent-plant-parameters/1` / `independent-plant-observed/1`。全確定ターンで陸水別の個体数・本体/可食/容量B・蓄えE/M・生産/再生/被食・光入力を保存する。欠測や未知版を0で補わない。旧署名互換は新モデル指定のない条件へ限定する。

採用画の正確な原画portraitと、盤面用の透明な派生atlasを区別する。原画の再設計は行わず、画像編集ツールで背景/文字等を除いた33形態を静的に格納する。原図/crop/派生素材/hashは [素材台帳](../../../design/appearance-runtime-v1/registry.json)へ接続し、実行時の背景除去や囲みカードを追加しない。

## 実測範囲の限界

180Tの固定条件の成立例を、500Tの生存率/R1〜R6、全枝の自然発生率、全端末性能、Windows新配布へ広げない。循環の種別量は各ターン終了時に残る本体のサンプル合計で、死亡本体を含む全移転量は地域別の全ターン観測を正とする。群落/独立植物が生産を支えても、分解者やP/Q等の後続バランスは未完。

透過atlasはI03の観察接続用であり、全年齢/全方向/密集時の最終素材ではない。発光縁等の仕上げと描画全体の最終確認はI10。現在のWindows配布は4.2.32のまま。次の実装単位はI04「量機」。

経路比較を再実行する際は、基準commit `66bfd0d` の `src/ecology/` を `/tmp/valis-i03-baseline-66bfd0d/ecology/` へ展開して `model/paths-script.cjs` を実行する。循環は `model/circulation-script.cjs`。いずれもプロジェクト直下を作業ディレクトリとし、現在の静的生成物を使用する。描画試験の初回fixtureは初期占有の制約へ合わせて修正しており、成功するための生態ルール変更は行っていない。
