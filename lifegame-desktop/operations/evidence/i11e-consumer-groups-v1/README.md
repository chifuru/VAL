# I11e 一次消費者の小集団化 — 4.2.47

草棲虫・水游虫を1マス1小集団へ接続した。植物・菌膜の群落、主生物・大型植物の個体単位を維持する。これは採用された構造変更の実装と限定比較であり、下層全体の生存バランス完成ではない。

正本は[小集団仕様](../../../design/specification/consumer-groups-v1.md)、[実行契約](../../plans/i11e-consumer-groups-v1.md)。基準main `23b2e18` / 4.2.46、新規設定 `consumerModel: group/1`。生態署名と集計は[verification-summary.json](verification-summary.json)。旧記録は小集団モデルへ変換せず、従来の個体経路で再生する。

## 実装した範囲

- 初期総人数・E/B/M・P/Q数を保ち、同種の近傍個体だけを束ねる。比較開始値は上限8体、初期上限4体、内部出生上限2体、分散開始4体。
- 内部の人数・相・年齢区分・有限栄養・傷害を持つ。部分死亡の材料だけが死骸へ移る。成熟個体が費用を払い出生し、子はI相・年齢0。集団の経過時間で一斉に寿命を迎えない。
- 分散/合流は人数と材料を移し、移動費を払う。出生/死亡へ水増しせず、同じターンの再分散/出生を防ぐ。
- Pは内部の感染代表1体へ対応させる。その個体の部分移動/死亡へ同じP/Qを一度移し、全員感染や複製にしない。
- 全ターンの内部人数・集団数・相/年齢・出生/死因/分散を記録。既存画面の詳細・単位・人数バッジと説明を更新。個体数と集団数、生物量は区別する。画像素材・画面構成は変更していない。

## 固定条件の結果

前回の[同じ河川・湖条件](../i11d-lower-renewal-v1/check-cases.json)を使い、既存の供給/優遇を保持。全条件の生存率を推定する標本ではない。

| 条件・時点 | 旧個体モデル 草棲虫 / 水游虫 | 小集団モデル 草棲虫 / 水游虫 | 小集団数 草棲虫 / 水游虫 |
| --- | ---: | ---: | ---: |
| 河川 初期 | 33 / 34 | 33 / 34 | 17 / 23 |
| 河川 50T | 0 / 47 | 0 / 123 | 0 / 42 |
| 湖 初期 | 33 / 34 | 33 / 34 | 15 / 19 |
| 湖 50T | 22 / 80 | 52 / 121 | 26 / 73 |
| 湖 150T | 23 / 92 | 31 / 259 | 16 / 113 |
| 湖 500T | 42 / 103 | 0 / 490 | 0 / 134 |

河川の草棲虫は40T、湖では269Tで絶滅した。湖は150T時点で世代更新が続いていたため、同じ状態を引き継いで500Tまで延長した。明確に失敗した河川を再び500Tまで回すことはしていない。湖500Tでは主生物256体が存続した。

草棲虫の個体収支：

- 河川：初期33＋出生17−戦闘16−直接採食8−栄養不足15−寿命11＝0。
- 湖：初期33＋出生282−戦闘51−直接採食0−栄養不足18−寿命246＝0。

戦闘死は捕食の成立と同義ではない。湖では寿命による世代交代を出生が長期には補えず、**群れ化しても草棲虫の生存は改善しなかった**。水游虫には前版の優遇された寿命・維持費が残り、500Tで490体（134集団）。両種を同じ係数に揃えてはいない。

内部個体ごとの分散延べ数は湖で草棲虫294、水游虫9,310。頻繁な分散/合流が費用や個体数へどう影響するか、草棲虫の採食可能な場所・出生頻度と合わせて次に相談する。今回の結果から勝手に寿命・出生・供給の追加優遇を採用していない。

- [旧計算との一致](model/legacy-parity.json)：旧survival/4の8優遇構成と旧3/2/1/版なし各1構成、24状態・12全期間観測スナップショットが基準ソースと一致。
- [生成元との一致](model/source-parity.json)：新モデル8優遇構成の16状態が製品の生成コードと一致。
- [河川50T](comparison/river-0-T50.json)、[湖500T](comparison/lake-1-T500.json)：各ターンの有限収支/占有等の不変条件と「前人数＋出生−死因別人数」を照合。再開用の全世界一時ファイルはリポジトリへ追加していない。
- [Linux画面16確認](browser/report.json)：実Workerの停止/再開、直接計算との指紋・全観測一致、群れ詳細、IndexedDB保存、再生の初期値/1T一致、明示再保存の別記録化。[実画面](browser/consumer-group-detail.png)を目視確認。

生態比較中に個体世代別funnelへ混合世代を誤計上しない修正を入れ、最終ソースで比較を取り直した。最初の50T試行は上表へ混ぜていない。画面検査の初回はlocalhost権限で起動できず、環境のネットワーク権限を付けて再実施した。生成元比較の初回は量機モデル指定が不足した検査設定を修正した。失敗を生態結果へ読み替えていない。

残る判断は草棲虫の長期更新、水游虫の個体量と分散頻度、P/Q自然循環、全系統R1〜R6・性能。新Windows/ZIPの作成はI12。既存61Nodeの正式状態は草案を維持し、既存Manifestへ現在の範囲だけを反映する。
