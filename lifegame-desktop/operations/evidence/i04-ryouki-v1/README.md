# I04 量機の限定検証

対象は開発版4.2.36、基準main `04b7bf6` / 4.2.35。[実行契約](../../plans/i04-ryouki-v1.md)に従うFLOW-05/08の記録。Nodeの正式状態は草案のままで、I04の実装と実測範囲を区別する。

## 実装対象

量機を独立した主生物として登録。通常型は相ごとに移動/感知1・2・3・4、相変異中は全相3歩。密度6以上3Tで変異し、2以下6Tと本人だけの通常枠で解除する。進化相・枝・本人年齢・ID・経験を相変異で巻き戻さない。同居中の解除は待機し、個体を削除したり無償移動したりしない。

変異した量機同士だけ同セル最大3体。各歩で通行・有償予算・残容量を調停し、成功した経路だけを確定/表示する。攻撃・配偶・清掃・寄生を実IDで選び、食料在庫と個体数を複製しない。同居死亡の各死骸とP/Qを保持する。子は有償で通常型I・年齢0・経験0として通常空セルへ生まれる。

有機栄養は生産者可食部と小型一次消費者。一口2B/変異2.4B、有限M取得は既存経路を使う。情報を食事にせず、光合成・救済補充を追加しない。弱い攻防0.45/0.60/HP0.80、移動と世代更新を強みにする。経験20/60/140と実績32T窓でIII三枝→IV六枝を選び、実績不足ではIIIで待つ。最近セルは16T/最大64件に制限する。

`ryoukiModel:'ryouki/1'` / `ryouki-parameters/1` を明示した世界にだけ適用。旧D.species31とD.main21を保持し、世界別の有効カタログは旧31/I03の34、量機のみ32/植物と量機35に分ける。初期数は既存main総数/系統選択/重みを使い、重み0での除外を永続的な繁殖禁止にしない。

## 素材・観測・保存

採用した通常I/II・III三枝/IV六枝、背中だけ黒の変異I〜III、黒と深緑の変異IVを13形態へ接続。原図は変更せず、正確な原画portraitと透明な派生atlasを区別する。[実行素材台帳](../../../design/ryouki-runtime-v1/registry.json)へ原画/crop/透過編集/静的pack/hashを記録する。実行中の背景除去や囲みカードを追加しない。

`ryouki-state/1` / `ryouki-observed/1` で、毎確定Tの通常/変異・早期/IV・実個体数・占有セル数・同居個体数/最大同居数を保存する。欠測や未知版を0で補わず、旧記録へ量機を補完しない。旧署名互換は量機の設定がない条件に限定し、再生で枝や密度判定を再抽選しない。

## 制約と次

今回の固定条件の成立例は、500Tの系統生存率/R1〜R6や全端末性能の認定ではない。全条件での相変異/同居/全枝の自然発生率を保証せず、専用fixtureと自然生成の試験を分ける。透過素材の細い発光縁・全年齢/全方向・密集時の最終品質はI10。P新生活環・遺伝/抵抗はI05以降、情報循環はI07へ残す。配布済みWindows版は4.2.32のままで、新ZIPはI12。次はI05「一次寄生P」。

経路比較の再実行は、基準commit `04b7bf6` の `src/ecology/` を `/tmp/valis-i04-baseline-04b7bf6/ecology/` へ展開して `model/paths-script.cjs` を実行。循環は `model/circulation-script.cjs`。作業ディレクトリはいずれもプロジェクト直下。
