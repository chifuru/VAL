# I11 P/Q 局所行動と有限費用の限定確認

`src/ecology/parasites.js` の追加動作は `balanceModel: survival/1` に限定する。既存の生活環・初回成熟窓・再感染抵抗・同一QのIV羽化・Pだけの致死・有限収支は変更しない。新食性、無親補充、情報による栄養供給、娘PへのQ継承は追加しない。

## 実装と境界検査

- 自立Qは既存の可食資源と死骸を、現行視界の半径3だけで探す。現在セルで既存の有限採食を行い、栄養・接触機会・実際の捕食者・移動費を比較して移動または滞在する。生体植物への採食は追加していない。
- Qの捕食者判定は `nutrition.js` の既存Q捕食条件と一致させた。鉱物食・腐肉食・菌食の `hunt < 0` の主生物を一律に捕食者と扱わない。recursive は general/hunt=.1 で実際の捕食者に含む。
- P/Qの任意投資は、次ターンの維持・発育、Pの既存放出実費、Qの発育/羽化実費を留保した残余から支払う。費用・成功率・寿命などの係数は変更していない。
- `unit.log`: 新規6検査、6成功。隣接栄養への接近と次Tの有限採食、非捕食者と捕食者の区別、情報/遠方資源の除外、P/Qの留保、無指定8Tの旧APIとのworld/RNG完全一致を確認した。
- `regression.log`: 既存一次寄生・高次寄生・有限フロー・接触の69検査、69成功。`before-parasites.js` は旧API一致検査用の `af9ae14` ソース。

## 限定した自然初期条件の実測

`source-comparison.cjs` は40×28・初期主生物80・river固定seed・優遇全OFFで、生成後の個体追加/変更をせず32T比較する。各結果JSONに全TのP/Q状態・初期実効値・実際の観測フロー・対象ソースSHAを残す。CPU時間は環境依存で、一般的な生存確率/500T達成の証拠にはしない。JSONのソースSHAは各実測時点のものであり、後続のP放出reserve厳密化より前の限定診断である。

| 診断 | 初期Q E | 旧Q採食E→新Q採食E | 旧移動回数→新移動回数 | Q新定着/羽化 | 32T Q |
| --- | ---: | ---: | ---: | --- | ---: |
| `source-comparison.json` | .08 | 0 → 0 | 3 → 3 | 両方0/0 | 両方0 |
| `source-high-reserve-comparison.json` | .35（診断override） | 0 → .15 | 14 → 10 | 両方0/0 | 両方0 |

両方の比較でPの32T個体数は25、新定着は3。高初期Eの場合、新探索は有限採食と滞在を増やし維持支出を .322→.48 E へ延ばしたが、Q生活環の自然更新は成立していない。

`baseline-diagnosis.json` は追加実装前の生成済みモデルで取得した32T診断の記録。元レコーダーの観測参照先が誤っていたため `flows` は空であり、この欄から採食/伝播の成功を主張しない。個体の各T状態・死亡理由の記録としてだけ使用する。可搬化した `.cjs` は観測参照を訂正済みで、再実行するとその時点の生成モデルを読む。

## 次の係数比較候補（未適用）

1. `hyperParasiteSettings.initialEnergy`: .08 は維持.02と移動.002で約3.6T分しかなく、卵費.10にも届かない。.35なら卵1回と約11Tの探索に相当する有限初期蓄えとなる。ただし本診断ではこれだけで自然更新は成立しなかった。
2. `primaryParasiteSettings.hostTax[3]`: .10→.12を比較候補とする。Q III寄生中はP維持.06＋Q栄養.04＋排除費.01で.11となり、任意投資を止めても.01/T不足する。宿主から実際に徴収する有限量を.02増やす候補で、宿主Eがなければ得られない。
3. `primaryParasiteSettings.inoculumLifetime.edible`: 4→8を先に比較する。部分採食による同一対象への感染量の積み上げを許すが、最低感染量・栄養を緩和しない。
4. 3だけで不十分なら、同時に `standardReserve` と `emissionReserve` を .06→.12、`emissionCost` を .12→.16へ上げて有限放出費を支払わせる。`emissionReserve <= .75 * emissionCost` を維持し、単なる無償感染力増加にしない。

Qの予定attached枠の不足はそのまま不足として扱い、別の探索Qで埋めない。適合する終宿主と初回窓が自然に生じたかを別指標で確認する。

R5では初期ID・親ID・世代を区別し、Pの娘の成熟/再放出、Qの非初期定着→同一ID羽化→その成体由来の次世代定着を測る。初期探索Qの残存や移住した同じPは世代更新に数えない。窓の総数、視認/接触機会、費用を払えた試行、定着、羽化を分け、死亡した宿主や閉じた窓で後から感染させない。
