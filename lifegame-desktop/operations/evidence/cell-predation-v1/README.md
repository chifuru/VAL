## 確認できた範囲

- 同マスの全小集団を候補とし、実在1個体だけを捕獲する比較実装。通常食料との既存評価、有限な合計採食枠を保持する。複数捕食者による同一個体の二重抽出を防ぎ、配列順を入れ替えても実取得者/人数/E/Mが一致する。
- 低次動物の整数人数・実コホートB・自由E/M・身体Mを分け、失われた個体分だけを取り出す。残存人数の維持・保持上限へ接続する。
- 同マスの実攻撃参加者だけが、倒した身体の有限在庫から直接取得する。複数攻撃者の受取と食べ残しの総和を保つ。描画イベントを偽装しても取得資格を作れない。
- 隣接マスの攻撃で倒しても遠隔栄養取得は0。実際に翌Tそのマスへ入れば旧死骸を利用できる。相討ち・同系統・新死骸への資格のない要求を区別する。
- 物質の所有は一行だけ。`capture` は当Tの実捕獲/撃破に対応した限定参照であり、別の食物コピーではない。一般の `carcass` は新死骸をT+1まで拒否し、残量はその利用可能Tを保持する。
- 実際に消費した割合でPの摂食経路を一度試し、次T定着の実移行先へ一つのP/Qツリーだけを移す。直接摂食と死骸経路を同じ捕獲で重ねない。成熟・適合・遺伝・抵抗・既存成功率は維持した。
- 自律Qの実E/Bも同じ有限在庫へ移し、死亡時に再度散逸させない。既存の有償回避は一回の成功で当Tに有効、複数捕食者から重複請求しない。寄生中Q・当T羽化体は自由な餌にしない。Mだけ不足した捕食者は、Mを持たないQを不要に殺さない。
- 捕食/実到達の2T、生成元/生成物、Worker差分/JSONを照合。旧方式の固定4T結果と再生、新方式通常ターン/新図鑑保存のガードを確認した。

## 接合時に追加発見した不整合

小集団の部分戦闘死で、負傷を人数比に縮めたうえで死亡人数のHPを再控除する旧処理が残っていた。残存HPと負傷を同じ実人数へ揃え、保持上限も更新した。

また、新版の幼体小集団の損傷計算へ旧年齢HP上限が混入し、実損傷以上のHP低下が生じていた。新版の実HP上限を用いる。部分飢餓死についても、死んだ人数分を除いた負傷を一度だけ残す。修正には実攻撃・幼体への損傷・飢餓の3境界を追加し、自由な回復や生存ボーナスで補っていない。

## 有効条件・無効化

[source-hashes.json](source-hashes.json) の生成元/生成物・計画・検査・生態署名が対象。[final-check.json](final-check.json) はCore/A/B・61Nodeの正式状態/Graph・Manifest一意性・ログ/生成署名の照合結果。旧方式の再生別名は `cellModel` 未指定に限り、新方式へ旧署名互換を与えない。

捕獲資格・実物質・負傷/人数・食性/回避・寄生移行・取得可能時点、または対応ソース/生成物を変えた場合は該当証跡を再評価する。異なる初期条件・別版の存続保証へ転用しない。
