## 判明した未達

- 1920×1080でマップcanvasの上端624.5px、下端1224.5px。ページ高1874pxで一画面に収まらない。
- 1366×768では上端702.66px、下端1102.66px。右グラフ欄は高さ742pxに内容989pxでスクロールが必要。
- 集計カード・現在像・ターン説明がマップ前の高さを占有。単にcanvas高さを縮めるだけでは盤面が小さくなる。現行UIのまま上部配置とサイドパネルの密度を調整する必要がある。
- 近景は実素材を表示できるが、状態札と背景が密集する。今回の画像のみで全地形・全状態の判読完了とはしない。絵柄・遠景記号を変更せず次の配置修正後に再照合する。
