## 残件・原因の切り分け

河川の水游虫は供給なし127T/あり157T、疎林は65T/64Tを最後に途絶えた。供給ありでも地形によって水系の更新は未達。供給ありの全期間の水游虫死亡は河川が戦闘80/寿命90、疎林が戦闘12/寿命28。出生は河川124/疎林11、子孫の初繁殖到達は69/4。直接の飢餓死亡がないことと、繁殖に十分な栄養があることは同義ではない。寿命で減る前に次世代が補えたか、適地/出生近傍・空き枠・栄養資格を限定監査する必要がある。今回の死因集計だけで特定の繁殖ゲートを原因と断定しない。

一次寄生は供給ありでも疎林で0、高次寄生は全6試行で0。菌も供給ありの疎林以外は500Tで0。全機能群の維持を認定しない。製品接続に向けて湖の自由設定を観察用基準候補にできるが、全地形の水系安定や各系統の存続確率は保証しない。旧R1〜R6と未使用条件での後続評価は保持する。今回の未達を隠れた補充で埋めない。
