## 実画面（表示検査用）

[近景](age-ui/near-age-fixture.png) / [遠景](age-ui/far-age-fixture.png)。同じ日輪・第三相・同DNAの3個体へ幼体/成体/老齢の年齢を明示的に設定したfixture。自然に第三相で出生・進化した記録ではない。表示fixtureでは生態を進めず、自然60ターンは別の新規世界で検査している。

肖像: [幼体](age-ui/juvenile-phase-III.png) / [成体](age-ui/adult-phase-III.png) / [老齢](age-ui/elderly-phase-III.png)。既存アトラスの体の比率と表面差を接続した初期描画で、採用した専用新造形の完成ではない。餌生物の年齢は印と能力表示までで、専用体形は残る。

## 適用境界と残件

新UI世界はlife/1。エンジン無指定の旧比較モデルは保ち、旧版の記録は計算指紋不一致で拒否する。旧1.5や2.3の長期試行を今回のモデルへ流用しない。自然3条件の短期検査は300〜500の連続存続率、各系統10条件、P/Q維持の合格ではない。専用素材・雌雄・新植物・景観仕上げ・長期バランスは未完。Windows実exe2.5も未確認で、2.2の成功は流用しない。
