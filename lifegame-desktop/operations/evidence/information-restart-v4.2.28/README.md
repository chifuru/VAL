# 情報餌の刻印・再始動 — 私有比較

製品4.2.28/f0aeba5は変更していない。情報の現行系と2案を、同じ初期状態から比較した。今回の採用候補はfootprintだが、製品接続・再生互換・長期認定とは区別する。

## 比較した意味

- **current**: 現行製品そのもの。
- **imprint**: 現行B3/S23で選ばれた内容なし初期粒子の成長時に、近傍の有効な経験を参照する。資金調停が成功した場合だけ内容を刻印。すでに内容がある粒子の書換えは許さない。
- **footprint**: imprintに加え、直近8T未満・期限内・発信者が生存し近傍にいる経験の所在を、CAの潜在占有に加える。実粒子と経験場のセル集合の和で近傍数を数え、B3/S23後にだけ実餌の候補を作る。経験場自体はE/Mを持つ餌ではない。物理粒子がなくなっても局所経験が揃えば再始動できる。

生成は現行の1単位0.1E費用/0.05E保持、発信者の最低E予算、セル資源枠、内容整合、期限、Q追加費用を通る。期限の延長・無償生成・DNAの変更は追加しない。製品で使う場合はこの潜在場の意味をA/Bへ明文化する必要がある。

## 代表短期比較

河川40×28、初期主40、供給OFF、3優遇ON。3初期値×3案×60T=540遷移。各初期値内で初期の全生態指紋一致。全遷移の不変条件とE/M収支を照合し、最大誤差はともに0。

|初期値|案|生成|内容付き取得|重み適用|情報セル最大|60T主個体数|
|---|---|---:|---:|---:|---:|---:|
|baseline41/custom|current|0|0|0|16|52|
|baseline41/custom|imprint|23|0|0|16|52|
|baseline41/custom|footprint|4527|16|12|127|49|
|information-coast|current|0|0|0|28|61|
|information-coast|imprint|64|2|2|28|61|
|information-coast|footprint|4035|18|9|129|63|
|information-marsh|current|21|1|1|30|51|
|information-marsh|imprint|77|1|1|30|53|
|information-marsh|footprint|4540|13|6|140|51|

currentでも1初期値では自然生成と適用が起きた。現行が全条件で不可能という結論ではない。imprintは生成を増やすが、代表baselineでは取得/適用に至らない。footprintは3初期値すべてで生成→内容付き取得→実際の重み変更が成立した。20Tより後の生成数も{'baseline41/custom': 3218, 'information-coast': 2959, 'information-marsh': 3121}で、初期粒子への刻印だけで終わっていない。

footprintの情報セル最大127〜140は1120セル中の約11〜13%。情報からの同化Eは各試行0.65〜0.90、植物/動物/菌からの有機同化Eは約4.9〜5.0万。短期に栄養源として情報へ依存した結果ではないが、長期の過剰発生や行動への過大な影響は未判定。行動重みの変更は移動経路や生存が改善した因果証拠ではない。自然試行の受容に自己由来が含まれるか、系統間の作用頻度は未集計。

自然試行のQ媒介は全案0。局所でQの有償媒介が残ることは検査したが、自然な情報媒介網の成立を認定しない。

## 局所検証と限界

`node tests/information-restart.test.cjs` 10試験を通過。B3/S23、経験なし/古い経験/死者の除外、資金不足、既存内容保護、期限非延長、有限費用/収支、生成内容の他個体・他系統による取得→学習、DNA不変、Qの追加費用、物理粒子消滅後の再始動を確認。local-tests.log参照。

私有変換は現在の静的モジュールをメモリ内で差し替え、対象構文が変わればエラーにする。src/・UI・画像・版・製品再生署名・Windows配布を更新していない。私有世界を製品の図鑑記録として保存しない。今回の60T比較を500Tの生存率や全地形/全系統の認定に置き換えない。
