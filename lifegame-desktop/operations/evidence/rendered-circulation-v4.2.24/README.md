## 次の修正

静止近景の温まった描画は短い一方、実進行は遅い。単に常時の描画が重いと断定せず、段階ごとのsetWorld→初回描画→継続モーション→commit/履歴/サマリ/DOMを個別計測する。先行バッファが残ることだけでWorkerの影響が皆無とは断定しない。同じ絵・全個体・全ターンを保ち、原因に応じた処理削減を優先する。

寄生除去clearは実モデルとrendererにあるが、通常再生の3段階の表示種別から漏れている。修正と通常Worker経由の回帰確認が必要。密集札/背景継ぎ目の限定評価と、死亡済み行為者の動き、情報/菌膜/水中生産者の既知未達、実Windowsも残す。具体的な実見とコード追跡はreview.md。
