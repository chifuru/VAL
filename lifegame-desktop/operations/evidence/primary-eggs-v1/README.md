# 一次寄生の終宿主から卵による循環 / 1

製品4.2.75、新規世界のprimaryEggModel: egg/1。基点main b9aee71。A/B正本はdesign/specification/primary-eggs-v1.md、契約はoperations/plans/primary-eggs-v1.md。

## 接続

陸系20T・水系30Tの有限卵塊。水中では毎T25%で隣接水域へ塊のまま移送し、希釈・複製しない。適合第一宿主に付着後2Tで一回の侵入を試し、成功時は翌Tの定着判定へ進む。親P死亡後も卵は残るが、期限を延長せず、付着先消失では失活する。生存P群体数と卵塊の在庫・産卵/孵化等の流量を分け、セル詳細・ゲーム内説明・CSV/保存再生へ接続。Q、宿主表、既存の抵抗と費用は維持する。

旧世界は卵モデルを後付けせず、旧署名で新モデルを名乗れない。新署名から旧署名への互換は卵フラグ/設定のない記録だけに限定する。

## 100Tの代表条件

[return-path.json](return-path.json)。40×28、主48、ryouki/solar/jelly/recursive、河川、供給OFF、優遇既定ON。前段で取得した旧モデルの100T診断と、同条件で卵モデルだけを加えた100T診断を比較した。両者とも全T不変条件違反0。旧モデルの100Tを今回再実行したとはしない。

| 種類 | 旧：放出→第一宿主定着 | 卵：放出→第一宿主定着 | 戻った群体の再放出を直接追跡した件数 |
| --- | ---: | ---: | ---: |
| 陸系 | 128→38 | 104→30 | 3→5 |
| 水系 | 48→1 | 20→2 | 0→1 |

水系で「終宿主→卵→第一宿主→終宿主→再放出」の一例を確認した。再放出の追跡は戻った群体のレコードIDに限定し、その後に分割された全子孫を網羅しない。単純な成功率比較には使わない。

100TのP/Q総数は旧30/30、卵25/28。全体個体数の回復を認定しておらず、500T安定・全初期値・全条件・実Windows・配布は未確認。診断後の製品差分は卵メタデータ欠落の検出と画面説明で、追加の生態調整は行っていない。正式Nodeは草案を維持。
