## 範囲と残件

最終第三版は河川の固定1条件で確認。湖/疎林は第一版の実測であり第三版の同数/確率を保証しない。Qが毎回維持される必要はなく、条件に合う存続経路があることを今回の目標とする。各系統の生存率、結果多様性、Qの成功確率など旧R1〜R6は後段へ保持する。水生植物等の未追加種も残すが、基本バランスの仮決めを延々と延期する理由にはしない。

製品への3枠/設定/Worker/観測/保存接続、近景/遠景とUIは未変更。次は現行記号/絵柄を維持した代表画面比較と既存UI/記録の未完差分。Linuxの描画なし実行秒数はWindows/画面性能の保証ではない。
