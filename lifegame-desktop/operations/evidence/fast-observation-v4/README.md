## 現行動作

新UI世界は500ターンを一区切り、基準1000ms/ターン、三段階を約333msずつ表示する。先行する3ターンを準備し、以後は表示中の予約を含む最大6ターンの先行バッファ。ローカルWorkerが生態計算を行う。準備は開始から合計60秒で中止・再試行、途中で応答が止まっても60秒で中止する。計算が追いつかなければ待機を明示し減速する。ターン/個体/造形を間引かない。手動送りは同じ同期計算を即時確定する。旧比較用の無指定エンジンは1000区間を保持し、新UIの500はconfig.blockTurnsに保存する。

マップ操作は最後から1秒後に再開し、pointer保持中は再開しない。個体選択/詳細ロック、説明、図鑑、設定はそれぞれ閲覧終了/閉じる/適用または取消まで保持。複数理由があればすべて解除するまで停止。手動停止では自動再開を取り消し、ホバーだけでは停止しない。タブ非表示でも停止。途中操作は最後の確定世界へ戻し、再開時の追いつき早送りは行わない。未表示の未来をカウンター・履歴・図鑑へ混ぜない。旧世代メッセージを拒否し、終了/リセット/設定/手動送りで先行結果を無効化する。変更した観測対象の診断は再計算する。

固定地形のキーは寸法と確定地形/壁/光/障害物の内容。土壌量/占有は毎回評価する。最大2地形の近傍/通行、上限付き静的視線を再利用。Workerはやり直しに再利用し、異常時のみ終了して再生成。メイン画面へは変更された生物/資源・削除/順序・土壌と確定時メタデータを送る。段階ごとの全地形コピーと部分集計を省略した。SHAの作業領域も再利用し、同じSHAの先頭32bitを乱数へ使う。原画21PNGとart/habitat/scenery/projection/rendererは3.9と一致（visual-identity.json）。

## 操作再開とCI互換検査の修正

表示中の準備済みターンを予約し、操作停止では先頭へ戻して再利用する。予約を含め上限6。設定/観測対象変更と手動停止は無効化する。これにより単なるズーム/ドラッグのたびに初回準備を繰り返さない。compute.logで上限と再利用、interaction-ui-report.jsonの25項目で再開・結果一致を確認。

Windowsの最初のCI（e501fb5、run39092996636）は、旧usability検査が設定編集中のrunning=falseを期待して失敗した。新仕様は再開意図を保持して停止するため、実際の停止理由と1ターン以上の生態指紋不変を確認する検査へ更新した。usability-report.jsonの20項目がLinuxで成功、画素の一致と停止中の再描画省略も保持。最初の試行では配布exe検査まで進んでおらず、成功としない（windows-first-attempt.json）。再実行を待つ。

標準マップの描画実測には他のブラウザ検査とのCPU競合が含まれ、今回の遠景平均は約1.85秒、近景平均は約1.22秒。負荷次第で500ターンの進行が15分を超える場合がある。小マップは約1.06秒で、5〜15分の観察には小マップを推奨する。表示品質や個体を削って速度を合わせる変更は行っていない。
