# 描画全面置換 / app 3.0.0

旧実行用グラフィック6枚と従来の真上描画を置き換えた。採用画面v4・素材/分岐/場面モック・特殊生物の採用構造を、新しい量産原画と斜め俯瞰の実画面へ接続した。草案の正式状態を変更せず、見た目の承認を自動検査から推定しない。

作画比較配置だけは、実際の河岸へ第三相の主7体と菌膜、宿主P/Q、情報餌を明示配置した表示用fixture。採用造形と同一セル内訳を比較するもので、自然に進化・共存・存続した証拠ではない。各遠近の状態同一性はreport.jsonに記録する。全系統一覧も原画の接続確認用で、生存実績ではない。

## 何を置き換えたか

- 遠景は主21・餌6・資源8の固有記号で存在位置を保持する。個体を代表点へ集約しない。遠景の植生/岩/倒木は実際の被覆/地形/壁に対応し、装飾の花草や泡を障害物記号に変換しない。
- 近景は240px/実セル、上限480px。連続材質を地形由来の浅い起伏へ貼り、樹木・岩・倒木と生物を奥行き順に描く。個体を遮る前景は透過する。地表は静的キャッシュとし、描画用起伏を保存や生態へ混ぜない。
- 全30登録系統の専用原画10枚を読み込む。主83相、餌12枠、P/Q9造形。早成は専用三相、植物共生05・社会性01・早成08の採用構造を反映。多頭蛇は多頭、深淵触手と頭足は別の体形へ置換。
- 日輪/浮遊傘はIII三枝・IV六枝を専用画に接続。他系統の枝は描画比率の差で、全系統全枝の専用画ではない。
- 幼体/成体/老齢は進化相と独立。年齢・雌雄は原画から比率/表面を変える表示変換。全性別・全年齢の別原画を量産したとは扱わない。
- 主と餌を同一セル内で分け、情報は量/鮮度付きの浮遊光、P/Qは宿主印と内訳へ表示する。寄生の造形区画から新たな生活環や独立占有を作らない。
- 確定イベントに基づき、移動補間・攻撃の傾き・採食の収縮と作用粒・その他の作用を表示する。全方向の骨格アニメーションは未実装。
- 開始操作の後に観察表示へ移り、設定を戻せる。操作バーを盤面上に置く。全体/近景/パン/ホイール/選択は同じ世界を扱う。

## 実測

Linux / Node v24 / Chromium 154 / HTTP loopback。新規Node・状態遷移は行わない。条件は `validation.json`、対象SHAは `source-hashes.json`。

| 検査 | 結果・範囲 |
|---|---|
| npm test | 14テストファイル成功。生態・保存・地形・新投影など |
| graphics-rebuild | 18項目。全素材・全30種・83主相・代表分岐・実ポインタ・100ターン自然進行・重複/P/Q・画面独立 |
| browser-smoke | 46項目。開始/停止/設定変更/系統樹/説明/自然成長/外部通信なし |
| age-ui | 16項目。全年齢の表示と能力、60ターン収支 |
| overview-ui | 15項目。160×112を含め全個体/資源を描画対象に保持 |
| map-ui | 31項目。6地形・初期値分離・再生/保存/不正設定 |
| observation | 13項目。90ターンの結果再現と再生時の再記録防止 |
| asset validation | 10原画のSHA/寸法/全領域、JSON/JSの意味的一致 |

生態11ファイル＋計算指紋の12 SHAは2.5時点から変わらない（`biology-identity.json`）。今回の画像検査を300〜500ターン存続率や寄生の長期安定性の証明には使わない。2.7のscenery-uiと2.8のmock-alignment-uiは旧素材構成の記録用契約であり、現行の検査はgraphics-rebuildへ移す。

## 残る範囲

モックは一枚絵の構図・滝・複雑な枝組みを含む。現行は実タイル・実地物を動的に組み合わせるため、全地形で同じ密度/構図にはならない。地表や水面の密度、材質の馴染み、全枝/雌雄/年齢の専用造形、遮蔽の仕上げは追加の視覚調整余地がある。極小の遠景では同一画素へ重なる限界を案内する。

独立四相植物と海洋光合成系統は既存の未確定仕様を維持し、今回追加しない。Windows exeをこの環境で実行していない。E7の2.2実測を3.0の合格根拠へ拡張しない。
