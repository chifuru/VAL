# 背景景観の再制作 / 3.1.0

利用者から「生物はよいが、背景がモックに届いていない。ビジュアルを最優先」と指摘されたため、地表と水面を作り直した。受入目標は `design/visual-alignment-v4/near.png` と `design/asset-mock-v1/01-terrain.png`。機能検査だけで視覚的な再現を合格扱いしない。

通常配置と作画比較配置は、3.0の記録と生物指紋・地点・倍率を照合した。比較fixtureは主7体の第三相、菌膜、宿主P/Q、情報を明示配置した表示用条件で、自然な共存や生存成績ではない。岩場の画像は通常世界の実地形から地点を選び、地形を書き換えていない。背景単体は世界のコピーで生物を非表示にした描画確認。8環境のサンプルも表示用で、通常世界の生態を変更しない。

## 背景の変更

- 単色とノイズ中心の地表を廃止。草原・林床・岩・砂礫・浅水・白波・深水・雪・熱域・情報域・腐食域の11専用素材を制作した。
- 見えている範囲だけ高解像度で合成。近景128〜256texel/セル、遠景は縮小用。原画の端を重ね、位置の異なる小区画を合成し、大きな四角い反復を抑える。キャッシュは最大3区画。
- 実タイルから深浅・地形・8環境のマスクを作り、川床・水面・砂礫の岸・草と苔をつなぐ。深水の中心では底を見せない。地面の原画に別の水路を混ぜない。
- 地物は輪郭から作った影で接地させる。泡の楕円影を削除。個体に重なる前景の周辺だけを透過し、森林全体が幽霊状になる表示を避ける。
- 遠景の地表は細部と彩度を抑え、全個体と資源の記号の位置を保持する。設定画面の環境見本も実素材へ変更。
- 生物原画10枚、相/年齢/雌雄の造形、生態計算・通行・占有・保存条件は維持。

## 視覚の照合

前回は、岸が滑らかな色境界だけで、水面もほぼ一色だった。今回は、川床の石・波の反射・白波・砂礫の岸・草花と苔・根の密度が近景で判読できる。林床や岩場に地物が接地し、背景の情報密度は採用モックへ近づいた。比較画像は同一fixtureで、見た目の差を直接確認できる。

モックの特定構図を一枚絵として背景へ貼ったものではなく、実際の盤面から合成する。滝・巨大な枝組み・全地形で同じ構図など、モックの一枚絵すべてを完全再現したとの報告や、利用者の最終承認は行わない。原画に含む小石・植物・鉱物の細部は装飾で、独立した餌や物理障害物を意味しない。

## 検査の範囲

Linux / Chromium / HTTP loopback。`habitat/report.json` は専用背景の検査、`graphics/report.json` は生物造形・分岐・位置/選択・描画独立の回帰、`overview/report.json` は160×112を含む全位置表示。投影とNodeの契約はcontracts/structureのログ。素材のSHAと寸法はasset-validation、実行対象はsource-hashes。

生態12ソースと既存10原画の同一性はidentity.jsonに記録。長期存続率・Windows実機・全分岐の専用原画・全方向モーションを今回追加検証したとは扱わない。検査画像は必要な比較画像を選別して保持し、再実行では同じコマンドで他の補助画像も生成できる。
