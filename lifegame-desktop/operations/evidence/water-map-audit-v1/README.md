湖沼では水系Pが100Tで12、150Tで18、250Tで19群体。終端の保持場所全体の宿主段階は第一9/中間6/終4で、卵由来の同ID群体の再放出を69/97/111/160/228/248Tに確認した。水系が循環できるパターンは存在する。ただし500Tや成功確率を保証しない。

湿地は初期11→25T15→100T9→150T1→200T0。75T以降の25T刻みの観測点では終宿主内Pが0。250Tでも第一宿主101レコード、中間650集団（1787員）、終宿主16個体が生存しており、宿主全体の絶滅ではない。終宿主への移行成功イベントは全期間で3、湖沼は17。単なる宿主総量より、局所配置・接触・定着失敗・感染者の更新が候補となる。今回の粗い比較だけでいずれか一因へ断定しない。

## 利用者の初期数に関する指摘

現行は`floor(第一宿主数 × initialFraction .2)`で水系の初期数を決める。河川1/湖2は確率的な失敗で途絶えやすい小集団であり、初期数を揃える比較が必要。一方、湖2で循環し湿地11で途絶えたため「初期数さえ増やせば解決」とも断定しない。

次の候補は水系Pを6〜8群体程度、第一/中間/終宿主へ分散した比較条件にすること。これは未試行・未採用。既存の直接初期数指定は初期配分を第一宿主だけへ変えるため、単にその指定を増やした実験では初期数と生活環段階の効果が混ざる。段階別の分散と合法宿主枠を保持した比較として設計する。今回、その初期配置変更を製品へ追加していない。
