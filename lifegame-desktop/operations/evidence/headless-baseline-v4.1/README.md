河畔の餌生物数は0T670→100T255→150T35→250T1→500T0。150Tの草28体・藻7体は全てM<0.2。主生物の出生阻害には栄養不足・鉱物不足・局所配偶相手なしが重なり、全3条件で子孫の再繁殖が0。自由設定にも餌不足と出生不足があり、湖沼の初期餌増量だけでも500T経路は維持されなかった。
