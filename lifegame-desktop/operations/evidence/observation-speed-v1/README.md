# 観測速度・10T表示 / 1

基点main 594e45a、app4.2.73、2026-10-23。契約は `design/specification/observation-speed-v1.md`、実行計画は `operations/plans/observation-speed-v1.md`。今回、中断中だった3速度の差分をレビュー・補正して採用した。

基準約1秒 / 2倍約0.5秒 / 最速を設けた。通常・2倍の3段階表示を維持し、最速では内部3段階を毎ターン計算し最終差分だけ転送、確定10Tごとに表示する。停止/別画面/速度変更/区間終了、明示的な選択・詳細更新・グラフ対象変更では端数を表示する。盤面とグラフの表示時点は一致させる。保存される観測行は全確定Tを保持。

最速中は任意のモーション/効果/行動札/状態札/年齢印/追加名札を停止し、その設定は操作不可とする。操作中背景簡略化は強制しない。記号化と絵柄/画質、生態規則/乱数/個体数は変更しない。解除時は元の全チェック状態と表示ラベルを復元し、画像予熱を現在世界から再開する。

追加発見として、予約済み画像予熱の世代破棄漏れ、Worker応答疎配列の検査、10T表示途中のグラフ先行を修正した。既存テストの古い12体fixtureと削除済み確認ダイアログへの待機も修正。

実測: compute-client 35試験、compute-worker 10試験、実ブラウザ18項目、通常段階表示の回帰26項目が成功。Linux Chromiumの実WorkerでT13まで進めた時点で盤面/グラフT10、観測行14を確認し、停止時にT13へ表示。T13の生態fingerprintは同初期状態を逐次計算したものと一致した。明示選択/グラフ変更/画面遷移の端数反映、設定全項目の復元、通常速度への再開も確認。通常回帰では保存/再生、途中取消、世界リセットを含む。根拠: `verification-summary.json` / `report.json` / `staged/report.json` とNodeログ。スクリーンショットは実画面。
