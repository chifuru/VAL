群体へ一律適用した途中候補は、通常swarmの餓死11→26、500時37→8へ悪化したため不採用。女王維持/育児のための社会性待機を同じ式から取り除かないよう、今回は既存の群体評価を保つ。原画・表示・餌生成・維持費・戦闘損害・出生予算は変更していない。

diagnostic-before.jsonは前版3.6の通常crystal300ターンを、実処理を呼ぶ読取フックで計測。摂食後E35未満の延べ4636個体ターン中、防衛1461回。空腹かつ主生物の敵なしでもguardの危険回避の加点がある。trace.cjsで再測定でき、前診断の再現にはbeforeCommitの計算コードを使う。消失例の死因は下記製品観測を正とする。emptyHarvestフィールドは有機吸収0.5未満を意味する。
