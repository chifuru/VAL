# CS08三次：共有配分の内部表現

起点90d1e22cad783759a474c208b6047e650c69d091。製品4.2.77。変更前9631330d…、変更後f51df1f1…。[実装契約](../../../design/implementation/current-state-allocation-v1.md)、[要約/対象ハッシュ](report.json)、[出力ゲート](final-check.json)。

今回の変更は、マス内の共有配分で資源名を最初に番号へ変換し、反復計算の作業配列を再利用すること。配分の重み/順番、独立したE/M需要、EPS、浮動小数点の加算順、取り分の切下げ、残量の丸めと実収支を維持する。作業配列は世界や保存へ追加しない。

| 対象 | 結果 |

| 34の配分条件 | 複数資源・0在庫・0能力・混合/未指定需要等の32条件と特殊診断キー2条件で、grantsと残量が変更前と一致。入力も不変 |
| 保持した実世界2境界 | T0→1とT133→134で、観測を含む全世界が変更前と一致。入力不変・不変条件も確認 |
| 再生/従来経路 | 9631330d…の形式4記録を初期条件から再生して一致し、原bytesを保持。未選択の従来マス境界も一致 |

[44項目のログ](tests.log) / [世界と配分の比較](boundary.json)。34条件は追加の配分比較数で、44項目とは分けて記載する。保持世界のハッシュはCS08一次のsummary.jsonと一致する。自然133Tの進行を繰り返していない。

## 効果と範囲

| 保持世界 | 取得・配分：変更前 | 変更後 | 全1T：変更前 | 変更後 |
| --- | ---: | ---: | ---: | ---: |
| T0・生体419レコード | 28.62ms | 20.30ms | 283.67ms | 232.12ms |
| T133・生体6,314レコード | 622.79ms | 447.46ms | 2426.74ms | 2219.93ms |

各点は同じ保持世界からの各1T・単回計測。取得・配分は要求のコンパイル、配分、実移転を含むメソッド時間で、全1Tに内包される。メソッド計時の負荷とJIT/キャッシュ/GCを含み、全体の安定した改善率ではない。

別に34条件×8回＝272呼出しを暖機後3バッチ測った。バッチ中央値は11.64→8.05ms。32の通常条件に特殊診断キー2条件も含む。小さい人工配分の時間を、実世界1Tの時間へ足したり、全盤面の保証へ換算したりしない。

今回の改善は採用する。世界・観測・取り分を変えない範囲の作業表現の変更であり、能力/費用/繁殖力等の調整ではない。生体やターン、全T観測を省略していない。旧規則との同値ではなく、直前の同じ規則への等価な再生接続のみを追加した。
