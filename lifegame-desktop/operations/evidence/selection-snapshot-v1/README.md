# 選択詳細固定/1・限定証跡

基点main 9f72b23 / 4.2.72。2026-10-23 UTC、Linux Chromium、40×28/主24、実Worker。契約は `design/specification/selection-snapshot-v1.md`、計画は `operations/plans/selection-snapshot-v1.md`、D9の検査は `tests/selection-snapshot-ui.cjs`。

## 対象と限定結果

選択または手動更新した確定ターンの詳細DOMを保持する。表示ターンと現在ターンを分け、最新の状態への更新操作を設ける。同じ対象の再選択でも更新する。保存用の世界複製や新たな個体履歴は追加しない。

`report.json` の17項目が成功。実際の進行とカメラ追跡中に詳細HTMLと先頭DOMノードが置換されないこと、更新後も次のターンに内容が固定されること、停止中の更新が世界指紋/停止意図を変えないことを確認した。マス/系統の固定・更新、不在IDの非代替、選択解除/新世界での解除、観測行の整合も確認。ブラウザ例外0。

開発中の `tracking-conflict.json` は、追跡中にマスへ選択を変えても旧followIdが残り、次ターンに旧個体へ戻った反例。別対象の選択で以前の追跡を解除し、修正後は同じ確認が成功した。不在IDは表示の明示的fixtureであり、自然死や死亡確率の検証ではない。

共有の詳細表示を変更したため、`tests/observation-recovery-ui.cjs` を限定再実行。`recovery-regression/report.json` の11項目が成功した。選択/表示変更での継続、停止意図、単発Worker/表示故障からの復帰を確認。

## 限界

生態規則・画像素材・正式状態・保存形式は変更なし。長期/全条件/Windows/配布物/速度変更の中断案は未確認。フレーム時間の性能倍率や、すべての画面寸法の判読性は認定しない。既存記録の検証範囲は各対象版の証跡を維持する。
