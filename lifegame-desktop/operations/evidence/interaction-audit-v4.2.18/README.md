## 修正と理由

旧「捕食で優勢」は生体からの動物性直接採食だけで、戦闘死亡→死骸食を拾わなかった。実死亡と既存hitByから1死1件を帰属する「戦闘討ち取り」、動物性死骸の実同化Eの「動物死骸食」へ分離。生産E/P定着と期間・単位を分ける。死骸食から殺害者を推測しない。全ターンの討ち取り、50Tの両指標を保存/CSVへ保持し、追加定義combat-observed/1を記録。旧欠測は未記録。
