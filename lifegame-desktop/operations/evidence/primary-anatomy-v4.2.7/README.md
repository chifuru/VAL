## 今回の範囲

日輪・深淵頭足・星晶・群体節足・早成甲殻の5系統を対象に、旧共通の帯状変形から、身体部位ごとの連続局所変形へ切り替えました。新しい原画や外付けの飾りを増やさず、既存の描線・鱗/羽/殻/外套・配色・発光を使用しています。

|対象|雌雄/階級|幼体/老齢|
|---|---|---|
|日輪|冠羽と後端羽を伸ばす雄、胸を厚くして後端を抑える雌|未展開の冠羽/短い尾、下がる羽端と材質の退色|
|深淵頭足|外腕の長さ、中央外套の厚さを独立変形|短い外腕と丸い外套、垂れる腕/低い外套|
|星晶|背晶の伸長、中央胴晶の厚さ|短い背晶/支持部、低い支持姿勢と晶表面の摩耗|

|早成甲殻|外側板の張り、中央板の厚さ|幼体も体制の完成度を保ち支持だけ短く、老齢は支持の沈み/板の摩耗|

原画35PNG、全183枝の参照、他16主系統、下層/P-Q/死骸/資源、生態コードと計算版は不変。相と年齢は別。通常I〜IV、早成I〜IIIの各相に全年齢があり得ます。群体の旧女王点3個は部位差へ置き換えました。新しい繁殖能力や階級を追加したものではありません。

## 表示処理と負荷

12×12の連続メッシュを生成時だけ適用し、各種で別の部位/変位を使います。三角形面積を確認して折返し/つぶれが起きない強度へ抑制。外側へ伸ばした組織は18%の余白で保持し、元サイズへ合わせて表示します。表示テクスチャは最大490×490px、既存の256フレーム上限付きキャッシュを使用。

今回の固定入力では152フレーム生成中13フレームで変形を制限、最小強度0.5625、折返し0。画像のピクセル差や折返し0を、人間が全状態を見分けられる合格とはしません。
