# 河川500Tの世代循環・要所利益の限定照合

対象は製品4.2.19/cf3dc84の計算モデル。標準coreをOperation→Summary→Flowの順で関連節を実読。既存A1.7/B4/C7/D8/E5内で実測と現在要約を接続し、正式状態は草案を維持。生態source・UI・原画を変更せず、版上げ・再配布なし。

河川40×28、初期値baseline41/custom、同じ5主系統、初期主80体、3優遇ON。供給OFFは従来の採用条件、ONは供給の基準値と下層の基準密度/資源量を使用する。各1試行であり、成功率・全地形・全系統のバランスを認定しない。

供給OFFのエンジン最終統計は既存observation-model-v4.2/river-500.jsonと完全一致。ONのエンジンP296/Q83と観測値P298/Q84の差は、有効死骸上の群体を現在像が含むため。両尺度を混同せずoff.json/on.jsonに併記した。

主の終端はOFFが重力翼19/並列生命19/異化通信生命82/記憶鯨157、ONが同90/24/169/186。多頭蛇は両条件で0（OFFでは出生2・成熟2、次世代繁殖0）。全初期系統が残ることを条件にはしていない。双方の残存主系統集合は同じ4種であり、単一初期値から終端構成の多様性は評価しない。

水游虫はOFFで自然出生138・子孫成熟135・子孫初繁殖51・観測最大世代9、ONでは127/127/50・最大世代6。陸の草棲虫は最大43/45世代。初期の長寿個体が残っただけの結果とは区別できる。子孫成熟/初繁殖は個体のcohort集計で、同じ親の反復出生を毎回初繁殖として数えない。P/Qの出生は別の群体tallyを使用し、世代番号/個体成熟指標は非該当としてnull。

Q出生はOFF256/ON70、潮環出生は2474/681、葉環出生は154/236。探索寿命480Tを越えた500Tで存続し、初期探索体の単純な長寿だけではない。ただし全試行存続やQの情報媒介成立を意味しない。

## 要所と栄養経路の局所確認

site-benefits.jsonで主21系統を同じ条件で対比較し、遮蔽の有限な防御利益、防御姿勢の追加利益、茂みによる移動費増を確認。占有から無限に能力が増える所有権モデルは追加しない。

私有の滞在観測は同一マスへの遷移が5回以上連続した場合を対象（初期run0、移動で0へ）。OFFは2,532区間開始/48,060個体ターン、ONは4,158/79,766個体ターン。そのうち遮蔽地点7,875/17,380、資源地点8,377/20,434個体ターン。有機同化Eは56,781.79/97,717.97。最長421遷移。場所を保持しながら採食する実例だが、滞在が生存を改善したという因果比較ではない。資源地点はその時点で資源がある位置で、資源を得た証拠ではない。有機同化は実採食を別に集計。

死骸作成の実処理で身体Mを死骸と土壌へ有限配分し、その後の植物の土壌M吸収とM保存を別の局所ケースで照合。不変条件も通過。これは同じ原子を500T追跡した試験ではない。長期試行のsourcesは同化E（光は総入力E）で、soil|mineralのE=0をM取得なしと解釈しない。

## 記録・実行時間・限界

- off/on-history.json.gzは0〜500Tの実観測全原値。off/on-states.json.gzは各状態の統計/台帳/cohort/最大世代。off/on-turns.csv.gzは全ターンCSV。比較図comparison.pngはこれらの実測を標準プロットで描いたもの。UIモックではない。
- 保存形式のcapture/replay、観測復元とCSVの同一性をNodeで確認。実ブラウザIndexedDBの501T往復、画面付き500T、実Windowsは今回未確認。
- off/on.logは検証済みstates/reportから作った正規化要約で、標準出力の時間系列保存ではない。詳細生成はtools/audit-circulation.cjs→summarize-circulation.cjs→plot-circulation.py。
- 同時実行の私有監査は約290/343秒。計算step平均約387/460ms、最大約1208/1119ms。描画や通常の1秒スケジュールを含まず、実ゲームの完了時間保証ではない。
- 情報生成は両条件0、payloadなし由来不明の情報取得は2/1、実適用とQ情報媒介は0。前区切りの観測接続を長期の情報伝播成立と読み替えない。この条件の情報ネットワークは未成立で、後続の頻度調整候補とする。
- 菌膜はOFF157/ON161出生し、10/11世代まで更新した後、両方で終端0。水中の微藻・浮遊微藻は子が成熟したが、その子孫の初繁殖は0。草本/一次消費者/主は世代循環を確認したものの、分解者と全生産者の持続更新まで完成とは扱わない。

少なくとも一消費者の500T存続、消費者の子孫繁殖、実戦闘/死骸食、有限収支というR0の限定経路を確認。この代表条件のために係数を追加調整しない。R1〜R6の成功率/創発多様性、情報の長期伝播、菌膜/水中生産者の追加経路、要所保持の製品表示、最終判読/性能、画面付き結合・実Windowsは継続する。
