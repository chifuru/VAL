## 実装と比較用の具体化

- `state.CellLife` が版、基部、定着、葉の損失、身体M、小集団世代ごとの実Bを保持する。自由な蓄えは既存E/Mに一度だけ保持する。新世界の初期身体Mは初期台帳へ含む。
- `nutrition.CellResources.lifeDemands` は移動後の実所在・実組織・相・不足量から共有要求を作る。`engine.cellLife` は内部の要求→取得→維持→生活の入口。主生物/分解者等の維持未接続を無償0へ補完せず拒否する。
- `reproduction.CellLife.advance` は不足衰退、組織形成、I/0の子、内部出生、有限分群、年齢/相の終端を更新する。公開通常ターンのガードは維持する。
- 成長と子の予約を共通予算で扱い、実費・維持3T留保を同じ在庫へ二重支出しない。子へ移すE/M/身体を形成熱と分ける。形成費は量子化で不足しないよう最小単位へ切り上げ、余剰Mは次Tへ戻す。
- 植物維持は基部率1/4＋葉率3/4、高次I〜IIIの基部のみ維持もIVと同じ1/4とした。年齢の生産/維持係数は80%齢から寿命へ線形補間する。光捕捉は実葉率×4Eを基礎とし、高次は相を掛ける。物理的な高さは実基部、同高の葉面積で共有する。これらは比較開始式であって実環境での保証ではない。
- 吸収の残差変動は再現可能な±10%、累積定着は別の一回の+10%。同じ根の効果を二重加算しない。
- 高次植物は既存の実績12/36/80・相費用2/4/6・32T配分窓・III三枝/IV各二枝を維持する。実際の形成・修復・出生・任意準備費0.1を配分へ記録する。既存の高生産/省資源・拡散・耐食の補正を接続し、新しい枝は追加しない。再生専用補正は状態に保持しているが、新しい固定の合計形成上限への作用は未接続。相別の固定枠/本体/葉上限を増やさない。
- 低次の旧E6という成長資格は旧貯蔵上限の30%として、新容量の30%へ比較用接続する。植物は累積維持3Tと葉2以上、動物は実世代の成熟8Tも必要。相変化だけで組織を増やさず、次Tの資格として使う。
- 小集団はE/M/B/年齢/相のまとまりで処理し、内部8体のAIや全履歴を追加しない。分群先と親群の既存世代は同じTだけ年齢を進め、新しい内部出生児は0を維持する。
- 生活段階では層索引を一度作り、出生・消失・分群のセルだけを更新する。各親が全盤面を再索引しない。
- 既存移動試験の草棲虫を実在するI相へ修正した（従来の主生物用ヘルパーがIV相を付けていた）。接触・途中停止・致死・支払の検査内容は保持する。小集団の損傷は現在HPに未記録の損傷があっても回復させない。
