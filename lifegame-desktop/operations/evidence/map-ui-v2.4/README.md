# 地形・開始設定・再生の実画面と検査 v2.4

製品2.4.0、Linux x64 / Node24.19.0 / Chromium154.0.8037.57、HTTPループバック。対象実体は[source-hashes.json](source-hashes.json)、実行契約は[地形UI v2.4](../../plans/map-ui-v2.4.md)。3 core・正式状態は変更していない。

## 今回接続したもの

- 代表6地形（蛇行河川・湖沼・湿地・岩地・疎林平原・盆地）、各40×28/80×56/160×112の事前セルデータ。実行時に地形を伸縮・全域生成せず、作者が用意した候補地点の地物のみ変更。
- 地形の指定/おまかせ、地形用と生態用の初期値分離、解決済み地形の可視表示。
- 宣言した主要陸路/水路の保護、安全既定配置または開始拒否。
- 最終configに集合版/ID/版/寸法/データと地形指紋/候補列/既定配置利用を保存し、再生時に復元・照合。旧計算署名は拒否し、再生を再記録しない。

## 有効範囲と残り

新造形・年齢能力・雌雄差・背景仕上げの全面反映は未実施。画像は実画面であり、手描きモックと同等の外観を承認済みとはしない。新地形の300〜500連続存続・世代更新・P/Q維持・勝者の多様性も未評価。以前のwatershedの長期試行を新地形の成功へ流用しない。

WindowsのZIP/同梱資産/実exeは対象コミットのCI再検査が必要。以前の2.2成功は2.4へ流用しない。旧結果は削除・上書きせず、必要な旧計算版がない場合は再生を拒否する。実行の速度を全端末へ保証するものではない。
