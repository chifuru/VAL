# 下層7対象の量・年齢・環境と浮遊微藻 4.2.6

契約: [実装前計画](../../plans/lower-states-v4.2.6.md)。既存B5.3/C8.1/D9/E6、配布C4/D4/E7内。3core/正式状態は変更せず、新Node・初期登録なし。

## 実装

- 微藻/浮遊微藻/岩苔/草本/菌膜/水游虫/草棲虫の7対象へ、同じ進化相での幼体/成体/老齢、B量、環境の表示差を追加。
- B量は現在選択している生態モデルのspec.capacity[1]に正規化。優遇ON/OFFで容量が違っても、同じ割合を同じ密度として表示。B=0を既定値へ戻さない。
- 植物・菌は可食部の疎密/外周欠損、動く一次消費者は体の厚みとしてB量を表現。進化相は原画、年齢は幼体の寸法/未発達支持部と老齢の退色/姿勢に分ける。年齢や表示で生態能力を変更しない。
- 浮遊微藻は既存の細胞原画から散在粒を合成。微藻の密な群と識別できる形へ。粒数は形態/密度を示し、実際の個体数の増加ではない。
- 原画PNGはすべて維持。food-atlasの12矩形を実体へ合わせ、脚・触角の切れや隣接画混入を補正。微藻の独立細胞を消さず、虫・葉束は主要な身体を保持。
- 熱域/寒冷/湿潤/腐食域に薄い色調を適用。それ以外の環境は既存色調。新しい適応/栄養/状態は捏造しない。
- 近景の選択候補が重なる場合は、判定領域内の中心までの相対距離が最小の対象を選ぶ。隣の大きな判定が小型対象の中心クリックを奪う不具合を修正。遠景/簡略の判定順序は維持。
- 表示フレームのキャッシュは最大128。描画中の再利用、原画輪郭/縁取りの既存キャッシュを使用。
