# 群体節足Cの展開・多頭蛇の再提案

## 現在の判断
群体節足の基本形は利用者指定により**v1のC（包殻胴型）を採用**。多頭蛇のv1口器型A/B/Cは不採用。元の多頭の蛇体・青紫金の材質を基準へ戻す。今回の画像は作画資料であり、製品4.2.3の原画/コード/生態/配布は変更していない。

## 多頭蛇：元の姿を基準とする4形態
[形態比較](02-serpent-forms.png)

|案|方向|主に変える部分|
|---|---|---|
|A：流線型|低い輪郭、前へまとまる頭群、長いS字の胴|一体の前胴から首が分かれ、狭い輪郭に流れをまとめる|
|B：冠帆型|立ち上がる首群と、根元から連続する帆状組織|頭の付け根・首・胴を一つの大きな輪郭へまとめる|
|C：重装型|低く厚い巻き胴、太い肩と首群|胴の量感と鱗の重なり、中央と側方の頭の大小差|
|D：遊泳型|横に広い流線の胴、長く連続する側鰭|頭を増やすだけでなく、胴から尾へ流れる鰭の輪郭を変える|

口器/吸盤/露出した喉/花弁状の摂食部は使わず、元の顔・鱗・鰭を維持。頭数だけの変化や、同じ首の単純な並び替えを完成条件にしない。図の頭数を全相/全枝の固定条件にしない。現段階の4図はデザイン方向の比較で、4新系統/4進化相の登録ではない。特にA/Dの細長さ、Bの縦方向、Cの厚みをシルエットでも比較する。Bは元の多頭の個性を保ちながら全体構造を変えやすい候補だが、利用者確認前として扱う。
