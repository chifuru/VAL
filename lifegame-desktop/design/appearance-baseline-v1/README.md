陸生I〜IVの基本形は[既存の森冠・星冠](../creature-design-review-v3/03-land-plants.png)を維持する。両者は別系統、同画像上段A/下段Bを対応させる。図内のメートル表記・人影は実寸/占有数の定義に使わない。植物の相と年齢は別で、相比較は成体条件。再生葉は若返りを示さない。

Pの旧A/B/C比較は[原資料](../creature-design-review-v3/01-parasites.png)を形の由来として参照できるが、現在の各相は上記専用図、QのIVは06を優先する。蜂/ハエ案、翅付き案、途中の淡水改訂案を混ぜない。図が似ていてもファイル名・ハッシュ・区画で判定する。旧海生02は今回の淡水系統の採用形ではなく、海の追加は保留。
