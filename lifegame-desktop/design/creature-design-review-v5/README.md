# LIFE LAB 生物別8案：造形の幅と描画粒度 v5

造形方向はv4の多様さを維持し、描き方は従来好評だった精細な手描き、自然な材質、繊細な発光、豊かな色彩へ合わせる。特殊3生物と海生光合成体を各8案、独立した4紙で比較する。

採用を受領：**植物共生05・社会性01・早成08・海生光合成体02**。実装時は形の参考とし、案出し前の素材・場面・分岐モックへ絵の雰囲気を合わせる。[決定稿と完成条件](../specification/ui-balance-baseline-v1.md)を参照。

## 統一する部分と変える部分

統一するのは描画の仕上がりと資料の読み方。細部の描き込み、材質の自然さ、光の繊細さ、奥行きのある色、濃紺と金枠の資料様式を、v2の承認済み植物資料へ合わせる。v4の暗い彫刻・無機質な物体のような仕上がりは基準にしない。

生物の体型・材質・色・密度・支持面・光を受ける面は変える。厚い肉質、硬い板、密な繊維、細かな粒状組織、流動的な体、層状の節、毛状の組織、薄い片の重なりを、各責務へ組み込む。全生物を透光膜と多孔質骨格へ寄せない。実在動物の顔や胴へ装飾を加える方法にも戻さない。

各紙の役割を維持した造形比較であり、絵から新しい攻撃、移動方式、射程、飛行、感染経路、栄養値を追加しない。明るい部分は演出を含み、魔法や全域操作を定義しない。番号ごとの能力値は未設定。

## 実行契約と出力範囲

FLOW-04/05、既存B5.3/C8.1の責務内で比較画像4枚・索引・対応表、現在のNode実体参照とManifestを更新する。新規Node分割・正式状態変更はしない。core、src/tests、製品用素材・カタログ、生態能力の更新は行わない。

年齢と進化相の独立、出生第一相・幼体、年齢能力v1.8、早成系統の第三相完結、有限収支・占有・宿主条件を維持する。表示用の名称を変えても既存Nodeや系統IDを改名・再登録しない。

検査は画像の実在・参照・Node/Manifestの整合に限定する。これは透過アトラス、全相/枝/年齢/方向、モーションの完成品ではない。実寸判読性、描画性能、ゲーム動作、生態バランスを検証済みとはしない。選択後に造形と差分を固定し、実装用の原点・縮尺・方向・モーションへ接続する。
