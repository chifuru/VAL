# LIFE LAB 場面・状態の補足資料

## 遠近で保持する共通の内訳

`scene.json`は画像へ指示する説明用の設定であり、ゲームエンジンの保存データではない。座標ごとの完全な世界は生成していない。遠景の金枠が近景の対象範囲で、川の曲がりと以下のIDを対応の目印とする。

|ID|対象|遠景での表示|近景での表示|
|---|---|---|---|
|S1|日輪・第三相|橙の光輪記号と選択枠|羽毛・光輪を持つ同じ成体|
|S2|日輪・第一相|小さい日輪記号|同系統の小さな幼体。S1と別セル|
|J1|浮遊傘・第三相|水色の傘記号|透ける傘膜と触糸|
|K1|植物共生・第三相|緑の分枝記号|葉と共生する身体|
|W1|星海鯨・第三相|青い鯨記号|大きな鯨の輪郭|
|F1|草棲虫・第二相|S1セルの餌位置に小虫記号|主生物とは別の餌枠にいる一個体|
|R1|情報|S1セルの資源位置に渦記号|滞留・浮遊するエネルギー状の表現|
|C1|餌由来の死骸|S1セルの死骸記号|小さい死骸。F1とは別の死亡個体由来|
|P1|葉環|S1に付随するP印|宿主内を拡大した寄生群|
|Q1|抑環|Pに付随するQ印|Pを宿主とする高次寄生群|

S1は汎食なので葉環の終宿主例を使う。潮環の終宿主例はJ1の系統など、水域適性の適合主生物を使い、日輪を潮環の終宿主として追加しない。P/Qを地面の別占有個体として描かない。R1は生物やDNAの媒体ではなく、延長された表現型を抽象化した外部情報として扱う。

## 資源・地形・モーションの読み方

- 植物は基部だけなら可食葉なし。草本・微藻・岩苔の可食量は通常刈り取らない基部を除いて評価する。菌膜へ植物と同じ基部保護・光合成を追加しない。
- 残量と鮮度は別の軸。量は疎・中・密、情報の鮮度は光輪の濃さ等で分ける。環境で水膜・霜・乾いた殻が付いても、資源IDや栄養種を増やさない。
- 地形の連続した描写は固定セルと辺のルールを見せる外観。固定環境の時間変化や、新たな侵食・流体・季節システムを追加しない。
- 攻撃・移動・採食・育児は確定結果の演出。移動通過中の採食、攻撃直後の死骸の先取り、失敗した移転の発光、出生時の成人化はしない。
- 死骸は有限の別予算。寄生の感染ペイロードが成立するものだけ、適合・成熟・期限・実採食の条件で移行する。図の矢印だけで全死骸を感染源にしない。

## 特殊生態の補足

潮環の代表経路は微藻→水游虫→成熟感染を持つ小型死骸の実採食→適合主の第三相以上。葉環は草本→草棲虫→同じ条件の死骸→適合する植物食・汎食主。若い主を経由する追加中間Bなどの別経路は既存仕様を参照し、代表図の省略を廃止扱いにしない。

成熟終宿主から第一宿主への子候補は局所的・有償・期限付きであり、餌個体を生成するものではない。QはPに付随して移行し、情報への作用も根宿主由来の成立した情報に限定する。P/Qの無限複製、全域情報の書換え、遺伝子の水平伝播は描かない。

浮遊傘は通常の有性出生を優先し、可視の成熟雄を8ターン観測していないことと、本人・出生枠・支払い等の条件が揃った場合に単為出生候補を持つ。子は雌の第一相。働育雌の育児は局所的な有限エネルギー移転で、群れ全体への命令ではない。植物共生は光と有限の採食を併用する混合栄養で、全系統の餌不要化ではない。

## 実寸・対応関係の限界

縮尺比較は点・記号・詳細の役割を示す概念図である。生成画像の中に小さく描かれた記号は、ゲームでその画素数まで識別できた証拠にはならない。実装時には同じ保存世界から遠近を描き、ID・セル・全占有枠の一致と、各画素寸法での判読を実画面で調べる必要がある。

この資料は、少ない画素へ全個体の名前・性別・相・行動を同時に押し込むことを保証しない。存在・位置は保持し、詳細は選択内訳・拡大・輪郭表示で読む設計を示す。独立生成した絵の物体数や位置の完全一致は、画像の目視と本文の対応表を超えて認証しない。

### 図中の補足・読み替え

- 02のW1「巨鯨類」、K1「植物系の共生体」は造形の説明であり、正式名はそれぞれ星海鯨、植物共生。餌の凡例の小魚は移動する餌の仮図で、水游虫などの正式な素材は04と既存素材資料を参照する。小魚の新系統は追加しない。
- 04の「芽・葉群・繁茂」「疎・中・密」は身体量・可食葉量・残量の見た目で、第三の成長相を追加するものではない。植物・菌の正式な相数は既存の二段階のまま。
- 05の共同育児の説明にある「同じマス」は同一局所場面という意味に読み替える。W2とY1は同colony_idの別個体・別の隣接主枠であり、一マスに複数の主生物を入れない。T1の「触手生物」は深淵頭足の略記で、独立した新系統名ではない。
- 06の遮蔽説明に使われたカエル状の個体や背景の魚は仮の尺度・見通しの例。新しい系統として登録しない。製品素材化する場合は既存系統の造形へ置き換える。岩場の多角形も固定セルの8方向辺を説明する模式線で、六角盤面への変更ではない。
- 07の単為の子に付く「クローン」は母由来の出生を示す略記。既存仕様どおり出生時変異を持ち、母の経験・枝・Q補正をそのまま複写しない。
