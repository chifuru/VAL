## 寄生生物：小さな装飾差から構造差へ

|候補|潮環 P|葉環 P|抑環 Q|
|---|---|---|---|
|A 付着型|扁平な吸盤状の体、放射状の内部管|種子状の殻と付着根|脚でPへ取り付く微小なダニ状の体|
|B 潜行型|細長い分節した線虫状の体|組織へ広がる糸状の分枝|Pの組織内に連なる珠状の体|
|C 被覆型|短く分枝する杯状の群|丸い嚢胞の集まりと連結糸|Pを覆う網状の微細な体|

比較用に拡大している。Qの対象はPであり、主生物に直接寄生する独立大型生物として扱わない。「潜行」「被覆」などは見た目を比較する言葉で、新しい感染経路・宿主枠・作用能力を確定しない。既存の生活環、宿主内の群単位、雌雄を持たせない条件を維持する。

## 特殊生物：胴・脚・殻の構成を変える

|候補|植物共生|群体節足|早成甲殻|
|---|---|---|---|
|A|低い四脚、苔と葉の背|丸い甲虫・アリ状、六脚|低いカブトガニ型の盾殻|
|B|高い六脚、背中に一枚の大きな葉傘|長い多節・多脚の体|巻貝状の殻を担ぐ甲殻の体|
|C|低い多脚、肉厚な葉の房|背の高いカマキリ状の体|角張った箱状の殻と前面の盾|

全て第三相・成体の比較。植物共生は移動する動物であり、根を張る独立植物とは別。群体節足の一図は一個体で、多数個体を合体させない。脚の数や殻の造形だけで移動速度・射程・防御値を追加しない。早成甲殻の第三相完結、出生第一相、幼体の高い完成度を維持する。

## 陸生植物：両方向を残し、違いを拡大

- **森冠（仮称）**：太い幹、張り出す根、非対称の層状樹冠、垂れ下がる枝葉。森の生きた大樹らしい重さを強める。
- **星冠（仮称）**：細い編み幹、放射状の透光葉、星形の開いた冠、細い光る花糸。広い樹冠とは異なる軽さと異質な植物らしさを強める。

森冠/星冠の二つの造形方向を別系統として採用する。現在の相/枝は[造形対応](../specification/appearance-correspondence-v1.md)を参照する。正式な機械ID/能力表/カタログ登録は実装接続であり、製品へ登録済みとはしない。

03に描かれたメートル表記は生成画像の参考演出で、採用する寸法ではない。全生物の占有は既存の一セル規則に従い、実装時の縮尺と重なりは別途調整する。

## 海生植物：陸の木を沈めるのではなく水中の構造へ

- **海藻林（仮称）**：岩へ付く基部、しなる茎、細長い帯葉、浮袋。水流に沿った姿と葉の重なりを見せる。
- **潮星草（仮称）**：底へ定着した基部、葉脈の見える透光の扇葉、放射状の段。星冠との意匠上のつながりを残しつつ、水中植物の体にする。

どちらも定着する光合成生物の候補。珊瑚・クラゲ・イソギンチャクや移動型の植物共生とは区別する。水深・光入力・流れによる作用・生育可能地形・栄養・繁殖・正式な系統登録は、この造形から確定しない。

## 年齢・進化相と採用の読み方

年齢は出生からの経過期間と個体の成熟・老齢境界、進化相は経験値・栄養・行動実績などの条件で決まる。両軸は独立し、各相に幼体・成体・老齢があり得る。画像03/04は**全図が成体**で、I〜IVは進化相の比較。第四相を老齢と同一視しない。出生は第一相・幼体、進化しても若返らない。[年齢能力仕様v1.8](../specification/ab-age-abilities-v1.8.md)を維持する。

## 今回の実行契約と残る作業

FLOW-04/05、既存B5.3/C8.1の責務内で、比較画像4枚・索引・対応表、旧資料の現在参照、Node実体参照とManifestを更新する。新規Node・分割・正式状態変更は行わない。core、ゲームコード、tests、製品の画像・カタログ、生態能力は変更しない。
