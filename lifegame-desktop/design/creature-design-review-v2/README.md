# LIFE LAB 生物デザイン比較 v2

利用者の「差分の特徴を強める」「特殊生物を詰める」「年齢を盤面で見せる」に対応する、選択用の造形モック6枚。確認済みの濃紺・金枠、精細な発光生物、自然な材質を基準とする。既存資料は[素材](../asset-mock-v1/README.md)、[分岐・雌雄](../branch-mock-v1/README.md)、[場面](../scene-mock-v1/README.md)。

この6枚は造形の比較資料。年齢による能力差は[A/B v1.8](../specification/ab-age-abilities-v1.8.md)へ反映した。画像・ゲームコード・製品カタログ・正式なNode状態は未変更。新しい造形の採用は確認待ち。現行の正本は[仕様索引](../specification/README.md)から参照する。

## 選び方

案A/Bは各対象ごとに選べる。全てを同じ案へ揃える必要はない。A/Bは造形候補の名前であり、VALISのA層・B層や新しい生物系統を表さない。

|選択対象|候補|比較の軸|
|---|---|---|
|日輪の雌雄|03-A / 03-B|冠と胴・羽の輪郭差をどこまで強めるか|
|浮遊傘の雌雄|03-A / 03-B|細長い傘と幅広い丸い傘の差|
|潮環|04-A / 04-B|水のような柔らかい環と、波形・内側の管の強調|
|葉環|04-A / 04-B|葉状の付着体と、螺旋状に重なる葉脈の強調|
|抑環|04-A / 04-B|小環の付着と、Pへ絡む分枝構造の強調|
|植物共生|05-A / 05-B|動物の身体と葉の一体感、葉冠の強調|
|群体節足|05-A / 05-B|有機的な節足と、重なる外骨格の強調|
|早成甲殻|05-A / 05-B|低くまとまった殻と、層状の防護輪郭の強調|
|光樹|06-A / 06-B|森の植物らしさと、星形の光冠を持つ異質さ|

01・02は年齢と分岐の代表的な強調案。ここで選ぶのは見せ方であり、全系統・全方向・全モーションの完成を意味しない。

おすすめの出発点は、**雌雄は両系統ともB、潮環A・葉環B・抑環B、特殊生物3系統はB、光樹B**。輪郭での判別を強め、潮環には柔らかい生物らしさを残し、葉環とQには複雑な付着構造を持たせる組合せ。光樹Bと植物共生Bも、定着した幹と移動する身体で区別できる。選択状態は未選択。

選択後はその基本形を固定し、寄生群の生活環段階、残る系統の分岐、雌雄・年齢・向き、実寸とモーションへ展開する。04は寄生群の代表形の比較で、全生活環段階の差分ではない。06も四相の代表像であり、第三相3枝・第四相6枝の全図ではない。候補を選ぶ前に全組合せを量産しない。

## 読み方の固定条件

- **年齢と相**：01は全て第三相の比較。第三相の幼体が出生する図ではない。出生は第一相。老齢は負傷・飢餓・第四相と別で、進化によって若返らない。
- **年齢印**：01の点線輪・刻みの付いた輪は識別の比較案。v1.7の小点付き輪郭・切欠き輪郭という方針を、実寸で判読できる形へ接続するための参考で、画素寸法の確定ではない。
- **分岐**：02の正式な第三相名は熱糧蓄積・光輪巡航・日輪闘争。第四相は効率採集/蓄積回復、広域探索/地形適応、攻勢/防衛。形から射程・速度・回復魔法を追加しない。
- **雌雄**：03は同じ系統・相・枝・成体で比較する。色分けだけに頼らず、各系統の基本形は維持する。現在のv1.6より誇張している部分も比較提案であり、自動的な仕様改訂ではない。
- **寄生**：04は拡大した群の構成単位・代表形。潮環は適合する水域系統、葉環は日輪など適合する植物食/汎食主の宿主内に付随する。QはPに付着。地表の独立した巨体にしない。一宿主に異なる二種類のPを入れず、群に雌雄や内部個体ごとの年齢計算を追加しない。
- **特殊生物**：05の各大型図は一個体。群体節足を多数の合体生物にせず、階級も別系統にしない。早成甲殻は第三相で完結する。
- **独立植物**：06は根を持つ定着型の光樹であり、移動する植物共生とは別。上二段は年齢が成体のまま相を比較し、下段は同じ第三相のまま年齢を比較する。第四相＝老木という意味ではない。生物の占有は一セルのまま。

## 仕様・実装との境界

光樹の名称は仮称で、固有数値・正式な分岐名/条件は未確定。画像に具体的な構造があっても、生態条件の確定・製品登録を意味しない。P/Qの情報作用は延長された表現型の既存仕様に従い、遺伝子の水平伝播や全域操作の能力を追加しない。

画面での見え方は、精細な造形に加え、近景・遠景の実際の画素寸法で確認が必要。小さい見本やシルエットがあることだけでは、全系統の識別性や描画性能を検証済みとしない。透過・原点・向き・部位配置を揃えた実装用アトラス、アニメーションは未制作。
