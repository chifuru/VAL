## 接続と不足の判定

|対象|現在の接続|不足・次の作業|
|---|---|---|
|主21系統の相/枝|専用枝は全21系統、計183枠。今回の群体・多頭蛇採用形を維持|専用枝の作り直しは不要。密集と実寸で最終確認は残る|
|主21系統の雌雄|全系統共通の帯状変形、雌の幅/雄の高さ補正|器官・輪郭の系統固有差が未実装。色・拡大縮小だけでは仕上がりとしない|
|主21系統の年齢|幼体の帯状変形と縮小、老齢の退色/共通曲線|固有の未発達部位・姿勢・摩耗の差が未実装。どの相でも全年齢がある条件を維持|
|群体の階級|繁殖雌に小点3つ、他は雌雄の共通変形|繁殖雌/働育雌の差が小さい。指定の環状体を維持して構造差を付ける|
|植物/菌の相と量|2相原画、Bで全体サイズを約16%変化|年齢に応じた身体差、残量による葉/群の疎密や欠損差がない。環境4の薄い発光以外の環境差なし|
|動く餌の相|2相原画。food-atlasから描画|Bのサイズ補正と環境4の発光のみ。年齢/雌雄による身体変形は適用されない。隣接枠由来らしい断片も原画切出しの再点検対象|
|浮遊微藻|微藻の原画を同じ参照で描画|浮遊粒/水中分布など微藻との専用識別がない|
|潮環/葉環/抑環|原画は各3段階あり。盤面は宿主上P/Q印と探索Q記号|専用原画は未接続。宿主追従/選択領域を守って既存生活環の状態へ接続する。画像から新しい種・性・能力を追加しない|
|資源8種|種別の色/形、量による粒数、情報は時間で退色|環境/鮮度ごとの専用外観は限定的。情報の表現は変更不要として出発|
|死骸|rendererで固定の小さな×を描画|由来・残存量・分解段階が見えない。新生物/無償栄養を作らず描画を追加する|

「未実装」は該当する専用差を指し、生態機能がすべて存在しないという意味ではありません。主生物の年齢能力は現行規則のままです。草本などへ主生物と同じ雌雄を追加しません。寄生の原画3枚と生態状態3つが必ず一対一対応するとは決めつけず、実際の生活環を読んで割り当てます。

## 制作順

1. 既存原画のあるP/Qと死骸を盤面へ接続。宿主重なり・通常/相分離・選択・遠景記号維持を限定確認。
2. 下層の残量/密度/状態と浮遊微藻の識別、動く餌の切出し・年齢差を補完。
3. 主21系統の雌雄/年齢と群体階級を、制作台帳の固有器官に沿って順次補完。群体/多頭蛇の採用体制は変えない。
4. 実寸・密集・明暗地形を確認して重要モーション工程へ接続。

新しい絵柄の提案は不要。既存材質に合わせ、共通の飾りを全系統へ貼らない。今回の画像は新素材の量産や全画面の確認の代替ではありません。
