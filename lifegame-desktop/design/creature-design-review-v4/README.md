# LIFE LAB 造形言語の再比較 v4

## 今回の停止位置

特殊3生物と海生植物をそれぞれ8案にする依頼に対し、既存種を土台にした案を作成したが、利用者の指示で候補から外した。続いて独自体制を各8案にしたものも、全紙が同じ透光膜・多孔質骨格へ偏ったため、今回の採用候補から外す。

現在は各生物の量産前に、**造形言語そのものを8方向で比較する1枚**を提示する段階。特殊3種と海生植物の新しい各8案はまだ完成扱いにしない。先行した32案は本資料に収録せず、製品やNodeの検証済み実体に使わない。

## [生命の造形言語・8方向](01-visual-languages.png)

上段01〜04、下段05〜08。各番号は別の造形方向であり、相・年齢・系統番号ではない。

|番号|方向|主に変えるもの|
|---|---|---|
|01|厚肉・丸塊|深紅、不透明で柔らかい厚い組織、少数の大きな丸い塊|
|02|硬板・角構造|黒い硬質板、鋭い角、細身の支持構造|
|03|繊維・流線|青緑の密な繊維束、長い流線と動きの方向|
|04|粒組織・集合|黄橙の細かな肉質組織、幅広く密度の高い一体の体|
|05|液質・非対称|濃青の濡れた流動的な塊、低い非対称の輪郭|
|06|節・螺旋|土色の厚い不透明な節、ねじれた立体構成|
|07|毛状・膨張|濃紫と金の短い感覚繊維、毛羽立つ丸い輪郭|
|08|薄片・扁平|白と黄緑の不透明な薄片、低く幅広い重なり|

統一するのは資料の背景・枠と比較条件。生物の材質、色、明暗、対称性、密度、胴や支持面の配置を統一しない。実在動植物の顔や身体へ装飾を足す方法にも戻さない。多孔質の骨格と透ける膜を全系統共通の意匠にしない。

次は気に入った複数の方向を、植物共生・社会性・早成防護・海生光合成の各責務へ組み合わせる。1方向を全生物に当てはめない。一枚の8図は新しい8系統の登録ではなく、既存生物の能力を示すものでもない。
