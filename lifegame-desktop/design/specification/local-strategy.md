# 計算量を抑えた局所経験と系統戦略（A/B確認案）

ユーザー指定：計算量を考慮して適切な形にし、判断に迷う場合はライフゲームの創発を参考にする。環境による隔離を避け、共有資源と局所的な接触から生存競争を生む。実装・動作測定は行わない。

## 採る構成

**各個体が周囲8マスと少量の内部状態から行動を決める。系統全体の司令、一族集団の計算、群れ単位の管理は設けない。** 同じ局所ルールを同期適用した結果として、採食集団・防衛集団・移動の列・周回などが現れることを狙う。創発が実際に起きるかは未検証であり、成立済みとは扱わない。

| 単位 | 保持・更新するもの | 計算範囲 |
|---|---|---|
| 系統 | 6行動の基本傾向、環境適性 | 20系統の固定表。全個体への戦略伝播なし |
| 一族 | 子の初期行動傾向 | 出生時に両親から弱く継承するだけ。一族専用の集計・探索なし |
| 個体 | 6行動の経験値、現在行動、方向、直前の位置、短い生還判定状態 | 本人と周囲8マス |
| 群れ | 専用状態を持たない | 近くの同系統個体との局所的な協調から生じる |
| 情報の餌 | 小さな6成分の経験要約、強度、環境の文脈 | そのマスの生成・維持・消費と近傍のみ |

系統戦略は「同じ系統の基本傾向と、各地で生じた行動のまとまり」を指す。系統全体が一つの可変戦略を遠隔共有する意味にはしない。同系統は一族が違っても仲間のまま。

## 六つの行動と局所ルール

| 行動 | 周囲から見る条件 | 経験として評価する結果 |
|---|---|---|
| 積極攻撃 | 隣接する敵、本人のHP・栄養、局所的な有利不利 | 有効な損害・脅威排除と、支払った損害/消費 |
| 逃走 | 隣接する脅威、空きマス、地形コスト、仲間の位置 | 攻撃圏から離れ、短い期間を実際に生還できた成果 |
| その場を守る | 所在マスの餌・遮蔽・仲間、隣接する敵 | その場所で仲間や自身の採食・生存を維持できた成果 |
| 周回 | 前の進行方向、前の位置、通行可能な隣接マス、障害物 | 複数地点の利用による採食・安全維持。歩いただけでは加点しない |
| 餌を求める | 現在地と隣接マスにある餌、不足する栄養/数字/情報 | 実際の摂取・不足解消と、移動消費 |
| 群れる | 隣接する同系統の数、空きマス、局所的な混雑・敵 | 仲間の近くでの本人の生存・採食と、混雑による損失 |

移動は1ターンに隣接1マスまたは停止を基準案とする。遠距離移動・遠隔戦闘・視界拡張は初期案へ追加しない。最短経路探索や遠くの全餌・全敵の走査は行わない。

周回は既定の大域ルートを持たず、進行方向の維持、障害物沿いの曲がり、短い往復の抑制から生じさせる。閉じた周回ができる保証はない。餌が隣にない時は方向を保った局所探索を行い、未発見の遠方餌の座標は知らない。

群れる時は近くの仲間へ寄る一方、密集しすぎるマスを避ける。群れID、全員名簿、リーダー選挙、連結成分の全盤面探索を使わない。離れれば自然に分かれ、近づけばまとまる。

## 経験・継承・切替の上限

6行動それぞれに上限付きの小さな経験値を持ち、少しずつ減衰させる。全履歴、全対戦相手、全訪問マスは戦略計算に保存しない。生還は「直近の脅威後、短い判定期間に生き残れたか」という少量の状態で評価し、単に生存ターンが増えたから逃走が強化されることにはしない。

行動選択は、系統の基本傾向＋出生時の弱い継承傾向＋本人の経験＋摂取した情報の弱い影響＋今の状態を比較する。6行動と移動先最大9候補の範囲で判定し、相手の将来行動を何手も予測しない。HP低下・飢え・通行不可など現在の必要条件を優先する。小さな点差で毎ターン行動が反転しないよう、現在行動を保つ余裕を設ける。数値重み・減衰率・切替幅は未確定。

子には両親の現在の傾向を上限付きで弱く引き継ぐ案。本人の経験値はゼロから始め、親の成功回数・既得分岐は継承しない。これは基礎DNAを書き換える処理とは別。出生後は経験で変わるので、一族が同じでも同じ行動を強制しない。

## 情報の餌による経験伝達

1. 有効な採食・攻防・逃走生還などが起きたマスに、小さな経験要約を残す。内容は6成分と強度・環境の文脈に限定する。
2. 要約は情報の餌の内容候補であり、残すだけで食べられる資源セルを誕生させない。情報の餌自体の成立は、既存の近傍更新条件を必ず通す。
3. 情報の餌が近傍則で成立・維持する際、そのマスと近傍の要約を上限付きでまとめる。保存する要約は各マス一つで、時間経過で弱める。無制限の出来事一覧にはしない。
4. 成立した情報の餌を食べた個体だけが、行動経験への弱い影響を受ける。他系統も摂取できるが、自身の系統・環境適性と照合する。
5. 本人の実経験を主とし、伝聞だけで際限なく同じ戦略を強化しない。情報摂取だけの出来事を新たな成功情報として再発行しない。餌を作るための経験と、餌を食べて得た情報を区別する。

情報から身体能力・系統・相・獲得済み進化枝をコピーしない。遠くの仲間へ即時配信しない。経験要約が消えれば伝わらず、情報の餌が成立しない場所では食べられない。この局所性が地域ごとの戦略差を生む候補となる。

## 隔離を避ける環境と共有資源

得意環境は攻防・消費の有利であり、苦手環境にいるだけで進入不可・即死にはしない。大岩・崖などの物理的な通行制約と環境適性は分ける。身体形態による絶対的な生息環境の隔離は初期案へ追加しない。

数字・情報は複数系統が同じ資源を利用できる。生命・鉱物も環境差はあるが、系統専用の採食権を設けない。環境境界での混在は近傍則と資源成立条件を満たす範囲で扱う。餌の消費・局所的な発生消滅・環境作用の変化が移動と接触を促す。競争は戦闘だけでなく、採食の先取り、空きマス・出生先・経路の占有も含む。

## 生物の近傍条件の調整案

生物に厳密なS23即死を課す従来案は、逃走・採食・防衛が成功しても近傍数だけで死ぬ問題がある。このため、**餌・環境にはB3/S23基準を残し、生物の孤立・過密は維持負荷としてHP/エネルギーへ反映する**案を優先する。生存は局所条件・採食・消費・損害の結果で決まる。生物の出生はB3の近傍条件と、同系統・異性・双方III以上等を重ねる案を維持する。

これは厳密なConwayの規則からの変更であり、多状態のセル更新として扱う。孤立・過密の負荷量・回復・出生近傍数の最終値は未確定。行動経験から負荷を無効化する能力を自動追加しない。

## 計算量の目安（仕様からの見積もり）

盤面セル数をN、生存個体数をIとする。資源カテゴリ4、環境作用4、行動6、近傍8を固定した場合、1ターンの計算量は **O(N＋I)**、現在/次状態と上限付き経験の記憶量も **O(N＋I)** を目標とする。実測値ではない。

餌の差分が増えても、全セルで全差分を総当たりしない。近傍8マスに実在する差分IDだけを候補として集計し、成立条件を参照する。戦略選択で全個体同士を比較するO(I²)、一族・群れの全体再計算、全盤面の経路探索を避ける。移動・出生の競合は候補マスと固定数の近傍候補で調停する前提とする。

描画や履歴表示の費用は別。観測用に全履歴を保存する仕様も今回追加しない。性能上限、盤面規模、同時個体数は実装許可後に測定して決める。
