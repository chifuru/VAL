# 食性と生存戦略 v1.9

3.2の対象範囲で既存の食性係数を優先更新する。系統/進化相/年齢は独立のまま。

| 食性 | 主な供給源 | 植物/菌/動物/鉱物の消化係数 |
|---|---|---|
| 草食主体 | 生葉・種実・有機粒 | 1.5 / 0.9 / 0.65 / 1 |
| 肉食主体 | 小型餌生物・異系統の死骸・栄養卵 | 0.65 / 0.9 / 1.5 / 1 |
| 雑食 | 各種有機餌 | 1 / 1 / 1 / 1 |
| 菌食主体 | 菌・失活胞子 | 0.9 / 1.5 / 0.7 / 1 |
| 腐食主体 | 異系統の死骸・菌 | 0.9 / 1.2 / 1.1 / 1 |
| 鉱物食併用 | 鉱物片・鉱液滴と有機餌 | 1 / 1 / 0.8 / 1.3 |

係数は吸収効率の既存DNA/特性倍率へ掛け、既存上限を守る。腐食主体は死骸の選択評価1.6倍（資源量を増やさない）。全食性は不足時に不得意食を利用でき、鉱物だけでは有機成長を代替しない。餌生物の植物食、菌・植物の専用収支は維持。腐食主体は記憶殻と反記銘生命に適用。食性は図鑑/個体の両方へ表示。

行動は可視範囲の好適な食物へ向かう局所評価を加え、飢餓で重みを高める。肉食は生きた小型餌も供給候補として認識。攻撃は食性・空腹・相手の小型/主生物区分による得点補正で選び、草食も防衛や競争で攻撃し得る。固定の行動モード、全域透視、無償補充、絶滅救済は追加しない。

生存調整の評価は初期配置を固定しすぎず、同じ10初期値・6地形・5系統構成を旧版と比較。絶滅の有無だけでなく繁殖と終端優勢系統の違いを見る。係数の最終採否と未達目標は実測証跡へ記載する。
