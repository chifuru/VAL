# 死亡地点に残る実績由来の情報

## 1. 適用

情報の定義・経験を蓄積した保持個体・通常/親養育者の伝達・学習と場所作用・非排他的5成分・集中/反復/非消費読取は [持続する情報/1](persistent-information-v1.md)を現在正本とする。本書は死亡地点での生成・由来・抽選・層適合を担当する。新正本が置換する範囲以外は維持し、追加ルールの数値は未確定とする。

仕様版 `death-information/4`。優位に生存した個体の経験が、死亡地点へ実績に応じた確率で残る方式を採用する。情報は延長された表現型の抽象モデルであり、遺伝子の水平伝播ではない。情報に餌要素・可食栄養は持たせず、全生物の死亡情報を対象として同層向け/全層向けの適用範囲を区別する。Qの主力となる間接作用は [寄生メタ仕様](parasite-meta-v1.md)と接続する。

現行4.2.32の「生存発信者の近傍経験からB3で有償放出」「潜在経験8T未満・元経験+20Tの一律期限」は新方式への変更対象。旧実装・版付き証跡は改変しない。本書はA/B反映段階であり、新方式の生成/頻度/性能/生存効果は未実装・未測定。有限収支、局所性、文脈/鮮度/感度、撹乱、重複学習防止、DNA不変は維持する。旧情報資源の0.05E/単位等の栄養取得とQによる情報摂食も、新方式では撤去する。

## 2. 生存中の蓄積と死亡時生成

1. 生物は自身の生存期間・栄養/健康の維持・行動成果・適用可能な繁殖/子の生存実績を集約する。全行動を保存せず、少数の累積値・代表経験・由来時刻を保持する。
2. 死亡が確定した時点の実績から出現確率を決め、世界初期条件/死亡ID/ターンに紐づいた再現可能な抽選を一回行う。描画順や再試行で再抽選しない。
3. 成功した場合、死亡したセルに有限量・有限期限の非栄養情報を生成する。量は痕跡の強さ/残量でありE/B/Mではない。記録・歪曲等の活動費を伴う場合は生存中の有限台帳で支払う。死骸のE/B/Mを情報の可食栄養へ変換せず、死後の無限生成も行わない。
4. 死骸と情報は別資源として存続する。死骸の消失だけで情報を消さず、情報の取得を感染や屍肉食として数えない。死亡情報を取得しただけで寄生は成立しない。

実績は発信個体が生きていた時点で確認可能な量だけを使う。系統ごとの寿命/生活様式を考慮し、絶対年齢・攻撃力・大量出生・系統全体の多数だけで優良としない。戦闘で死亡した場合も、それまでの実績があれば情報を残せる。全生物が死んだ時点で後知恵の勝者評価を与えない。

低実績でも低い出現確率を許し、少数派や撹乱情報が混ざる余地を残す。高実績の出現率と残存期間を主に優遇し、作用強度まで一律に最大化しない。具体の確率/寿命/量は調整値であり、今回は数値を採用しない。

## 3. 量・時刻・局所更新

情報にはID、発信元ID/系統、死亡セル/死亡T、生成T、元経験の時刻/文脈/内容、発信時実績、Q加工者/加工内容、撹乱属性、残量と確定期限を持たせる。死亡で過去の経験を新鮮な経験へ戻さない。保持期間と経験の有効鮮度は別に減衰させ、再取得/再放出/Q加工で元時刻や上限期限を無限に更新しない。

死亡地点を起点にし、周辺への増減・広がりは局所セル則と有限量で扱う。死亡時の種になる生成と、周辺のCA更新を区別する。生存している発信者が近くにいることを全更新の必須条件には残さない。死者の痕跡が原因である以上、元個体が不在でも由来スナップショットから処理する。

同じ場所の大量死で無制限に情報が蓄積しないよう、セル内の保持件数/量/期限を上限付きにする。整理で別発信元の実績や時刻を混ぜて架空の優良情報を作らない。間引く対象は表示や動物計算ではなく、定義された情報資源の有限容量。蓄積/消費/失活/容量不足を観測する。

新方式の既定生成では架空の死亡者・経験を持つ初期情報を置かない。既存の初期情報量欄/旧記録は版別に扱う。新方式で初期情報をどう提供するかは、由来の明示がない限り追加しない。情報読取は採食/同化と分離し、通常栄養を一切与えない。見た目の発光や漂う表現を、栄養エネルギーの保有量と解釈しない。

## 4. 内容と作用強度

主生物の学習では既存の9行動重み（攻撃圧/危険回避/資源欲求/仲間親和/空間確保/場所愛着/探索性/方向維持/ランダム性）への補正を比較基準として維持する。全生物の作用先と場所刺激は持続情報の正本9節に従い、情報を個体の重み補正だけに限定しない。1件の代表内容は上位最大2項目を比較基準にし、本人の素質/経験と区別する。身体攻撃力やDNAへ直接加算しない。

標準1倍では、情報内容×受信感度×鮮度×環境一致を計算し、1項目±3の基本上限を通す。生成時の「情報の行動への影響度」kを最後に掛け、上限も±3kとする。最後は重み0〜100で制限する。例えば標準+2の取得はk=0/0.5/1/2で+0/+1/+2/+4。例は他要因の更新前であり、同ターンの本人学習/出生重みへの回帰/飽和で最終差は変わり得る。

kの基準値は1。明示0も有効な固定値とし、情報の生成/保持/読取の観測と既定費用は維持して、情報による学習補正と場所刺激を0にする。情報からの栄養は全倍率で0とする。発生量・寿命・取得間隔・本人の経験・P直接誘導/QのP向け補正を同じ設定で変えない。Q加工情報にも同じkを一度だけ適用する。単純な近接だけで重みを増やさず、内容の受容と適用を必要とする。環境情報の読取だけでは痕跡を消費しない。通常個体/親養育者の伝達も成立した局所受容を必要とする。重複学習や取得待機は別条件として維持する。

高実績だから常に正しい情報ではない。異なる環境や競争相手には不利な場合があり、古い情報に従うことも損失になり得る。情報量/重み差だけで生存改善・協力・創発の因果を認定しない。

## 5. Qの主力：出現率上昇と内容歪曲

寄生中のQはPを通じて結び付く宿主Hの経験へ有償の痕跡を与える。Hの死亡時に、基礎実績から決める情報出現率へQ由来の上昇分を上限付きで適用する。生成に成功した情報はQの痕跡に応じて内容を歪曲する。これは情報の発信元H、直接寄生先P、加工者Qの別ID/作用経路として保存する。

Qは発信者の生存実績そのものを書き換えない。出現率上昇・内容歪曲・生成後の受信作用を別の係数にし、Qの相/栄養状態/活動費に応じて実効量が変わる。主作用はこの二つとし、情報の寿命延長/受信感度増幅を自動的な追加能力にしない。P直接誘導への小補正は別係数のまま維持する。

Qの離脱/死亡後は新しい痕跡を与えず、既に刻んだ痕跡が期限/減衰内で死亡情報へ反映される。成体Qが盤面の既存情報を書き換える案は採用しない。遠隔で将来の死亡者を再加工せず、同じQによる無限上乗せや期限更新を防ぐ。

元の発信者の実績・経験と、Qによる歪曲方向/量を分けて保持する。歪んだ情報が残りやすくなっても、その内容が成功経験として真実であると判定しない。改変した情報が第三者へ届いて行動が変わり、Qの生存/寄生先遭遇/子の定着へつながる経路を評価し、加工件数だけで利益と数えない。

## 6. 観測と比較

死亡対象/実績/基礎出現率/Q出現率補正/抽選/生成/容量不足/活動費不足/失活、同層/全層、内容付き取得/範囲不適合、直接重み変化、行動選択の違い、Q歪曲由来を別集計にする。生成場所は死亡セルであり、受信場所/現在位置と区別する。由来が不明な情報を推測で成功個体へ帰属させない。

既存の全ターン3グラフと現在像サマリを維持し、通常画面に長いCSV説明や第四の全期間グラフを追加しない。細かな原値は図鑑結果から確認し、表示軽減で集計を省略しない。

影響評価は同じ初期条件の通常/情報の行動補正なし/Q加工だけなしを診断比較する。全条件で情報の栄養は0。比較目的に応じてQの出現率補正/歪曲/費用を分離し、生態が分岐した後の差を「情報補正一回だけの直接効果」とは断言しない。固定3→固定10+未使用3→製品Worker/保存再生へ接続し、R1〜R6を維持する。

## 7. 全生物・同層向け/全層向け

情報の発信/受信対象は主生物、一次消費者、生産者群落、分解者、P/Qを含む全生物へ拡張する。個体・群落・群体の集計単位を維持し、群落の部分採食や感染体量の失活を死亡情報の発生へ置換しない。生物ごとの実績は寿命/維持/生産/繁殖/宿主伝播等の適用可能な少数値から定義し、全対象へ攻撃や雌雄を捏造しない。

| 情報の適用範囲 | 受信条件 |
| --- | --- |
| 同層向け | 発信時に記録した層IDと、受信時の対象の層が適合する場合だけ作用。別系統でも同層なら対象にできる |
| 全層向け | 生態系の全層の生物が受信候補。ただし、その場へ到達して読取/文脈/感度等の条件を満たす必要がある |

全層向けは全マップへの即時一斉命令ではない。適用範囲（誰に作用できるか）と、空間的な到達距離/残存量は分離する。範囲が広くても内容が非適用なら架空の変化を作らず、取得/適用不能を記録する。生産者には移動や攻撃を強制せず、維持/成長/繁殖への資源配分等、実在する選択項目に対応させる。基礎能力やDNAを無条件に書き換えない。

各情報の内容成分へscope（同層/全層）と適用条件を持たせ、発信層と由来を保存する。同じ束の全層成分で他成分の親子/同層条件を上書きしない。一つの情報を二種類として重複生成/二重学習せず、出現比率や対象ごとの感度は版付き調整値とする。同層情報を全層に偽装する操作は今回Qへ追加しない。

情報の層区分は利用者回答により、生態系ピラミッドの役割を基準にし、分解者/P/Qを別枠として確定する。

| 層ID | 役割 |
| --- | --- |
| producer | 生産者 |
| primary-consumer | 一次消費者 |
| secondary-consumer | 二次消費者 |
| higher-consumer | 高次消費者 |
| decomposer | 分解者。通常の消費者階層へ混ぜない |
| P | 一次寄生。宿主自身の層とは別 |
| Q | 高次寄生。宿主P/Hの層とは別 |

「主生物」は表示/操作上の区分として維持し、情報の層IDに使わない。主生物の光合成・植物食・動物食・雑食等を同じ高次層へまとめない。役割タグは版付きの食性/生産様式/生活状態から定義し、情報の受信のたびに乱数で所属を決めない。

複数食性の生物は複数の有効役割を持てる。同層向けは発信時の役割集合と受信時の役割集合に共通IDがあれば適合し、共通IDの数にかかわらず一情報を一回だけ適用する。全層向けも一回だけ適用。適用項目/文脈/局所到達の判定は別に維持する。所属不明は記録して推測で補わない。

発信元の役割集合と役割定義版は死亡情報へ固定保存し、受信側はその時点の確定した有効役割で判定する。生活状態で役割が変わる場合は状態遷移時に更新する。Qは寄生中/自立成体のどちらもQ別枠を持ち、宿主の層を自動継承しない。QがH由来情報を歪曲しても、発信層をQへ置き換えない。

情報の離散的な役割タグと、生物量ピラミッドで実測栄養履歴から配分するBは役割が異なる。Bの配分比や一時的な採食一回を、そのまま毎回の情報所属タグへ変換しない。表示グループ・適用役割・実測Bを保存/説明で区別する。

## 8. 調整と未実装

個体の情報保持資格と、死亡時に被害などの痕跡を残す資格は分ける。情報保持には一定の実経験の蓄積を必要とするが、低実績の被害者も警戒情報の根拠になれる。高実績の出現/残存優遇だけで危険情報を消さない。一般経験を学習へ、死亡セル近傍に結び付く経験を場所作用へ接続する。

学習/場所刺激の分離、環境情報の非消費読取、集中・独立反復の飽和、親養育者から幼体への強い伝達は持続情報の正本に採用済み。個別閾値・係数・処理順/費用・局所更新の詳細はC02以降で確認し、新しい固定数値をここで推定しない。

Q自立成体は通常の採食で栄養を得て、既存情報の局所加工は行わない。Q主作用は出現率上昇と内容歪曲。従来の3確認と層区分の最終確認は利用者回答により解消済み。具体の食物適合/代謝係数、出現率/痕跡減衰/期間/同層・全層比率/倍率の許容範囲等は後続比較で選ぶ。新モデルは未実装・未測定で、目標生存率を保証しない。
