# 第4組：状態の表示・説明・計数・保存

仕様版 `observation-state-contract/1`。利用者が採用した第4組の現在正本。第1組の情報循環、第2組の寄生/遺伝適応/抵抗/Q第四相、第3組の群落更新/独立植物を、現行UI/観測/図鑑へどう対応させるか定義する。[観測UI](observation-ui-v1.md)、[サマリ](ecosystem-summary-v1.md)、[関係面](relationship-network-v1.md)、[保存](archive-history-v1.md)、[表示軽減](display-load-reduction-v1.md)のうち明示した条件を優先する。今回はA/B文書反映のみで、ゲームコード/画像/保存実装の変更や新モデルの動作/性能実測はない。

[造形対応/1](appearance-correspondence-v1.md)を植物/P/Qの採用形の現在正本とする。森冠/星冠/淡水系統の本体・可食量、P形態×本人相、Qの旧IV除外/最終IV、年齢との独立を同じ確定状態へ対応させる。画像の保存は実行素材/画面の更新ではない。

## 1. 配置と画面の役割

| 領域 | 現在の役割 |
| --- | --- |
| 上部の一体サマリ | 総括1文・関係面の統合図→実生物量Bピラミッド→現在構成ドーナツ。分散配置しない |
| 右側の常設3パネル | 全期間の個体数推移、集団構成、生態関係。折りたたみ/個体詳細との置換をしない |
| 独立した横詳細 | 個体/系統/群落/寄生/情報の選択内容。盤面やグラフの上へ被せず、閉じても3パネルを復元する処理は不要 |
| 作成/初期設定画面 | ライブ3パネルを表示せず、取消/失敗で保持中の履歴を破棄しない |
| 図鑑の結果分析 | 保存結果の最終サマリと全期間3パネル。ライブ世界と混ぜない |

現在像の構成/Bは最新確定状態、関係面は100T区間の上1大図/下4小図で500Tを分担する。既存の広がり/多様さ/持続性の50T観測窓と混同せず、期間/単位/根拠の短い補助値を残す。100T境界/途中区間/続行時の扱いは関係面正本を維持する。総数の重複、3観点の棒や恣意的総合得点、長い説明パネルは追加しない。標準寸法は一画面把握を目指し、狭幅は判読性を保つ縦配置にする。

## 2. 盤面で区別する状態

| 対象 | 確定状態から示す違い |
| --- | --- |
| 基底群落 | 可食部の疎密/量、残る基部、活性/衰退。可食部0と完全消失を同じ空マスにしない |
| 独立四相植物 | 系統/相/枝/個体年齢を別軸で示す。被食による葉量低下を老化や相の後退にしない |
| 寄生P | Hへの付随。自由歩行する地表個体や主生物の占有枠として描かない |
| 寄生中Q | Pへの付随。卵/幼生/発育/羽化準備等の生活状態と相/年齢を分ける |
| 第四相Q | Pから離脱した自立群体。Pの死亡とQの自立を同じ遷移に対応させる |
| 体外感染体 | 水中等に存在する有限量/感染性/期限。生きた寄生群体の記号/数と混同しない |
| 死骸/植物遺体 | 生体から区別した残存物。可食量と感染性は別状態 |
| 情報 | 滞留/浮遊する非栄養の痕跡。量/鮮度/期限と、死骸/感染体/可食栄養を分ける |

遠景の既存記号と近景の絵柄・採用造形は維持する。近景の主生物は明度/彩度/輪郭の描写と事前に用意した接地/局所陰影で背景から識別し、装飾的な囲み枠を使わない。背景の奥行き/自然な接続も維持し、毎フレームの全画面暗色マスクに戻さない。同居は描画順/ずらし/同じIDのヒット対象で識別する。

主生物以外の名札は既存の分類別ON/OFFと同期し、消しても個体/群落/寄生対象の選択を失わない。系統の複数選択は固有色で所在を強調し、0数の現在一覧項目は消すが過去グラフから絶滅系統を消さない。遠景での強制記号化と近景の任意簡略表示、幼体/老齢マークの独立切替は既存条件を維持する。

## 3. 横詳細と観察者の知識

通常の要約は名称/系統/相/年齢/性別または階級/現在状態を短く示す。該当しない項目は捏造せず、内容に応じて必要な詳細を同じ枠内で確認できるようにする。

| 対象 | 詳細の対応 |
| --- | --- |
| 寄生 | H/P/QのID/結合/所在、曝露/侵入/定着/発育/移行、成熟窓、羽化準備/不足理由/結果 |
| 適応と抵抗 | 宿主選択の好み、寄生先別の遺伝適応、後天抵抗の対象/残存、当該条件の実効費用/成功率を分離 |
| 群落/植物 | 基部/可食部/活性/蓄え/再生、同ID回復/新ID再成立、個体の成熟条件/相/枝/進化実績 |
| 情報 | 発信元/由来/内容/適用範囲、本人経験と受取内容、元経験の古さ/鮮度・生成後の期限、Q痕跡/学習/場所刺激 |

これらは観察者向け解析であり、生物が相手の遺伝子/内部状態/正確な成熟時刻を知る能力ではない。計算で確認できる値/記録された根拠だけを表示する。成功率は経路/宿主適合・窓・費用を通った条件付きの値で、不適合/窓外を高い率で成功できる表示にしない。未観測の値を0や成功へ補完しない。

低根拠の半重みを正しさ50%と表示しない。Qの情報歪曲と元経験/実績を別に示し、濃度や発光を安全性/真実/栄養価として説明しない。全層向けは局所へ届いた適用可能な生物への作用であり、全域命令ではない。新しい遺伝適応/抵抗等の数値欄を常設の別グラフへ拡張しない。

## 4. 演出と確定結果

移動/採食/生体捕食/攻撃/実防御/排除/感染/羽化を、既存の行動マーク/短い演出で区別する。命中/実損害/軽減/栄養移転/感染段階の確定結果を元にし、試行/接近だけを成功演出にしない。死骸食と自分で殺した捕食も分ける。

Q羽化ではPの死亡/同Qの離脱/第四相更新を一回の確定遷移から描く。Hを直接死亡表示せず、羽化に成功したQまで付随死亡にしない。失敗は準備/不足/費用の状態として示し、毎表示で羽化を再抽選しない。群落の部分採食/再生を死亡/出生モーションにしない。

補間中の見た目を計算上の占有/攻撃対象/生体数に使わない。モーション省略でも確定位置/必要な識別/横詳細の値は維持する。新しい演出の作画/全系統差分の完成は今回の文書反映から認定しない。

## 5. 記録数・生物量・量・欠測の契約

| 量 | 数え方 |
| --- | --- |
| 生きた管理対象数 | 動物個体/独立した大型植物個体/基底植物群落/P-Q群体を各IDにつき一度。H/P/Qは別IDだが、Qの付随/離脱を二重計数しない |
| 体外感染量 | 感染性だけが残る水中/死骸内の有限量は、生体数へ加算しない。生きた群体が実在する場合はその生存状態/IDを別に判定 |
| 情報/死骸/資源量 | 生体数/群落数へ加算しない。量/期限/用途/移転を別に持つ |
| 生物量B | 実在する生体B。群落の基部/可食部等は既定の収支で一度合算し、P/Qに架空Bや宿主のBを付けない |
| 未該当/未記録 | 0、非該当、未観測/未記録を区別し、存在する年齢/相を捏造しない |

例：H1＋P1＋Q1からQが羽化した場合、同じH1＋P0＋同じQ1（第四相）となる。Qを新群体として追加したり、Hを死亡として減らしたりしない。可食部だけ減った群落は1記録のまま。完全消失は0、新ID再成立は新しい1記録で、旧IDの復活とはしない。

ドーナツは内側の生物グループ/外側の系統が同じ全体分母を使う。主生物という表示グループとピラミッドの栄養階層を混同しない。森冠/星冠/淡水系統は生産者へ一回だけ集計し、主生物同等の詳細/追跡の対象でも主生物数へ二重加算しない。本体内の葉/受光膜/可食量を別個体数にしない。雑食等のB配分は合計Bを保持し、B未定義/食性未観測を別区分へ残す。生産量/可食量/占有率/作用量を同じ尺度へ換算しない。逆転ピラミッドだけで異常を断言しない。

## 6. 全期間3パネルと現在サマリ

個体数推移は系統別積み上げ実数、集団構成は相/雌雄/年齢の3本の実数時系列。いずれも既定の主生物から全体/分類群/系統を選択できる。集団構成は対象を3本で共通にし、相I〜IV/雄・雌・無性別/幼体・成体・老齢を区別する。性別と社会階級を同じ区分へ潰さず、特殊内訳/非該当を明示して二重計数しない。Q第四相の成熟羽化という例外を維持する。

群落の代表相/成立後経過を内部全株の年齢分布に見せない。該当しない年齢等は非該当として母数を保つ。100%化や最新Nターンだけへの切捨てをせず、0Tから全確定ターンの原値を保持する。表示上の間引きは収集/保存と別である。

生態関係は接触/試行/成立作用/継続と、その量/期間を分ける。P→H/Q→Pの直接関係、Pメタ誘導、QのP向け小補正、情報由来の間接作用を区別する。Qの存在/情報量/同居だけで成立線・複雑さ・因果的重要性を加点せず、同由来/区分の重複を排除する。

一体サマリは全体総括1文、3面をまたぐ実際の担い手/役割別優勢、Bピラミッド、同分母ドーナツを保つ。3観点の50T指標と100T関係面/区間境界を区別し、右側の全期間グラフを置き換えない。通常観察は対象選択以外の細かな分析操作を要求せず、詳細分析/CSV等は図鑑の最終結果へ集約する。

## 7. 保存・再生・旧記録

保存対象は初期/全実効条件、計算/乱数/指標/状態定義の版、最終集計/収支/状態要約、全確定ターン原値、100T関係面の区間要約/境界値。第1〜第3組の遺伝形質/抵抗/生活環/相/年齢/発育/窓/羽化/群落更新/情報由来と、表示/集計の対象ID/単位/データ有無を対応付ける。

表示用の集約や補間画像と保存原値を分ける。全個体/全内部株の全行動映像や毎ターン完全世界の保存は追加せず、再現に必要な初期条件/計算版と現在状態/確定集計/少数由来を使う。保存された初期状態から同じ計算を再実行し、同じ終端/指紋へ到達したかを照合する。

単なる再生では新規保存せず、再生後の明示保存だけ別ID/元記録参照を持つ新記録にする。保存失敗は成功表示せず、保留結果/旧図鑑を保持して既存の再試行/救出へ接続する。新世界生成は未保存警告なしで進め、成功時だけ世界/履歴を置換する。

旧記録の欠測/旧栄養情報/旧Q三相・非致死羽化/旧個体植物を新仕様で補完しない。読める旧結果は旧定義で閲覧し、未記録は未記録と示す。未対応版/破損等は理由を示し、読めない値を0へ置換せず元データを上書きしない。新定義の再生互換/スキーマは後続接続で版付きに設計し、既存schema2へ黙って追加したとは報告しない。

## 8. 進行・選択・表示軽減

通常の停止操作は右上の開始/停止と説明/図鑑/設定等の別画面遷移へ集約する。同じ観測画面の種族/個体/所在強調/追跡/横詳細/表示/グラフ対象では停止しない。手動停止中も観察操作を使える。区間終了/終了/エラー・計算待ちは既存の別状態で、進行中のように見せない。

復帰は世界IDと進行意図を維持し、別世界/終了/エラーへ古い再開予約を流さない。生成失敗や遅延応答で旧世界/履歴を壊さない。UI操作から学習/感染/変異/羽化/乱数を進めない。

表示軽減はモーション/粒子/追加札/描画更新頻度へ限定し、近景の原画/系統差/必要な所在と選択は維持する。最大軽減だけで近景を記号化しない。操作中の背景簡略化は既定OFFで独立切替、陰影は事前素材/キャッシュを使う。生態/個体数/行動/収支/全ターン集計/保存を間引かず、手動停止/終了/選択時は最新確定値を残す。

## 10. 実装への引継ぎ順序

1. 現在製品の計算署名/初期条件とA/B差分を固定し、初期係数・適合/役割/状態フィールド・単位/保存版の対応表を作る。未決値はこちらが候補を選び、暗黙の既定値を使わない。
2. 既存C/Dの対象責務/検査接続を実読して更新要否を整理する。新しい分割が必要なら従来どおり事前確認。今回C/D/Eは更新しない。
3. 描画なしの基準再現一致を確保し、生産基盤/群落、独立植物、寄生/抵抗/Q羽化、情報循環を単独差分から結合する。UIだけで生態結果を変えない。
4. 固定条件の短期比較→有望候補のR1〜R6→未使用固定条件の退行確認。失敗/未評価を残し、成功した世界だけを選別しない。
5. 同じ計算をWorker/全ターン観測/保存再生へ接続し、画面遷移/再開/再生成/保存失敗と計数の一致を確認する。
6. 現行UI/採用モックと照合し、遠近・同居・各状態・行動マーク・標準/狭幅・軽減ON/OFFを仕上げる。重要な見た目を変える場合は必要な代表例を提示する。

後続の受入観点はQ羽化のH1/P0/Q1と一回性、感染体/情報/死骸の生体数除外、群落同ID回復/新ID再成立、相/雌雄/年齢と非該当の合計、同分母円/B配分、全ターン/100T境界/欠測、表示切替での生態不変、停止/遷移/再開/保存の整合。文書照合をこれらのゲーム合格へ流用しない。

第1〜第4組の構造/提示済み比較値と植物/P/Qの造形対応はA/Bへ反映済み。次は実装差分・データ対応とC/D接続要否を整理する。採用画像の保存は実行用素材の更新とは別であり、本ターンは3core・C/D/E・src/tests・製品4.2.32・配布物を変更しない。
