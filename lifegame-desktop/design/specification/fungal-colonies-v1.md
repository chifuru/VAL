# 菌膜群落 / fungal-colony/1

> マス再編の現在採用仕様は[マス再編/1](cell-reorganization-v1.md)。新正本9節の6群落・基部1＋可食3、環境/土壌/有限配分、出生費、最大0.4B/Tの衰退、背景分解を優先する。下記の1マス1群・可食容量12・連続不足12T等は旧製品の値である。菌食の基部保護・無償再生禁止・群落の非一斉寿命は維持する。 新正本はA/B反映のみで、製品4.2.77・既存証跡は旧対象版のままである。


利用者の「菌膜を群落化」に基づく採用差分。従来の分解者一個体を、1マス1群落へ変更する。既存の草棲虫・水游虫は個体のまま。造形・生産者/消費者/分解者の役割、P/Qの宿主/生活環は変えない。旧記録は旧個体モデルで再生する。

- 群落数、基部B、可食部B、蓄えE/M、活性、実分解・実再生量を区別する。描画上の菌の数を個別に計算しない。
- 通常採食は可食部だけを消費する。同ターンの複数の採食も同じ有限在庫を使い、基部は食べ尽くさない。可食部0は死亡ではなく同じ群落IDで再生できる状態。
- 再生は既存の有機物・死骸から得たEを支払いBへ変換する。光合成・無条件の栄養補給・死亡後の無親再配置はない。既存の鉱物吸収範囲も拡大しない。
- 基部にも正の維持費がある。可食部がない間は維持費が小さくなり、入力が途絶えて蓄えを使い切り、維持不足が続けば群落は消滅する。死亡時は残E/B/Mを一度だけ死骸へ移す。
- 群落の成立後Tと稼働・分解の実績を持つ。個体寿命80Tで一斉に死ぬ規則と個体の幼体/成体/老齢は適用しない。年齢・雌雄構成では非適用として集計し、成体へ偽装しない。I/II相の成長は実入力/蓄え・稼働に従う。
- 隣接群落の成立は既存の適地・空き枠・CA近傍・出生費を維持する。新群落は別ID/親/世代を持ち、同IDの可食部再生とは区別する。既存の分解者枠を使い、離れた群落との無条件共有や枠追加は行わない。
- 計数・名札・説明・全ターン原値・CSV・図鑑保存/再生で単位を群落へ揃える。身体Bと個数の割合は別。元の菌膜の絵柄を維持し、群落の説明に必要な状態だけを表示する。

新規則は `survival/4` に分離。実効設定には版付きの群落比較値を保存する。開始比較値は基部1B、可食容量12B、最大維持.0375E/T、可食部0の維持.01E/T、再生上限1B/T、再生費1.2E/B、留保2E、連続維持不足12T。初期の総E/B/M、初期群落数と0指定を無断で増やさない。比較値の有効性は実測で判断する。
