# 生態系の餌：種類・環境差・量の表現（A1.2 / B5）

ユーザー指定：情報は滞留・浮遊するエネルギー体。餌はFizzBuzz分類に固定せず、ライフゲームの生態に合わせて増やす。同じ餌でも環境・量によって見た目を変える。以下はA/B草案。生物の元となる20系統は保持する。

## 餌の種類の候補

Fizz/Buzz/FizzBuzzを餌の分類名や生成条件には使わない。数字と情報は独立した食べる資源として残す。以下の10種類は初期候補であり上限ではない。情報以外の役割・効果量は提案。

| 餌 | 基本形 | 役割の案 | 環境に合わせた見た目の例 |
|---|---|---|---|
| 微藻群 | 薄い葉・微粒の群れ | 基礎栄養 | 水域は透明な葉群、熱域では耐熱色の短い膜状群 |
| 岩間苔 | 岩に沿う短い植生 | 維持・緩やかな回復 | 湿潤域では柔らかく、静域では短く密な苔 |
| 菌膜 | 面に沿った薄膜 | 回復寄りの栄養 | 水域は濡れた緑、熱域は赤褐色、情報域は発光模様、静域は灰緑 |
| 胞子房 | 小さな房と胞子粒 | 成長・備蓄寄り | 水域は膜に包まれ、熱域は乾いた房、静域は殻状 |
| 水生卵 | 膜に包まれた楕円粒 | 繁殖前の蓄積寄り | 水面と深水で透明度・房のまとまりが異なる |
| 有機粒 | 茶・琥珀色の欠片 | 汎用の栄養 | 水域は沈積した粒、乾地は乾いた欠片 |
| 鉱物片 | 硬い角・欠片 | 鉱物成分 | 水域は丸い沈積片、熱域は黒曜/熱色、静域は層状 |
| 鉱液滴 | 丸い滴と薄い液膜 | 鉱物成分の別資源 | 水域は淡い滴、熱域は粘性のある滴、静域は小さい滴 |
| 数字粒 | 読める数字を持つ粒 | 数字の摂取。栄養/成長への配分は検討中 | 水域は透明な泡、熱域は熱光、情報域は細い光の数字、静域は淡い印 |
| 情報エネルギー | 半透明の光霧・帯・発光核 | 個体外に残る経験の媒体。摂取で本人の6傾向へ作用 | 下記の4環境差分 |

成立する環境・地形、食べた効果は、見た目の差と別に定義する。描画例があることだけを理由に、その環境で必ず生成・大量供給される仕様にはしない。単一系統だけが食べられる専用資源に固定せず、共有資源を巡る競争を残す。

## 情報：滞留・浮遊するエネルギー体

情報は鉱物のような硬い結晶・石片ではなく、その場に滞留する半透明のエネルギー。ゆるい渦・薄い膜・光の帯・小さな発光核を共通の形とする。生物の顔や翼は付けない。

| 環境 | 同じ情報エネルギーの表現案 |
|---|---|
| 水域 | 青緑の波紋を帯びる淡い光霧 |
| 熱域 | 金橙の縁と熱の揺らぎを帯びる光の塊 |
| 情報域 | 細い帯と紫青の渦が重なる光 |
| 静域 | 白紫の静かな霧だまり |

以前の符号晶・流路結晶等の「情報結晶8差分」を物理的な餌の分類として固定した案は置き換える。水流・熱・防衛・生還等の経験内容は、同じ情報エネルギーに載る内容や文脈として扱う。環境の見た目、量、経験内容の濃さは別項目。

浮遊はまずセル内の見た目の揺らぎとして扱う。別マスへの漂流・風・流体シミュレーションは追加しない。マスを越える影響は資源の近傍更新と個体の移動・摂取を通す。

## 同じ餌の環境差と種類の区別

同じ餌IDの色・材質・模様・まとまりを現在環境に合わせて描き分ける。菌膜は環境で見た目が変わっても同じ菌膜であり、近傍数を別種類に分断しない。役割や成立則まで異なる場合だけ、別の餌IDとして定義する。

環境変化で成立条件を外れた餌は次のセル更新で消滅する案。成立条件を保つ餌は残量を保持して外見だけ切り替え、別の資源や満量へ置換しない。

## 量で見た目を変える

各資源に上限付き残量を持たせ、残量/その餌の上限の割合から少・中・多の見た目を選ぶ案。区切りの数値は未確定。量の増加は細部と密度で示し、1マスを越えて大きくしない。

| 餌の形 | 少量 | 中量 | 多量 |
|---|---|---|---|
| 藻・苔・菌膜 | 小さな斑・薄い被覆 | 複数の斑・中程度の被覆 | 密な葉/膜・重なり |
| 胞子・卵・有機粒・鉱物片 | 少数の粒/欠片 | 数粒のまとまり | 密な房/堆積。粒を無制限に増やさない |
| 鉱液滴 | 小さな滴 | 複数の滴 | 厚い滴と重なる液膜 |
| 数字粒 | 薄い粒・少ない光点 | 明瞭な核と光点 | 密な光点と輪。数字そのものは残量で書き換えない |
| 情報エネルギー | 小さな核と薄い霧 | 複数の核と中程度の霧 | 密な光帯と重なる核。強い光で個体を隠さない |

ゼロなら採食資源を表示せず、正の少量は消費可能だと区別する。色や光だけでなく形・密度・詳細の残量表示を併用する。残量と、数字の値/情報の内容/経験の確かさを混同しない。

## 生成・維持・消費

[餌セル更新仕様](food-cellular-rules.md)の近傍条件を必須とする。量だけで餌を誕生させない。B3/S23は基準案であり、環境適合だけの自動湧き・時間だけの全量回復を行わない。採食で残量が減り、ゼロならセルが空になる。維持しただけで満量へ戻さない。
