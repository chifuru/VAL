# 環境別の餌差分（A1.2仕様案）

合意した方向：各マスの環境で餌に違いを設け、特に生命系は複数の差分を持つ。以下の名前・形・役割・発生条件は認識合わせ用の提案。ゲーム実装は変更しない。

## 4入力の区別を保つ

生命差分を増やしてもすべてFizzとして扱い、鉱物Buzz・情報FizzBuzz・数値入力との区別を保つ。生命の差分を20系統の個体と混同せず、マス上の採食資源として表示する。数字も食べて消費する資源とし、成長調整・栄養への作用は最新仕様で検討する。

| 環境案 | 生命Fizz：3差分 | 鉱物Buzz：2差分 | 情報FizzBuzz：2差分 | 数値入力の表現案 |
|---|---|---|---|---|
| 水域 | 微藻群／浮遊プランクトン／水生卵 | 塩晶／沈積砂 | 潮紋片／流路結晶 | 潮汐数列の印 |
| 熱域 | 耐熱菌膜／熱胞子／赤色地衣 | 黒曜片／熱鉄砂 | 熱振動片／放射結晶 | 熱周期の印 |
| 情報域 | 光藻群／発光菌／共生菌膜 | 導光鉱／共鳴鉱 | 符号晶／共鳴片 | 脈動数列の印 |
| 静域 | 休眠胞子／岩間苔／低代謝微生物 | 層状石／微晶砂 | 記憶片／残響晶 | 静穏数列の印 |

生命12種、鉱物8種、情報8種、数値の環境別表現4種を提案する。これは20系統以外の新たな生物個体を盤面へ追加する案ではない。4環境の名称も引き続き検討対象。

## 生命の違いを見た目だけにしない

| 生命差分 | 見た目の案 | 特徴づける役割の案 |
|---|---|---|
| 微藻群 | 小さな葉状のまとまり | 安定した基礎栄養 |
| 浮遊プランクトン | 透明な小粒の群れ | 成長に向く栄養 |
| 水生卵 | 膜に包まれた楕円の粒 | 繁殖前の栄養蓄積 |
| 耐熱菌膜 | 岩に沿った薄い膜 | 熱域での適応経験 |
| 熱胞子 | 粒を放つ小さな房 | 熱域での成長傾向 |
| 赤色地衣 | 岩面に張り付く葉片 | 維持に向く栄養 |
| 光藻群 | 細長い光る葉 | 情報域での適応経験 |
| 発光菌 | 点状に光る傘・粒 | 回復に向く栄養 |
| 共生菌膜 | つながった網状の膜 | 繁殖前の栄養蓄積 |
| 休眠胞子 | 殻に包まれた粒 | 保存が利く栄養 |
| 岩間苔 | 岩のすき間の短い葉 | 緩やかな回復 |
| 低代謝微生物 | 少数の小さな群れ | 省エネ型の維持 |

役割は差分設計の候補であり、効果量・回復速度・保存期限は未確定。摂取でDNAを書き換えたり部位別XPを復活させたりしない。個体全体の成長、状態、環境経験、進化分岐の条件へつなぐ。

## 発生・回復・環境変化（最新の生成則を優先）

- 最新要求により、環境に合うだけでは生成しない。[餌セル更新仕様](food-cellular-rules.md)の近傍条件で誕生・維持・消滅を判定する案。無条件の時間回復は採用しない。
- 生命・鉱物・情報は独立カテゴリ、数字も食べる資源（作用は検討中）。各餌に固有の名前・役割・成立条件を持たせる案。種類の追加は可能。
- 環境変化で成立条件を外れた資源は次の更新で消滅する案。別の餌へ自動置換しない。
- 境界での餌混在は個別の成立条件と近傍を満たす場合のみ。環境名を理由に希少な餌を抽選で補充しない。
- 数値は促進・抑制の双方を取り得る案。栄養への寄与・進化条件への配分は未確定。

## 表示機能

盤面では色と形で4入力を区別し、生命は同じ緑一色・同じ粒だけにしない。選択マスの詳細に「Fizz / 微藻群 / 量 / 回復状態 / 主な役割」を表示する。餌の詳細から、それを条件に挙げた進化経路へ移れる機能を検討する。系統樹の条件からも餌の詳細を参照できる。
