管理版 `decision-register/16`。現在の仕様入口は [README](README.md)。マス再編の現在合意はS38と[マス再編/1](cell-reorganization-v1.md)を優先し、従来表の占有・初期値・具体化待ちのうち明示的な置換範囲を除く。既存A1が採用範囲、B5.2が説明と参照の整合を担当する。本書は現行条件の索引であり、会話履歴や変更履歴を蓄積しない。

## 状況の読み方

| 採用状況 | 扱い |
| --- | --- |
| 採用済み | 方針としてA/Bへ取り込んだ対象。具体化・実装・検証が終わった意味ではない |
| 保留 | 既存資料で将来範囲・未確定として残した対象。現在の必須条件へ自動追加しない |
| 撤回 | 後の利用者指示/現行仕様で置き換えた対象。古い文章や画像から復活させない |
| 提案のみ | 検討候補。採用済みの要求として実装しない |

採用状況はNodeの正式状態と別に管理する。全Nodeの草案状態・親子・層間参照は維持する。実装/検証の有無は対象版付き証跡と各Nodeで確認し、未実装を仕様未反映と呼ばない。記載があっても境界条件の足りない項目は「具体化待ち」とする。比較で選ぶ係数はその旨を示し、方針の欠落と区別する。

## 維持方法

要求は方針単位でID・採用状況・現在正本・残る具体化を結び付ける。利用者が変更したら、現在の行と参照先を更新し、相反する二条件を採用済みとして残さない。経緯はGit/作業ログへ委ねる。すでに記載済みの「情報適用/行動/結果の区別」「感染失敗の段階別集計」「栄養依存の偏り」は新規提案へ戻さない。

仕様の索引・採否整理だけでは、既存C/D/Eや製品4.2.32の完成・生存目標の達成を認定しない。第1〜第4組/提示済み比較値/植物・P・Q造形対応と量機の採用条件はA/Bへ反映。量機の分岐2画像は採用済み。次は比較案と専用データ/実寸素材・C/D接続を整理する。今回ゲーム実装/実測は行わない。
