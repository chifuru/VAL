# A・Bの採用状況と具体化待ち

管理版 `decision-register/8`。現在の仕様入口は [README](README.md)。既存A1が採用範囲、B5.2が説明と参照の整合を担当する。本書は現行条件の索引であり、会話履歴や変更履歴を蓄積しない。

## 状況の読み方

| 採用状況 | 扱い |
| --- | --- |
| 採用済み | 方針としてA/Bへ取り込んだ対象。具体化・実装・検証が終わった意味ではない |
| 保留 | 既存資料で将来範囲・未確定として残した対象。現在の必須条件へ自動追加しない |
| 撤回 | 後の利用者指示/現行仕様で置き換えた対象。古い文章や画像から復活させない |
| 提案のみ | 検討候補。採用済みの要求として実装しない |

採用状況はNodeの正式状態と別に管理する。全Nodeの草案状態・親子・層間参照は維持する。実装/検証の有無は対象版付き証跡と各Nodeで確認し、未実装を仕様未反映と呼ばない。記載があっても境界条件の足りない項目は「具体化待ち」とする。比較で選ぶ係数はその旨を示し、方針の欠落と区別する。
