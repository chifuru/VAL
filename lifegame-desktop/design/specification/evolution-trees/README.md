# 全20系統：第三相3分岐 → 第四相3×2分岐

**ユーザー指定の構造：各系統の第三相は3枝、その各枝の第四相は2枝、最終6経路。全20系統で第三相60形態・第四相120経路。雌雄差を別の枝には数えない。**

参照元の四相と名称を保持する。分類・特化名・経験の評価方法・造形差は具体化の提案。以前の2〜3枝・計46経路案を置き換える。実装は行っていない。
