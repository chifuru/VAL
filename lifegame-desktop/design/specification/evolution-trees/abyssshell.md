# 08 深殻系統：第三相3枝・第四相6経路

系統ID `abyssshell`。特徴は「重なる貝殻と深海の鉤爪」。基本系統・基礎DNA・仲間関係を保持する。

![深殻の3→6分岐図](diagrams/abyssshell.svg)

## 分岐の理由

元の生態傾向を参考にする環境：水域・静域。対応餌の例：微藻群・浮遊プランクトン・水生卵、塩晶、潮紋片。これは既存の環境傾向の参照であり、環境名だけで枝を強制する規則ではない。

| 第三相の特化案 | 分岐する経験の傾向 | 第四相の2方向 |
|---|---|---|
| アビサルド〔深海採食／採食・代謝〕 | 実吸収・餌配合・適合環境での資源利用 | 効率採集 / 蓄積回復 |
| アビサルド〔殻体巡航／機動・適応〕 | 有効な探索・移動後の成果・消費と環境適応 | 広域探索 / 地形適応 |
| アビサルド〔重殻防衛／戦闘・生存〕 | 敵との実交戦における有効な攻撃・防御・生還 | 攻勢 / 防衛 |

## 第四相6経路

| 親となる第三相 | 第四相の表記案 | 第三相で新たに必要になる経験 |
|---|---|---|
| 深海採食 | ウル＝ダルシェル〔効率採集〕 | 消費に対する吸収が高く、安定して資源を獲得 |
| 深海採食 | ウル＝ダルシェル〔蓄積回復〕 | 消耗後の回復と栄養維持を両立 |
| 殻体巡航 | ウル＝ダルシェル〔広域探索〕 | 新しい土地への移動が採食・生存につながる |
| 殻体巡航 | ウル＝ダルシェル〔地形適応〕 | 特定の生息地で効率よく移動・採食・生存 |
| 重殻防衛 | ウル＝ダルシェル〔攻勢〕 | 有効な脅威排除と交戦後の維持を両立 |
| 重殻防衛 | ウル＝ダルシェル〔防衛〕 | 損害の軽減・回避・回復によって生き残る |

栄養・成長・環境適応の共通条件に加え、親となる第三相で新たに得た経験を比較する案。相の既存名称を残し、特化は別ラベルとする。具体的な点数・閾値・見た目・能力補正は未確定。戦闘しない個体も採食・機動から第四相へ進める。第三相から繁殖でき、第四相を待つ必要はない。
