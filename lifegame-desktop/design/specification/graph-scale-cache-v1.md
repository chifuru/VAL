# 全期間グラフの縦軸最大値を再利用 / 1

全ターンの観測原値・全点の描画・3グラフ配置・色・集計対象・相/性別/年齢の共通縦軸を維持する。生態/乱数/保存形式へ変更しない。

集団構成の最大値は既存stackShapeの増分キャッシュを使用する。毎回の全履歴mapとMath.maxへの可変長引数展開を除く。新しい履歴キャッシュ/観測系列/間引きは追加しない。追記時は既存の追加行走査、同じ系列の再描画は追加走査なし。異なる系列/短縮は既存キャッシュ規則に従う。

効果は縦軸最大値の走査/一時配列/引数展開の除去に限定する。グラフ全点の描画コストは残り、アプリ全体や生態ターンの速度改善率は別に測らない限り報告しない。
