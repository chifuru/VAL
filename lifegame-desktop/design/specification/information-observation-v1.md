# 情報の由来・実効適用・Q媒介の観測

4.2.19の観測補完。生態の決定・費用・情報寿命・系統/DNAは変えない。遺伝子の水平伝播ではなく、環境に残った経験が行動重みに作用する延長された表現型として扱う。

## 計測単位

|原値|意味|
|---|---|
|generated|実際に支払いと配置を終えた情報資源の生成/増量取引数。同じ発信イベントの複数地点生成は複数件|
|received|実際に情報資源を取得した取引数。初期資源などpayloadなしも含む|
|applied / unchanged|payloadが処理され、情報による直接重み差が非ゼロ/ゼロだった適用件数。上限飽和・期限切れ等は適用成功にしない|
|deltaAbs|情報適用前後の丸め後の重みの絶対差合計。経験学習や10Tの出生基準への復帰は除く|
|mediatedGenerated|その生成/増量時にQ操作が実際に支払われた取引数|
|mediatedReceived / mediatedApplied|Q媒介印を持つ情報の取得/非ゼロ適用。Qなしとの差を測る反実仮想実験ではない|
|noiseReceived|撹乱印を持つ情報の取得|
|unattributed|payloadなし、または観測上の有効な由来を特定できない取得|

取得後に当日死亡するなど適用に至らない場合もある。取得＝適用とはしない。直接重みが変わっても次の行動が必ず変わるとは限らない。行動結果への因果寄与はここでは認定しない。

## 由来と関係性

成功した生成/増量と、今ある情報payloadから確認できるイベントID→発信系統を、観測側で元時刻+20Tまで保持する。再観測や再送で期限を更新しない。発信元が死亡しても期限内の受信を由来へ結び付ける。個体の全履歴を保管せず、記録の各ターンには集計だけを残す。受信時に初めて現れた出所不明情報を推測で特定しない。

情報作用の関係は、由来が既知かつ直接重み変化が非ゼロの場合だけ成立する。旧計測の「情報取得＝作用」を新計測へ置換し、追加定義information-observed/1で区別する。既存の生態関係3レーンはこれを利用する。旧保存結果は改変せず、旧情報関係は取得基準・新しい内訳は未記録と注記する。

生成/取得/適用の個体別ctxはターン確定用の一時観測。50Tの栄養履歴へ情報の個別記録を重複保持しない。由来キャッシュは有効期間分に限定し、観測容量不足時には追加を確定しない。

## 表示・保存

既存の生態関係パネル内に今ターンの生成/取得/適用/Q媒介取得・適用/由来不明を短く表示。3グラフ構成とサマリは維持する。詳細原値は全ターンCSVと保存結果へ出力。追加定義information-observed/1を保存し、未知定義・負数/不正数を拒否する。旧欠測を0にしない。
