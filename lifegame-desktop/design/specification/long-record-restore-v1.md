# 長期観測記録の復元 / 1

既存の検査を通過した全行を、可変長の関数引数へ展開せず順番に復元する。300,000行などの長い有効記録でもpushの引数上限で失敗させない。全行・時点・値・定義版・保存形式は維持する。

元記録との分離と、記録内で共有されたオブジェクト参照を保つため、既存のstructuredCloneによる全行複製を一回行う。その結果を1行ずつ追加し、既存の読取専用/CSV/系列取得/検査・読込予算を変更しない。新しい容量拡張や行の間引き、別保存形式は導入しない。

これは引数上限による復元失敗の修正であり、上限1GiBの実記録全体や長期シミュレーションの完遂、ブラウザ全体のメモリ保証ではない。

既存B5.4/C8.2/D9/E6内。新Node/分割/正式状態変更なし。中断中の速度変更は含めない。
