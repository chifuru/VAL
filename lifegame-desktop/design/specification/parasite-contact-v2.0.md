# 寄生の接触経路 v2.0

既存A1.5/B4.2の生活環に有償の接触による分散を追加する。Pは雌雄のない群体で宿主に付随し、空の地表マスへ独立配置しない。

近傍1の見通しの通る適合宿主と、8ターン以内に3回接触すると娘P群体を置ける。成熟した終宿主段階は近傍2へ最大3件、それ以外は1件。同日多重呼出しと新生群体からの連鎖を拒否。接触記憶は受け手ごと最大4発信源で期限付き。

発信元はターン開始時に存在し、段階別成熟4/6/6/8を満たす必要がある。第一宿主からは同じ第一宿主または適合小型餌へ、それ以外の未終宿主は同段階の宿主へ。成熟終宿主からは第一宿主・小型・適合主生物へ分散できる。主生物の成熟/適合条件を満たさない場合は追加中間であり、終宿主成熟を飛ばさない。

1件PのE0.12を支払い、娘E0.04・散逸0.08。QII以上がE0.06を払える場合のみ娘Qを付随させ、娘E0.02・散逸0.04。P待機は未終宿主18/終宿主3。各受け手は一群体、同時競合は初期値による順序独立調停。費用不足・感染済み・遮蔽・接触不足では感染しない。維持費と既存の有償放出は変更しない。

既存の捕食・感染死骸経路は維持。接触記憶/待機は有限の個体状態で再生署名に含む。初期感染数や宿主を無償追加せず、絶滅を救済しない。

Qの基本的な群体分散はIIから可能とし、IIIの整流/鮮度保持/変調という高度な情報作用とは分ける。娘Qは常にIから開始し、成熟状態や特化を継承しない。Q Iの段階では娘を分散しない。
