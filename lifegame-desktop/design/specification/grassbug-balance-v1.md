# 草棲虫の暫定バランス / 4.2.49

水游虫相当の存続条件をそのまま草棲虫へ適用した4.2.48では、固定湖の500Tで草棲虫が1526体まで増えた。草棲虫の適地は水游虫より広いため、同じ能力値でも同じ個体数にはならない。新規観測の草棲虫小集団だけ、比較開始値を一段下げる。

`consumerModel: group/1` と `consumerGroupSettings.version: consumer-group-parameters/3` の組で適用する。水游虫の実効値を基礎に、草棲虫の寿命を240T、維持費を毎T 0.06E、出生待機を2T、初期/最大HPを30とする。成熟年齢・初期E/B・E/B容量は同条件の水游虫を参照する。水游虫の優遇スイッチが無効でも、新版草棲虫の寿命/維持/待機/HPはこの値を使う。植物食、適地、採食効率、移動、種名、有限な出生費用と集団上限は維持する。

設定版2の水游虫完全一致、設定版1と個体モデルの旧挙動は変更しない。各旧記録は保存時の計算版で再生する。暫定値は固定河川・湖の存続と湖500Tの過密傾向を一度照合して採用する。全条件の生存率・性能をこの結果だけで認定しない。
