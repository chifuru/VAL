# 確定世界の詳細・追跡索引 / 1

同じ確定世界内の選択/詳細表示で、個体・資源・死骸を何度も全走査しない。IDとマスの索引を1つの現在状態だけ保持し、通常個体のIDは寄生虫の列挙より先に解決する。P/Qと旧寄生モデルの既存locate規則は維持する。

新世界の確定とターン確定では古い索引を明示破棄する。索引は世界参照/確定T/対象配列参照・長さの変更で更新する。開発用smokeの明示refreshでも破棄する。個体の値は複製せず参照し、詳細の表示固定/手動更新とは役割を分ける。マスの同居配列はコピーしてから従来の優先順へ並べる。初期配列の順序や生態計算を変更しない。

同居個体、資源、死骸、消失ID、P/Qの宿主・期限、選択と追跡の独立、ターン更新/別世界/明示refreshを保持する。描画用の既存索引・生態計算索引は作り直さない。新しい生態モデルや保存項目は追加しない。

範囲は既存B5.6/C8/D9/E6。新Node/分割/正式状態変更なし。中断中の3速度/10T描画は含めない。総合速度や全設定の認定は行わない。
