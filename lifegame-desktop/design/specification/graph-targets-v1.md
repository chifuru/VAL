# 生態観測の対象選択/1

既存分類（主生物・生産者・一次消費者・分解者・一次寄生・高次寄生）と全生物を第一段階で選び、第二段階で分類全体または所属系統を選ぶ。初期値は主生物全体。全生物では全体を表示し、個別系統は分類から探す。系統名は既存カタログを使い、個体数0でも履歴の系統を隠さない。

対象は従来と同じIDで個体数・相/雌雄/年齢の集計へ渡す。生態関係の全期間グラフは従来どおり全体の関係系列を表示することを短く区別する。図・分類・生態計算・保存形式は変更しない。

操作は停止/選択詳細/追跡と独立する。世界/図鑑のカタログに基づき表示し、図鑑から戻るとライブ対象を復元する。不在の系統は主生物全体へ戻し、無効な値で空集計を表示しない。
