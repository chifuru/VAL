# 所在強調・名札の確認/1

個別系統の固有色、分類全体の淡い共通色、複数選択と全解除を維持する。現行の生存P/Qは、生体宿主内だけでなく有効な死骸内/同一個体の移行待ちも、その記録上の現在マスへ強調する。死骸そのものや感染量を生存個体として数えず、期限切れの搬送個体は対象外。P/Qの生活環・感染成立の判定を変えない。

現在の生活モデルの生存P列挙を正として使用する。描画で繰り返し全探索せず、現在描画世界の候補へキャッシュし、世界の差し替え時に失効させる。生存Pに付随するQも同じ場所に含める。

既存の近景名札チェック、主生物の名称表示、選択対象の例外表示、分類チェックと詳細表示の独立を維持する。不要な一般型の文字を再追加しない。系統樹の正しい通常/相変異の説明まで削除しない。0体の項目は従来どおり隠し、履歴や選択状態は保持する。
