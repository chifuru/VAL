# 観測セッションと計算・操作 v2.3

利用者の2026-10-18実装指示による現行差分。既存の生態条件・決定した造形は維持し、本対象ではこの文書を旧2秒/1000ターンの記載より優先する。正式なNode状態は草案を維持する。

基本区間は500ターン、進行の目安は1ターン約1秒、約8分20秒。初回準備は最大60秒、画面操作・閲覧の停止は進行時間に含めない。重い条件では待機を表示して減速する。全端末・全条件で5〜15分を保証する仕様ではなく、個体やターンの間引きを行わない。500で停止して続行または終了して最終結果だけを保存する。

存続目標は参加した各主系統の150〜250ターンの連続存続、10条件中3条件を目標・最低1条件、終端500の勝者と存続集合の多様性を評価する。確率は半分にせず、寿命・成熟・進化・繁殖間隔も時間変更だけで半分にしない。目標率の達成判定には系統別の必要な標本数を要する。短い試行や未参加系統を成功として計上しない。

生態計算はローカルWorkerで行い、開始時に最大3ターンを準備、以後最大6ターンの待機バッファを維持する。未表示の未来を集計・詳細・図鑑へ出さない。三つの表示段階を各約333ms露出させ、確定後だけ集計を更新する。先行計算を使っても同期順・有限収支・競合調停・乱数列・子I相は維持する。準備が60秒を超える場合は計算を中止して確定状態から再試行できる。負荷待ちに早送りで追いつかない。

地形の近傍と隣接通行を先に作り、静的な視線判定を上限付きで再利用する。キーは寸法と確定した地形/環境/障害/光/壁の内容。土壌量や生物の占有は再利用対象にしない。同じ地形の再読込みはWorker内の最大2地形キャッシュを使う。SHAの一時領域も再利用し、乱数に必要な先頭32bitを同じSHAから直接取り出す。表示へは差分を送る。既存の遠景記号・詳細造形・地形素材・30fps上限を維持する。

操作中は再生を停止する。マップのドラッグ中は保持し、ホイール/ズーム/移動キー/表示操作の最後から1秒後に再開する。単なるホバーは止めない。個体クリックや「詳細を読みながら停止」は「閲覧を終える」まで、説明と図鑑は閉じるまで、設定は適用/取消まで保持する。停止理由が複数ならすべて解除されるまで保持する。手動停止は自動再開権を取り消す。タブを隠した場合も保持し、表示に戻った後に再開する。

再設定/リセット/手動送り/終了/観測対象変更は古い先行結果を無効化する。途中表示で操作した場合は最後の確定状態へ戻る。生態そのものを操作・壁時計で書き換えない。未完のターンを保存しない。再生結果を追加記録しない。設定編集の失敗で現在の世界を失わない。旧計算版の記録は版不一致として拒否し、削除しない。
