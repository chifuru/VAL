# 餌との重なり・早成型・高次寄生による情報操作

ユーザー指定：餌セルと生物の重なりを許容する。子は第一相から始め、第三相までで出生時完成度が高い系統も設ける。高次寄生は間接的な関係を利用し情報伝播へ作用する。A/Bのみの追加草案で、実装・生態成立・負荷は未検証。本書を占有枠/早成型/高次寄生の情報作用の最新案とする。

## 1. 重なりを許す占有枠

一セルを以下の固定上限の枠で扱う。同じ個体を二枠へ登録しない。

| 枠 | 上限 | 扱い |
|---|---:|---|
| 主生物 | 高度生物一体 | 同じ主枠で複数個体は不可 |
| 餌生物 | 植物/菌/小型のいずれか一体 | 主生物と重なれる。餌生物同士の同居は初期案では不可 |
| 非生物資源 | 最大3種 | 鉱物/有機物/代謝因子/情報等。各生物枠と同居可能 |
| 死骸 | 生物枠ごと一件、計2件 | 元の主/餌枠由来を保持し、有限予算/期限を分ける |
| 宿主内 | 各宿主にP一件/PにQ一件 | セル枠を占有せず、宿主IDで所在を決める |

全ての独立生物は共通ID/状態を持つが、占有枠は系統定義の属性として分ける。「食べられる生物は全て餌枠」という意味ではなく、高度生物は捕食対象でも主枠に残る。生物を集団平均へまとめる方式は採らない。旧「植物も含め一セルに全て合わせて一個体」を本書で更新する。

植物/小型のセルへ主生物が移動/出生可能。小型も主枠のあるセルへ移動できるが、捕食リスクは局所回避へ反映する。各枠の移動予約は別々に調停し、大岩/崖/角抜け等は両方に適用。餌枠は足場や永久障害物の代わりではない。

同セルの植物/菌からの刈取りを認める。同セルの小型生物は攻撃距離0の候補として攻撃できるが、生きているだけで自動摂取しない。HPによる死亡→死骸→次ターン以降の採食は維持。食べる前に移動で逃げられる場合もある。各個体の同系統攻撃禁止は維持する。

最大候補は移動/停止17、攻撃17（隣接8セルの主/小型最大16＋同セル小型1）、植物刈取り9（同セル＋隣接8）、防御1＝44。対象IDと枠を含めて識別し、同じセルでも対象を取り違えない。植物/菌への攻撃を初期の捕食候補へ重ねず、刈取りとして扱う。小型の攻撃は引き続き0。

通常資源採食/刈取り/受動取得/死骸食は最多2単位を共有。二つの死骸がある場合も予算/感染を別々に持ち、必要性と初期値で一単位ずつ選ぶ。同じ死骸の感染ペイロードは一回だけ。死骸の置換は元の生物枠内のみで行い、別枠の死骸を巻き込まない。

初期配置/空き出生先も枠ごとに判定し、主生物数の上限は主枠数、植物/小型総数は餌枠数。主枠の満員を植物の存在で判定しない。高度生物の出生B3/密度は主枠、自系統の植物/小型近傍は餌枠で数え、同セルの別枠個体を隣接数へ加えない。両枠満員を前提に外部個体最大2N、宿主内部最大2Iで上限を持つ。

表示は餌を小さく背面、主生物を前面へ置く。両方のIDと状態を選択でき、主生物がいても餌の消費/感染印を隠さない。描画で重なっても身体予算/攻撃対象/個体数は別。これはモーションを実装した報告ではない。

## 2. 子の第一相と出生時完成度

子は全てその系統の第一相/年齢0/G0から開始する。能力の初期値が高いこと、成長段階が少ないことと、親の獲得相/分岐/経験を継承することは別。親が第三相/第四相でも子の相を飛ばさない。

既存20系統の四相/III3枝→IV6経路は維持し、早成型として主生物へ「早成甲殻」一系統（仮名）を追加する案。I→II→IIIで完結し、IVはない。相IIの本人の実成果から第三相の採食/機動/戦闘の三方向へ分岐し、各方向の第四相二分岐は付けない。全系統の階層を同じ数にそろえない。

| 項目 | 早成甲殻の初期案 |
|---|---|
| 攻防相倍率 | I1.20 / II1.35 / III1.60。既存DNA基礎に掛ける |
| 成長 | G45でII、G120/M8と相別成果4以上/他より差2でIII。一ターン一相 |
| 繁殖 | IIIのみ、同系統異性/B3/HP70/E75/M4/被害なし等 |
| 親支払 | 各E30/M2、待機18、III到達後初回待機4 |
| 子の配分 | 実支払合計TのE0.6T/B0.4T。標準T60ならE36/B24/M1 |
| 寿命 | 第一相基準240、相係数I1/II1.15/III1.40。年齢リセットなし |
| 維持・移動 | 基礎維持E1、相係数I1/II0.95/III0.90。最大一歩、感知1 |
| 食性/適性 | 汎食、静域/寒冷域が得意・熱域が苦手、防御型。既存DNA/9値の仕組みを使用 |

第三相の枝補正は採食＝有機取得効率+5%（有限移転の上限1は維持）、機動＝移動費−5%、戦闘＝D+5%を初期案。全方向に共通のIII倍率を掛け、進化により能力を下げない。初期9値は攻撃圧35/危険回避55/資源欲求60/仲間親和60/空間確保55/場所愛着65/探索性40/方向維持45/ランダム性20。

系統樹の構造は `I → II → III（採食 / 機動 / 戦闘）`。既存20系統の四相図とは別の三相図として説明し、名前を既存系統へ流用しない。

完成度は成人に対する比率としても説明する。A/D倍率比はI/III=0.75。第一相でも動けて身を守れるが、繁殖やIIIの枝能力を先取りしない。出産コスト/待機/子への身体投資が重く、既存の多産型と違いを作る。勝率や生涯出生数が均衡する保証はない。

主生物の候補は既存20＋早成1で21、全生物候補は従来29＋1で30。既存「全20」プリセットは元の20を維持し、早成甲殻を加える拡張選択を設ける。手動選択の上限は21へ拡張。最低四体/選択系統という条件は継続するため、80体で21系統指定など成立しない設定は不足を示し、自動削減しない。

## 3. 高次寄生が情報へ作用する理由

設定上は、宿主を直接強く操作するより、一次寄生と宿主が残す経験情報の伝達を変える形質が伝播成功につながり残った、と説明する。進化が未来を予見して技術を発明したとはしない。これはゲーム世界の生態仮説で、実在の高次寄生一般が情報を操作するという説明ではない。

Qは直接の宿主Pを介し、根宿主Hが実際に発生させた情報候補へだけ作用する。全域の情報・他個体の記憶・DNA・進化・初期値・シミュレーション規則は書き換えない。Qがいるだけで情報セルを生成しない。情報の通常成立条件がそろった時に限り、内容への影響が表に出る。

### Qの成長と情報特化

Qの成長はI潜伏→II成熟→III情報特化の三段階案。IIは4回の実取得、IIIはII以降さらに8回の実取得と蓄積E0.2の支払いが必要。旧「成熟Qだけ同伴」を更新し、未成熟QもPと一緒に移行できる。未成熟でも移行は可能だが、情報操作/繁殖はできず、Pを失えば消える。

植物/小型も共通Eを持つ最新モデルに合わせ、Pの宿主負担E0.2は適合した全生物宿主で一回徴収し、実取得からQへ最大0.05を移す。初期の植物内Qも取得を積み重ねられる。徴収不能なら成熟/情報操作の費用を前借りせず、P/Qに無料供給しない。QのためにHから追加徴収しない。新規感染の費用/操作は次ターンから。

IIは既存のP抑制を行い、IIIは次のいずれか一つに特化。根宿主の実際の情報候補発生数、既存情報との局所接触数、内容取込み数を固定三カウンタ（各上限8）で数え、III進行時の最多で決める。同点は初期値。操作結果を自分の選抜理由へ循環加点しない。植物/小型は情報学習をしないが、情報セルへの局所接触は観測可能。出来事のない条件ではその型の効果が表れない。

| III特化 | 局所的な作用 | 制限 |
|---|---|---|
| 発信整流 | Hの実成果情報の最大二成分のうち、一成分を0.5倍にして発信 | 新しい経験/対象位置を捏造せず、正負を逆転しない |
| 保持調整 | Hの実成果から誕生した情報の鮮度効果を1.25倍 | 成立時固定のタグ、元の最大強度以下。誕生時刻/20ターンの内容期限を変えない |
| 内容変調 | Hの実成果情報の一成分へ−1/0/+1を固定で加える | 非ゼロの追加、最大二成分、各絶対値3以下。操作は誕生時一回のみ |

内容変調の符号はQの型/個体ID/情報誕生ターンから決め、閲覧/摂取で引き直さない。発信源の環境タグは実際のHの環境のままで、都合よく偽装しない。操作の有無/元の発信源は観測用メタデータへ残すが、受け手個体がそれを見抜いて評価することはない。

一回の内容操作はQ蓄積E0.02を消費し、Qごと4ターンに一回まで。候補だけの段階で無限に書き換えず、対応する情報の誕生が成立した時だけ支払/適用する。同じHの複数候補がある場合は既存優先順の一件に限定。操作はQ個体をキーに調停し、一つの候補が複数セルで誕生しても一件だけ選ぶ。

保持調整は内容の鮮度倍率だけで、情報qの誕生/残量/移動を変えない。情報へP/Qの生体や感染性を載せず、情報を食べることと寄生感染を分離する。操作済み情報を食べた事実だけでは新しい実成果情報を再発行しない。Hがその後実際に行動して結果を得た場合は通常の新しい経験になり得る。

QがHの恒久9値を直接更新する規則は設けない。他個体が情報を摂取した結果として行動が変わり、それが食物網/接触/次の宿主の分布へ影響し得る。この二段階以上の因果関係が高次寄生の特色となる。

## 4. A/Bと確認事項

占有枠はA1.7/A1.2/B4/B4.1/B4.4、早成型はA1.1/A1.3、Qの情報作用はA1.5/A1.4/B4.2、表示/説明はB5/B5.2へ接続。既存の共通モデル/生活環/個体差の責務内で追加し、新Node分割は行わない。全Node草案、C/D/E/コード/画像なし。

重なりによる捕食頻度、植物の隣接/同セル採食、早成型の生涯繁殖、Qの情報操作の強さと伝播効果は未検証。Qが技術的であることを、特定の結果を必ず実現する全能性へ置き換えない。30系統は候補構成で、全系統の同時初期配置を必須にしない。
