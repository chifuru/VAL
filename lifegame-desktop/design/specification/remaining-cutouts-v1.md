# 残る画像経路の切り抜き確認 / 1

現行の採用造形・透明素材を維持し、主生物の基本相/専用分岐、下層生物、地形小物の画像経路に背景矩形の取り残しがないか確認する。既存のP/Q・独立植物・量機の68状態は inspector-cutouts/1の範囲を維持する。

不透明な背景、空画像、素材領域の取り違えと、透明な生物自体の密な造形を区別する。元の参照図/説明資料や地表面そのものは透過切り抜きの対象にしない。現行経路が適切な場合は描画/素材を変更せず、確認範囲を記録する。新デザイン/背景再生成/動的マスク/生態計算は追加しない。

実描画で見つかった主生物の詳細画像の端欠けは、描画半径を枠の幅だけから決めず、縦横の短い方へ合わせる。横長の詳細/系統樹でも全身の透明余白を保ち、盤面/採用素材/生態は変更しない。
