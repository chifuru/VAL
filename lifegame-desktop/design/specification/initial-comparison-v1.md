# 境界規則と比較開始値

> マス再編の現在採用仕様は[マス再編/1](cell-reorganization-v1.md)。マス・占有・植物等の開始値は新正本の明示範囲で置換する。本書の数値表を維持するとの記述は、その置換範囲を除く。P/Qや情報の未変更の境界・値は維持する。 新正本はA/B反映のみで、製品4.2.77・既存証跡は旧対象版のままである。


仕様版 `initial-comparison/1`。利用者が一括案へ「良いと思います」と同意した現在のA/B正本。第1〜第4組を補完し、本書が明示する境界規則・比較開始値だけを優先する。数値の採用は実測による妥当性確認ではなく、製品4.2.32への実装も意味しない。

## 1. 採用範囲と保留

宿主移行/Q随伴、同ターン競合、遺伝適応/獲得抵抗、Q羽化/初期数、群落の部分採食/再生、独立植物の成長、情報評価の基準、比較方法を採用する。既存の有限収支・局所感知・再現性・R1〜R6・相と年齢の分離を維持する。

植物/P/Qの採用造形と系統・相・枝への対応は、利用者との議論を経て[造形対応/1](appearance-correspondence-v1.md)へ採用済み。森冠/星冠は別系統、今回の水生植物は海生02とは異なる移動する淡水系統。機械ID/専用値/配置容量の実装接続と造形の採用を区別し、画像枚数から系統数を増減しない。本書の数値表は変更しない。

## 2. 宿主移行・子群体・死亡

- 同一Pが生存したままH間を移行する場合、内部Qも同じIDで随伴する。P/Qの出生時刻・年齢・栄養・発育・抵抗を維持する。
- Pの娘群体は新IDであり、親P内のQをコピーしない。新PへのQ感染は別に適合と感染窓を通す。
- 移行直後の1Tは発育を休止する。初回成熟時刻やQのT+1〜T+3窓を更新/再開しない。
- 羽化前にPが死亡すればQも死亡する。H死亡時にPが残れるのは、適合する移行先または体外感染段階が実際に成立した場合だけ。Qは生きた同一Pが維持された場合にのみ継続でき、感染量だけへ置換されたPに便乗して救済しない。
- 感染体は有限の別量であり、P/Q群体IDを複製して複数宿主へ配らない。新規感染の同ターン再放出は認めない。

## 3. 同ターン競合の確定順

1. 既存の合法な行動による損傷・採食量・栄養支出を確定する。
2. 実際に成立した捕食感染/宿主移行を確定する。
3. 生存するP内のQについて、相・自身の成熟・発育・栄養・抵抗・再準備条件を満たす羽化を判定する。
4. 死亡・離脱・情報生成・集計を一度だけ確定する。

致死が確定した主体はその後の通常行動を行わない。致死に至る捕食で起きた適合P移行は別の成立遷移として判定し、死亡主体の追加行動とはしない。移行による発育休止や死亡で満たせなくなった条件を無視して羽化させない。Q羽化によるP死亡/同Q離脱/IV相更新は一つの確定遷移とし、一般のP死亡処理で成功Qを重ねて死亡させない。Hは直接殺さず、H死亡/情報生成も捏造しない。

移動・戦闘・採食を排他的な一行動へ戻さない。この順序は境界の確定規則であり、情報の開始時受容/末尾生成/次T作用も維持する。

## 4. 遺伝適応と再感染抵抗の比較開始値

| 項目 | 値・制約 |
| --- | --- |
| 遺伝適応 | 0〜1、標準0.5 |
| 感染成功への遺伝補正 | 適合後の基準に対して最大±25%。絶対確率への±25ポイント加算ではない |
| 費用補正 | 基本費用の0.75〜1.25倍。費用を無料/負にしない |
| 子の変異 | 出生時10%で小幅±0.05。範囲内へ制限 |
| 特化 | 有利な形質を増やす際は別の適応への配分を減らし、万能化を無料にしない |
| 実際の排除後の抵抗 | 対象系統へ0.4加算、上限0.8 |
| 抵抗減衰 | 半減期40T |
| 近い感染経路への交差抵抗 | 本来の抵抗の半分。無関係な全系統へ拡張しない |

宿主選好/実適合/遺伝適応/獲得抵抗を別にする。高適応でも非宿主・到達不能経路・窓外は突破できない。侵入/定着/発育を一つの確率に潰さず、抵抗はそれぞれを妨げる係数として扱う。抵抗の維持/排除費は有限栄養から支払い、実際の排除なしに獲得させない。親の学習/後天抵抗を子へ直接コピーせず、出生後の感染成功で固定DNAへ自動加点しない。

## 5. Qの羽化と初期構成

| 項目 | 比較開始値/条件 |
| --- | --- |
| 羽化試行の追加栄養 | 試行時の相の通常維持費6T分。通常維持費とは別の一回支出 |
| 失敗後の再準備 | 最低4T＋必要栄養の再蓄積。再準備だけで他条件を省略しない |
| 条件成立後の羽化成功率 | 抵抗補正前60% |
| 自動設定時の初期Q総数 | 実在する適合P数×20%を切り捨て |
| 初期Qの内訳 | 約3/4寄生中、約1/4自立IV。少数時は寄生中を優先 |

Qの年齢成熟・進化相・発育進捗・栄養蓄積を別々に保持する。発育は必要栄養を支払えたTだけ進む。III相＋自身の成熟/発育/栄養/抵抗条件を通り、成功時だけPを殺して同じQがIV自立へ移る。出生時刻/寿命を更新せず、自立後は残存期間に通常採食/移動/被食/産卵を行う。情報は栄養源にしない。

自動初期数の母数は適合Pであり全生物数ではない。寄生中の配置には初回成熟時刻と窓を整合させる。配置不能分は強制宿主追加/無断の成体化で埋めず減数し、予定/実配置/不足理由を保存する。明示した直接数/0は既存の手動設定契約を維持し、20%を強制上限にしない。開始時に置いたIVは実測の羽化成功に数えない。開始後のQ総数を常時P以下へ抑えない。

## 6. 群落の採食・再生・感染量

可食部だけ減った群落は同ID・経過・実績・獲得抵抗を維持する。基部まで完全消失した後の再成立は新ID/新実績で、旧年齢/学習/抵抗/情報保持資格を継承しない。子の遺伝形質と旧群落の後天状態は区別する。

部分採食の曝露量は、**可食部に実在する感染体量×実際に食べた割合**とする。可食在庫/付着感染量の同じ確定在庫に対し複数採食者を調停し、総移転を在庫以下にする。可食量0ならこの経路の移転も0。P群体を分割複製せず、放出にも有限量/生産費を要求する。基部内Pの全量を無条件に可食部へ付与しない。

| 群落の自動設定 | 陸上 | 水中 |
| --- | --- | --- |
| 適地に対する初期占有率 | 20% | 15% |
| 可食容量 | 標準採食量10回分 | 同10回分 |
| 初期可食在庫 | 容量70% | 容量70% |
| 好条件での最大再生量 | 容量10%/T | 容量10%/T |

標準採食量は比較条件に保存する固定の量尺度で、現在の消費者数や要求に追従して増幅しない。陸水の単位換算/基準量は実装接続表で明示する。再生上限は実在する光/水/有限養分/基部活性と容量を満たす場合の上限で、無条件の供給ではない。

配置はまとまりと空白を作り、消費者の到達性も確認する。容量/再生と分布拡大は別予算。供給なしで隠れた外部補充をせず、供給ありは外部入力を別台帳へ記録する。直接設定/明示0を尊重する。

## 7. 独立四相植物の経験と機能分岐

比較開始値は累積経験II=12、III=36、IV=80。生産・維持・被食後再生・定着成功の実成果から得る。処理分割や微小量反復で経験を水増しせず、通常の生産/維持だけでも上位相への経路を持つ。相到達と年齢成熟/繁殖待機は分離し、I/II相でも成熟/予算/適地/空き等を満たせば繁殖できる。

分岐の根拠は直近の生産配分・繁殖/定着配分・被食対処の実績。第3組のIII生産/繁殖拡散/耐食→IV各二方向を維持し、造形は[採用対応](appearance-correspondence-v1.md)へ接続する。実績換算の単位/期間/同点処理や専用寿命/出生費など未提示の細かな係数は、実装比較表で選び版を付ける。12/36/80の到達性や生存は未実測である。

## 8. 情報の役割別評価基準

第1組のS=0.4A+0.4B+0.2C、保持/生成閾値、鮮度、非栄養、由来重複排除を維持し、基準量を次で補完する。

| 評価軸 | 比較開始基準 |
| --- | --- |
| A 維持 | 基準寿命の半分に相当する、栄養/健康を維持できた期間 |
| B 役割成果 | その生活様式の標準10T分に相当する実成果 |
| C 関係継続/世代更新 | 実際の作用が成立した関係10T、または子の定着/成熟等の成果 |

基準寿命を持たない群落は評価上100Tを基準期間とする（寿命100Tで一斉死亡させる意味ではない）。各軸を対応する基準で0〜1へ制限する。消費者=実採食、生産者=純生産、分解者=実分解、P/Q=実発育/伝播等として、対象役割の固定基準量に換算する。非繁殖の働育個体には実支援/養育等を対応させ、存在しない出産等を要求しない。

接触/再読取/単なる経過だけで成果を加算しない。非適用/未観測を成功に補完せず、具体換算が未定義なら評価未確定とする。標準量と実成果の対応は保存する定義版で固定し、将来の勝者や現在の集団順位で書き換えない。情報評価を生態系健全性/戦闘力/R1〜R6の達成点へ転用しない。

## 9. 比較・保存・実装接続

固定3条件で、収支/経路適合/再感染抵抗/羽化/群落更新を個別比較し、その後に同じ固定10条件＋別の固定3条件で500Tを比較する。失敗例を除外せず、未使用条件での退行も残す。R1〜R6を緩和せず、出生→子の成熟→次世代繁殖、感染→再伝播、Q羽化→子の定着、終盤勢力構成の違いを確認する。条件間の基準量/供給/優遇/直接数/定義版を保存し、実行途中の無親補充で達成を作らない。

本書の数値は採用した**初期比較値**。個別適合表、侵入/定着の基礎確率、抵抗維持/排除の実費、相別通常維持費、Qの発育/経験閾値、植物の経験換算/出生費/寿命、標準量と実データの対応、保存スキーマは実装接続時にこちらが明示して比較する。未提示の値を実測済み/調整済みとせず、既定の意味/上限/再現性を変える場合だけ確認する。

次は実装差分/欠落フィールド/単位・係数版/保存スキーマと既存C/Dへの対応を整理する。造形対応は採用済み、素材化は未完。新分割が必要なら事前確認する。本書の比較値の採用はA/B文書であり、製品/配布版の実装・実測は別に扱う。
