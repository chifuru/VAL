# 選択詳細の切り抜き表示/1

採用した造形・相・枝・素材そのものは維持する。現在の寄生虫P/Q・森冠/星冠/淡水植物・量機の詳細/系統樹では、背景付き参照図の矩形を直接合成せず、既存の透明アトラスと登録済みbodyBoundsから全身を描く。実行時の画素走査/背景除去/新規マスクは追加しない。元の参照図は資料として保持する。

相/形態の選択には現行の本人状態と既存の対応表を使う。Pの宿主段階と本人相、Qの生活状態と本人相、年齢と相を混同せず、型の表記を復活させない。既に適切な相の表示や採用デザインを作り直さない。

盤面の描画、旗なし旧寄生虫の素材経路、生態計算/栄養/保存形式は維持する。透明素材の全身と外縁の余白を保ち、画像表示は個体の状態/履歴/相を変更しない。素材の新規生成・全デザイン差替えは対象外。
