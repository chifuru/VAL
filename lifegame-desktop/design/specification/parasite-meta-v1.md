# 寄生の生活環・経路遺伝・メタ操作

[持続する情報/1](persistent-information-v1.md)により、関係性の情報は個体保持/環境保持と学習/場所作用を持つ。P直接誘導とQのP向け小補正を情報成分へ混ぜず、Qの痕跡は内容/出現率の既定範囲だけに作用する。集中による強化でもQが元実績・親子関係・scopeを偽装したり期限を延長したりしない。通常個体/親養育者の伝達はDNAの水平伝播ではなく、寄生の感染そのものでもない。 追加はA/B反映段階、製品4.2.32は未変更。

## 1. 適用と現在地

仕様版 `parasite-meta/2`。合意したPの感染過程/経路適応の遺伝、Qの寄生成長から自立成体への移行、Pのメタ操作/Qのメタメタ操作、相別の影響と栄養負担をA/Bへ反映する。製品4.2.32の寄生処理は変更しておらず、本書の実装・生存率・画面・性能は未検証。

本書は、旧「QはPへ定着したまま子の探索群体を放出」「Qの栄養は外部情報だけでPへの負担なし」「Qは主にPの誘導を抑える」の該当条件を置き換える。H→P→Qの寄生階層、限定感染窓、無雌雄の群体扱い、有限収支、生活環と通常進化/年齢の区別、毎回のQ存続を要求しない原則は維持する。通常の生物のDNA・食性・攻防能力・寿命を寄生補正だけで書き換えない。

責務はA1.3（遺伝）、A1.4（行動層）、A1.5（寄生生活環/負担）、A1.7（単位/関係）、B4.1（最終判断）、B4.2（遷移/競合）、B5.2/3/4/5/6（説明/表示/保存/観測/選択）に分担。新Node・分割・状態変更はない。情報の正本は [死亡由来情報](death-information-v1.md)。今回回答により、情報は全生物に対して非栄養、Q成体は通常の生物として栄養を得る。Qの主力は寄生先由来の死亡情報の出現率上昇と内容歪曲であり、成体が既存情報を局所加工する案は採用しない。

## 2. 関係の階層と作用の階層

| 観点 | 順序と意味 |
| --- | --- |
| 寄生の結合 | 生物H → Hに寄生するP → Pに寄生するQ。Qの直接寄生先はP |
| 基本判断 | 素質/本人の経験/外部情報による学習と、空腹・危険・環境・局所関係から候補行動を評価 |
| Pのメタ操作 | Hの判断に比較的強い一時補正を加え、接触/移動/被食/採食場所等の機会を偏らせる |
| Qのメタメタ操作 | Pの誘導を小さく補正し、主に寄生先由来の死亡情報の出現率上昇/内容歪曲を通じて他個体の判断へ間接作用 |

概念上の合成は「元の行動重み＋情報学習＋候補場所の情報刺激＋Qで小さく補正したPの誘導」。Qの情報加工は情報受信側の学習へ到達する別経路であり、受信者にQが直接寄生していることにはしない。情報倍率は情報による学習と場所刺激へそれぞれ一度だけ掛け、P直接誘導/QのP向け補正へ重複適用しない。

メタは世界のルールを書き換える能力ではなく、個体ごとの判断補正層。局所性、上限、費用、適用中の感染ID/相/負荷を持ち、離脱/排除時に一時補正を除く。既に受けた学習は情報の記憶規則で別に扱う。補正を毎ターン永続重みへ無制限加算しない。最終行動は合法移動・可視範囲・有限予算・競合調停を通り、実行不能な命令を強制しない。

## 3. 一次寄生Pの感染過程

| 段階 | 成功条件 | 失敗・停滞の扱い |
| --- | --- | --- |
| 曝露 | 接触/採食/死骸/水等から感染可能な量が届く | 曝露0では感染判定なし |
| 侵入 | 経路と対象の組合せが適合 | 不適合なら感染力が高くても侵入できない |
| 定着 | 侵入量、宿主の防御/健康、寄生適応が条件を満たす | 排除/短期保持/消失を原因別に記録 |
| 発育 | その宿主と生活環段階で栄養/時間/適性が成立 | 発育停滞、有限の保持期限、死亡/排除。定着を成熟成功に数えない |
| 伝播・繁殖 | 次段階への経路または成熟後の繁殖条件が成立 | 行き止まり宿主、放出先欠落、材料不足等を分離 |

段階は同じ一回の成功抽選にまとめない。経路適合は通過ゲート、曝露量・経路感染力・宿主防御は適合後の確率/進行に使う。試行・放出・維持は有限予算で支払い、失敗分の消失/還元を台帳へ記録する。成功した寄生群体が同じターンに再拡散する連鎖は許可しない。

宿主適性はP系統/遺伝形質/宿主の組合せで決まる。発育できる適合宿主、発育せず保持/捕食移行を支える運搬宿主、定着しても次へ進めない行き止まり宿主、定着できない非宿主を区別する。実在生物すべてに共通の固定分類として扱わない。

葉環の草本→草棲虫→適合主生物、潮環の微藻→水游虫→適合水系主生物という既存経路は初期比較基準として残す。宿主を変える生活環段階と、寄生群体自身の成長相は別に保存する。追加宿主は生活環上の状態であり、成長相の数を増やす意味ではない。

## 4. 経路の遺伝・変異・再感染

Pの子群体は、親の経路適応、宿主/段階適性、体外耐久性、放出量/条件、行動誘導の重みを継承し、小さな変異を持つ。Qも適合Pへの感染適応・補正/情報加工の傾向を子群体へ継承する。正確な宿主個体IDや成功履歴を遺伝せず、動物DNAや情報による水平伝播とは分離する。各経路の得意不得意と放出/耐久/誘導の費用を組にし、全経路/全宿主に最高適応する万能型を自動生成しない。具体係数は比較で選ぶ。

同じ侵入強度でも、不適合な経路/相手なら感染0、定着しても発育不能、繁殖できても次宿主へ届かない、という結果を認める。生存や感染先をモデルが保証せず、実際の子孫が残ることにより形質が選択される。

排除後の再曝露は新しい侵入/定着判定を通す。感染中の追加曝露を無制限な別群体や感染成功数にしない。初期設計では既存の一宿主一P群体/一P一Qの容量を維持し、未占有の感染先を巡る競争から始める。免疫/清掃は有限費用と状態を持ち、永久免疫や通常打撃による体内Pの一律除去を追加しない。

## 5. 環境を通る経路

水媒介は「成熟群体が感染体を放出→水セルに滞留/移動→適合対象が取り込む→侵入判定」とする。感染体は微小な一体ずつでなく、セル×P系統/形質型の有限量/感染性/期限として集約可能。宿主内群体数や主生物個体数へ混ぜない。移動で量を複製せず、既存の流れデータがない水域へ架空の一方向流を付けない。局所の滞留/拡散から始め、視界全体/全水域への即時感染はしない。

死骸経由は死骸の残存と感染性の残存を区別する。現在の感染保持4T/死骸12Tは比較の開始値であり、新P適応での有効期間は版付きの調整値として別評価する。感染死骸を食べても適合しなければ失敗する。接触、屍肉利用、水の感染圧を別々に計測する。

## 6. Qの生活環

新しい基本環は「自立成体による感染先探索/産卵→P内の卵/幼生→寄生成長→変態/羽化・離脱→自立成体」。羽化はQ自身の成長で起こり、異なる宿主種を順に渡ることを必須にしない。卵から幼生になる孵化と、成体になる羽化を区別する。卵/蛹は軽量な生活状態で扱い、通常生物の進化相・年齢と同一視しない。

感染可能な対象は、適合Pが終宿主内で初めて成熟したTの次、T+1〜T+3という既存の短い窓を開始値にする。対象PのID/成熟時刻を保持し、栄養停滞や宿主移動で窓を延命/再開しない。Pの娘群体は別IDで、自身の生活環を通る。窓外の侵入失敗と、既感染Qの発育/維持は別判定。

寄生中はH→P→Qへ付随し、離脱時にQの所在・付随関係を更新して同じQを二重計上しない。自立成体は局所移動・採食・危険回避・感染先探索を行い、被食/栄養不足/寿命で死亡し得る。主生物と同じ戦闘能力/配偶ルールを自動付与しない。群体単位・無雌雄の有償な繁殖を維持する。成体が生存するだけでなく、その子がPへ定着して育つことを世代更新とする。

羽化に必ずPを殺す条件は付けない。生物はPの維持で負担し、PはQの発育に有限の蓄えを消費して繁殖余力等を失う。直接負担の追加を認める一方、QがPの成熟カウンタや待機期間を無償に直接改変する旧方式へは戻さない。栄養不足による停滞/死亡は収支の結果として認める。自立成体は通常の生物として、系統の食性に適合する実在の餌/栄養を採食し、移動/回避/繁殖を行う。情報には栄養価がなく、情報を食べて維持する経路は撤回する。具体的な食物適合と代謝/徴収率は既存食物網と有限収支に沿って比較で選び、情報を代替食や無料の維持手段にしない。

## 7. 相と費用・相互競争

Pの主力は感染宿主への直接誘導、Qの主力は寄生先由来の死亡情報の出現率上昇と内容歪曲。QのP向け補正は小さな上限とし、情報作用と別係数にする。相が上がるほど作用上限と必要維持栄養が増え、強い誘導/加工/放出には追加活動費が必要。実効作用は相だけでなく現在栄養・寄生負荷・防御で変わる。飢餓時も最大作用を無料維持する設計にしない。

成長相数/閾値/係数は既存の三相表示を比較開始の候補とし、新しい四相や全層同数を自動採用しない。生活環状態、成長相、宿主の年齢成熟を別変数にする。相別の作用/維持/放出費用は同じ表で比較し、具体数値は未選定。

Hは採食/回避/排除で自己を維持し、Pは宿主や感染先、QはPと情報の利用機会を巡って競争する。過剰利用で宿主を失えばP/Qにも損失が生じる。弱い長期利用型と強い短期拡散型の両方に成立条件を持たせるが、全員の適度な生存を強制しない。宿主全体の能力上昇/低下を単一倍率で処理せず、費用と行動結果を追う。

## 8. 観測・保存・検証接続

曝露/不適合/侵入失敗/定着/排除/発育停滞/成熟/移行/次世代を経路・宿主・相別に集計する。接触量と感染成功、定着数と発育数を混同しない。Qは寄生中/羽化/自由成体/産卵/次世代定着を分ける。Pメタ補正、QのP向け補正、情報補正と、実行した行動は別の観測量。補正が非ゼロでも行動や生存への因果効果と即断しない。

保存にはPの遺伝型、感染経路・宿主段階、成長相、Qの生活状態/結合、実効係数/費用、初期条件/乱数方式/計算署名を含める。全個体の全行動履歴を永久保存せず、必要な現在状態と確定集計を使う。旧署名の結果を保持し、旧固定P/Qモデルを同一計算として再生しない。

後続D/Eでは適合/不適合、侵入/定着の境界、失敗時消費、再感染/占有競合、同ターン連鎖禁止、水の量保存、P/Q負担/排除、感染窓一回性、羽化のID/計数、相別費用を確認する。単独要因→同じ固定条件で組合せ→R1〜R6→Worker/保存再生の順を維持する。

## 9. 今回回答で確定した範囲と残る確認

- 情報にはE/B/M等の可食栄養を持たせない。P/Qも含め全生物で共通。情報の読取/記録/歪曲に活動費があっても、情報から栄養を得る意味にはしない。
- Q成体は普通の自立生物として適合する餌を採食する。寄生期のPからの栄養負担とは別経路。自立によって主生物枠/雌雄/攻防能力を一律に付与する意味ではない。
- QはPを通じて結び付く宿主Hの経験へ有償の痕跡を残し、死亡時情報の出現率を上げ、内容を歪める。直接寄生先Pと情報の発信元Hを混同しない。発信元自身がPの場合も同じ由来規則を使い、Qが無関係な個体へ同じ痕跡を配らない。
- 離脱後のQが盤面の既存情報を書き換える方式は採用しない。生存中に刻んだ痕跡は有限に残せるが、離脱/死亡後に遠隔操作を続ける能力ではない。
- 全生物の情報と同層向け/全層向けの二種を扱う。層IDは `death-information-v1.md` 7節のピラミッド役割＋分解者/P/Qで確定し、宿主と寄生者の所属を混同しない。具体係数は後続比較とする。
