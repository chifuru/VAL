# 雌雄の外見差と第三相からの繁殖（A仕様）

ユーザー指定：雄と雌で見た目を少し変える。繁殖は第三相から可能にする。外見の具体的な差と繁殖条件の細部は以下の案で詰める。実装は行わない。

## 雌雄の小さな外見差

- 基本系統・初期DNAの個体差・現在相・進化の枝を優先し、雌雄で別系統に見えるほど形を変えない。
- 系統の全身形態を共通に保ち、細い模様、発光点の並び、彩度・縁の光などを少し変える案。極端な体格差や人型の性的な表現は設けない。
- 日輪系統の例：雄は輪郭の細い放射線、雌は輪の内側の小さな対の光点。同じ相・同じ枝・同じ基礎色の2体として比較する。これは造形提案で、全系統に同じ輪を足す意味ではない。
- 浮遊傘なら傘の模様、星海鯨なら体表の細い斑、植物共生なら花冠の模様など、系統固有の部位の表現に合わせる。部位別の成長計算は追加しない。
- 外見だけに頼らず、盤面・個体詳細・繁殖説明に♂/♀と文字ラベルを併記する。
- 性別だけで攻撃・防御・進化条件の優劣を付ける仕様にはしない。雌雄は進化の別枝に数えず、第四相は1系統6経路のままとする。

## 繁殖の開始相

**双方が第三相・異相以上であれば繁殖候補。第四相・覚醒を待つ必要はない。第一・第二相は繁殖しない。**

| 判定すること | 条件案 |
|---|---|
| 系統 | 同じ基本系統。第三相の特化や第四相の枝は異なっていてもよい |
| 性別 | 雄と雌の2個体 |
| 相 | 双方が第三相または第四相 |
| 状態 | 双方が生存し、必要な栄養・エネルギー・HPを満たす |
| 待機 | 繁殖待機期間が双方とも終了 |
| 距離 | 互いに近接している |
| 出生先 | 子を配置できる空きマスがある |

エネルギー・HPの閾値、近接距離、待機期間、出生コスト・配置先は未確定。従前モックの数値を今回の確定値として持ち込まない。戦闘中・回復直後の扱いも今後詰める。

## 子の扱い

子は両親のDNAを継承し、同じ基本系統の第一相から始める。親の第三相の特化、第四相の枝、採食・移動・戦闘の後天的経験をそのまま到達済みとして受け継がない。雌雄の決定方法と遺伝の細部は別途検討する。

## 説明シート

第三相到達時に「繁殖可能な相になった」と説明する。実際に繁殖できるかは栄養・相手・待機・空きマスの条件を別に表示する。第三相到達と「今すぐ出生できる」を混同しない。個体詳細では不足条件を示し、分岐が違っても同系統なら繁殖候補になれることを説明する。
