# 選択詳細の固定と手動更新

個体・マス・系統の詳細は選択した確定ターンで固定する。「表示NTで固定 / 現在MT」と更新操作を示す。数値・画像・詳細の開閉・スクロールを毎ターン作り直さない。同じ対象の明示的な再選択、別対象の選択、更新ボタンで最新の確定状態へ更新する。

更新や選択では観測の開始/停止を変えない。一時停止しただけでは固定内容を更新しない。カメラ追跡と現在のグラフは独立して進行する。別の個体/マスを選ぶ場合は前の追跡を解除し、次のターンに旧対象へ選択を戻さない。移動は手動更新で最新の所在へ反映し、消失したIDは別個体へ置き換えない。固定した内容が現在も生存していることの保証ではない。新世界と選択解除では固定内容を解除する。

固定は詳細DOMと小さな対象/ターン情報を保持し、世界全体の複製や全個体の履歴追加を行わない。生態規則・ターン記録・描画素材は変更しない。
