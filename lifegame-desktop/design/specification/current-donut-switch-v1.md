# 現在の構成円・表示切替 / 1

単一のドーナツを、全生物の系統別/分類別、主生物、生産者、一次消費者、分解者、一次寄生P、高次寄生Qへ切り替える。既定は既存の全生物・系統別。分類は既存6分類を使い、栄養段階や系統を変更しない。個別分類では所属系統の内訳を表示する。

選んだ範囲の管理単位数を分母とし、0なら「対象なし」とする。動物・独立植物は個体、基底植物は群落、P/Qは群体、一次消費者小集団は既存記録の内部個体数。Bや栄養量へ読み替えない。色は盤面の既存系統色/分類色、凡例は該当する色と名称を使う。

切替はこの円だけへ作用し、生態観測3グラフの対象、ピラミッド、選択詳細を変更しない。観測を停止/開始せず、生態・乱数・原値・記録形式を変えない。最速の端数があれば明示観察として盤面/グラフを同期してから変更する。図鑑では保存された現在値を参照し、戻るとライブ側の表示選好を復元する。過去記録にない量を推計しない。
