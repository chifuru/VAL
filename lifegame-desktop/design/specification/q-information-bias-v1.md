# Qの遺伝傾向による情報歪曲と生態的な選択

仕様版 `q-information-bias/1`。利用者が採用した具体化C05の因果関係と遺伝/作用の扱いを定義する。[寄生メタ](parasite-meta-v1.md)のH→P→Q生活環、[死亡情報](death-information-v1.md)の痕跡、[情報生成](information-generation-v1.md)の通常/根拠不足候補へ接続する。今回はA/B反映であり、新モデルのゲーム実装/生存/性能は未検証。

## 1. Qが持つ性質

| 性質 | 作用 |
| --- | --- |
| 出現促進の強さ | 寄生先由来の通常情報の死亡時出現率を、費用と上限付きで増やす |
| 歪曲の方向 | 餌場・危険・他個体への接近等の評価を強調/抑制/反転する傾向。向きと強さを持つ |
| 加工への投資傾向 | 有限栄養のうち情報加工へ配分する傾向。維持/成長/繁殖と競合する |

Qの遺伝的な性質の組合せから偏りを作り、固定した戦略名/行動命令として与えない。出現率と内容歪曲、QのP向け小補正は別経路/別係数で維持する。受け手の適性/感度/状態と既存の上限・飽和を通り、情報だけで接近/攻撃/感染を確定しない。

出現促進はC04の通常枠へ接続し、通常候補の根拠や実績を捏造して通過させない。根拠不足枠は通常優先の残余に最大5%、初期判断重みは通常の半分を維持する。Qが根拠不足枠やその受信感度を増幅する新能力は採用しない。元経験の内容と、伝わる評価の歪曲を別に保存する。

## 2. 継承・変異と成長相

出現促進の性質・歪曲の方向/強さ・投資傾向はQ自身の子へ継承し、小さな変異を加える。遺伝するのは性質であり、成功した場所の座標/宿主個体ID、成功履歴、宿主やQの獲得記憶を丸ごと渡さない。Qの子孫の遺伝と、情報を受け取った生物の学習/DNAを混同せず、水平伝播を追加しない。

相が進むほど作用上限と必要維持栄養が増え、強い加工は追加費用を要する。実効作用は相/現在栄養/負担/活動費で制限する。相が高いだけで常時最大加工を保証せず、栄養不足では加工が弱まり、成長/繁殖との配分競合が生じる。同一費用を複数経路で二重計上しない。

遺伝形質の範囲、変異率/幅、相数/閾値、相別の促進/歪曲上限と維持/活動費は比較調整待ち。相数を今回新たに確定したり、全形質を最大にできる万能型を無償生成したりしない。生活環状態・進化相・年齢は既存の別変数を維持する。

## 3. 情報から子孫の存続につながる経路

例として、危険を低く伝える性質→その情報を利用する生物の接近/滞在が増える→宿主間接触/Pの伝播機会が増える→適合Pが所定の成熟窓へ進む→Qの産卵/子の定着機会が増える、という可能な経路を扱う。

各矢印は条件付きである。局所到達・受容・合法行動・実接触・経路/宿主適合・防御・有限栄養・成熟窓を省略しない。情報を読んだだけで寄生を成立させず、同ターンの無限伝播も認めない。捕食が増えて宿主を失えば同じ性質が不利になり得る。効果が他のQや別種へ利益を与えることもあり、加工者自身/子の成功を保証しない。

Qは未来の宿主分布や子の成功を透視して最適な加工を選ばない。実際に羽化・生存・産卵し、子が適合Pへ定着/発育して残る結果によって性質が選択される。成功結果を得た瞬間に全Qの遺伝値や世界の係数を書き換える大域的な学習は設けない。

加工量/出現件数/読取数だけを利益と呼ばず、Qの生存と世代更新を別に観測する。情報歪曲由来の行動変化と、自然な接触/競合の結果を区別する。単一観測から因果効果を断言せず、既存の同初期条件での通常/情報作用なし/Q加工なし等の比較へ接続する。

## 4. 痕跡と保護する情報

Qの直接寄生先はP、死亡情報の主な発信元はPを通じて結び付くHとする。発信元がP自身の場合も既存の由来規則で分け、Qが無関係な生物へ痕跡を配る能力は追加しない。元の経験/実績・発信者/役割/scope・親子関係・経験時刻/生成時刻/確定期限を保持する。歪曲した評価を実際の被害/本人の成功へ書き戻さない。

Qの離脱/死亡後は新しい痕跡を与えず、寄生中に刻んだ痕跡だけが有限期限/減衰内で死亡情報へ反映される。自立成体が既存の盤面情報を再加工することや、若返り/期限延長/遠隔操作は認めない。複数Qが順次寄生した際の置換/併存/競合はC06で詰め、今回合成則を決めない。

C02〜C04の保持/候補条件・生成確率/一死亡最大1件/一回抽選・根拠不足の半重み、C03の鮮度半減期25/50/100T・痕跡基本100/最大200Tを維持する。Qの加工投資は有限栄養を支払い、情報そのものは非栄養である。受け手の実在する選択にだけ作用し、植物に移動/攻撃を新設しない。

## 5. 観測・保存・後続

Qの遺伝型/親由来と変異、相/生活状態/栄養/投資/実費、直接P/発信元/加工者ID、元内容と歪曲方向/量、出現率補正と生成/受容、実行行動、羽化/生存/産卵/子の定着を区別して記録する。全個体の全文履歴や無制限の家系図は追加せず、現在状態/少数の由来・親参照/確定集計を用いる。加工者の成果は実際に識別可能な範囲で扱い、帰属不明を推測で成功へ補完しない。

既存の横詳細/説明シート/図鑑分析へ接続し、3グラフ/一体サマリ・全確定ターン原値を維持する。定義/係数版と実効条件を計算署名へ含め、旧記録を新しい遺伝/痕跡モデルへ黙って変換しない。表示/保存だけで加工/変異/抽選を進めない。

照合観点は方向/投資の違い、低栄養/相別費用、実被害と歪曲評価、元時刻/期限の保持、離脱後の既存痕跡のみ、通常/根拠不足の区別、有限収支、実際の産卵/子の定着、有利/不利双方の環境、保存再生である。文書照合はこれらの製品検査の合格を意味しない。

C05の因果関係/遺伝/作用範囲は採用済み。具体係数/変異率/相別表とC02/C03の比較事項は未選定。次はC06の順次寄生痕跡を個別確認する。捕食→寄生・川辺での死亡/産卵→拡散という生活環の連鎖は[寄生メタ](parasite-meta-v1.md)の後続項目としてC07/C08で具体化し、C12と照合する。今回は3core・C/D/E・src/tests・画像/配布物・製品4.2.32を変更しない。
