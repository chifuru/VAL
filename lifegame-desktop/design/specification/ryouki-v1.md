# 量機：通常型・相変異と機能

仕様版 `ryouki/2`。利用者の原案、通常型の初回案、相変異の最終訂正と通常型分岐2画像の採用をまとめたA/B正本。[原案・採用画像](../ryouki-v1/README.md)と[採用した第三相/第四相の対応](../ryouki-branches-v2/README.md)へ接続する。量機/1の生態/移動/相変異/比較値は維持する。製品4.2.32への登録/実装/実測は未完。ここで明記した量機の例外以外は[現在の仕様索引](README.md)を維持する。

## 1. 生態的な位置

量機は独立した主生物一系統。弱い戦闘力、高い移動力と繁殖力を持ち、草と小型の虫を食べる雑食性とする。植物を食べる一次消費と、草食性の虫等を食べる二次消費にまたがる。表示分類の主生物と食物網の栄養段階を別にし、固定の「最上位捕食者」にしない。

草は実在する生産者の可食部、虫は実在する適合した小型一次消費者を対象とする。接近/攻撃/実捕食/栄養移転を分け、食べた量だけ有限在庫から移す。光合成/情報栄養/無償補給を新設しない。生物量ピラミッドは実際の食性配分と実Bを使い、主生物と一次・二次消費へ同じBを重複加算しない。

通常型でも進化に伴う基礎成長は保ち、主な強みを探索・踏破・世代更新に置く。相変異4による攻防/繁殖率の大幅な追加強化は行わない。量機専用の寿命/栄養/出生費/経験換算/遺伝・性別のデータ接続は実装比較表へ残し、既存別系統の数値を暗黙にコピーしない。

## 2. 通常型と移動距離

通常型の造形は、利用者が最終選択した**初回の平たい菱形・長い脚の案**を正とする。青緑と金の外殻、前方の感覚器、下面に並ぶ脚を持つ。脚の連動はキャタピラに似た連続した接地/送りとして表現できるが、機械の履帯や車輪を追加しない。後の筒状サナギ案は通常型の現在参照にしない。

| 進化相 | 通常型の移動距離上限 |
| --- | --- |
| 第一相 | 1マス |
| 第二相 | 2マス |
| 第三相 | 3マス |
| 第四相 | 4マス |

距離は一回の移動機会で進める上限。合法な局所経路/占有/実費を通る各歩の積み重ねで、常に最大距離を強制しない。途中の不通セルや占有を飛び越えず、進めた分だけ確定する。到達点だけを検査する瞬間移動や全域経路探索にはしない。移動/戦闘/採食は既存どおり条件が成立すれば同じTに行えるが、移動歩数だけ採食/攻撃の回数を増やさない。

年齢は相と独立。子は第一相/年齢0/幼体から始まり、成熟・健康・有限栄養・方式・待機・空き等を満たせば第三相未満でも繁殖できる。相変異4の繁殖目的を、通常型や相変異1〜3の繁殖禁止へ読み替えない。

## 4. 相変異の共通条件

個体数が増えると相変異する。進化相・枝・年齢・相変異状態・個体IDを別に保持し、相変異だけで進化経験を加算したり年齢をリセットしたりしない。相変異1〜3/相変異4を下表の表示・行動区分として明示し、新しい別系統数や枝数に数えない。

相変異はゲーム内の**可逆な相状態の変化**とする。密度が低下し、通常型へ戻れる低密度の状態が一定ターン継続した場合に通常型へ戻る。現在の一時点だけで解除せず、通常型/相変異型の継続カウンタを使う。進化相/枝/個体ID/年齢/実績は解除でも保持する。遺伝子や系統が別物へ不可逆に置換される扱いにはしない。解除後の移動距離も、保持した本人の進化相に応じた1/2/3/4マスへ戻る。

| 項目 | 相変異中の共通仕様 |
| --- | --- |
| 移動 | 全個体3マス。第四相も3マスに統一 |
| 摂食 | 食べられる量が増える。実在在庫/採食機会/収支は維持 |
| 同居 | 同一セルに量機の相変異個体を2〜3体保持可能 |
| 繁殖力 | もともと高い繁殖力を据え置く。相変異による追加倍率は付けない |
| 外見 | 共通した輪郭、中央の窪み、小さくなる脚 |
| 個体単位 | 各個体のID/年齢/相/栄養/健康/親子/生死を別に保持 |

## 5. 相変異1〜3と相変異4

**利用者の最終訂正をそのまま正とする。**

相変異1〜3/4は本人の第一〜第四相に対応する区分。密度だけで第四相へ昇格させたり、密度低下で進化相を後退させたりしない。

| 区分 | 外見 | 行動上の差 |
| --- | --- | --- |
| 相変異1〜3 | **背中だけ黒**。ほかの部分は元の色を保つ。採用した元の相変異案を参照 | 既存の局所パラメータによる採食/探索/回避等 |
| 相変異4 | **黒と深緑**。採用した深緑の相変異案を参照 | **繁殖を目的に動く** |

両者の能力差は小さくする。相変異4は既存の候補評価で、繁殖適地・必要栄養の確保・方式に合った繁殖機会の優先を上げる。繁殖力の数値や出生数を直接増やす効果とは分ける。局所感知/成熟/費用/待機/競合を通り、条件不足なら採食・移動・回避等を行う。繁殖不能のまま同じ失敗だけを繰り返させず、不足条件の改善へ向かう。

相変異4の優先補正は一度だけ作用させ、枝・個体経験・情報/P/Qの既存補正との重複適用を避ける。系統全体を一つの意思で動かす仕組みを設けず、局所判断の積み重ねとして集合・分散・世代更新を観測する。

黒い窪みは閉じた背面の色と浅い形状。割れ目/傷/空洞にしない。通常型の第一〜第四相を進化しただけで黒系へ変更しない。相変異の第一・第二相を通常型そのものの色へ戻す案、全身を黒一色にする追加案、筒状案は現在の採用対象から外す。

## 6. 同セル2〜3体の調停

通常型と他の主生物は既存の一枠一個体を維持する。量機の相変異型同士だけ、主生物側の同セル容量を最大3個体へ拡張する。他の主生物との無制限同居へ広げず、生産者/一次消費者/H→P→Qの既存配置は別に調停する。

移動/出生の予約は個体IDごとに行い、同じ空き容量を重複使用しない。最大3体を超える候補は既存の公平な競合処理へ戻す。同居者は有限の可食在庫/空間で競合し、1個体分の食事を人数分複製しない。攻撃/捕食/死亡/情報/寄生宿主も実際の対象IDへ接続し、一体への作用を同居全個体へ自動適用しない。

密度低下の継続で相変異を解除する際は、通常枠に収まる状態を確保し、必要なら解除待ちとして同じ個体を保つ。同居したまま通常型一枠へ戻して個体を消失させない。分散のための無償移動/強制死亡は行わない。出生は第一相/年齢0で、親の相変異4の姿・行動・経験を丸ごと複製しない。

## 8. 観測・表示・保存

同じ確定時点から、通常/相変異、相変異1〜3/4、元の進化相/枝、年齢/性別、個体ID、現在行動/目的、同居ID、摂食量と不足理由を横詳細へ渡す。通常型と相変異型は背面の黒と脚の大きさで識別し、相変異4は深緑の外殻で識別する。黒色を単なる影として描かない。

同居時も各個体の選択/追跡/所在強調を保ち、同じセル内の対象を既存の横詳細で選び分ける。概観で数が判別できない場合は同居数を補助表示する。近景の絵柄、遠景の既存記号方針、名札/軽減の切替を維持し、相変異型だけの強制記号化や追加の常設グラフは作らない。

グラフは同居3体を3個体として計数し、セル数/群体数/生物量と分ける。相変異の成立/解除と出生/死亡を別イベントにし、単なる相変異を新系統/新個体/生態的な成立関係へ加点しない。第一〜第四相の既存構成集計を保ち、相変異だけで合計を重複させない。

初期/実効条件、計算/係数/表示版、各個体の相/枝/年齢/相変異状態/判定に必要な短いカウンタ/同居参照、最終集計/全ターン原値を保存・再現へ接続する。全個体の移動履歴や全セル間探索を追加せず、乱数/集計/表示操作の分離を維持する。旧記録に量機/相変異/複数占有があるように補完しない。
