# 持続する情報：関係性・個体の学習・場所への作用

[第2組・寄生生活環/1](parasite-lifecycle-v1.md)により、情報が変える宿主選択の好みと、感染コスト/成功率を変える遺伝適応、後天的な抵抗を区別する。QのPを殺す羽化後もHの既存学習/有効な痕跡は別規則で残り、情報だけで適合/成熟窓/抵抗を迂回しない。

[第1組・情報循環/1](information-cycle-v1.md)が、下記の評価/鮮度/生成/伝達/集中/Q痕跡をつなぐ具体化の現在正本。既存の意味/作用先を保ち、実際の動きによる調整へ進める暫定仕様とする。

仕様版 `persistent-information/7`。利用者が採用した具体化C01の基本構造と対象別作用を定義する。C02の暫定経験条件・実績評価は[情報評価/5](information-evaluation-v1.md)、C03の内容鮮度・痕跡残存・学習の区別と暫定期間は[情報鮮度/4](information-freshness-v1.md)を正本とする。C04の通常候補3件/2ターン・根拠不足枠最大5%/初期半重みは[情報生成/3](information-generation-v1.md)を正本とする。C05のQの遺伝傾向/歪曲/投資と生態的選択は[Q情報歪曲/3](q-information-bias-v1.md)を正本とする。既存の [死亡情報](death-information-v1.md)、[寄生メタ操作](parasite-meta-v1.md)、[採用状況](decision-register-v1.md)へ接続する。A/Bへの仕様反映であり、製品4.2.32・ゲーム実装・生存率・外観・性能の検証は変更しない。

## 1. 情報の定義と対象

情報とは、生物が環境や他の生物との関わりで積み重ねた経験・関係性が、個体内や環境中に痕跡として保持され、受け手と文脈に応じた意味を持つものである。個体・群落・群体の全生物を対象とするが、実際に持つ感知・選択・配分へだけ作用する。

情報は関係性の完全な記録や世界の真実ではない。局所の実績に偏り、古さ・誤認・撹乱・Qの歪曲を含める。発信元の実績、元の経験、伝達された内容、受け手の解釈を分ける。ゲーム内部の由来/歪曲タグを、生物が自動的に見抜く能力にはしない。

遺伝由来の発信・保持・受容の性質→体外の痕跡→他個体の判断→場所利用と生態関係、という経路を延長された表現型の抽象モデルとして扱う。獲得経験のDNAへの書戻し、水平伝播、情報による基礎能力/E/B/M/HPの直接増加は行わない。

## 2. 影響は2つ、保持形態は2つ

| 影響 | 適用 | 持続の意味 |
| --- | --- | --- |
| 学習の蓄積 | 内容を受容・利用した個体の実在する判断傾向/資源配分へ反映 | 場所を離れても個体の経験として残り、本人の実経験・既存回帰/忘却で修正される |
| 場所への作用 | 情報が残るマスと局所到達範囲で、接近/回避/滞在/採食先/定着先等の評価に使う | 情報がその場所に残る間の刺激。離れた個体を遠隔操作せず、学習重みへ毎ターン永続加算しない |

保持形態は「個体が保持する情報」と「死亡地点を起点として環境中に持続する情報」。同一の経験由来を共通に扱えるが、生存中の保持を死亡情報の生成と数えない。場所作用と学習を同じ補正として二重適用しない。場所刺激は候補評価時、学習は受容/実経験に応じた状態更新として区別する。

通常の情報の行動影響度kは、情報による学習と場所刺激の両方の実効作用へそれぞれ一度だけ適用する。k=0は両作用なしとし、生成・残存・読取の観測や既定費用は維持する。本人の独立した実経験、P直接誘導/QのP向け小補正、情報の栄養0を同じ倍率で変えない。既存の主生物9重み/0〜100/受信上限は学習の比較基準として維持するが、全生物・全作用へ±3を機械的に適用しない。新しい場所刺激や配分の係数は後続比較で選ぶ。

## 3. 関係別の内容を束ねる

| 区分 | 内容と適用の意味 |
| --- | --- |
| 全体向け | 資源・被害・混雑等、局所へ届いた各層の生物が適用可能な内容を利用する。全盤面への一斉命令ではない |
| 種族間 | どの系統との採食/捕食/支援/競争等の経験かを持ち、受け手と相手の関係によって意味が変わる |
| 親子間 | 親/実際の養育者との接触・観察・養育で伝わる経験。血縁だけで遠隔伝達せず、出生時コピーと区別 |
| 各層向け | 生産・消費・分解等、その役割に適合する経験。ピラミッド役割＋分解者/P/Qという既存の役割集合で判定 |
| 寄生由来 | P/Qの関係や寄生先由来の経験、Qによる出現率補正/歪曲。物理的感染やPの直接メタ誘導とは別の情報経路 |

5区分は排他的な資源種ではない。一件の情報に複数の成分・適用条件を持てるが、毎回5つすべてを作らない。区分、内容、発信/対象系統、発信役割集合、親/養育の関係、媒体/保持形態、元経験/由来、強度/時刻/期限、歪曲の有無を分ける。原データを区分ごとに複製して同じ経験を複数件にしない。

scopeの同層/全層は適用可能な受け手の範囲、種族間は相手との関係、親子間は伝達関係、寄生由来は起源/媒介を示し、単一の排他的enumへ潰さない。適用範囲と対象条件は内容成分ごとに持てる。同じ束の一成分が全層向けでも、他の同層/親子条件を全層へ拡張しない。複数役割や複数区分に適合しても、同じ由来・内容・受け手への同じ学習効果を重複加算しない。Qが内容を歪めても、発信元/役割/親子関係等を偽装する能力は追加しない。

## 4. 経験の内容と受け手の解釈

| 内容 | 根拠と解釈 |
| --- | --- |
| 資源利用/生産 | 実際の採食・生産・維持等。受け手の食性/役割/不足に適合する時に利用先の手掛かりになる |
| 被害/捕食 | 実際の被害や遭遇。被食者には警戒、捕食者には獲物の存在の手掛かりになり得る。被害者が短命でも重要な根拠 |
| 支援/共存 | 実際に成立した庇護・共同育児等。単なる同居だけで支援成功を捏造しない |
| 繁殖/定着 | 実際の出生・子の生存・群落定着等。親や発信者の成功を他種/別環境の成功保証にしない |
| 混雑/競争 | 実際の競合や局所利用の経験。個体の親和/空間確保/状態により集合または分散の材料となる |
| 寄生の関係 | 曝露・負担・排除・伝播等の該当経験と既知由来。受け手へ見えないP/Q内部状態を透視させない |

情報の内容は「集まれ/避けろ」という固定命令ではない。正負の評価は受け手の適性・空腹・年齢・経験・可視状況で決まる。飢餓や危険を無効化せず、通行/視界/有限予算/競合の既存条件を通る。

## 5. 一定の経験を蓄積した情報保持個体

本人の採食・被害・支援・繁殖/定着・寄生等の経験を少数の累積値・代表内容・時刻へ要約する。同じ関係・内容の実経験6件以上、かつ3つ以上の異なる経験ターンを蓄積した個体を、まとまった情報を保持し他者へ伝達できる状態とする。同じ相手・同じ結果は1ターン1件までとし、受取/再読取は本人の実経験へ数えない。これは比較調整用の暫定値である。年齢や生存ターンだけで自動認定しない。成功と不利益の両方を扱う。

幼体や未達個体も受容/学習は可能だが、他者へ伝えられる本人由来の内容は乏しい。受け取った内容と、自分が実行して確かめた経験を区別し、受容だけを新しい成功経験へ変換しない。同じ内容を読んだ回数だけで保持資格や発信実績を水増ししない。

情報保持個体の成立条件、死亡時の生成抽選、高い生存実績の評価、危険痕跡の根拠は別にする。保持閾値未達/低実績でも、実際の被害など意味のある経験に由来する死亡情報の候補になり得る。低実績の出現余地を維持し、無経験の個体に架空の経験を作らない。C02の保持条件・40/40/20の実績配分・通常10〜70%/実被害痕跡の下限40%は情報評価の正本に採用済み。保持資格を死亡情報生成の一律必須条件にしない。正規化/Sと基礎確率・残存の写像は第1組に暫定採用済み。役割別基準量は観察調整する。C04で通常の死亡情報候補は3件/2ターンとし、意味ある実経験があれば未達でも根拠不足候補として最大5%の枠を使う。確認済み被害は未達でも通常枠/既存下限40%を維持する。根拠不足の初期判断重みは通常の半分であり、内容の真偽確率ではない。

## 6. 通常の伝達と親・養育者からの学習

通常の個体間は、局所の接触・観察・身体に伴う信号等を通じ、成立した受容だけが弱い作用を持つ。近くにいるだけで全内容を共有せず、相手の内部記憶やDNAを直接読み取らない。本人の学習基盤は維持し、弱くするのは他者へ伝わる作用。多個体からの伝達には受信総量/反復上限を設ける。成立した受容の倍率は環境1/通常個体0.25/親養育者→幼体1。全経路合計で新規学習は2由来/Tまで、1由来に通常維持費1%相当を有限台帳から支払う。同由来/内容の再読取で再学習しない。

親・実際の養育者から幼体への伝達は通常より強くする。幼体期の受容性と実際の接触/養育を条件にし、成長後は本人の経験で修正される。年齢段階と進化相は独立で、第一相だけを幼体とみなさない。真社会性は実親以外の実際の養育者も対象にできる。全系統へ共同育児や養育能力を自動付与しない。

出生時の素質/固定DNA/出生傾向の遺伝は既存規則を維持する。出生後の経験学習と分離し、親の獲得経験・相・枝・情報差分を出生時に丸ごとコピーしない。親不在時に直接伝達は起こらず、死亡後の親由来情報の追加優遇は今回決めない。大域的な家系管理や全親子対の総当たりを要求しない。

## 7. 死亡地点への定着と保持媒体

環境情報は既存の死亡時条件/一回抽選で死亡セルに生じ、発信者の不在でも存続する。情報保持個体の内容や実績を生成候補へ接続するが、生成を確実に保証しない。老衰・飢餓・捕食等の判別可能な状況と生前実績を区別し、死亡そのものを全生物共通の危険命令にしない。

一般的な経験は学習内容に利用できるが、死亡地点の好適性はその場所/近傍に結び付いた実経験から得る。遠くの採食成功を死亡地点の豊かさとして出力しない。空間文脈が不明な内容は場所作用の根拠へ推定補完しない。

化学的痕跡、膜/殻/残留物、身体に伴う信号、行動観察等を束ねた抽象媒体として扱える。媒体は保持/局所到達/減衰の意味を担う。媒体ごとの微粒子や新しい微生物系統の個体計算を必須にせず、元モックの漂う/滞留する表現と両立させる。生涯の全経験が化学的に完全記録されるという現実再現は主張しない。

生存個体の弱い伝達と、死亡地点に環境情報が定着する処理を区別する。歩くたびの強い環境情報生成、偽情報による能動的な縄張り維持能力は今回採用しない。地形/障害物は固定し、情報による利用の変化を地形書換えにしない。死骸・感染体・可食資源も別に維持する。

## 8. 環境情報の集中・反復と存続

同じ意味/文脈の情報が同マスと周囲2マス（最大5×5、斜めを含む）に集中すれば局所作用が強まる。距離重みは同マス1/隣接1マス0.5/周囲2マス0.25。由来を重複排除して近傍全体を集計し、集中増幅の上限2倍を一度適用する。1マス最大4由来/各2内容の保存上限とは別に扱い、近傍感知を2由来/Tの学習枠と混同しない。近隣で同種の被害が何度も生じれば警戒の根拠が強まり、採食/繁殖成功の反復も適合する生物の利用価値を強める。量・新しさ・距離・内容の一致を使い、飽和/容量/実効強度の上限を設ける。未観測の成功確率や安全性を自動的に正解へ近づける処理にはしない。

同じ由来を移動/局所拡散/再読取/複製したものは新しい独立実績ではない。量を複製せず、単純な同居数や読取回数で無限強化しない。別の実経験/死亡から追加された痕跡と、古い痕跡の残存を分ける。異なる発信元を混ぜて架空の一人の優良実績を作らない。

同じ痕跡が後のターンにも場所刺激として働くことは認めるが、新しい独立情報の発生や同じ学習の再加算とは数えない。観測上の反復した作用と、強化の根拠となる独立した経験数を区別する。

情報の読取だけでは環境痕跡を消費・増殖・延命せず、複数個体が利用できる。拡散は隣接1マスへ1ターン合計最大20%を同期移送し、分割しても量/由来/時計/期限と独立根拠の数を複製しない。残量、元経験の古さ/有効鮮度、受け手の適合性を分け、時間と局所更新により減衰・失活・消失させる。長期残存を永久有効と解釈しない。Q加工でも元時刻/上限期限を更新しない。内容別の半減期は25/50/100ターン、痕跡は生成後100ターンを基本に実績で最大200ターンとする。鮮度は元経験から、残存期限は生成から数え、新しい根拠で古い根拠を若返らせない。個体が既に学んだ傾向は痕跡消失だけで即消去しない。詳細は情報鮮度の正本に従う。

集合と警戒など異なる内容は、単一の正負値へ相殺せず別に保持する。各生物が利益と危険を比較する。「豊富だが危険」「適するが混雑」の場所があり得る。情報を永久に残して接近/回避を固定せず、再探索の余地を残す。世界が現在の真相を参照して古い情報を自動修正するのではなく、時間減衰と、受け手の現地での実経験を通じて判断が変わる。

## 9. 対象別の作用先

| 生物 | 作用してよい実在の選択 |
| --- | --- |
| 主生物/一次消費者 | 探索、回避、採食先、接近/分散、配偶/庇護等の該当判断。一次消費者へ存在しない攻撃/育児を新設しない |
| 生産者 | 維持/成長/可食部/繁殖への配分、定着先等。移動・攻撃や無料の栄養生成に変えない |
| 分解者 | 利用可能な分解資源の選択、維持/成長/増殖/定着等の配分。固定型に動物の移動を捏造しない |
| P | 感染先探索/試行、維持/成長/放出、既存範囲の誘導への配分。感染適合や経路遺伝を情報で書換えない |
| Q | 寄生中の維持/成長/既存情報痕跡作用への配分、自立成体の探索/回避/採食/産卵。既存情報の成体加工を復活させない |

Qの出現促進・歪曲方向/強さ・加工投資傾向はQ自身の子へ継承/小変異し、実際の羽化/生存/産卵/子の定着で選択される。固定戦略や未来の成功を参照する大域最適化は使わず、相/栄養/費用で実効作用を制限する。具体係数は比較選定待ち。

Qの加工は既存の寄生先由来の死亡情報への痕跡に限定し、新設する個体間伝達の内容を直接書換える能力は今回追加しない。P/Qの誘導で変わった行動や実経験が他者へ間接的に伝わることとは分ける。

場所の占有、集合、競争、庇護、食物網や寄生経路は、上記判断と有限な生態処理の結果として生じる。情報だけで勝者・友好・栄養獲得・感染・生存を確定しない。危険信号の残る実際には安全な場所を、一部の個体が経験により利用する結果も認める。専用の占有権/免疫を付けない。

多種の実際の採食・支援・分解・感染が繰り返される関係を、個体が交代しても続くものとして観測できるようにする。同居、情報量、補正値だけで持続的関係/協力/創発を認定せず、本人の継続と世代を越えた関係の継続を区別する。R1〜R6と既存3グラフ/一体サマリを維持する。

## 10. 観測・保存・負荷・残る具体化
