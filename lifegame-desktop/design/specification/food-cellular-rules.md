# ライフゲームによる餌の選択・生成・量（A1.2 / B4 / B5）

[最新の餌一覧と表現](environment-food.md)に従い、FizzBuzzの4分類固定を外す。生物の20系統は保持する。餌の種類を増やし、数字・情報は独立した食べる資源として残す。以下は未実装の基準案。

## 元資料と今回の案

添付由来のLifegame_gas.mdの資源は、採取後5ターンで全量回復する方式だった。今回の餌は近傍更新に従い、時間だけで全量回復しない。硬い情報結晶という旧表現は、滞留・浮遊する情報エネルギーへ置き換える。

## 状態と種類

各マスには個体とは別に、成立している餌のIDと上限付き残量を持たせる。複数の餌種の同居は可能とし、同時保持種数には固定上限Kを設ける案（値は未確定）。無限の種類を一つのマスへ積み上げない。

同じ餌の環境別外見や量の段階は、別IDにしない。例えば緑の菌膜と熱域の赤褐色の菌膜は同じ種類として近傍を数える。数字粒の「数字の値」と「残量」は別にする。数字の同値/値群のどちらで近傍を数えるかは未確定。

## 近傍8マス・同期更新：B3/S23案

1. 初期値から、各餌が成立できる環境・地形に初期パターンと残量を置く。
2. 前ターン末の状態を固定し、周囲8マスに実在する同種の資源セルを数える。盤面外は空。環境・地形への成立条件も確認する。
3. その種類がないマスでは同種近傍3で誕生候補、成立中は同種近傍2/3で維持、それ以外で消滅する。残量の多い1セルも近傍数は1であり、粒の描画数を数えない。
4. 誕生時の残量は同種近傍の残量と環境条件から上限内で決める案。維持では消費後の残量を持ち越し、満量へ戻さない。量の計算式は未確定。
5. 同居上限を超える誕生候補は局所の成立条件と固定の競合規則で選ぶ。候補のない場所を抽選で埋めない。全マスを一斉確定する。
6. 個体は実際に成立した餌だけを採食し、摂取量を残量から引く。ゼロならその餌種は空になる。消費後を次ターンの入力にする。
7. 環境は初期値で固定。餌の成立条件はそのマスの固定環境を参照する。別の餌への自動置換・無条件回復は行わない。

餌が全滅する場合も観測結果とする。再播種は追加合意がない限り隠れた自動補充として実行しない。食べる量・回復の有無・初期パターン・K・競合順序は未確定。

## 情報エネルギー

局所的な有効行動の経験要約を、情報の内容候補として各マス上限付きで残す。要約があるだけでは食べる資源を誕生させず、情報エネルギーの近傍更新を必ず通す。成立した資源を消費した個体の、本人の6傾向値を修正する。

情報の残量、経験内容、内容の強さ/確かさは別項目。残量を消費する割合と内容の影響量の関係、内容の減衰・混合は未確定。情報を食べたことだけを新しい成功経験として再発行しない。DNA・身体能力・進化済み状態はコピーしない。

浮遊はセル内の描画表現。マスをまたぐ流体・漂流計算は追加せず、近傍則・個体の移動と摂取を通じた伝達を基本とする。

## 計算量と表示

全セルで全餌種を総当たりせず、近傍に実在するIDだけを候補として数える。近傍8と同居上限Kが固定なら、餌種の総カタログを増やしても更新はO(N)を目標にできる。残量は上限付き一値、外見は環境と量から選び、個々の光粒や胞子を別のシミュレーション個体にしない。性能は未実測。

B4は同期更新・残量・消費の接続、B5は種類/環境/残量/近傍条件/情報内容の参照、B5.2は説明を扱う。静止画はセル更新から算出した実盤面ではない。

## ランダムな撹乱情報

[最新方針](fixed-environment-and-perturbation.md)に従い、近傍則で誕生した情報エネルギーの内容を低率で撹乱情報にする案。実経験由来でない内容であると区別する。内容だけをランダム化し、無条件の餌生成はしない。乱数は初期値等から再現可能とし、内容は成立時に固定。率・強さは未確定。
