# ゲーム内の進化・分岐ツリー参照機能（B5.1案）

A/Bの機能仕様と静止画による検討。ゲームコードは変更せず、実装再開は利用者の許可待ち。

## 入り口

- ゲーム内メニュー「図鑑 → 進化・分岐ツリー」から、全20系統を選べる。
- 個体詳細の「この個体の系統樹」から、系統・現在相・選択済みの枝を表示する。
- 餌や環境の詳細から、関連する分岐条件を参照できる。

## ツリーに表示するもの

1. 第一相・萌生、第二相・変容、第三相・異相、第四相・覚醒を全系統で表示する。
2. 既存の相・個体名と、今回提案する特化名を分けて記載する。
3. 個体を選んでいる場合は、現在相、既に通った経路、候補の経路を文字と線で区別する。見本の第四相をその個体が到達済みであるかのように表示しない。
4. 枝・相を選ぶと、必要な成長、餌の組合せ、環境経験を右側へ表示する。確定した条件では現在値・必要値・不足分を示し、未確定条件は「未確定」と表示する。
5. 餌条件は「生命」だけでなく「Fizz / 耐熱菌膜」のように環境別差分まで参照できる。
6. 全体を眺める図鑑表示と、選択個体の進捗表示を切り替えられる。系統樹を開いても世界の設定や個体の系統を変更しない。
7. 線・選択状態は色だけで伝えず、ラベルと線種も使う。狭い画面では図と条件を順に確認できる配置を検討する。

## 未確定事項

- 系統樹を開いている間のシミュレーションを止めるか。
- 未発見の相や分岐の名称・姿・条件をどこまで開示するか。静止図は説明用にすべて表示しており、全開示仕様の決定ではない。
- 条件を複数満たす場合の選択・優先順位。第三相以降に別の特化へ移れるか。
- 詳細な条件の数値と、各枝に専用の造形差分をどこまで持たせるか。
