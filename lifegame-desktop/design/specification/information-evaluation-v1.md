# 情報を保持する経験条件と死亡時の実績評価

仕様版 `information-evaluation/5`。利用者が採用した具体化C02の暫定条件を定義する。[持続する情報](persistent-information-v1.md)の保持資格と、[死亡情報](death-information-v1.md)の生成確率を分離する。以下の値は比較調整の開始値であり、新モデルの実装・生存/性能・出現頻度を検証した値ではない。

## 1. 採用した暫定値

| 項目 | 暫定値/条件 |
| --- | --- |
| まとまった情報の保持 | 同じ関係・内容の実経験が6件以上、かつ3つ以上の異なるターンにわたっている |
| 重複抑制 | 同じ相手・同じ結果は1ターンに1件まで。同じ情報の再読取は本人の実経験に数えない |
| 生存・維持の実績 | 評価配分40% |
| 役割を果たした実績 | 評価配分40% |
| 関係の継続・世代更新 | 評価配分20% |
| 通常の経験情報の死亡時出現率 | 実績評価に応じて10〜70% |
| 確認済み被害に由来する死亡痕跡 | 被害痕跡の出現率を最低40%にする |

保持資格と死亡時の出現率は別の条件である。6件未満の実経験にも内容はあり得るが、まとまった情報を他者へ伝達できる状態とは分ける。親や環境からの学習、幼体/未達個体の受容を禁止しない。C04の[情報生成/3](information-generation-v1.md)で、通常の死亡情報候補は3件/2ターン、未達の意味ある実経験は根拠不足枠最大5%と定める。保持6件/3ターンや個体の生存実績とは別軸であり、確認済み被害は候補基準未達でも通常枠/下限40%を維持する。

## 2. 経験を蓄積する単位

採食/生産、被害/生還、実際の支援、繁殖/定着、寄生の伝播等、成立した関係と結果を本人の実経験として要約する。成功だけでなく失敗や不利益も含め、異なる経験種を広く集めることは必須にしない。一つの関係を繰り返し経験した個体も情報を持てる。

件数は同じ意味・関係に対応する内容について蓄積する。無関係な内容を合算して、どの内容にも6件分の根拠があるとみなさない。3ターンは同じターンの複数段階を3回と数えず、実経験が確認された異なる確定ターンを数える。連続3ターンを追加条件にはしない。

同じ相手・同じ結果の同一ターン重複は抑止する。観測/表示の重複、5区分や複数役割への分類、同じ痕跡の再読取/拡散を別の実経験にしない。受取内容と、自分が実行して確かめた経験を別に保持し、親から受け取っただけの内容を本人の成功実績へ変換しない。単なる生存経過・同居・移動量・架空の失敗試行も実経験の代用にしない。

個体・群落・群体ごとに、少数の関係/内容別カウンタ・経験を得たターン数・代表経験/時刻を保持する。全行動の全文記録・全個体対の検索は追加しない。同じ相手/結果の識別、各内容の有限保持件数等の実装前詳細はC10/C11と照合する。

## 3. 死亡時の実績評価

| 評価軸 | 配分 | 評価する根拠 |
| --- | --- | --- |
| 生存・維持 | 40% | 栄養/健康を維持できた期間。系統/生活様式の寿命・必要栄養等に応じた基準で扱い、絶対年齢だけを優遇しない |
| 役割成果 | 40% | 消費者の実採食/生還等、生産者の実生産/維持、分解者の実分解、P/Qの適合する発育/伝播等。単純な量/攻撃力/殺害数だけにしない |
| 関係継続・世代更新 | 20% | 継続して成立した関係、子の定着/成長、養育等。単なる接触回数や出生数をそのまま成功へ置換しない |

各軸は適用可能な生活様式の基準で正規化し、評価に上限を設ける。生産量・体格・短期大量出生などの絶対値の合算で無限に高評価へ進めない。生存中に観測できた本人実績だけを使い、将来の勝者や子孫の未来から評価しない。

通常動物、植物群落、分解者、P/Qの根拠を区別する。植物へ捕食実績、非繁殖の働育個体へ本人の出産を要求せず、該当する定着/更新・養育/支援等を使う。存在しない能力を新設したり、非適用の値を成功として補完したりしない。適用根拠や基準が未定義なら評価未確定として扱う。

[第1組・情報循環/1](information-cycle-v1.md)で、各軸を本人の確認済み実績/役割別基準量として0〜1へ制限し、S=0.4A+0.4B+0.2C、pBase=0.10+0.60Sを暫定採用する。基準量は生活様式に対応させ、現在の集団順位や未観測の成功で補完しない。役割別基準量/対応表はこちらが第2・第3組と合わせて用意し、観察調整する。

## 4. 通常情報と被害痕跡の出現

意味のある経験内容を持つ死亡個体について、通常情報の出現率を実績に応じて10〜70%とする。情報保持の6件/3ターンは死亡生成の必須条件へ一括流用しない。高実績ほど出現しやすく、残存も優遇する方針を維持するが、残存期間はC03の[情報鮮度/4](information-freshness-v1.md)で生成後100ターンを基本に実績で最大200ターンを採用済み。実績写像はL=100+100Sターン（整数化）を第1組で暫定採用する。高実績だから情報内容が常に正しい、受け手への作用が常に最大、と扱わない。

捕食・攻撃等の確認済み被害に由来する痕跡には、被害痕跡の出現率40%を下限として使う。短命・保持閾値未達・低い生存実績だけで警戒根拠を消さない。通常の実績評価で40%を超える条件を、この下限で引き下げない。

40%の下限は被害痕跡に適用し、その個体の通常の成功経験・発信実績・受信効果を底上げしない。Qの歪曲や撹乱で被害を装った内容を、確認済み被害として下限の根拠にしない。老衰・原因不明の死亡を一律の危険痕跡にしない。無経験/由来不明から架空の経験を生成しない。

死亡時の生成は、既存の死亡ID/ターンに結び付いた再現可能な一回抽選へ接続する。通常/被害の条件や内容が複数あっても再試行・再読込・描画順で独立再抽選しない。同時に含まれる内容の選択/抽選の具体的順序はC10で整合させ、出現率を加算して複数回の独立死亡として扱わない。

Qの出現率補正/内容歪曲は別要因として維持する。通常情報10〜70%と被害痕跡40%はQ補正前の基準であり、Qの遺伝傾向/加工投資と成果への経路は[Q情報歪曲/3](q-information-bias-v1.md)へ採用済み。具体上限/費用は比較選定待ち、C06の順次痕跡は第1組の最大2痕跡/上限付き加重平均/離脱後半減期50T・100T失活へ接続する。Qが元の実績や親子関係、被害の観測事実を改変する能力は追加しない。

## 5. 記録・照合・残る調整

情報/評価の定義版、暫定係数版と全実効値、内容別の根拠件数/経験ターン数/保持資格、本人経験と受取内容、3軸の評価根拠/適用状態、通常確率/被害下限/Q補正/生成結果を区別して保存する。旧記録を新しい6件/3ターンや新確率で再計算して元の観測へ置換しない。

必要な説明は既存の横詳細/説明シート/図鑑分析へ接続し、新しい常設グラフや長い計算説明欄を増設しない。既存3グラフ・一体サマリ、全確定ターン原値、計算署名と保存/再生を維持する。評価値を生態系の健全性、個体の戦闘能力、R1〜R6の達成点に転用しない。

比較では保持成立の速さ、個体/群落/群体・生活様式ごとの偏り、通常/被害痕跡の出現密度、警戒への偏り、親養育者/通常個体の情報源、集中/反復の飽和と有限費用を確認する。6件の直前/到達、経験ターン数の直前/3到達、同ターン重複、受取だけ/本人実経験、専門的な単一内容、低実績の実被害/老衰/原因不明、Q有無、保存再生を境界観点にする。

第1組は暫定採用済み。役割別の評価基準量、集中曲線/微小量失活/容量競合や受容候補の細かな優先度はこちらが実装比較・観察で調整する。第2組の寄生生活環/遺伝適応/抵抗/Q第四相は採用済み。次は第3組C09/独立四相植物、その後に第4組C13/表示説明保存。今回はA/B文書のみで、製品4.2.32・3core・C/D/E・src/tests・画像/配布物は変更しない。 通常候補/根拠不足の一回抽選、被害下限、鮮度、受容費/由来重複排除は第1組の結合定義に従う。
