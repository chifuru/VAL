## 2. 世界・セル・初期配置

### v1.3確定：セルと宿主内の存在を分ける

セルは主生物一体、餌生物一体を独立に保持できる。**寄生虫は生物に寄生するため、同セルは「生物H＋その寄生虫P」、さらに高次寄生虫Qがいる場合は「H→P→Q」**になる。P/Qは自由歩行する地表個体でも、主枠・餌枠を奪う別セルでもない。Pはhost_id、QはPのIDを参照し、位置は根宿主から導出する。宿主の移動に同伴し、独自の移動予約・空きマス・攻撃候補を要求しない。

主生物と餌生物が同じセルにいる場合、両方がそれぞれPを持つことも可能（各宿主P1、各PにQ1）。セル全体でP1と制限しない。適合は生活環の規則で判定し、同セルにいるだけでは宿主間移行しない。H/P/Qは別ID・別E台帳で、選択時に階層表示する。死骸感染一件と有償子候補一件は休止ペイロードであり、地表で生きたPが動くことではない。H死亡・移行・ペイロード消費は12/13/14節に従う。

### v1.3確定：有効化と配置保証

- 無効群は初期0、生成候補0。群目標の再配分は同じ有効群の有効系統内だけ。他群の比率を増やさず、無効群を保証のために復活させない。
- 有効化は存在・存続の保証ではない。P/Qは対応宿主不足を開始前に警告し、適合宿主がなければ初期0。生活環を成立させるための主/餌の強制追加はしない。全生物群OFFだけはSETTINGS_INVALID。
- 資源保証は主の各四体組への有効な可食餌（菌を含む）と鉱物への接触を対象とする。有効な可食系統なし/置場なしならGUARANTEE_FAILED。主群OFFは対象0で追加0と表示し、保証のためだけに主を作らない。
- 主初期0の場合は主全滅停止を適用しない。初期主>0から主0へなった時だけ一度停止し、続行なら残存群を観測する。無効・初期未参加・現在不在・絶滅を区別する。
- 初期配置例は設定の模式図であり、未実行の初期値を「長期生存確認済み」とは表示しない。

盤面は小40×28/標準80×56/大160×112、端は接続しない。主生物初期80/320/1280は目標で性能実績ではない。主1/餌生物1/非生物資源最大3種/死骸は主由来と餌由来各1/宿主ごとP1/PごとQ1。独立個体を一つの平均個体に集約しない。

### 3.2 配置と初期投入

同一枠の配置候補は適合→位置優先値→キー順で有限に列挙し、足りなければ開始前エラー。主の環境適合は得意2/標準1/苦手0で、苦手も配置可能。草本/小型等の生息適合は系統表の制約を守る。

植物35%は微藻/岩苔/草本を1:1:1、菌3%、小型10%は水游虫/草棲虫1:1の目標。各比率の個体数は通行可能セル数×比率を四捨五入、同群内は最大剰余法。同群で配置不足なら同群の他系統へ再配分し、それでも群目標に届かなければ不足表示して開始しない。各初期餌はI/年齢0、系統表の予算を持つ。主と餌は独立枠なので重ねてよい。

主の少数モードは初期値の系統優先順先頭5。手動は有効主系統1〜21。最低四体ずつを配り、残り四体組を重み最大剰余法で配分。自然は各系統の適合×近隣食用餌（半径2、一体+0.1/上限0.8）の高いセルを優先、同点初期値。散開は既配置主との最短距離が最大、集中は系統ごとの初期値由来中心から最短、同点は適合/初期値。これらは開始時だけの配置処理であり、通常ターンの全個体探索には使わない。

資源保証ONは各四体組の代表点半径2に食用植物/小型一件と鉱物一件への接触可能性を要求する。既存で満たせば追加なし。不足時は空き餌枠/資源枠に初期投入として一件ずつ追加、対象系統は食性最適/生息可能なもの。同点初期値。場所がなければ保証不成立を表示し、地形や他個体を消さない。

各セルR_M5を最初に投入。鉱物片は岩セル20%/その他通行可能3%、鉱液滴は浅瀬/泥20%/その他2%の確率でq2、必要MをR_Mから支払う。初期情報媒体は通行可能セル2%でq2/内容なし/E予算0.1を別途初期投入として記録。種実/胞子/卵/有機粒/因子/死骸は初期0。資源枠3種を超える初期候補は鉱物片→鉱液→情報の順。P/Qは最後に系統表の確率で配置する。

初期媒体を孤立点だけにして初回S23でほぼ全て消すことを避けるため、上の確率で得た種類別候補数を目標数とし、配置は2×2通行可能ブロックを初期値順に先に埋め、端数1〜3だけ単点へ置く。ブロック候補は平均適合度→hで選択、重複なし/枠とM予算を予約する。目標数に届かない場合は単点配置へ戻して不足分を埋める。それでも予算不足なら開始前に不足を表示する。光・資源の初期投入を記録し、毎ターンこのパターンを再投入しない。

## 3. 時刻・再現性・ID

- 単位はセル、ターン、E、B、M、HP、G。距離はチェビシェフ距離。座標は左上(0,0)、右へx、下へy。近傍は自己を除く8近傍、端の外は不在。半径rは最大(2r+1)²−1セル。
- `S_t`はtターン終了状態。初期状態は`S_0`。ターンt+1の途中状態を表示や次の意図へ漏らさない。光供給後・移動前の判断用状態を`V_t`と呼ぶ。
- E/B/M/HP/G、重み、特徴、得点は内部小数で保持。判定前に丸めない。各確定書込みを小数点以下6桁へ四捨五入（正値の0.5は上へ、負値は絶対値で同様）。HP/E/M/B/Gは0未満にしない。被害整数だけ`floor(x+0.5)`。表示は別に丸める。
- 初期値はUTF-8文字列（空白も値）。独立な疑似乱数値`u`は「仕様版、初期値、用途、ターン、ID、候補キー、軸番号」を順序固定のJSON配列としてUTF-8化し、SHA-256の先頭32bitを符号なしbig-endian整数hとして`u=h/2^32`。不要引数はnull。用途名はworld/env、world/terrain、world/edge、world/light、init/group、init/position、birth/dna、birth/sex、birth/role、behavior/jitter、arbitration等で分離。連番乱数の消費順に依存しない。
- 無作為区間[a,b)は`a+(b−a)u`。確率pはu<p。同点は独立用途のhが小さい候補、さらに正規化候補キーの辞書順。候補キーは動作種、主体ID、対象ID、経路、セルを順に含む。観測・描画・画像出力は乱数用途を持たない。
- 生物IDは初期`i:枠:y:x:系統`、子`b:出生ターン:枠:y:x`。一枠一出生なので一意。P/Qは`p:出生元ID:ターン`/`q:出生元ID:ターン`。移行でIDを再発行しない。イベントIDは`ターン:主体ID:種類:同種通番`、通番は確定した対象キー順。過去IDは再利用しない。

## 4. 栄養・採食・回復の共通台帳

Eは活動用備蓄、BはEを投資した身体、Mは材料、Gは成長進捗。E→Bは同量Eを引く。GをE/Bへ逆換算しない。主初期E60/B16/HP100/M0/G0、子の配分は出生費に従う。内部小数は補遺1節の確定丸め規則に従い、表示丸めで判定しない。

植物刈取りの一単位は最大B2を取り出す。有機資源/死骸の一単位は、その供給元の残予算/qを取り出す。種類ごとの一単位量は等しいとは限らず、残予算を超えない。各供給元の有限予算を先に引き、吸収効率η=min(0.95,0.5×食性係数×DNA係数×固有補正×枝補正)。有機DNA係数0.9+0.2aptitude。上限超過分は失われ、再配布/経験にはしない。基準0.5により得意食が初めから上限へ張り付く旧方式を避ける。Mの直接取得はηM=min(1,0.5×鉱物食性係数×(0.9+0.2skin)×固有M補正)を使い、取得できなかった残MはR_Mへ戻す。供給予算以上の材料は得ない。代謝因子の直接Eにも有機のηを適用し、微量予算を固有補正で超過生成しない。

植物のBを実際に取得した量×ηをEとG進捗へ使う。Gは進捗であり同量の物質を二重生成したことにしない。死骸は有限BE/BM/BGを個別に減らしてE/M/Gへ反映。HP回復は不足時に取得Eの一部を2E→1HPへ振り分け、菌/苔の回復特性や固有HP補正はその回復効率へ適用し最大0.75HP/E。EもHPも無料全量取得はしない。

毎ターン最多二単位を、所在資源/同セルまたは隣接の植物/受動M/死骸で共有。E<35なら維持解消、HP<50なら回復、以後G/M不足/代謝因子/情報の順。情報は学習待機中に積極採食しない。隣接刈取りは一つの基本動作を使い、移動/攻撃と同時に行わない。動作後の所在資源採食は残り上限内で可能。

基礎維持は付表×DNA×相×固有。主枠8近傍0〜1で追加0.5、2〜4で0、5〜6で1、7〜8で2。餌枠は主の密度へ加えない。主の各相維持係数1/0.98/0.95/0.9。停止割引は割引前の支払可能額で意図を作り、実際に停止/防御を選んだ時だけ適用。食べる予定を前借りしない。採食確定後の未払い1EにつきHP2を失い、HP≤0/年齢上限で死亡。植物/菌は刈取りでB0になった場合も死亡し、後段のB投資で復活しない。

### 確定条件の詳細

単位は一供給元への最大一口。各生物は一ターン二口で、隣接刈取り/所在採食/受動M/情報を共有する。二回の予約ラウンドを使い、各回は生存取得者が一件のみ要求。同じ供給元へ複数要求ならh→主体IDで順に残予算を配分。第二回も二重取得を除外しないが、残q/Bが必要。移動後資源は本人の所在から取得可、隣接刈取りは選んだ植物IDがまだ隣接・生存の場合だけ。通過点から食べない。

主の取得源の選択優先は(1)E<35なら有機Eを持つ源、(2)HP<50なら回復効率の高い有機源、(3)次相G不足なら有機源、(4)Mが次相要求または繁殖資格4に不足なら鉱物/含M源、(5)有効な因子、(6)待機なしで未取得イベントの情報。各群内は本人食性で予測できる単位吸収E/M/Gの大きさ→h。源の実予算/相手Eを透視して動作評価しない。予算予約時だけ実量を使い、実量不足の取得で別源へ無限に再要求しない。植物/菌/小型の取得源と専用収支はv1.4 1/2節による。

主の実取得有機エネルギーeについて、E<35ならまず35までEを充当、残りをHP<HP上限なら`不足HP/回復率`まで回復へ（緊急優先閾値50と回復目標100は別）、最後を容量までEへ。回復率は基準0.5×餌回復適性×固有×枝、上限0.75。Eへ入る前に回復に回したeはEに重複加算しない。Gは有機の実吸収eから別に進捗を加える（主のみ、基準1e→1G、頭足の動物G固有はここだけ）。Eが満杯でも吸収できた有機はG進捗になり得る。情報/鉱物/因子単独では通常有機Gを生まない。

ただし死骸だけは正本の有限BG台帳からηを掛けた進捗を取り出し、上のe由来Gを重ねない。植物/脱落有機はe由来、死骸はBG由来と供給種で一意に分ける。因子の固定加算は有機取得>0の一回だけ、基本Gの後へ加え、倍率を掛けない。通常回復適性は1、苔/菌由来は1.2、失活胞子も1.2、他の有機は1。

単位資源は残qを1減らし、供給元の各残予算/消費直前qを取り出す。B植物は`min(2,残B)`、qではなく実Bを減らす。残Bが2未満でも一口、B0は即座に刈取死として次の要求から除外。未吸収Eは散逸、未吸収Mは源セルR_Mへ。菌が処理しても同じMを二回還元しない。感染は**取得M/Gだけでなく実際の有機摂取量>0**を要する。

数値例：aptitude0.5/植物食係数1/固有なしの主が草B2を刈るとη0.5、草B−2、吸収e1、主G+1。E20なら主E+1でHPは回復しない。E40/HP48ならe1を回復へ回してHP+0.5、Eは増えない。M0.2を含むB10の草ならM0.04を供給元から引き、ηM適用後の残Mを土へ返す。

### 食性ごとの吸収の適用

汎食主/aptitude=skin=0.5/固有・枝なしの例で、草B2→吸収e1/通常G1。鉱物片の供給M2→吸収M1、鉱液M1→0.5。生体Mは刈取り割合で有限移転しηMを適用。苔/菌の回復適性はHP/Eの倍率であり、直接HPを無償加算しない。

主の食性型は植物/菌有機/動物/鉱物の係数を変える。小型の植物吸収0.65、菌の有機吸収0.7は主の基準0.5式を重ねず直接使う。因子の直接Eだけは主のaptitude/固有を使うが、植物/動物/鉱物の食性係数は1。因子の固定G補助は倍率なし、次の有機取得一回/3ターン、強い活性だけ保持。情報の最大E0.05/単位には有機食性倍率を掛けない。

動く餌は倒してから有限死骸を食べる。たとえば精算後E8/B2/M0、I相・既定body0.5の餌が死ぬとBE5/BG1/q2。汎食主の一口はE1.25/G0.25（回復振分け前）。毎回同じ価値とは限らず、死ぬまでに消耗したE/B/M、相、残qで変わる。攻撃成功と、実際の採食成功は別のイベント。

## 5. 光・生産者・分解と材料循環

光量0〜1は固定環境/障害物から初期生成。植物は2×光量のE/ターンを維持前に取得し容量上限へ制限。菌は光を利用しない。高度植物共生は既存1.5×光量×相係数1/1.1/1.2/1.3の混合栄養を維持する。光によるEに食性倍率を重ねない。

植物/菌のB回復はEを最大1消費して同量Bへ投資。成熟して有効なB3出生先が見える時は繁殖E8を留保、ない時はE5を残す。これでB回復が繁殖費を永久に先取りしない。維持/寄生費をまず支払い、留保は生存を保証する無料予算ではない。

材料リザーバR_Mを一セル上限20/初期5で持つ（変動資源であって環境種別ではない）。鉱物片/鉱液滴の誕生B3はR_Mからそれぞれ一単位M2/M1を引ける場合だけ成立。植物の受動取得は所在鉱物一単位、通常採食と二単位上限を共有。R_Mがない場所からMを生成しない。

死亡時Mは半分を死骸BM、半分をR_Mへ。死骸腐敗時の残余BM、有機物を菌が処理した時の未吸収M、出生M費用の未移転分もR_Mへ返す。上限超過は散逸として集計。菌のM取込み率0.5、残りは還元し二重計上しない。初期投入/境界損失/光は別に計上し、厳密な現実生態の保存系と主張しない。

光成長は当該ターンに光Eを得て、支払後E≥60/M≥1の高度植物共生のみ、E1→G1を一回。Mは材料の保有条件としここで無料増加も二重消費もしない。従来のM0.1消費案を更新。植物/菌の二段階は付表の年齢/Eで判定し、G210は要求しない。

## 12. 寄生・高次寄生と宿主遷移

### v1.3確定：移行ターンの徴収先と死亡

### 確定条件の詳細

P潮環の終宿主適合は深淵触手/深殻/浮遊傘/星海鯨/深淵頭足。P葉環は食性が植物寄り/汎食の主（早成含む）。終宿主はIII以上。感染植物の刈取りは植物を殺さなくても有機取得があれば移行候補となり、成立したら植物からP/Qを除く。一つのPが複数の口へ分裂しない。実取得順hで最初の**適合した**取得者だけが受け取り、不適合な先の一口はPを消費しない。

小型→主の移行は生体への直接吸収ではなく、小型死骸の感染ペイロード一件を介す。中間成熟6を満たして死んだ小型の死骸はTTL4のペイロードを持つ。適合主III以上なら終宿主、適合主I/IIなら追加中間Bになる。未成熟小型の死亡/初回植物の死亡はペイロードを残さない。追加Bは成熟6の死骸から別系統の適合III以上へ移る。終宿主の死亡はペイロードなし。これにより「捕食には先に殺す」規則と生活環を一致させる。

ペイロード有効死骸を最初に実採食した個体が不適合/同系統/感染枠満杯なら、その一件は失敗消費する（栄養は通常通り）。植物からの部分刈取りと区別する。感染源の旧P/Q枠は移行成立時に空、根宿主死亡後は元のIDをペイロードへ移し宿主なしの活動はしない。移行先が段階6で死亡したら連続再移行せず失敗。元の身体へ巻き戻さない。

Pは根宿主から**満額0.2を取得したターンだけ**成熟回数+1。QがいればP0.15/Q0.05へ分配、Qは満額0.05だけで回数+1。0<取得<満額は蓄積には入るが成熟回数は増えない。Qによる隔ターンはQがII以上だったターン開始状態を使い、`(ターン+Pの固定位相)%2=0`だけP回数を増やす。蓄積容量超過は散逸。段階移行でP回数0、Q同行は自分の段階/回数を維持。

Pの宿主操作は中間段階でのみ：潮環=探索+3/回避−3、葉環=資源+3/場所−3、第一/終段階は0。QII以上はこれらと環境誘導項を0.5倍。操作は恒久重みでなく一時項。QのIII特化カウンタは根宿主の発信成功/接触成功/情報取込成功に各+1（各上限8）。III到達で最多を発信整流/保持/変調へ対応、同点h。全0でもhで一つを固定する。

成熟終Pは放出間隔4（QII以上8）かつ蓄積≥0.1で、適合第一宿主の空P枠一件へ子を置ける。候補なしなら所在セルに一個だけTTL8の有償子候補を留置し、新たな候補を重ねない。第一宿主の通常出生が同セル/8近傍で起きた時に候補h順で一件だけ感染。候補中は活動/摂食/成熟なし。P親は残る。子は新ID/第一段階/取得回数0/蓄積0、感染の費用は翌回から。

成熟QIIIの子はQ蓄積≥0.1で同時P子に一件同伴、Q親は残る。生活環を渡る既存Qの移行とは別の**出生**。Q子はI/蓄積0/特化未定。P移行だけで新Qを無料に作らない。Q媒介情報の操作は新しい根宿主由来イベント一件にのみ一回、4待機/0.02支払、同じevent ID再発信では再操作不可。保持タグの1.25倍は内容時刻を変えない。宿主内深さはH→P→Qで止め、Qへのさらに高次寄生は初回外。

## 13. 死骸・腐敗・感染の残存

死亡ID一件につき一回、由来枠の死骸を置き、同枠の旧死骸は置換して残余MをR_Mへ戻す。別枠は消さない。BE=0.5(E+B)、BM=0.5M、BG=0.5B、残りE/Bは散逸/MはR_M。q=ceil(2×相係数×(0.75+0.5body))、上限4。植物/小型の相係数はI1/II1.1。qは単位数で総予算を増やさない。

一単位でBE/q/BM/q/BG/qを引き、残余を更新。EとGを相互変換しない。予算/残量0で消失、死亡後12ターンで腐敗、栄養のない死亡から栄養を生まない。死骸は主枠/餌枠の生存を妨げない。作ったターンは採食終了後なので次ターンから食べられる。

同系統死骸は初回の生物採食対象外、菌の分解はその制限外。攻撃者に所有権はなく他個体が先に食べられる。P/Q感染ペイロードは別の一件/短期限で、消費/失敗/置換で二重伝播しない。

補間時間は実時間ターン区間の80%/最大300ms、残り静止。10Hzなら80ms、1Hzなら300ms。停止/一歩送りは確定位置で止まり、リプレイ演出は同じ結果を示すだけ。動き軽減は補間なし/輪郭一回。点表示では移動先/相色/選択輪のみ、詳細な雌雄/感染を無理に描かず選択資料で読めるようにする。

### 不成立理由と集計

開始前エラーは`SETTINGS_INVALID / PLACEMENT_SHORTAGE / GUARANTEE_FAILED`。通常の不成立は`BUDGET / SLOT_BUSY / RESERVATION_LOST / PATH_BLOCKED / OUT_OF_SIGHT / OUT_OF_RANGE / TARGET_LOST / COOLDOWN / IMMATURE / HOST_MISMATCH / INFECTION_OCCUPIED / EXPIRED / DUPLICATE_INFO / CAPACITY`。同候補に複数理由があれば設定→対象/経路→成熟/待機→予算→枠/競合の順で代表一つ、観測者が詳細を展開可能。

観測の全状態は生物の感知とは別。例：観測者はQの型を見られるが、個体は可視外の餌も隣の相手Eも知らない。表示は現在セル内の全枠を選択可能にし、「餌の下に個体が消えた」ように見せない。

集計は有効系統の生存/出生/死亡原因/相/枝、E獲得源、M投入/土/生体/死骸/散逸、感染の段階/移行成功/失敗理由、情報の発信/新規取得/重複拒否/Q操作、階級/colony別の生存/出生を固定チェックポイントで記録する。全家系履歴や毎ターン全個体録画は初回外。選択個体の説明は直近一ターンの候補最多3件と得点内訳を**選択中だけ**保持し、全個体の全履歴は残さない。
