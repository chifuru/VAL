# 草棲虫の存続優遇 / 4.2.48

固定河川・湖で草棲虫だけが早期に絶滅したため、新規観測の草棲虫小集団に水游虫と同等の生存枠を与える。利用者指定に従い細かな中間候補は設けない。

`consumerModel: group/1` と `consumerGroupSettings.version: consumer-group-parameters/2` の組で適用する。水游虫の**実効** `life / maturity / maintenance / birthCooldown / initial E,B,HP / capacity` を草棲虫の該当値とする。水游虫の優遇スイッチが有効なら優遇後の値、無効なら通常値を参照する。草棲虫の名称、生息域、植物食、採食効率、移動と種固有の行動は維持する。初期差分は世界生成時の有限初期蓄えとして台帳へ入れる。出生は既存の小集団の有償内部出生とする。

設定版1および `consumerModel` 未指定の旧記録は旧規則で再生する。新版の小集団状態だけに適用印を持たせ、分散先の子集団へ引き継ぐ。途中で設定を切り替えない。採用判定は固定河川・湖での存続と、集団上限・台帳不変条件・旧版再生の維持に限る。全系統の500T生存率や性能はこの限定比較から推定しない。
