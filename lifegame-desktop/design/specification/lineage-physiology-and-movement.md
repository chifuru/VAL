# 系統別の繁殖・寿命・栄養要求・移動範囲

ユーザーの追加指定を反映したA/B草案。攻防だけでなく生態上の差を設ける。原資料の繁殖コスト/最大年齢/energyCost/speedを参考にしつつ、ターン長や値は今回のゲーム用に再設計した。以下は未実装・調整前で、原資料の数値の転記や性能実績ではない。

本書を寿命・基礎維持・出生待機/資格・進化M条件・移動距離の最新仕様とする。[相強化/固有特性](lineage-strength-and-evolution.md)と併用し、旧「全系統寿命240/維持E1/出生待機12/資格E60/進化M4・10/一歩固定」を置き換える。攻撃射程拡張は未採用のまま。

## 2. 進化した時の強化

- 共通攻防と固有発現率は別資料の四相表を維持する。
- 寿命上限＝floor(L×相係数)、係数I1/II1.10/III1.25/IV1.40。現在年齢はリセットしない。寿命死は既存順序で判定するため、そのターンの寿命死を後続の進化で取り消さない。
- 基礎維持＝表のE×相係数、係数I1/II0.98/III0.95/IV0.90×該当する固有維持係数。孤立/密度の追加負荷は別に加え、割引しない。停止/防御に条件付く固有割引は判断前に前借りせず、割引なしの支払可能額で候補を作り、実際に停止/防御を選んだ場合だけ維持費確定時に適用する。進化で代謝が改善し、強くなっただけで餓死しやすくしない。
- 出生後待機はIII=C、IV=max(4,ceil(C×0.85))。親ごとに別の値を付ける。進化時は残り待機を新しい上限以内へ短縮するが0へリセットしない。III到達時の初回待機4は維持。
- 移動は解放相以降に最大2歩を選択でき、1歩/停止も残す。解放なしの系統も移動効率/攻防/代謝等が進化する。遠くへ必ず移動する命令にはしない。

これらは同一系統内で進化による能力を下げないための設計。異系統や異環境の相性まで上位相の勝利を保証しない。現HP/Eを増やす即時回復はしない。

## 3. 必要栄養素は既存資源へ接続

新しい栄養ゲージは増やさず、必要な役割を既存E/G/Mで区別する。

| 役割 | 必要性 |
|---|---|
| 維持エネルギーE | 有機餌が主供給。必要量は系統の基礎維持と密度/行動費で変わる |
| 身体成長G | 有機餌の吸収と数字による補助。共通閾値30/90/210を維持し、食性/固有G効率で到達速度が異なる |
| 身体材料M | 鉱物系が主供給。相III/IVへの閾値は表を使い、硬い身体の系統ほど要求が重い |
| 繁殖材料 | 資格HP70/M4と表のE、各親の支払M2/E20（固有軽減あり）。親自身の維持とは別 |
| 数字・情報 | 数字は成長補助、情報は行動傾向。全系統で摂取可能だが毎ターンの必須栄養にはしない |

植物食/動物食/菌・有機/鉱物の吸収差と固有特性を継続する。特定の餌一種だけを食べないと必ず死ぬ仕組みにはしない。将来タンパク質等を独立ゲージにする場合は、状態数と餌表を別途設計する。今回それらまで作成済みとはしない。

## 4. 繁殖力の定義

繁殖力は出生待機・親資格E・固有E費用・生涯の繁殖機会で表す。毎ターンの繁殖確率を別に足さず、条件がそろえば既存の局所調停へ進む。一親一ターン一出生、出生先B3、同系統の雄雌、双方III以上、被害なし、出生先の空きと通行可能条件は維持。多産でもB3や栄養を無視しない。

両親の相が異なる時は各親の資格/待機/費用を個別に使う。子は初期I/E40/HP100/年齢0、基準L等は同系統の表へ戻り、親の年齢や残り待機は継承しない。雌雄自体の優劣は作らない。

## 5. 二歩移動と局所範囲

二歩は8方向のいずれかへ直進する連続2セル。一ターン中の折れ曲がり、跳躍、すり抜けはしない。通過セル/到達セルとも行動意図前の主役配置で空、地形/境界を通行可能であることが必要。各歩の斜め角抜けも不可。移動Eは各歩の進入先の費用を合計し、全額支払える候補だけ作る。全額不足なら1歩等の別候補を評価する。

二歩能力を持つ相では感知半径も2へ広がり、最大24セルを参照する。他個体は従来半径1。追加の視界は固定地形による遮蔽を適用し、射線はセル中心を結ぶ線が触れる大岩/崖境界で遮断する。角接触も遮断する。同じ遮蔽規則で一歩視界も判定する。未感知の餌/敵へ有利な評価は与えない。感知2でも攻撃は隣接1のまま。B3/S23、接触学習、仲間連携の近傍も半径1を維持。

候補は停止/1歩8/2歩直進8＝最大17移動候補＋隣接攻撃8＋防御1＝最大26。二歩の途中の餌を採食せず、終点で最多2単位採食する。二歩だから攻撃回数/採食回数を増やさない。判断時の各候補特徴は上限半径2の同じ可視状態だけを使う。

移動調停は固定2段階の予約で扱う。1歩候補は第1段階の先へ進み第2段階は同位置、2歩候補は第1段階に通過点、第2段階に終点を予約する。各候補へ初期値/個体ID/ターンから優先値一つを付け、両段階の全競合に勝つ候補だけ移動成立。落選候補の繰り上げはせず、次ターンに再判断する。同時すれ違い/交換は事前の空き条件で禁止する。落選は元位置、移動E支払なし。途中までの移動は成立させない。

戦闘と採食は移動全体の確定後のみ。通過点での迎撃/採食/繁殖は追加しない。生還判定は実際の最終位置が元攻撃者の射程外かを見る既存方式で、歩数だけを成果にしない。固定2段階と26候補で多数個体でも全経路探索を避ける。
