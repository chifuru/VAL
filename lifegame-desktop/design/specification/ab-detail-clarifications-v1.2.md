## 2. 戦闘と防御

- 一個体の基本動作は移動/攻撃/隣接刈取り/防御/育児/停止の一つ。全体処理が「移動→戦闘」でも、一個体が移動攻撃する規則ではない。所在採食と出生は別段階で条件を判定する。
- 攻撃対象は別系統の主生物/動く餌。植物/菌は刈取り、同系統は仲間で攻撃不可。同セル小型への距離0は近接として費用E3、遠隔の待機を迂回しない。射程外/射線不成立では攻撃費/実績を発生させない。
- A/DのDNA式は主生物に適用し、小型のA0/D1、植物/菌のA0/D0をDNA式で上書きしない。遠隔の途中を遮る「個体」は主と動く小型、植物/菌は被覆による防御/光とは別。
- 損害は有効な一攻撃ごと`max(1,floor(A−0.5D+0.5))`。Dの環境×遮蔽×防御姿勢の積だけ上限1.6、相/固有/枝は外側。一括損害後にHP0を死亡とし、自動反撃や命中抽選/回避率/範囲攻撃は初回では設けない。防御は軽減であり無敵ではない。
- 比較例はbody/appendage/skin全て0.5、I相、固有/枝/環境なしならA9/D6。近接の予定損害6、相手が防御姿勢ならD7.5で5、射程2ならA7.65で5。攻防倍率が変われば結果も変わる。ここでの値は設計計算例でゲーム実測ではない。

## 3. 移動と環境

- 地形部分の計算順を`min(1.8,基礎地形×倒木/茂み倍率)`→地形適応枝`1+0.75×(地形部分−1)`→進入環境→固有→移動効率枝、とする。地形適応枝と移動効率枝は別の第四相経路なので、同一個体へ両方を付けない。
- 平地/浅瀬1、岩1.3、深水1.4、泥1.5、倒木/茂み1.2。大岩はセル、崖は辺を通行不可にする。斜めは両脇セルと四つの直交辺を確認する。主/餌は別枠なので重なって通行でき、同じ枠の交換や通り抜けはできない。
- 二歩は八方向の直進のみ。(2,1)のような曲がった到達は一動作では不可。二セルとも前状態で可視/通行可/同枠空きで、全費用を支払える場合だけ候補にする。途中で食べない。
- 二歩候補の一セルでも予約負けなら全体を取り消し、費用0/元位置。移動落選を、意図した停止/防御の固有維持割引には使わない。固有の移動費軽減と維持費軽減を混同しない。

## 4. 餌全種の分類と発生源

| 対象 | 食性の分類 | 実体/発生源 | 現行仕様での独自差 |
|---|---|---|---|
| 微藻 | 植物 | 光生産/水域・湿潤の浅瀬 | 生息域、成熟/寿命、深淵触手の吸収固有補正対象 |
| 岩苔 | 植物 | 光生産/静・寒冷・湿潤の岩/浅瀬 | 長命/遅い出生、回復適性1.2 |
| 草本 | 植物 | 光生産/深水以外 | 広い生息域、成熟脱落から種実 |
| 菌膜 | 菌・有機 | 有機分解/湿潤・静・情報・熱・腐食 | 光生産なし、吸収0.7、Mの未吸収還元、回復適性1.2 |
| 水游虫 | 動物 | 植物を食べる餌生物/浅瀬 | 偶数ターン移動、HP8、寿命40/出生待機4、成熟脱落から栄養卵 |
| 草棲虫 | 動物 | 植物を食べる餌生物/深水以外 | 毎ターン移動、HP6、寿命32/出生待機3 |
| 種実 | 植物 | 成熟草本からの非孵化性脱落 | 発生元が草本。通常の可食物で、子植物にはならない |
| 失活胞子 | 菌・有機 | 成熟菌膜からの非孵化性脱落 | 回復適性1.2、菌の分布に依存 |
| 栄養卵 | 動物 | 成熟水游虫の未受精脱落 | 動物食性係数の対象、孵化しない |
| 有機粒 | 植物 | 成熟微藻/岩苔からの脱落 | 前版「その他の許可された生産者」の対象をこの二種に限定明記 |
| 鉱物片/鉱液滴 | 鉱物 | R_Mを支払う局所CA | 一単位M2/M1、周期4/3、E/Gなし |
| 代謝因子 | 通常食性係数1の専用資源 | 草本/菌膜の脱落候補10%を置換 | 低/中/高活性で次の有機取得G+1/2/3、直接Eは微量 |
| 情報 | 有機食性倍率の対象外 | 実成果の有償分泌と局所CA | 行動学習、文脈/鮮度/撹乱、Eは微量、Gなし |
| 死骸 | 元の生体の分類 | 主/餌の死亡予算 | BE/BM/BG、期限、感染ペイロード。主生物由来は動物分類 |

「種実/有機粒などに、種類ごとの新しい固定栄養値がすでにある」とは説明しない。通常脱落は同じB2/M0.1/q1予算を共有し、由来食性/発生場所/回復適性が違う。将来の独自追加効果や毒性を今回の既定仕様へ混ぜない。因子や情報は独立資源であり、有機粒の別名ではない。

通常脱落を出せる対象は草本/菌膜/水游虫/微藻/岩苔の成熟個体。8ターンの個体別位相、当該ターン出生不成立、B2/M0.1の支払、近傍資源枠の条件を満たす時だけ。草本/菌の10%因子置換だけB0.2→E予算0.1、他の通常有機予算を同時に複製しない。草棲虫/主生物から通常脱落を作らない。前版の有機粒の未列挙と食性分類を補ったもので、新しい餌の追加ではない。

## 5. 栄養値を読むときの条件

汎食主/aptitude=skin=0.5/固有・枝なしの例で、草B2→吸収e1/通常G1。鉱物片の供給M2→吸収M1、鉱液M1→0.5。生体Mは刈取り割合で有限移転しηMを適用。苔/菌の回復適性はHP/Eの倍率であり、直接HPを無償加算しない。

主の食性型は植物/菌有機/動物/鉱物の係数を変える。小型の植物吸収0.65、菌の有機吸収0.7は主の基準0.5式を重ねず直接使う。因子の直接Eだけは主のaptitude/固有を使うが、植物/動物/鉱物の食性係数は1。因子の固定G補助は倍率なし、次の有機取得一回/3ターン、強い活性だけ保持。情報の最大E0.05/単位には有機食性倍率を掛けない。

動く餌は倒してから有限死骸を食べる。たとえば精算後E8/B2/M0、I相・既定body0.5の餌が死ぬとBE5/BG1/q2。汎食主の一口はE1.25/G0.25（回復振分け前）。毎回同じ価値とは限らず、死ぬまでに消耗したE/B/M、相、残qで変わる。攻撃成功と、実際の採食成功は別のイベント。

## 6. 説明資料の成立条件

各詳細図は「入力/条件→処理→結果」「同条件の比較」「不成立の例」「参照する規範節」を持つ。食物の比較では、外形/環境だけの差、代謝/栄養の差、由来/発生則の差を区別する。旧55図は概観として残し、詳細56〜69を読み順へ挿入した修正版PDFを現行とする。

項目別照合は今回対象の戦闘/移動/餌と、その前後の費用/成長/失敗に対して行う。全仕様のあらゆる細則を完全に図示した保証には使わない。実装や生態の成立は未検証のまま。Nodeの新分割・承認状態変更なし。
