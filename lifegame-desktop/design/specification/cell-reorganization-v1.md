# マス・占有層・資源循環の再編

仕様版 `cell-reorganization/1`。利用者との議論で採用したA/Bの現在正本。構造の合意と、未検証の比較開始値を区別する。今回の反映は文書のみであり、新モデルは未実装・未実測。製品4.2.77、ゲームコード、テスト、画像、配布物には未接続である。全61 Nodeの正式状態は草案のまま維持する。

## 1. 読み方・適用範囲

本書は、マスの意味、0〜5次の占有、有限資源の配分、植物・低次動物・分解者の生活、主生物の移動と定住、量機の相変異占有例外、ターン内の利用可能時点を対象とする。既存仕様と競合したときは、本書が明示した対象だけを置換する。旧記録の再生は旧版の条件を使う。

「採用」は実装済み・動作検証済み・生存目標達成・Node承認済みを意味しない。表の数値は比較を開始するために採用した値であり、観察後に調整できる。収容枠は今回の構造上固定値であり、身体の大小や環境によって毎ターン増減させない。

未変更の系統数・造形・進化枝・食性・年齢と相の独立性・情報の非栄養性・P/Q生活環は、[現在の仕様索引](README.md)の対象別正本を維持する。移動する淡水光合成体の占有層、量機の占有、今回の比較値など、明記した置換だけを適用する。

## 2. 再編の目的とマスの意味

LifeGameでは、マスを生態系の基本処理・資源帰属・収支確定の単位とする。各マスで資源、生産、消費、競争、占有を管理し、状態変化の原因を追えるようにする。

長期観察では、豊富な食料、密集、場所愛着、無性繁殖、情報による集合、雑食などが相互に補完し、同じ場所を占有し続けることが優位になりやすかった。今回の目的は特定の強い系統を恣意的に弱体化することではない。安定戦略にも、有限資源の消費や他生物との競争による負担を成立させることである。これらの観察は設計の動機であり、各要因の因果関係を新モデルで実証したものではない。

- 資源取得は、実際に占有・滞在しているマスの内部に限る。
- マス間の関係は、実際の移動、繁殖・新規定着、身体・感染体等の合法な移送によって接続する。
- 占有していない隣接マスからの直接採食・養分吸収は導入しない。これは性能だけでなく、資源帰属と制御可能性の制約である。
- 隣接・遠距離への攻撃や情報の到達範囲と、物理的な栄養取得範囲は別の条件である。今回の制約だけで既存の射程を消さない。
- 定住期限、密集への直接の維持費罰、密度だけを理由にした出生抑制、強制追放、集団戦闘ボーナスを追加しない。既存の同種の直接補正は再編時の置換対象とする。
- 雑食の消化効率、移動と回避の能力値関係、気候による移動の必要性などは後続の能力・戦略調整に残す。

### 2.1 物理的上限と生態的な維持可能量

枠数は、最大規模の生物・群落をすべて格納できる物理的な上限とする。小さい群落も最大の群落も1枠を使い、縮小しても半枠を空けない。実際の出発・死亡・完全消失で枠が空く。

生態的に維持できる個体数や体量は、有限資源と競争によって変わる。これを可変の物理枠へ読み替えない。最大規模が上限を超えるなら、まず群落の定義や枠数を見直すか、実際に複数マスを占有する生物として別途設計する。

### 2.2 空間占有層

0〜5次は同マス内の空間占有層であり、捕食順位ではない。

| 層 | 対象 | 固定の上限・単位 |
| --- | --- | --- |
| 0次 | 水分、土壌・鉱物等の基礎養分 | 生物枠ではなく有限在庫と保持上限 |
| 1次 | 低次植物 | 6群落 |
| 2次 | 高次・独立した定着植物 | 3個体 |
| 3次 | 低次動物 | 移動中を含め5小集団、各群最大8個体 |
| 4次 | 全食性共通の主生物 | 定住3枠、移動を含め最大5枠。量機の例外は第7節 |
| 5次 | 分解者 | 6群落 |
| P/Q | 宿主への付随関係等 | 別管理。今回、新しい収容数を定めない |

各層は同マスで共存できる。草食・肉食・腐肉食等で4次の枠を分割しない。情報の「同じ層」は、従来どおり栄養・生態的役割＋分解者/P/Qであり、この空間層番号へ置換しない。

動く生物の枠数を奇数にしたのは、配置の非対称性が動きを生み得るという設計上の期待である。奇数そのものに能力補正は付けず、群落数や内部個体数まで奇数にそろえない。

## 3. 0次：固定環境と変動する資源

### 3.1 固定条件

| 条件 | 今回の意味 |
| --- | --- |
| 雨 | マスへの一定の水分入力率 |
| 光 | 一定の受光予算。未利用分はそのターンに失われる |
| 気温 | 光合成、維持、蒸発、分解等に作用する固定条件 |
| 土壌の質 | 保水性・通気性・根や菌糸の活動しやすさ等を包括する一つの軸 |
| pH | 吸収・活動の適性に関わる固定の酸性・アルカリ性。消費資源ではない |

光量の説明には「光合成に使用。二酸化炭素は十分に供給される前提で、今回は個別計算しない」と明記する。CO2を光の数値へ加算したり、CO2在庫を実装済みとしたりしない。

### 3.2 土壌の質と在庫の区別

土壌の質は全植物・分解者に共通して、良いほど有利となる。保水性・通気性等を別々に入力・更新する方式にはしない。土壌の質から、水分・無機養分の保持上限、植物の養分取得能力、分解者の処理能力を導出する。

比較用の共通補正は、悪い0.75・標準1・良い1.25倍。各保持量・能力への詳細な写像は、この共通軸の意味を維持して実装時に表にする。基礎条件を既に反映した値へ、同じ土壌理由の補正を重ねない。

水分、土壌の利用可能な無機養分、有機物は実在する別の在庫であり、消費・入力・分解で増減する。土壌の質が良くても、空の在庫から栄養は得られない。分解者の活動エネルギーは有機物に由来し、無機養分だけでは維持できない。

### 3.3 標準環境の比較開始値

| 項目 | 値 |
| --- | --- |
| 雨・光の基準倍率 | 各1 |
| 気温 | 20℃ |
| 土壌の質 | 標準1 |
| pH | 陸6.5、淡水7 |
| 利用可能な無機養分 | 標準：初期5・保持上限20。乏しい：2・8。豊か：10・40 |
| 陸上水分 | 入力6.5/T、20℃での基準蒸発0.5/T、保持上限30、初期15 |
| 標準光予算 | 光合成エネルギー換算15.6/T、同マス全体で共有 |

土壌の質と養分の豊富さは別の設定である。保持上限の表は基準土壌での値として扱い、土壌補正後の実効値も保存する。水中の水分・底質プロファイルの専用数値は未選定であり、陸の値を無断コピーしない。

水分1は、標準の最大低次植物群落の最大活動1T相当の比較単位とする。光合成エネルギー2.6に対して水分1を基準とする。これは測定された自然単位ではない。光合成・蒸散に使った水を、組織形成時に同じ理由で二重請求しない。

標準植物の温度適性は15〜25℃で1、5℃/35℃で0.5、−5℃以下/45℃以上で0。pH適性は5.5〜7.5で1、4.5/8.5で0.5、3.5以下/9.5以上で0を比較開始値とし、その間は連続的につなぐ。活動係数0を即死判定にはしない。分解者・各系統へ植物の適性曲線を一律コピーしない。

### 3.4 水分・養分の収支

水分は「前在庫＋入力−排水−実蒸発−実利用量」で更新する。上限超過の排水と実利用を区別し、存在しない水を蒸発・消費させない。マス間の流体計算は今回追加しない。

養分は、0次在庫→生物の蓄え・組織→捕食者または有機物→分解→0次へ循環する。組織形成の基準は身体量1につきエネルギー1.2・養分0.02。身体へ保持される分と形成時の散逸を区別し、形成費を全量散逸させた上で同じ身体エネルギーを無料加算しない。維持の養分費は組織更新・排出等の物質移転として扱い、消滅させない。死骸を即座に全量無機養分へ戻さず、pH等で取得できなかった分は元在庫に残す。

0次保持上限に戻せない分は未無機化の有機物側に保持する。上限で切り捨てない。初期の身体・蓄え・在庫、合法な外部入力、移転、熱散逸を分けて台帳化する。

土壌在庫5は、低次植物6群落が各0.05/Tを連続取得すると約17T分に相当する。ただし再循環なし・最大要求の単純比較であり、実際の寿命や絶滅時刻ではない。

### 3.5 世界設定と事前計算

世界の初期条件として、土壌養分の初期量・保持量・外部供給条件等を調整してよい。世界設計上の調整値を実効設定に含め、同条件で再観察できるようにする。生存状況を見て隠れて補充する処理にはしない。供給なしと明示供給ありの台帳を分ける。

固定マップ、固定環境、系統・相の基礎適性は事前計算する。毎Tは在庫・体量・可食部・蓄え等の変動だけを反映する。処理量を理由に今回の生態的な群落数を削らず、必要なら世界の基礎条件と実装方法を調整する。

## 4. 共通の資源配分と栄養予算

### 4.1 必要量・取得能力・届きやすさ

各マス・各資源について、実際の必要量を上限に、取得能力と資源への届きやすさで重み付けした要求を集める。十分なら要求量を満たし、不足時は重み付き配分とする。上限に達した主体を除き、余りを残りへ再配分する。例えば同じ取得能力・届きやすさで要求2/1/1、在庫2なら1/0.5/0.5が基準になる。

層番号だけで優先しない。同種・異種とも、利用する資源が重なれば競争する。水分・0次養分は植物と分解者等、植物可食部は低次動物と植物食の主生物等、死骸は腐肉食動物と分解者、菌可食部は菌食生物の共有在庫である。

届きやすさは、光の高さ・葉位置・遮光、土壌に対する根・菌糸の接続、食物の可食部分への接近等を表す。土壌・食料では近い側が多少有利になるが、近さだけで常に独占させない。マス内の到達性であり、隣接マスの遠隔取得許可ではない。

低次植物の先住優位＋10%と各群落の小幅な変動±10%を比較開始値とする。根等の接続という同じ理由を、先住補正と近接補正で二重加算しない。この値を高次植物や動物へ自動追加しない。

水と養分等を組み合わせて使う場合、実際に成立する利用量で収支を確定する。使えない余分を消費済みにせず、容量内で貯蔵するか元在庫へ残して再配分する。食物の取得量と同化効率は別で、同化効率の違いによって元の食物を複製しない。

### 4.2 光の配分

光はマス全体の一つの予算を、葉の高さ・広がり・残存組織等による受光・遮光に従って配分する。上で捕捉された残りが下へ届き、同程度の位置では受光組織等に応じて分ける。1次・2次へ別々に予算15.6を与えない。

受光による遮光と、受けた光を実際に光合成へ使える量を区別する。水不足でも葉が残っていれば遮光は起こり得る。未利用の光はそのTに失われるが、合成済みエネルギーは容量内で蓄積できる。葉面積は受光の属性であり、占有枠の可変化には使わない。

標準低次植物6群落の各2.6/T、高次植物IV3個体の各5.2/Tは、ともに共有予算15.6/Tに対応する規模比較である。両者を同時に最大稼働できる保証ではない。相・系統による高さ・受光・利用上限の差を表す基礎構造を置き、詳細な専用係数・戦略は後続とする。

### 4.3 栄養の利用優先順位

1. 実際に成立した移動・攻撃等の費用を確定する。既払分は再徴収しない。
2. 現在の身体・個体数の維持費を支払う。
3. 維持費3T分を基本の留保目標として確保する。
4. 残りから修復・成長・再生・繁殖を選ぶ。
5. 余剰を貯蔵上限まで残す。

留保は支出ではない。貯蔵満量を繁殖の一律条件にせず、留保不足だけで衰退させない。実維持費が不足したときに衰退へ進む。同じ栄養を成長と出生へ二重予約せず、E/Mがそろった処理だけ成立させ、不成立予約は解放する。各系統の既存の支払義務も台帳へ接続し、新しい無償費用免除は作らない。

基本判断は、重い損傷では修復、植物の可食部不足では再生、資源余裕では成長、成熟・待機・空き等が成立すれば繁殖、不利なら追加投資を見送り貯蔵、という局所的な有利不利に基づく。全用途を毎T必須にせず、詳細戦略は後段で重み付けする。

### 4.4 抽選の意味

同条件の空き枠競合等には、同じ初期条件で再現可能な抽選を使う。これは未表現の細かな位置関係、進入順、場所を発見・確保する機会等を包括する。新しい幸運能力や精密なサブセル座標の実装を必須にしない。

移動費を多く払った個体を優先しない。高費用は地形の不適性や非効率でも生じるため、既払費用を占有権へ変換しない。将来の天候等による揺らぎは拡張候補であり、現段階の残差変動と同一視しない。

## 5. 1次：低次植物群落

### 5.1 単位・生産・維持

同マスに最大6群落。同種・異種とも共存可能で、実資源を競争する。内部の株を一体ずつ行動計算せず、基部・可食部・蓄え・活動・定着を持つ。群落の成立後Tを内部全株の年齢にせず、一斉寿命死させない。

| 項目 | 比較開始値 |
| --- | --- |
| 基部／可食部の上限 | 2／20 |
| 生産＋被食後再生の合計上限 | 2B/T。各々2ではない |
| 最大時の維持費 | E0.2/T・養分0.01/T |
| 可食部なしの基部維持費 | E0.05/T・養分0.0025/T |
| 貯蔵上限 | E4・養分0.2 |
| 組織形成費 | B1あたりE1.2・養分0.02 |

既存の比較初期可食率70%、陸20%/水15%という適地の初期占有面積率は、初期配置の設定として別に保持する。枠上限6と面積率・初期群落数を混同せず、収容上限を増やしただけで初期数を6倍にしない。種別の明示数・0と初期条件の実効値を維持する。

実際の組織量に応じて維持負担を変える。満量で維持のみなら最大時約20T、基部のみ約80Tの蓄えに相当するが、再生・繁殖・環境・取得を含む実生存期間ではない。可食部は標準2B採食の10回分。被食は基部を残し、葉がない状態で最大光合成を続けない。初期再生には実際の蓄え・入力が必要である。

### 5.2 定着と先住優位

成立した群落は直ちに枠を占有し、通常の生産・維持を行える。定着カウンタは養分取得組織の形成を表し、枠確保の待機時間ではない。実取得が維持を満たしたTを累積3T数え、3回目の次Tから先住補正＋10%を適用する。不足Tは進めず、移動でリセットする。連続3Tは要求しない。古さに比例して優位を無制限に増やさない。

### 5.3 移動・繁殖・衰退

滞在・移動・繁殖は選択肢であり必須ではない。移動可能な種類だけが稀に移動機会を持つ。全群落移動は隣接の合法な空き枠へ同じID・身体・蓄えを移し、成功時に現在の維持費5T分のE（基部〜最大で0.25〜1）を支払う。元の土壌在庫は持ち出さない。

繁殖は親を残し、同マスか隣接の合法な空き枠へ最大1子群落/T。親は定着済みで、費用後に維持費3T分を残す。子は基部1・可食部1・E0.5・養分0.025、親の総費用はE2.9・養分0.065。移動と繁殖は同Tに両立させず、維持・生産は別に判定する。

維持不足は、E/Mの未払い割合の大きい方を使い、二重罰にしない。可食部が残る間は最大1B/T、なくなれば基部を最大0.1B/T、不足割合に応じて減らす。基部0で消失する。失われた物質は同マスの有機物へ。維持未払い中は成長・繁殖しない。資源回復時は実費で再生できる。

## 6. 2次：高次・独立した定着植物

### 6.1 位置づけ

森冠・星冠等は、1個体の意味が大きく長期に場を支える定着植物とする。親は逃げず、子の成立で版図を広げる。最大3個体は幼体〜最大相・老齢でも固定。同環境での競争は緩やかで、資源取得差・被食・寿命等が重なって遷移する。安定した優占も許容し、強制的に交代させない。

通常被食は葉等の可食部を減らし、幹・根・基部を残す。木質等の利用は別の形質候補であり、全動物へ無条件に与えない。逃げられないことを支える本体・蓄えと、成長・維持・繁殖の費用を持つ。

移動する淡水光合成体は動物側の4次占有へ変更するが、生産者という生態的役割、四相、造形・分岐・移動の採用内容を維持する。通常植物を捕食者に変えない。下表は定着高次植物の基準であり、淡水系統へ移動費等を無視して自動コピーしない。

| 貯蔵養分上限 | 0.375 | 0.450 | 0.525 | 0.600 |
| 出生間隔/T | 40 | 32 | 24 | 20 |

最大時の蓄えは維持のみ約30T分。可食部を失ったIVの基部維持はE0.1・養分0.005/Tを基準とし、中間状態は実組織に応じる。相進行は上限・基礎能力の変化であり、身体・葉・蓄えを無料で満量にしない。

### 6.3 繁殖・年齢・衰退

成熟40T、基準寿命600Tに出生時固定の±10%、個体寿命の80%から老齢を比較開始値とする。老齢は徐々に生産・再生を最大80%、維持を最大120%へ変える。老齢も条件を満たせば繁殖でき、相進行で若返らせない。成熟は年齢で決まり、III相を条件にしない。

子はI相・年齢0、本体2・可食部2・E1・養分0.05。親の総出生費はE5.8・養分0.13、費用後に維持費3T分を残し、同マスか隣接マスの空き枠へ成立させる。I相の貯蔵上限でも出生が成立する数値関係を維持する。有性・無性・受粉等は種類別の後続設計であり、全植物に一律の雌雄遭遇を要求しない。

維持不足の判定は低次植物と同じ考え方で、可食部を最大1B/T、その後は本体を最大0.05B/T、不足割合に応じて減らす。本体0または個体寿命で死亡する。最大本体8に全不足が続く場合の本体衰退約160Tは規模比較であり、蓄え・葉・取得等を含む寿命予測ではない。残存物は有機物へ移す。

## 7. 4次：主生物の移動・定住と量機

### 7.1 通常の枠

定住は全食性共通で3枠。移動を含めて5枠とし、使っていない定住枠は移動個体も使える。定住3なら移動2、定住2なら移動3、定住0なら移動5。第三の占有状態は追加しない。

移動したTは移動。同マスで継続し、合法な定住先を確保できれば定住する。既存定住者を優先し、空きへの希望は公平で再現可能な抽選とする。移動費の多さを優先権にしない。

定住満員でも移動枠があれば進入・通過・採食・攻撃可能。定住できない個体は、戦闘するか次の移動を選ぶ。勝利という判定だけで枠を空けず、相手が実際に死亡・退避して空く必要がある。優劣だけで強制追放・瞬間移送しない。

移動不能なら、合法な敵への戦闘を優先する余地はあるが、友好個体への戦闘を強制しない。防御・待機して移動状態を維持し、再試行できる。同マス滞在だけで4体目の定住権を得ない。密集の防波堤は各個体の接触・攻撃機会から生じさせ、集団倍率は付けない。

### 7.2 戦闘と複数マス移動

戦闘はHP損傷を積み重ねる既存の有限行動であり、即時決着の勝敗比較ではない。同時損傷・相討ちを維持し、射程・費用・視線・待機などの資格を通す。移動・戦闘・採食は条件別に同T成立可能だが、移動距離だけ攻撃回数・採食回数を増やさない。異種というだけの自動戦闘・自動反撃は追加しない。

複数マス移動は1歩ずつ、地形、障害物、通行、移動予算、収容枠を確認する。実際に進めた分だけ費用を支払う。通過途中の接触も記録し、危険回避・通過・交戦の局所判断へ反映する。交戦を選んだ地点で移動を止め、後続の戦闘段階へ参加する。戦闘後に残り歩数を使い直さない。相手の最終位置・生存・射程を再確認し、不成立の攻撃費は請求しない。

採食・物理資源取得は移動終了地点だけで行い、出発地と途中と到着地で重ねて取得しない。途中の感染は既存の経路・接触資格・回数制限へ接続し、接触しただけの無条件感染にはしない。地形適性・渡河・障害物の既存条件は維持し、収容枠拡大だけで通行不能地形を通さない。

### 7.3 量機の相変異型だけの例外

量機の相変異型だけは、定住1枠に最大3体がまとまれる。通常型量機・他主生物は1体1枠。定住3枠すべてが相変異量機なら最大9体となる。

| 定住構成 | 使用定住枠 | 実定住個体数 | 追加で移動中として入れる数 |
| --- | --- | --- | --- |
| 通常主生物3体 | 3 | 3 | 2 |
| 相変異量機3体＋通常主生物2体 | 3 | 5 | 2 |
| 相変異量機9体 | 3 | 9 | 2 |
| 定住なし | 0 | 0 | 5 |

移動中は相変異量機も1体1枠。移動Tは移動状態を維持し、次T以降に合法なまとまりの空き等へ定住する。最大9定住＋2移動の一時的な状態は成立する。5枠を各3体として15体通過させる拡張にはしない。

まとまっても群体へ統合せず、全個体のID、栄養、維持費、繁殖、被害、寄生、追跡を別にする。集団移動や費用割引を追加せず、同じ食料を人数分複製しない。

継続低密度の解除条件を満たしても、通常型の占有へ収まらなければ解除待ちとする。空きや自発移動によって収まる個体から解除する。強制死・無償移動・個体削除は行わない。相・枝・年齢・本人実績は保持する。通常型I/II/III/IVの移動1/2/3/4、相変異中の全相3、摂食増・繁殖力据え置き、相変異IVの繁殖目的、採用造形は[量機](ryouki-v1.md)を維持する。子に親の相変異を自動複製しない。

## 8. 3次：低次動物の小集団

### 8.1 単位と食性

同マス最大5群、移動中も含む。群れ全体で行動し、内部は人数・年齢・相などのまとまりで更新する。最大8個体、1個体の標準最大身体量2、最大群の身体量16。1個体でも8個体でも1枠、0個体で群れ消失とする。

16個体案は採用せず8へ修正した。低次植物6群の可食量120に対し、低次動物5群×8体×身体2＝80という規模比較である。身体在庫の比較であって、厳密な可利用エネルギー・生産流量・生存保証ではない。主生物と総身体量を機械的に一致させない。

低次・高次植物の同マス可食部をどちらも食べられる。高次植物の幹・根等は通常採食の対象外。供給源をまたいでも採食上限は一つである。量・利用しやすさ・競争等で選び、高さや硬さの詳細な専用形質は後続とする。

### 8.2 比較開始値

| 項目/T | 1個体 | 最大8個体 |
| --- | --- | --- |
| 維持E | 0.05 | 0.4 |
| 維持養分 | 0.001 | 0.008 |
| 平坦な隣接1歩の移動E | 0.025 | 0.2 |
| 植物可食部の取得上限B | 0.25 | 2 |
| 貯蔵E上限 | 2 | 16 |

植物エネルギーの同化率0.65を比較開始値とする。植物可食部2Bにエネルギー2が含まれる場合、同化1.3Eから維持0.4と平坦1歩0.2を払うと0.7Eが残る、という条件付きの規模比較である。実食物のE/Mを無視してBから栄養を無料生成しない。

人数に応じて要求・費用・容量が変わる。必要のない満量採食は行わず、維持・移動・成長・出生・貯蔵余地を通す。貯蔵Eは維持のみ約40T分に相当するが実際の絶食生存保証ではない。

### 8.3 内部出生・成長・死亡

子はI相・年齢0、身体0.5（上限2）、E0.25・養分0.01。総出生費はE0.85・養分0.02。成熟8T、最短4Tに集団として1子、内部上限8を比較開始値とする。身体の成長は最大0.25B/Tで、B1につきE1.2・養分0.02を支払う。年齢成熟と進化相は別。現行の下層の無性別・一親方式は維持し、将来の有性系統へ自動一般化しない。

成熟個体と実予算があり、費用後に既存個体の維持3T分を残せる場合だけ出生する。満員・栄養不足なら見送る。内部出生では新しい空間枠を使わない。

捕食・戦闘・寿命等は実際に失われた個体分だけ人数・身体・蓄えを減らす。負傷や部分損失だけなら修復の余地を残す。損失分の栄養を生存群へ全量残さず、捕食者・死骸へ一度だけ移す。人数減で容量を超えた分を黙って削除しない。群成立後の同一寿命で全員を死なせず、内部世代の年齢で扱う。

### 8.4 群れの移動と分群

全群移動と、一部が分かれる分群を別にする。7〜8個体から分群を検討し、3個体を送り、元に4〜5個体が残る。隣接の合法な空き枠、食料・競争・危険・費用を評価し、見込みと当面の維持予算がなければ実行しない。到達人数だけで強制分群しない。

実在する人数・身体・蓄えを移し、栄養を生成しない。分群した内部世代の人数・年齢・相を保存し、親群と子群で重複させない。小さな群れが資源不足ならまず全群移動を使い、少人数の細分化規則は追加しない。

同種の別群もそのまま共存し、自動合体しない。先住群の枠を維持し、新しい移動・分群の同条件希望は同じ抽選で調停する。失敗は元に残り、不成立の移動費は払わない。枠を奪う専用戦闘は追加せず、有限の食料競争と捕食・移動・出生・衰退で推移する。

## 9. 5次：分解者群落と有機物

### 9.1 単位・資源・淘汰圧

最大6群落。同種・異種の群落が共存し、同じ有機物を利用する範囲で競争する。3群落という処理数重視の案は採用しない。有機物ごとの専用枠にも分けない。

分解者全体は広く存続し得る一方、局所では成立・成長・縮小・消失による入れ替わりを速める。主な淘汰圧は、有機物不足・分解者同士/腐肉食動物との競争、植物との水分・0次養分競争、菌食による被食である。有機物から養分も得るため、植物との競争が常に強くなるとは限らない。植物は落葉・枯死による供給者でもある。

標準分解者は生きた植物・動物を捕食せず、同マスの死骸・落葉・排出物等を利用する。寄生・病原性は別の特殊形質候補とする。個別表現しない微生物の働きは背景分解へ包括する。

### 9.2 環境

適度に暖かく湿った条件で高活動。低温・乾燥・極端な高温では活動低下。pHは種類の適性に作用する。空気の湿度を新しく計算するより、死骸・土壌等が置かれるマスの実水分を利用する。活動範囲外だけで即死させない。

水浸しの酸素不足、好気・嫌気の分解経路差は知見として残すが、個別酸素在庫・菌種別経路は今回追加しない。保水性・通気性の包括的作用は今回の共通土壌軸に含める。植物の温度・pH曲線を全分解者へ一律に当てない。

### 9.3 身体・処理・成長・繁殖

| 項目 | 比較開始値 |
| --- | --- |
| 最大身体 | 基部1＋可食部3＝4 |
| 貯蔵上限 | E2・養分0.1 |
| 最大時の維持費/T | E0.1・養分0.005 |
| 標準好適条件の処理上限/T | 有機物の身体量換算1 |
| 有機物エネルギー利用率 | 50% |
| 成長・再生上限/T | 0.25B、形成費はB1につきE1.2・養分0.02 |
| 繁殖資格 | 身体量2以上、最短10T、費用後に維持3T分を残す |
| 子群落 | 身体1、E0.25・養分0.01 |
| 総出生費 | E1.45・養分0.03 |

小さい群落は身体量に応じて処理能力・維持費も小さくする。身体1の子は基部を持ち、可食部0だけで活動不能・死亡とはしない。基部の組織で実有機物を利用し、実費で可食部を形成できる。最大時の蓄えは維持のみ約20T分。処理1Bと得られるE/M量は別で、元有機物の実在量を利用する。

同化Eは維持・成長・貯蔵に使い、利用できないEは熱として散逸する。養分は身体・蓄えへ入る分と、無機化して0次へ戻す分に分ける。取り込んだ養分を同時に土壌へも戻さない。維持に伴う組織更新は有機物へ戻す。6群最大処理6/Tは標準時の比較で、実在量・環境・需要が上限となる。

親は残り、同マスか隣接の合法な空きへ子を作る。有機物が少量でも候補にし、初期蓄えと当面の見込みで成立可能とする。大量の死骸だけを必須条件にしない。供給が続けば育ち、途絶えれば縮小する。世界全体への無償播種・死亡後の無親再配置は追加しない。

### 9.4 被食・衰退・再生

通常の菌食は可食部を減らし、基部を残す。処理能力・成長・繁殖余力は残存組織に応じて低下し、実資源があれば再生できる。菌食だけで常に食べ尽くせる案は採用しない。

維持費を取得栄養と蓄えで払い、不足割合の大きいE/M側を衰退率にする。可食部から基部の順に、最大0.4B/T×不足割合を減らす。基部0で消失。固定寿命・定期淘汰を追加しない。

0.1B/Tの旧衰退案は0.4へ変更した。全不足なら最大身体4からの身体衰退は約10T、蓄えの維持期間は別である。有機物供給が安定すれば長く残ってよく、広がる群落が必ず一定Tで死ぬわけではない。失われた組織・栄養は有機物として次T以降に利用可能とする。

### 9.5 背景分解と腐敗負荷

生物による採食・分解後の残存有機物に、標準0.1%/Tの背景分解を適用する。個別に表現しない分解作用の包括モデルであり、同じ在庫を重複処理しない。土壌の質・気温・実水分・pHに作用を接続し、Eは散逸、養分は0次へ戻す。戻せない分は有機物側へ残す。養分は次Tから利用できる。

長く残った時間そのものではなく、量・分解状態・環境条件が局所的な腐敗負荷を生む。通常の蓄積ではほぼ影響させず、かなり集中した場合だけ軽い不利を与える。比較上限は植物の成長・再生能力−5%、動物の維持E＋5%。分解者には基本的に直接の負補正なし。これだけで直接死亡・移動強制を起こさず、有機物が減れば回復する。基礎土壌の質を恒久的に悪化させる処理と混同しない。

腐敗・有機物の性質変化と、植物が使う無機養分まで戻ることは別。乾いた骨などは長く残っても負荷が小さい場合がある。病原体を含む死骸の感染源化は候補として残すが、死骸だけから疾病を自動発生させない。

## 10. 同期ターンの接合と利用可能時点

### 10.1 接合順

1. 固定環境に基づく入力、既存情報・既存在庫の更新を行い、開始時の資格・予算を参照する。
2. 各歩の移動と収容競合を調停し、終了地点・移動費・途中接触・交戦意思を確定する。
3. 最終位置等を再確認して戦闘を確定する。致死確定者は以後通常行動をしない。
4. 生存者について、最終所在マスの光・水・養分・採食・分解等の要求を調停する。出発地点の光等と到着地点で二重取得しない。
5. 実維持・支出、不足、衰退・死亡を確定し、成長・再生・出生用予算を二重使用しない。
6. 成長・再生、合法な空きへの繁殖・分群、背景分解と還元、情報生成、年齢・相等の終端状態を確定する。

これは生態上の順序と利用境界であり、既存の三段階表示を増やすUI指示ではない。新生・死骸・還元の「次T用」は当T利用在庫に混ぜず、末尾の状態・観測・保存に含める。P/Qの移行・羽化等は既存の有限生活環の境界順に接続し、今回の汎用順だけで順序を反転させない。

### 10.2 利用可能になる時点

| 対象 | 利用・作用の開始 |
| --- | --- |
| T開始時の食料・死骸・養分と合法な当T環境入力 | Tの該当段階で利用可能 |
| Tに実取得・同化した栄養 | Tの維持・修復・成長・出生へ使用可能 |
| 成長・再生した身体・葉 | T末に確定、採食対象・能力としてはT+1から |
| 新生個体・新群落 | T末の個体数・占有に含め、行動・取得はT+1から |
| 分解等で還元した養分 | T+1から |
| 新しい死骸・落葉・排出物 | T+1から |
| 新生成情報 | T+1から |
| 進化・成熟で得る能力・資格 | T+1から |

捕食で直接取得する部分は、その場で実移転する。食べ残し・死亡後残存分を次T用の有機物にする。攻撃で死亡しただけの相手から、存在地点や採食資格を無視して栄養を取得しない。同じ部分を捕食者と死骸へ二重加算しない。

出生は主生物の定住枠、植物・分解者の該当層の枠を必要とする。内部出生は群れの8個体上限で調停する。量機の子も出生時の実状態で収容し、親の相変異圧縮枠を自動継承しない。

分群で移った内部個体は同Tに再移動・再分群・出生しない。分群をターン内で繰り返して距離・出生回数を増やさない。死亡で空いた枠は後続の合法な出生等へ使えるが、その死骸・還元資源の利用時点は別である。

死骸分解→還元養分→植物再生→その葉の採食という循環は複数Tに分かれる。既存葉の採食→当T維持への支払は可能。新生の即時増殖、再生葉の即時再採食、新情報の即時再生成を防ぐ。

## 13. 後続課題・候補・今回の範囲外

### 13.1 植物の資源投資・適応戦略（マス再編後）

植物の資源獲得能力と要求量、得た栄養の投資傾向を分ける。後続候補は、吸収組織、受光・高生産、大型化、貯蔵・省資源、防御・耐食、修復・再生、繁殖・散布への投資。形成・維持・繁殖費を伴わせ、最大吸収型だけが常勝にならない構造を検討する。基本の有利不利判断は今回、遺伝的配分・専用戦略係数は後続。採用済みの生産/繁殖拡散/耐食のIII3→IV6を勝手に増枝しない。

有性/無性、雌雄、自家/他家受粉は候補。受粉と種子散布を分け、繁殖体形成→散布・輸送→到達→発芽・定着の段階、費用、失敗条件を検討する。近距離、風、水、付着、摂食・排出等は全植物への一律導入ではない。雌雄を持つことと有性/無性は別軸とし、有性の組換え機会と遭遇・受粉費、無性の成立容易さと相関した弱点を考える。無償の適応ボーナスを与えない。

有毒植物、同マスの化学的競争、接続した植物への寄生、食虫、資源提供と受粉・散布の共生は候補として保存する。器官・物質・行動の費用と成立条件が必要。既存の植物共生体は食虫型の別主生物として維持し、通常植物の非捕食を無断で変更しない。未採用の特殊形質を実装対象としない。

### 13.2 気候・撹乱・巨大植物

雨量・光量・気温の時間変化、干ばつ、暴風、洪水、火災、病害、酸素・好気嫌気経路等は後続候補。今回の固定条件と軽い腐敗負荷を、これらの実装済み扱いにしない。撹乱は実際の生産・取得・維持・繁殖への作用から生存差を生じさせ、恣意的な排除処理にしない。

巨大植物は実際に占有するA/B/C各マス内で個別に競争し、取得結果を同じ植物へ集約する方式に限る。未占有マスからの遠隔取得を認めない。既存の森冠・星冠等を今回複数マス化しない。

### 13.3 実装時に具体化する事項

- 枠・資源・次T物質のフィールド、各層の索引、逐次予約の調停と端数処理。
- 資源への到達性、受光高さ・葉面、土壌補正、系統/相の専用係数。層の機械的優先や遠隔取得へ変えない。
- 群の分群対象となる内部世代の選び方と、感染保持者の移転。既存のP/Qを複製しない。
- 水中の専用プロファイル、腐敗負荷の発生・回復曲線。合意した方向と上限を維持する。
- P/Qの感染範囲・卵・宿主の密度再調整は、今回の多重占有への接続後。生活環を今回無断変更しない。
- 能力値の詳細バランス、回避と移動、雑食効率、戦略投資、長期存続・創発、性能・画面・Windowsは後続。

意味や上限を変える決定が必要になった場合だけ利用者へ確認する。通常のデータ構造・数値比較・実装方法まで未決のゲーム仕様として再確認し続けない。
