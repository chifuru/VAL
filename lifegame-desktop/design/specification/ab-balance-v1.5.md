# A/B 生態バランス調整 v1.5

適用順は統合仕様v1.3 → 着手前調整v1.4 → 本書。利用者の生態バランス調整指示に基づき、既存の草案A/B内で具体化する。core、30系統、四相3→6、子はI相、固定環境、局所9重み、H→P→Q、情報の延長された表現型は維持する。検証結果はE5/E6/E7の対象版・範囲を参照する。

## 診断と目的

v1.4の小盤面・初期値 `extended-observation` では、25ターンで植物378→56、50ターンでは生き残った植物の平均Mが0で繁殖不能。土壌にはMが残るが、所在鉱物がない植物は吸収できなかった。主生物も材料不足でII相に留まった。満腹の小型が葉を採り続ける処理も供給を減らしていた。

材料吸収だけの比較ではIII到達が生じたが、葉の全量を個体全体として消費すると植物の再生産が崩れた。葉と基部を分けた比較で植物更新が続き、生産速度の調整によりIV到達が生じた。成熟個体が増えても、離れた同系統の個体同士は出会えない。全域の相手探索や救済出生で解決しない。

## 1. 葉と生存する基部（A1.2/A1.6/A1.7、B4.4）

微藻・岩苔・草本の総身体Bのうち2を、通常の刈取りで食べない基部とする。可食B=`max(0,B−2)`。菌膜は従来どおりB全体が可食。1口は可食Bから最大2だけを取り、含Mは取得B/取得前総Bの比で移す。可食部0の対象は候補/採食源へ出さない。

基部は無料の別身体ではない。初期B12、植物の子B2、容量B24の内数。通常脱落・因子も基部を支払いに使わない。基部だけの子はI相で、葉を成長させるまでは刈取りで栄養を得られない。

寿命、未払維持・寄生費によるHP喪失は適用する。基部があることは不死や全滅回避ではない。最後の個体が死ねば、B3の親なしに補充しない。

## 2. 光と再生産の収支（A1.6、B4.3/B4.4）

植物の光入力を `4×固定光量×葉面係数` とする。葉面係数=`0.25+0.75×clamp((B−2)/10,0,1)`。小さい芽の基礎的な光利用を0.25、初期B12以上を1とする。減った葉は光入力を下げる。植物共生の主生物、菌の無光合成、固定光そのものは変えない。

植物のE→B投資は最大2/ターン、菌は従来の最大1。植物B<4ではE2を残して葉の再生を優先。その他は成熟/合法B3出生先ありならE8、なければE5を残す。投資分Eを同量引き、光の余剰・維持・散逸を同じ台帳へ計上する。

## 3. 有限土壌からの材料吸収（A1.2/A1.6、B4.3/B4.4）

植物は所在鉱物に加え、所在土壌Mを1口最大0.1だけ取得可能とする。専用ηM0.5を適用するため、1口最大0.05、二口で最大0.1Mが生体へ移る。未吸収分は同じ土へ戻す。土が空、または生体M容量2が満たされていれば要求しない。鉱物と土壌は他の取得と同じ二口上限で調停し、別の無料吸収枠を作らない。

植物は土壌からE/Gを得ない。菌・主・小型は土壌を直接吸収しない。死骸・消化残M・出生の余材を土へ戻す既存の循環、上限20と散逸を維持する。鉱物片/鉱液/情報のB3/S23は変更しない。

## 4. 小型と菌の必要量（A1.7、B4.4）

小型/菌はE満杯かつHP全快なら有機要求を出さない。小型が植物を刈る時、要求Bを `min(2,可食残B,(E不足+2×HP不足/回復適性)/η)` へ制限する。HP不足0なら、維持や出生で生じたE需要だけを取得する。予約時の実残量で更に制限し、Mの移転も実取得量で決める。

小型は植物タグの源だけ、菌の鉱物取得は所在だけ。既存v1.4の合法源を守る。主の成長用G/M需要と二口共有は維持する。

## 5. 自然配置と配偶の局所条件（A1.3/A1.4、B4/B4.1）

自然配置は、適応と近傍餌で順位づけた地点へ同系統4体の初期組（雄2・雌2）を近傍配置する。各組は通行可能な中心と隣接地点を使い、可能なら既存の組から2マス以内を避ける。残容量が少なければ合法な残枠へ決定的に配置する。初期組に全体AIや指令を持たせない。群体節足の階級初期配分も維持する。

分散配置は個体間距離を優先し、集落配置は系統全体を一地点付近へ集める別モードとして維持する。自然配置の小組と同一にしない。系統ごとの均等/重み付き、少数/手動、初期保証は既存の設定を使う。

有性出生は主枠の8近傍主数 **2または3** とする。B3からB2/3へ変更し、第三の無関係な主生物の到着を必須にしない。同系統の隣接した雌雄双方がIII以上、HP70/E資格/M4/待機0/無被害、出生先への通行、二段階予約、親の有限支払いは全て維持する。子は必ずI相。単為の1〜3は変更しない。

本人がIII以上の繁殖型・HP70以上・E35以上の時、可視の同系統・異性・III以上の繁殖型へ近づく、または隣接を保つ候補の仲間特徴へ0.8を加える（旧0.1）。働育型は配偶の主体/対象から除外する。出生後の待機中やM補給中も近傍関係を保てるが、出生資格とは区別する。仲間親和の重みで評価し、最終特徴は−1〜1。相手の内部E/M、可視外の位置は使わず、配偶という固定戦略モードを設けない。本人が空腹・負傷条件を下回ればこの加点はなく、待機/材料不足時にも出生そのものは許可しない。

## 6. 表示・再現性・検証（B5/B5.2）

可食量の段階表示は植物では `(B−2)/(容量B−2)` を使い、基部だけを豊富な餌として見せない。選択表示で総B・基部・可食B・土壌Mと新しい繁殖近傍条件を説明する。既存の一枚図v1.3は概念図として参照し、変更した数値は本書とゲーム内説明を正とする。ルール版v1.5と乱数の名前空間v1.4を分離し、固定地形を比較できる初期値系列を保持する。通常の自然配置は小組化により初期位置が変わる。

検証は、基部と脱落費、葉量による光、土壌と生体間のM保存/枯渇/容量/二口共有、満腹小型の無消費、部分刈取り、二親/密度/費用/子I/待機、自然配置の小組、観測独立・再現性を対象とする。複数の調整用/未使用初期値で植物更新・III/IV・出生・子の成熟と更なる出生を測る。全系統存続、全初期値存続、特殊生態の自然完走を未実測で成功扱いしない。
