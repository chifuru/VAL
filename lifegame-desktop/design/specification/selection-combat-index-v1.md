# 詳細能力・量機同居の配置索引共有 / 1

通常ID/セル参照と凍結詳細は既存selection-index/1とselection-snapshot/1を維持する。能力値のpは既存の一回計算を保ち、新しい能力値キャッシュは追加しない。P/Qの生活環locate、追跡ルール、生態/乱数/観測/保存/画像は変更しない。

攻撃/防御の表示用powerContext.currentと量機の同居参照に、既存の現在選択索引から遅延構築する主生物配置Mapを渡す。powerが参照するmain/mainByCellだけを保持し、栄養/資源/死骸を走査してMapを再生成しない。mainの同セル最終要素、量機有効時のmainByCell全要素と配列順を既存S.maps/S.mainAtに合わせる。表示対象の並べ替えで原配列を変更しない。

既存索引と同じ寿命で、世界/T/配列参照・長さ/明示refreshの更新時に失効する。一つの現在状態だけ参照を持ち、履歴や生体値を複製しない。主生物の能力・同居を表示しない操作では構築しない。固定詳細のHTML/肖像は手動更新・再選択まで維持し、追跡は現在位置の既存ID索引を使う。

基点9d33590との実UI比較でMap作成/資源走査の回数、詳細HTML/肖像/全観測値/fingerprint一致を限定確認する。通常主生物と量機同居、量機無効時のMap規則、更新/新世界/消失ID、追跡と手動更新を扱う。総合速度や長期生存の認定はしない。
