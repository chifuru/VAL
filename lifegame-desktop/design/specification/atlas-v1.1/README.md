## 設計例と完成範囲

- 環境は固定、餌と生物は変動。同セルの主/餌は独立個体です。
- 情報は延長された表現型。遺伝子水平伝播・情報による階級や出生相の変更はありません。
- 30系統の数値定義と既存20の全分岐を説明しています。生物の輪郭は説明用の代表形で、全系統の最終スプライト制作ではありません。
- 全Nodeは草案。ゲームの実装・生態バランス・生活環完走・処理性能は未検証です。
