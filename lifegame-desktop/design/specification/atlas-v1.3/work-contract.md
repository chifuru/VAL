# A/B v1.3 FLOW-04 実行契約

2026-10-16。対象はA/B文書の接続不足と統合説明画像。ゲーム実装の契約ではない。

| 項目 | 今回の契約 |
|---|---|
| 目的 | 基本システムから詳細/特殊生態までを具体化し、一枚の説明画像へ統合 |
| 開始条件 | 既存の完全起動状態を継続、Operationの先行制御下でproject-local core関連節を実読 |
| 入力 | 接続不足を詰める指示、一枚の画像/階層的構成、宿主に寄生するPの占有関係、A/B限定/main統合 |
| 前提フィードバック | 接続可。元入力やcoreを仕様変更対象にしない。未実行の生態を確認済みとしない |
| 承認ゲート | A/B草案・資料更新とmain統合は既にユーザー指示あり。承認状態遷移なし |
| 構造展開ゲート | 登録済み17 A/B責務を維持。新しい独立責務なし、新規Node分割/機械的なC/D/E展開なし |
| 読むもの | project-local Operation/Summary/Flow関連節、現行Manifest、既存17 A/B Node、v1/v1.1/v1.2、系統表、採否、図解索引/制作データ |
| 作るもの | 統合仕様v1.3、一枚の統合PNG、索引/layout/資料照合/本契約 |
| 更新するもの | 既存17 A/B Nodeの本文/資料参照、仕様入口/旧版注意、既存Manifestの現行構造要約 |
| 変更しないもの | core/添付原文/A2/旧B1〜B3/C/D/E/src/tests/ゲーム実装/CI/全Node状態・親子・derived_from |
| 実行すること | 規則確定→階層資料作成→算例/参照/範囲/画像照合→Manifest反映→出力前ゲート→mainコミット/push |
| Manifest初期登録 | 不要、登録済みNodeのみ |
| Manifest反映 | 実際の17 Nodeの責務・参照・未実装フラグ・次FLOWを現行要約へ反映 |
| 検証 | 文書と図の照合のみ。ゲームテストやE層検証証跡を作らない |
| 作業結果照合 | 新規/更新ファイル、変更範囲、41草案/17更新、親子・承認不変、画像18部/20ツリーを確認 |
| 完了条件 | 統合仕様/PNG/索引/照合記録/Manifestが存在し、mainにpush、作業ツリー清潔 |
| 停止条件 | 新たな分割や意図変更が必要、仕様対立が解消できない、依存不足、出力不一致 |
| 出力形式 | VALIS / READ / TASK / INPUT / NEXT。実読と実作業のみ報告 |
| 次FLOW候補 | A/Bレビュー・必要時の修正。コード実装は別途許可待ち |

規則判断はOperation §32.4/§34.3/§1.1.7、Summaryの保持範囲、Flowの実行契約節を参照。完全起動状態や実装済み状態を、この資料照合から新たに推定しない。
