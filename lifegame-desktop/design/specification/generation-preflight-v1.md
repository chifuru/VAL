# 世界作成の事前整合確認

実際の初期配置に使う系統だけを数え、系統ごと最低4体を必要とする。標準は既存20系統＋量機、早成甲殻は従来どおり手動選択対象とする。重み0の量機は人数算定から外す。生態ルールや選択系統数を増減しない。

入力中の不整合は近くに条件を表示し、作成ボタンを非活性にする。上位設定の変更で下位制約を更新する。無効群の種別指定は非活性にして値を保持するが生成へ送信しない。種別数指定と初期餌保証は同時に有効化できない。

作成に失敗しても既存世界と観測行を保持し、条件を直して再試行できる。成功時だけ観測画面へ移る。固定観察モードの固定地形・人数を維持する。地形容量の不足や未知の実行エラーまですべて事前保証するものではない。
