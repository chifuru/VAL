# 世界作成画面の上位→下位整理 / 1

設定導線を、観察条件（プリセット/自動か直接指定）→地形/大きさ→参加生物/系統/初期数/配置→栄養/優遇/詳細→作成の5区画へ整理する。シミュレーションゲームのプリセット・世界・参加者・詳細という設定順を参考に、現在の画風/配色と単一画面の縦スクロールを維持する。画面遷移や次へボタンは増やさない。

上位条件で選べない下位設定は非活性のまま確認でき、固定モード/主生物OFF/自動生成の傾向/配分の方式/供給OFF/無効な生物群/種別数と餌保証の制約を、関連欄より上の短い案内で示す。系統選択と重みは詳細を開いて見られる。自動構成時の下のチェックは保存済み手動選択であり、その世界の実配置を表すものではないと区別する。

作成ボタンを全設定の後へ置く。入力不整合は欄の近くにも表示し、作成を非活性にして修正欄へ移動できる。既存の最低人数・宿主数・固定項目・自動生成ロック・0/空欄・値保持・生成後不足の案内を維持する。地形容量の全条件を事前保証しない。生態規則・初期値・生成/保存形式は変えない。

未適用の設定変更やデフォルト復帰で、現在の世界/記録/表示選好を変更しない。取消すと元の世界と進行意図へ戻る。新たな機能拡張・生態の近似計算・配布は対象外。
