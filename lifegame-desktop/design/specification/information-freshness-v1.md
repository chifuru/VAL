# 持続する情報の鮮度と環境痕跡の残存

仕様版 `information-freshness/4`。利用者が採用した具体化C03を定義する。[持続する情報](persistent-information-v1.md)の学習/場所作用、[死亡情報](death-information-v1.md)の由来/抽選、[情報評価](information-evaluation-v1.md)の保持資格/実績評価は維持する。以下は500ターン観察に向けた調整開始値であり、ゲーム実測で確定した値ではない。

## 1. 三つの時間を分ける

| 対象 | 起点と扱い |
| --- | --- |
| 内容の鮮度 | 内容ごとの元経験時刻から数える。古さによって新たな学習/場所刺激への実効作用が弱まる |
| 環境痕跡の残存 | 死亡地点への生成時刻から数え、生成時に有限の上限期限を固定する。残っているだけで有効性を保証しない |
| 個体が既に学んだ傾向 | 本人の実経験・既存の回帰/忘却で修正する。外の痕跡の消失を理由に即座に消去しない |

例えば50ターン前の経験を死亡時に残しても、その内容は50ターン分古い。痕跡が新しく生成されたことを、経験の新しさへ置換しない。高実績による長期残存も鮮度の時計を遅くしない。

## 2. 内容別の半減期

| 内容 | 鮮度が半分になる暫定期間 | 例 |
| --- | ---: | --- |
| 変動が速い情報 | 25ターン | 一時的な餌の集中、混雑、獲物の所在 |
| 関係や危険の傾向 | 50ターン | 捕食被害、競争、庇護/共存の経験 |
| 場所に根付く傾向 | 100ターン | 環境と結び付いた生産/定着の成功 |

半減期Hは、元経験からHターンで鮮度係数が初期の1/2、2Hターンで1/4になる意味とする。[第1組・情報循環/1](information-cycle-v1.md)でF=2^(-a/H)（aは元経験からの古さ）を暫定採用し、境目で段階的に落とさない。同じ古さを別名で二重減衰させない。同等の参照表/近似による最適化は定義と再現性を守って行う。

分類は内容成分ごとであり、全体/種族間/親子間/各層/寄生由来の5成分、発信元の役割、正負、保持形態とは別軸。長寿の生物の内容をすべて100ターン扱いにせず、同じ束に複数種の内容があれば古さを一つに潰さない。「場所に根付く」は実際に場所/環境との関係を確かめた内容に限り、遠方の成功や単なる固定地形だけから捏造しない。

古さは正しさの確率ではない。受け手の適性/環境一致/感度等は既存条件を使い、非適用の内容へ作用を作らない。鮮度は新たな受容/場所作用の既存経路へ一度だけ適用し、同じ由来の学習を毎ターン永続加算しない。既に学んだ重み全体をこの係数で毎ターン縮小する処理にはしない。

## 3. 環境痕跡の残存期間

環境情報は生成後100ターンを基本とし、発信時実績に応じ最大200ターンまで残存を優遇する。生成時に期限を確定し、その範囲を超えて延命しない。第1組でL=100+100Sターン（整数化）の写像を暫定採用する。新たな高実績判定の閾値や寿命抽選を追加しない。

残存期間は内容の半減期とは別の上限であり、100/200ターン残る間ずっと最大作用を保つ意味ではない。有限容量/局所更新による失活等はC11の条件に従い、最低100ターンの存続を保証する規則にも変えない。死骸の可食量/感染体・寿命や、個体の記憶期限をこの期間へ統一しない。

読取・移動/局所拡散・伝達・再保存/再生・Q加工では、元経験時刻や確定期限をリセットしない。Qの主力は出現率上昇と内容歪曲であり、寿命延長や情報の若返りを追加能力にしない。古い痕跡をまとめ直しただけで新しい痕跡として生成しない。

## 4. 新しい根拠の追加と相反する意味

同じ場所で新しい独立した採食成功や被害等が生じれば、新しい由来/時刻の根拠として既存の集中/反復へ接続できる。古い根拠も残る場合は、その時刻と期限を別に維持する。単なる再読取/複製/伝達を新しい実経験や再生成の権利にしない。本人が実際に確かめた結果はC02の経験条件で集約し、過去に伝えられた内容自体を若返らせない。

誘引と警戒は別々の内容としてそれぞれ減衰する。「豊富だが危険」「適するが混雑」等を単一の正負値へ相殺せず、受け手が状態/実経験に応じて判断する。近隣反復で強まっても上限/有限容量を保ち、恒久的な集合/回避や占有権を与えない。

情報は世界の真相を参照して自動訂正しない。古い警戒や餌場の情報に従う損失も起こり得るが、現地の直接観察/実経験で本人の判断を修正できる。未観測の安全/資源を内部状態から透視させない。これにより、時間と独立した新しい経験で場所利用と多種間の関係が変わり得る。

## 5. 観測・保存・比較と残る詳細

定義版/係数版と実効値、内容成分の由来/元経験時刻/鮮度分類、生成時刻/確定期限、評価時刻/実効鮮度、独立した追加根拠、学習/場所作用を区別して記録する。複数由来の具体的な有限合成形式はC11で選び、全生涯の全文履歴や全個体対検索は増やさない。時間経過の係数は時刻差から参照できる形とし、読み取りだけで生態状態/乱数を変更しない。

説明は既存の横詳細・説明シート・図鑑結果へ接続する。既存3グラフ/一体サマリ・全確定ターン原値を維持し、鮮度のための常設グラフ/操作を増やさない。旧記録の欠測を現在時刻で補完せず、新版で過去結果を書き換えない。定義版/実効条件を計算署名へ含め、再生で期限を延長しない。

比較観点はH/2Hの境界と滑らかさ、経験と生成時刻のずれ、100/200ターンの期限、古い高実績/新しい低実績、独立根拠の反復/再読取、誘引/警戒の併存、Q有無、倍率0、親養育者の伝達と元時刻、痕跡消失後の個体学習、保存再生/旧欠測である。文書照合をこれらのゲーム検査の合格へ読み替えない。

第1組は暫定採用済み。役割別の評価基準量、集中曲線/微小量失活/容量競合や受容候補の細かな優先度はこちらが実装比較・観察で調整する。第2組の寄生生活環/遺伝適応/抵抗/Q第四相は採用済み。第3組の群落更新/独立四相植物は採用済み。第4組の状態/計数/表示/保存対応は採用済み。次は初期比較表と実装差分/データ対応・C/D接続要否の整理。今回はA/B文書のみで、製品4.2.32・3core・C/D/E・src/tests・画像/配布物は変更しない。 鮮度は指数式、痕跡の残存は実績写像、既存学習は別状態として区別する。Q離脱後の痕跡の時計と、生成後の情報鮮度を同じ効果へ重複乗算しない。
