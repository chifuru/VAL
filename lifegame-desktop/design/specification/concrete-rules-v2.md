### 環境で成立する餌

すべての環境で、基礎栄養となる草葉/微藻群/岩間苔/菌膜/胞子房/有機粒の少なくとも一種、鉱物系、数字粒、情報エネルギーが成立可能。偏りはあっても、一つの必須資源を一環境に封鎖しない。

水域は微藻/卵、熱域は耐熱菌膜/鉱物片、情報域は発光菌膜/情報、静域は苔/有機粒、寒冷域は苔/鉱物片、湿潤域は菌膜/胞子房、強風域は胞子房/有機粒、腐食域は菌膜/鉱液滴を初期配置で優先する。優先は発生の保証ではなく、通常ターンの誕生には同種近傍条件が必要。水生卵は水域のみ、他は環境別外見を使う。

## 3. 固定環境・地形と攻防

環境は一マス1種類。各系統に得意2種・苦手1種、他は標準を割り当てる（後掲）。得意補正は系統の重視型で分ける。

|---|---:|---:|---:|
| 得意・攻撃型 | 1.15 | 1.05 | 0.85 |
| 得意・防御型 | 1.05 | 1.15 | 0.90 |
| 得意・移動型 | 1.00 | 1.05 | 0.75 |
| 標準 | 1.00 | 1.00 | 1.00 |

地形の移動倍率は平地/浅瀬1.0、岩場1.3、深水1.4、ぬかるみ1.5。倒木/茂みは追加×1.2、合成地形倍率は最大1.8。水生傾向の系統は深水を1.0、植物共生/群体節足はぬかるみを1.0とする。これらは後掲で対象を明示する。環境の得意/苦手だけで通行不可にしない。

基準移動消費はE=1×環境倍率×地形倍率。端数は0.1単位まで保持する。大岩/崖は不可、二つの通行不可セルの間の斜めすり抜けも不可。1ターンに隣接1マスまたは停止。飛行・漂流・大域経路探索は設けない。

攻撃A=6+6×攻撃係数、防御D=4+4×防御係数（攻撃係数=(2×body+appendage)/3、防御係数=skin。既存6軸DNAを参照し、新たなDNA軸を増やさない）。相倍率はI=1、II=1.15、III=1.35、IV=1.60。攻撃者の所在環境をA、対象の所在環境をDへ適用。岩陰/茂みの遮蔽が攻撃方向に成立する時D×1.15、防衛中はD×1.25。Dの環境/遮蔽/防衛の合成倍率は最大1.6（相倍率と進化枝補正はこの上限の外側）。

戦闘は隣接する別系統のみ、攻撃1回/ターンでEを3消費。損害はmax(1, 四捨五入(A−0.5D))。同時攻撃の損害を一括確定し、死亡個体もそのターンに確定した攻撃は取り消さない。大岩/崖に遮られる攻撃と、斜めのすり抜け攻撃は不可。遠隔攻撃・撃破時のエネルギー奪取は初期案へ追加しない。

## 4. 維持・密度・生死

各ターンEを1消費。生物近傍0〜1なら追加0.5、2〜4なら追加なし、5〜6なら追加1、7〜8なら追加2。近傍は同系統/敵を含む全生存個体。密度だけで即死させない。

Eは0〜100に収める。E不足で支払えなかった維持量は1不足あたりHPを2減らす。ただし当該ターンの採食を終えた時点で不足量を確定する。採食前のE=0だけで死亡確定しない。HP≤0、または年齢240に達した個体は死亡。回復は餌によるものとし、無条件のHP自動回復は設けない。

## 5. 動きを生む9パラメータ

固定の攻撃/逃走/防衛/周回/採食/群居モードから一つを選ぶ旧方式は撤回する。本人が持つのは以下の9値、各0〜100。どれも動作の命令や確率ではなく、局所的な刺激への反応の強さである。

| パラメータ | 高い時に強く働く要因 |
|---|---|
| 攻撃圧 | 局所的な敵への接近と、有効な損害を与える機会 |
| 危険回避 | 自身が受ける見込み損害・不利な接触を避ける |
| 資源欲求 | 不足を補う資源を得られる場所へ向かう |
| 仲間親和 | 近くの同系統との距離・動く向きを合わせる |
| 空間確保 | 密集や塞がった位置を避け、動ける余地を保つ |
| 場所愛着 | 最近実益があった場所への滞在・接近を好む |
| 探索性 | 直近に通っていない隣接マス・境界を試す |
| 方向維持 | 直前の移動方向を保ち、無意味な反転を抑える |
| ランダム性 | 成立する基本動作の評価へ上限付きの揺らぎを与える |

系統/親から初期化し、行動の実成果・個体接触・情報摂取は本人の同じ9値へ反映する。出所別の可変戦略配列は持たない。初期個体は系統表±4、子は系統表75%＋両親平均25%に±2（初期値から再現）で初期化する。10ターンごとに系統表へ各1だけ戻す。基礎DNA・相・進化枝は別である。

### 判断は局所の基本動作へ直接作用する

入力は本人の状態と現在地の周囲8マスのスナップショット。候補は、停止または空いている隣接先への1歩、隣接する敵への攻撃、現在地で防御姿勢を取ること。最大18候補。これらは物理的な基本動作であり、戦略を選ぶメニューではない。採食は動作後の所在セルで既定ルールに従う。

候補ごとに、資源の不足解消、見えている敵への損害/接近、見込み被害、仲間との距離/向き、空間、実益のあった地点との距離、新しさ、直前方向への一致を評価する。候補の特徴量を−1〜1に揃え、対応する本人の値/100を掛けて合算する。空腹は資源項、負傷は危険回避項を強め、移動/攻撃の費用を減点する。

具体式の草案：S(u)=Σi=1..8(Pi/100×fi(u))＋空腹度×資源項＋負傷度×回避項−動作費/5＋(R/100)×ξ(u)。空腹度=max(0,(35−E)/35)、負傷度=max(0,(50−HP)/50)。通行不可・費用不足・対象不在は点数比較の前に除く。最高点を選び、同点は初期値による選択。戦略モード変数・戦略名による分岐・旧5点のモード維持幅は置かない。

ランダム性Rは0〜100、全20系統の基準値はまず20。R=0なら揺らぎなし、R=20なら候補ごとに最大±0.2、R=100でも最大±1の評価変動とする草案。ξ(u)は−1〜1で、初期値・個体ID・ターン・候補の識別から一意に決める。再描画・詳細閲覧・候補の走査順で引き直さない。候補が成立しない時は、ランダム性が高くても選べない。

ランダム性は「ランダム戦略」というモードではない。他の8要因へ混ざる判断の揺らぎであり、探索性が高くなくても普段と違う一歩を試す場合がある。探索性は新しい場所への目的を持った反応、ランダム性は選択の揺らぎとして区別する。

資源項はその候補先の既知資源による不足解消の割合、攻撃項は有効見込み損害/10（上限1）または見えている敵への距離改善、回避項は現在地に比べた既知の敵からの見込み被害の減少/20（−1〜1）。仲間項は既知同系統の平均距離を縮める/向きを合わせる程度、空間項は既知の空き隣接候補の割合を使う。未知の位置の敵や餌を推測して有利な値を与えない。

場所愛着は直近8ターンに実際に採食/生還の実益があった一地点だけを記憶し、その距離改善を使う。探索性は直近4位置に含まれない隣接候補を好む。方向維持は前の移動方向との一致度を使う。候補先の周囲を追加で透視せず、今見えている8マスだけから評価する。記憶地点までの経路探索はしない。

### 実成果からの修正

経験は動作名へ加点せず、成果に関係した要因へ反映する。1ターンの本人/接触成果を一度だけ処理し、各値の増減は−2〜+2に収める。

- 有効損害2以上で生存：攻撃圧+2。被害5以上：危険回避+2、自分が攻撃した時は攻撃圧−1も候補。
- 危険のあった位置から離れて2ターン生還し追加被害なし：危険回避+2。同じ生還は一度だけ記録。
- 実際の不足を採食で解消：資源欲求+2。直近4位置以外への移動で資源が得られた時は探索性+1。
- 混雑による追加維持費を払った：空間確保+2。仲間の近さだけの軽減加点は撤回し、接触学習の具体条件は後述の補足を参照。
- 実益のある場所で有効軽減や継続採食が成立：場所愛着+2。同方向移動を続けて実益が得られた時は方向維持+1。

複数条件の加算も各値±2の上限を使い、予測しただけの成果や空振り・歩数だけは評価しない。揺らぎがなければ最良だった候補と実行候補が異なる時、その選択を一回分だけ識別する。実際に新しい餌の不足解消につながればR+1、HP損失5以上ならR−1。各値±2/ターンの上限内で扱い、全履歴や将来探索は追加しない。情報からの修正は後述の取込み上限で別に適用する。

### 経験情報と撹乱情報

情報エネルギーの誕生時、90%は経験情報、10%は撹乱情報。初期配置の情報にも同じ比率を使う。比率は設定で明示する。

経験情報はそのマス/近傍の直近の有効経験を最多2成分まで要約する。内容候補は8ターンで消滅し、成立した餌の内容も誕生後20ターンで影響0となる（餌の近傍状態/残量は通常則のまま）。候補がない通常情報は内容なしでE+1のみ。内容がないことを撹乱情報と偽らない。

経験情報の摂取は最多2パラメータに各−2〜+2、撹乱情報は異なる2パラメータへ各−3〜+3を作用させる。撹乱は少なくとも1成分を非ゼロとし、実経験なしでも成立できる。内容は初期値・座標・誕生ターンから決めて成立時に固定し、見るたび/食べるたびに引き直さない。

内容の取込みは本人ごとに5ターンに1回。影響量は摂取qと比例させず、1回分を適用する。情報の残量、内容、内容の新しさは別に表示。どの系統も摂取できるが、現在の状態に応じて実行可能な行動が選ばれる。情報を食べたことだけでは新たな成功情報を作らず、DNA・身体能力・相・枝は変わらない。

## 6. 四相・3枝→6経路

G≥30でI→II、G≥90かつM≥4でII→IIIの候補、G≥210かつM≥10でIII→IVの候補。一ターンに進める相は一つまで。進化の分類は行動の実成果から決め、戦略モードとして行動へ命令しない。G/M条件に加え、次の本人の実成果が必要。情報・撹乱で傾向が変わっただけでは進化済みにしない。

第二相に入ってから、本人の実成果を採食/機動/戦闘の3種類で数える。攻撃/防御の基本動作で有効損害/軽減2以上を得て生存した成果は戦闘、移動が資源取得や生還につながる成果は機動、それ以外でE/HP不足を解消またはGを増やす成果は採食へ分類する。同ターンで複数成立した時は戦闘→機動→採食の順で一分類だけ使う。1ターン最多1分類に1加算し、空振り・歩数だけ・同じ成果の再評価を除く。各分類は最大64、本人の固定数の統計であり別の戦略や部位XPではない。

III候補の最多分類が4以上、他分類より2以上先行したら3枝のいずれかへ進む。同点/不足ならIIのまま。III到達時に相別の実成果をリセットし、その枝の二方向だけを比較する。

| 第三相 | 第四相の二方向 | 第三相で新たに評価する結果 |
|---|---|---|
| 採食・代謝 | 効率採集 / 蓄積回復 | 採食でEを実際に6以上回復 / HPを実際に2以上回復 |
| 機動・適応 | 広域探索 / 地形適応 | 直近4位置へ戻らない移動後2ターン内の採食成果 / 同じ環境で4回続けた有効な移動・採食成果 |
| 戦闘・生存 | 攻勢 / 防衛 | 有効損害2以上を与えてHP≥50で生還 / 有効軽減2以上を得て生還 |

一成果を両方向へ加算しない。双方成立時は、採食系は行動前HP<70なら回復、それ以外は効率、機動系は同環境の有効連続成果4回が成立した時は適応、それ以外は探索、戦闘系は基本動作が防御姿勢なら防衛、それ以外は攻勢を使う。移動履歴は直近4位置だけで全訪問先を保持しない。III以降の各二方向も最大64で、最多が3以上かつ2以上先行したらIVへ進む。IIIの親分類は固定し、違う分類へ飛び移らない。

四相・20系統の既存名は維持する。形態/能力の分岐差は、IVの効率採集で有機餌E+10%、蓄積回復で餌HP+20%、広域探索で移動消費−10%、地形適応で地形コスト増分−25%、攻勢でA+10%、防衛でD+10%を初期案とする。部位成長を追加せず、第三相の枝は実成果の分類と造形差で示す。

## 7. 繁殖と遺伝

空きマスの生存個体近傍がちょうど3（B3）で、近傍に同系統の雄雌がいる時に候補。両親も互いに8近傍以内、双方III/IV・HP≥70・E≥60・M≥4、待機終了、当該ターン被害なしが必要。出生先は通行可能で、親から不可境界を越えない。

両親それぞれE20・M2を支払い、待機12ターン。初期個体もIII到達から最初の4ターンは待機。親一体につき同ターン一出生まで。競合候補は初期値による優先値を出生先・親へ割り当て、すべての競合に勝った候補のみ成立させる。選ばれない候補の再試行は次ターン。走査順に使った親を奪う方式にしない。

子は第一相、E=40、HP=100、G=M=0、年齢0。基本系統は両親と同じ。6軸DNAは各軸で両親平均＋初期値由来の±0.02、0〜1に収める。雌雄は各50%の再現可能な選択。出生後の基礎DNAは固定。親の相・枝・経験統計は初期化し、行動傾向は前述の弱い継承を使う。新生児は次ターンから行動する。年齢加算はターン開始時点の個体だけに行い、出生ターン末も子の年齢は0とする。

## 8. 一ターンの確定順序（B機能）

1. 前ターン末を固定。種類ごとの周期に従い餌をB3/S23で同期更新し、誕生量/内容を決める。続いて2ターンごとに小型餌生物の局所移動を同じ配置から調停する。ID/残量を移し、複製/合流/増量させない。環境・地形・障害物は更新しない。
2. Eの維持/密度負荷を記録し、同じ個体スナップショットから行動意図を選ぶ。移動先は前状態で空のマスのみ。交換移動・押し出しはしない。
3. 各移動先で初期値による優先値最大の候補を一体選び、一斉移動。失敗者は元位置に留まり移動消費なし。移動候補の再探索は次ターン。
4. 基本動作が攻撃の個体は、移動後も対象が隣接/通行条件を満たせば攻撃。攻撃費用と同時損害を確定。対象不在なら空振り費用や経験を加算しない。
5. HPが正の個体が所在マスで最多2単位採食し、残量と作用を確定。HP≤0の個体は採食で復活しない。維持/行動費は当該ターンの回復から支払い、不足はHP損失へ変換する。
6. 既存個体の年齢を1増やし、HP・寿命死を確定。そのターンの本人の実成果/傾向修正と情報要約を一度だけ記録し、進化を最多一相確定する。死亡個体の有効な損害等は経験情報の候補には残せるが、生還成功とは記録しない。
7. 生存者の出生候補を同じ仮配置で作り、親/出生先の競合を一括調停。出生と親コスト/待機を確定。IIIへ進んだ直後は待機4のため即出生しない。
8. 消費後の餌と次の個体配置・待機・年齢をターン末として確定。情報取込み待機、繁殖待機、数字期限は経過分だけ減らす。新しく付けた待機値を付与ターンに減らさない。

行動意図時の支払い可能額は「E−維持費」で判断し、正の残高で行動費まで支払える候補を選ぶ。不足時は停止し、所在セルの採食だけを行う。支払えない移動を予定の餌で前借りしない。採食後の支払いで二重に費用を引かない。戦闘時点でEは回復前なので、これから食べる予定を理由に無限に攻撃しない。
