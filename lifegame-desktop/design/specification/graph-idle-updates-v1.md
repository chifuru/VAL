# 内容が変わらないグラフの再描画を省略 / 1

対象は既存の描画スケジューラと図鑑解析の終了処理。生態/全期間原値/画像/グラフ配置/色/描画品質は維持する。

- 個体やマスの選択はグラフ対象と独立。選択だけでは強制再描画せず、履歴/対象が変わった時は既存の更新判定に従う。
- 解析を開いていない図鑑終了や、解析終了後の二重終了ではグラフを作り直さない。ただし非同期読込の世代は毎回無効化して古い読込応答を排除する。
- 実際に解析から戻る時の配置・対象・時点復元、別世界/ターン/対象の更新、停止中の寸法変更、進行中の選択を維持する。
- 既存の静止盤面drawIfChangedや非表示時のブラウザ制御を作り直さない。全ての非表示描画を新しい仕組みで停止する変更はしない。
