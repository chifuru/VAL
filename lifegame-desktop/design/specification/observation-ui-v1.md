# 観測操作の一本化とグラフの常時表示

[第1組・情報循環/1](information-cycle-v1.md)の横詳細/説明では、周囲2マスの集中と本人の最大2新由来/Tの学習、再読取と独立実経験、受容倍率/実費、Q痕跡2枠の残存時計と生成情報の鮮度を区別する。近傍の量を安全性や正解と表示しない。暫定値であり実際の動きで調整する旨を説明し、現行UI配置・常設3グラフ/一体サマリ・選択操作は増やさない。

[持続する情報/6](persistent-information-v1.md)の説明/横詳細では、経験を蓄積した保持個体、本人経験と受取内容、通常/親養育者の伝達、環境痕跡の集中/反復、学習と場所刺激を区別する。全体/種族間/親子間/各層/寄生由来は重なり得る成分と説明し、強度を安全性や栄養量と表示しない。既存の画面配置/3グラフ/非栄養/表示軽減を維持し、今回UIや画像は作成しない。 追加はA/B反映段階、製品4.2.32は未変更。

[情報評価/5](information-evaluation-v1.md)の保持6件/3経験ターン、本人実経験/受取内容、役割別実績の3軸、通常確率/被害下限/Q補正は必要な横詳細・説明シートで区別する。暫定値を実測した生存能力や生態系の健全性と表示しない。常設パネル・グラフ・操作は増やさない。

[情報鮮度/4](information-freshness-v1.md)は「元の経験の古さ」「痕跡が残る期限」「個体の既存学習」を横詳細/説明シートで区別する。古い痕跡が見えるだけで現在も安全/豊富とは示さず、独立した追加根拠と再読取を分ける。通常画面へ新しいグラフ/説明欄は増やさない。

[情報生成/3](information-generation-v1.md)の通常候補/根拠不足/確認済み被害、内容別の件数/経験ターン数、保持資格を必要な横詳細/説明シートで分ける。半重みを正しさ50%と表示せず、根拠不足だから虚偽/Q由来とは表示しない。通常画面の常設グラフ/操作は増やさない。

[Q情報歪曲/2](q-information-bias-v1.md)の遺伝傾向・相/栄養/投資・実費・出現補正/歪曲と、実際の羽化/生存/産卵/子の定着を既存横詳細/説明シートで分ける。加工量を利益/真実や固定戦略名へ置換せず、常設グラフ/操作は増やさない。

今回の適用はA/B文書とProject Summary Manifest実体のみ。C/D/E・src/tests・原画/モック・製品4.2.32・3core・Node正式状態/親子/層間参照は変更しない。製品への追加実装、動作/性能/Windows確認、外観承認は未実施。Manifest初期登録は不要、既存6Nodeの要約と処理フラグを反映する。主FLOWはFLOW-05、次候補はFLOW-04/05によるC/D影響整理。

## 1. 通常の停止を2つに限定する

| 操作/状態 | 観測の扱い |
| --- | --- |
| マップ右上の開始・一時停止 | 通常の開始/手動停止を行う唯一のボタン |
| 説明シート・図鑑・マップ作成/初期設定へ遷移 | マップを離れている間は停止 |
| 種族の選択・複数所在強調・生物/マスの選択・横の説明・追跡 | 同じ観測画面内の操作として進行を維持 |
| マップ移動/拡縮・遠近/簡略表示・名札/状態/演出・グラフ対象の選択 | 進行を維持 |

詳細欄の「一時停止して観察/観測を再開」ボタンは撤去する。開始/停止の判断を一つの制御へ集め、別々のボタンや描画処理が独自に進行状態を書き換えない。手動停止中でもマップ・種族/個体選択・詳細・グラフ対象変更を使える。

別画面は、モーダルで表示する説明/図鑑も含む。横の生物説明は別画面に含めない。ウィンドウの非表示/フォーカス変化を新たな通常停止操作へ追加しない。OSによるバックグラウンド実行の減速と、アプリの手動停止は区別する。

## 2. 別画面からの復帰

- マップを最初に離れる時点で、確定世界の世代IDと「観測を進める意図」を保持する。準備中/計算待ちで進行を要求していた場合も含む。
- 同じ世界へ戻ったとき、移動前が観測中なら再開し、手動停止中なら停止を維持する。別画面を経由しても最初の復帰条件を失わない。
- 初期設定の取消で元の世界へ戻る場合も同じ規則。入力エラーで設定画面に留まる間は再開しない。
- 新しい世界の作成・別記録の再生・終了・区間終了・エラーで世界/状態が変わった場合は、古い復帰要求を適用しない。新しく作った世界は開始操作を待つ。
- 設定確認の取消や閉じる操作が、別の開始/停止操作へ二重に伝わらないようにする。遷移の競合や遅れて届く結果で旧世界へ戻らない。

## 3. 区間終了・終了・異常と復旧

通常の一時停止以外に、500T区間終了、観測/再生終了、エラーを明示する。区間終了なら同じ右上ボタンから続行可能。終了済みは通常の再開を提示せず、再生成/新しい観測の導線へ分ける。計算待ち/事前準備は進行を要求している状態であり、手動停止と混同しない。

ボタン名・有効/無効・上部状態・実際の進行可否は同じ状態から導く。「再開」と表示した有効ボタンを押して無反応になる状態を作らない。停止・終了・異常の理由を、消える補助文や描画フレームだけに依存させない。

画面更新例外で次ターンの予約が途切れる場合と、描画例外で盤面だけが止まる場合を別々に検知/回復する。計算の進行・描画の進行・予約された処理の有無を把握し、確定世界と全ターン原値の対応を保護する。描画だけの失敗でターンを二重適用しない。復旧不能ならエラーと再試行を明示し、「観測中」のまま放置しない。利用者の手動停止を復旧処理で解除しない。

通常の一時停止/画面遷移では、確定状態と整合する先行計算・固定地形/外観の準備を安全に再利用できる方式を優先する。部分表示は最後の確定状態へ戻せるようにし、再利用のために未確定ターンを確定扱いしない。失敗した計算・旧世代の結果は再利用しない。再開不能の修正を優先し、未実測の待ち時間短縮を保証しない。

## 4. 保存・説明の整理

通常の観測画面から「観測値・CSV・集計の説明」欄と、その中の参照ターン/最新追従/全ターンCSV/数値一覧・長い集計説明を撤去する。通常画面は対象選択、グラフ、必要最小限の凡例/軸/単位を中心にする。削除した説明欄を別の大きい常設パネルとして再追加しない。

0Tからの全確定ターン集計は実行中のメモリ上で継続する。履歴を最終ターンだけから復元しない。永続保存の入口は図鑑保存系へ集約し、初期条件・最終状態・全期間集計・関係面の区間要約/境界値・定義版を一緒に保存する。既存の終了時保存条件や明示保存、単なる再生では保存しない条件、再生後の明示保存は別IDという条件は維持する。手動停止/画面遷移/対象選択では自動保存しない。

詳細な数値・集計根拠・保存済み記録のCSV/JSON等の分析は図鑑の最終結果から確認する。図鑑保存失敗時は同じ結果の再試行やデータ救出を結果領域で提供し、正常保存したと表示しない。新しい世界の作成は利用者の明示操作として扱い、CSV未出力/図鑑未保存の破棄警告や追加確認を挟まず生成する。生成成功時に世界を置き換え、失敗時は元の世界と未保存履歴を保持する。保存済み図鑑は削除しない。表示項目の撤去でデバッグ用の全ターン原値を失わない。

関係線の単位・対象期間・主要数値、相/雌雄/年齢の凡例、円の内外の意味は判読に必要な短い表示として残す。通常画面の長い集計説明をなくすことと、図の意味を読めなくすることを混同しない。

## 5. 3グラフの拡大と常時表示

全期間の個体群推移・集団構成・生態関係の3グラフを、折りたたみやパネル切替なしで同時表示する。見出しの開閉記号と折りたたみ操作を撤去し、保存された開閉状態で再び隠れないようにする。

削除した説明/操作欄の領域を優先して個体群推移と集団構成へ配分する。特に集団構成は相・雌雄・年齢の時間軸グラフ3本を同時に、相互に読める高さと凡例で示す。全期間の個体数積み上げ・実数軸・対象選択・既定の主生物・無性別/非該当の区別を維持する。100%構成比に変えない。生態関係グラフも読める大きさを確保する。

選択した生物の詳細は独立した隣の枠へ出し、3グラフを隠したり生物の上へ重ねたりしない。上部の現在像サマリ（総括/関係面→Bピラミッド→円）は別の役割として維持する。

現行UIの質感とマップ/グラフの一画面把握を標準寸法で目指す。全要素を一律に拡大せず、不要欄の撤去と領域配分を先に行う。狭幅では読めない縮小や横はみ出しを避け、折りたたみの代わりに縦配置を使う。具体寸法は後続の実画面照合で確定する。

## 6. 円グラフの拡大と二重リングの説明

現行の円グラフを拡大する。元の小さな円をCSSで引き伸ばすだけにせず、描画領域/解像度・リング幅・文字/凡例を合わせて調整する。

- 内側の見出しは「生物グループ」。生産者・一次消費者・主生物・分解者・一次/高次寄生の代表分類を示す。
- 外側の見出しは「系統」。各グループの扇形を草本・水游虫・深殻などの系統へ細分した内訳を示す。
- 見出しから対象のリングへ引き出し線を付け、凡例もグループと系統の対応が分かるようにする。細い扇形へ長い名前を詰め込まず、盤面の記号・既存の固有色を維持する。

両リングとも同じ全生物の記録数（動物個体/植物群落/寄生群体）を同じ分母で表す。外側の角度は全体に対する系統の割合で、各グループ内だけを100%に拡大しない。外側の系統合計と内側のグループ値を一致させる。同じ対象を二重計数しない。主生物は製品上の分類であり、一律に高次消費者を意味しないため、内側を「栄養階層」と表示しない。

中央は現在構成を示し、生物量Bは既存ピラミッドの役割とする。「個体・群落・群体数の割合」という短い注記を残す。総数0/一系統のみ/多数の細い区分/長い系統名でも両リングの意味を判読できるようにする。

## 7. 作成画面と観測画面の分離

| 画面 | 3グラフ |
| --- | --- |
| 起動直後・マップ作成・初期条件の編集 | 非表示。隠した領域の空欄も残さない |
| 世界の作成後・観測中・手動停止中 | 常時表示 |
| 設定取消で同じ世界へ復帰 | 保持した全期間グラフと対象選択を再表示 |
| 図鑑の保存済み結果分析 | その記録の3グラフを表示。ライブ世界の値を混ぜない |

作成画面から図鑑結果を開いて分析する操作は許容する。これは作成画面の背後へライブの3グラフを出すことを意味しない。図鑑を閉じたときも、元の作成画面ならライブグラフを隠したままにする。

非表示は描画領域の切替であり、保持中の世界・観測履歴・選択を破棄する操作ではない。新世界の作成成功時にだけ、その世界の0Tから初期化する。取消/入力不備/生成失敗で旧履歴を消さない。

## 8. 後続の確認条件

- 右上の開始/停止、準備中/計算待ち/各段階途中/区間終了/終了/異常で、状態表示・ボタン・実進行を一致させる。
- 生物一覧の名称/記号/個体数/強調を連続選択し、個体数変化で行が更新されても別ボタンへ誤伝播しない。安定ID/順序/フォーカスを維持する。ボタンがフォーム送信として働かないことも確認する。
- 地図/詳細/追跡/表示/グラフ対象操作で観測を止めない。説明・図鑑・設定では停止し、復帰前の手動停止と進行意図を保持する。新世界へ古い再開要求を流さない。
- 描画だけの例外と確定時UI例外を分け、復旧/再試行しても確定ターンや集計を重複/欠落させない。「観測中」のまま進行予約や描画が消える状態を検出する。
- 通常画面のCSV/長い集計説明と折りたたみの撤去、全期間集計/図鑑保存/未保存確認、対象選択の維持を照合する。
- 個体群/集団構成の拡大、相/雌雄/年齢の同時表示、独立詳細列、円の内外見出し・凡例と比率合計、作成画面の非表示を標準/狭幅で確認する。

これらは後続の受入条件であり、製品での合格を報告するものではない。停止調査での通常操作と障害注入の結果を区別し、利用者の症状の原因を断定しない。

## 9. 生存個体一覧の撤去

通常画面の「生存個体一覧 N · 先頭100体（計算は全個体）」は見出しと一覧領域を撤去する。種族ごとの記号/名称/現在数の選択欄は撤去しない。個体の確認は種族の複数所在強調、盤面からの個体選択、横詳細と追跡へ集約する。内部の全個体計算・観測原値は維持し、先頭100体だけの計算や保存へ変更しない。空いた領域に別の個体一覧や長いデバッグ説明を戻さない。

## 10. 格子と年齢マーク

格子ON時はマス境界が背景の明暗・陸水・近遠で読める線の濃さ/太さにする。通常の背景や既存の遠景記号は変更せず、固定画面px基準の線幅とコントラストを実寸確認する。OFFは従来どおり格子を出さない。格子を主生物を囲む装飾枠へ流用しない。

「年齢を強調」は「幼体・老齢マークを表示」へ名称を改める。体の造形を変える操作ではなく、幼体/老齢を判別できる補助印のON/OFFとする。幼体と老齢は色だけでなく形も違え、短い凡例を付ける。成体にはこの追加印を付けない。近景/記号表示の双方で同じ切替を守り、状態札のON/OFFにより年齢マークの設定を無効化しない。既存の年齢による外見差・能力差・選択詳細の年齢値は維持する。非適用対象へ年齢を捏造しない。密集/小縮尺での重なりは対象位置が分かる範囲で調整し、非表示の場合も詳細値を失わない。

## 11. 再生成と操作中の画質

「新しい世界を作成」を押したら、そのまま生成へ進める。「未出力の全ターン観測データを破棄…CSVを保存」等の警告欄・文言・確認ポップアップを撤去し、図鑑未保存という別名の確認にも置き換えない。設定の不正や配置不能はエラーとして示す。生成中表示、二重生成防止、失敗後の再試行を維持する。古い生成応答は世代IDで棄却し、生成成功まで元の世界/観測を破棄しない。成功後は旧世界の選択/追跡/再開予約を整理し、新世界は開始を待つ。

通常設定ではカメラ移動/拡縮中も詳細画質を維持する。近景の画面キャッシュを捨てて遠景背景へ置き換える動作を既定にしない。詳細タイル/区画の保持、周辺先読み、同じ縮尺の再利用を優先し、未準備領域を扱う場合も全背景を粗くしない。処理軽減欄の「操作中の背景を簡略化」は初期OFF。ONの場合だけ操作中の背景の一時的な簡略表示を許し、操作終了後は詳細へ戻す。最大軽減からも個別にOFFへ戻せる。近景生物の記号化とは別設定にし、画質と生態進行を結び付けない。詳細は `display-load-reduction-v1.md`。

## 12. 追加分の確認条件

一覧撤去後も全対象を盤面から選べること、複数強調/横詳細/追跡と0数項目の整理が機能すること。格子/年齢マークは近遠・簡略表示・状態札ON/OFFで切替が一貫すること。未保存の世界からも無確認で新規生成でき、失敗/遅延応答/連打で旧世界や図鑑が壊れないこと。画質軽減OFF時の連続移動/拡縮、ON時の復帰、最大軽減の上書きとフレーム時間/キャッシュ量を小中大で確認する。いずれも今回の実装/実測結果ではない。

## 13. 多様生成と情報影響度

マップ生成時は [おまかせ・多様生成](diverse-world-generation-v1.md)に従い、既定でも関連付いた複数の観察条件を選べる。手動固定/明示0/供給やモードの約束は維持し、自動項目だけを抽選する。簡潔な実効条件を表示し、内部seedや長い計算説明を通常画面へ出さない。生成成功時だけ世界を置換する既存条件を維持する。

「情報の行動への影響度」は生成時の初期条件として保存し、基準1倍、0倍は行動補正なしとする。0/0.5/1/2倍は説明用の例で、許容範囲は比較で選ぶ。情報の量/寿命、本人の経験、P直接誘導/QのP向け補正を同じ倍率で変えない。影響度が固定なら自動生成で上書きしない。実行中には変更しない。

情報の説明は [死亡由来情報](death-information-v1.md)を優先する。優位な個体の死んだ場所に実績依存の抽選で生じ、取得によって行動重みへ作用する。死骸/感染体と区別する。Qの寄生中/自由成体とPのメタ/Qのメタメタ操作も選択詳細・説明シートで読めるようにし、画面全体へ長い説明や追加グラフを増設しない。該当機能は未実装。

## 14. 非栄養情報と作用範囲

情報は餌ではなく、取得してもE/B/M/HP等の栄養・回復を与えない。Q成体は普通の生物として実際の餌を採食する。詳細では「情報読取」と「採食」を区別し、Qの主作用を「寄生先由来の死亡情報の出現率上昇/内容歪曲」と示す。既存情報への成体Qの局所加工は採用しない。

全生物の情報を対象とし、情報詳細には「同じ層向け」「全層向け」と発信元/層/実績/Q痕跡を既知範囲で示す。全層向けは全盤面へ即時作用する意味ではない。主画面へ長い説明/新たなグラフを追加せず、既存の横詳細/説明シート/図鑑分析へ接続する。層はピラミッド役割＋分解者/P/Qで確定し、主生物という表示分類と区別する。複数役割でも一情報の適用は一回。追加分は未実装。
