# 観測操作の一本化とグラフの常時表示

## 適用範囲と責務

仕様版 `observation-ui/1`。対象は既存A2/B5/B5.2/B5.4/B5.5/B5.6。A2は実行/画面の契約、B5は停止/遷移の接合、B5.2は必要な説明、B5.4は図鑑保存、B5.5はグラフ、B5.6は同じ観測画面内の選択を担当する。責務・変更単位・確認観点は既存ノード内で分けられるため、新Nodeや分割は行わない。

今回の適用はA/B文書とProject Summary Manifest実体のみ。C/D/E・src/tests・原画/モック・製品4.2.32・3core・Node正式状態/親子/層間参照は変更しない。製品への追加実装、動作/性能/Windows確認、外観承認は未実施。Manifest初期登録は不要、既存6Nodeの要約と処理フラグを反映する。主FLOWはFLOW-05、次候補はFLOW-04/05によるC/D影響整理。

本書は既存仕様のうち、説明/図鑑を開いても進行させる条件、詳細欄の別の停止ボタン、通常画面のCSV/観測値説明欄、3グラフの折りたたみ、個体詳細とグラフの置換、作成画面のグラフ表示を上書きする。食性・繁殖・寄生・乱数・収支・生存目標は維持する。関係面と線幅/数値は `relationship-network-v1.md`、保存内容は `archive-history-v1.md`、処理軽減は `display-load-reduction-v1.md` の未変更部分を維持する。

## 1. 通常の停止を2つに限定する

| 操作/状態 | 観測の扱い |
| --- | --- |
| マップ右上の開始・一時停止 | 通常の開始/手動停止を行う唯一のボタン |
| 説明シート・図鑑・マップ作成/初期設定へ遷移 | マップを離れている間は停止 |
| 種族の選択・複数所在強調・生物/マスの選択・横の説明・追跡 | 同じ観測画面内の操作として進行を維持 |
| マップ移動/拡縮・遠近/簡略表示・名札/状態/演出・グラフ対象の選択 | 進行を維持 |

詳細欄の「一時停止して観察/観測を再開」ボタンは撤去する。開始/停止の判断を一つの制御へ集め、別々のボタンや描画処理が独自に進行状態を書き換えない。手動停止中でもマップ・種族/個体選択・詳細・グラフ対象変更を使える。

別画面は、モーダルで表示する説明/図鑑も含む。横の生物説明は別画面に含めない。ウィンドウの非表示/フォーカス変化を新たな通常停止操作へ追加しない。OSによるバックグラウンド実行の減速と、アプリの手動停止は区別する。

## 2. 別画面からの復帰

- マップを最初に離れる時点で、確定世界の世代IDと「観測を進める意図」を保持する。準備中/計算待ちで進行を要求していた場合も含む。
- 同じ世界へ戻ったとき、移動前が観測中なら再開し、手動停止中なら停止を維持する。別画面を経由しても最初の復帰条件を失わない。
- 初期設定の取消で元の世界へ戻る場合も同じ規則。入力エラーで設定画面に留まる間は再開しない。
- 新しい世界の作成・別記録の再生・終了・区間終了・エラーで世界/状態が変わった場合は、古い復帰要求を適用しない。新しく作った世界は開始操作を待つ。
- 設定確認の取消や閉じる操作が、別の開始/停止操作へ二重に伝わらないようにする。遷移の競合や遅れて届く結果で旧世界へ戻らない。

## 3. 区間終了・終了・異常と復旧

通常の一時停止以外に、500T区間終了、観測/再生終了、エラーを明示する。区間終了なら同じ右上ボタンから続行可能。終了済みは通常の再開を提示せず、再生成/新しい観測の導線へ分ける。計算待ち/事前準備は進行を要求している状態であり、手動停止と混同しない。

ボタン名・有効/無効・上部状態・実際の進行可否は同じ状態から導く。「再開」と表示した有効ボタンを押して無反応になる状態を作らない。停止・終了・異常の理由を、消える補助文や描画フレームだけに依存させない。

画面更新例外で次ターンの予約が途切れる場合と、描画例外で盤面だけが止まる場合を別々に検知/回復する。計算の進行・描画の進行・予約された処理の有無を把握し、確定世界と全ターン原値の対応を保護する。描画だけの失敗でターンを二重適用しない。復旧不能ならエラーと再試行を明示し、「観測中」のまま放置しない。利用者の手動停止を復旧処理で解除しない。

通常の一時停止/画面遷移では、確定状態と整合する先行計算・固定地形/外観の準備を安全に再利用できる方式を優先する。部分表示は最後の確定状態へ戻せるようにし、再利用のために未確定ターンを確定扱いしない。失敗した計算・旧世代の結果は再利用しない。再開不能の修正を優先し、未実測の待ち時間短縮を保証しない。

## 4. 保存・説明の整理

通常の観測画面から「観測値・CSV・集計の説明」欄と、その中の参照ターン/最新追従/全ターンCSV/数値一覧・長い集計説明を撤去する。通常画面は対象選択、グラフ、必要最小限の凡例/軸/単位を中心にする。削除した説明欄を別の大きい常設パネルとして再追加しない。

0Tからの全確定ターン集計は実行中のメモリ上で継続する。履歴を最終ターンだけから復元しない。永続保存の入口は図鑑保存系へ集約し、初期条件・最終状態・全期間集計・関係面の区間要約/境界値・定義版を一緒に保存する。既存の終了時保存条件や明示保存、単なる再生では保存しない条件、再生後の明示保存は別IDという条件は維持する。手動停止/画面遷移/対象選択では自動保存しない。

詳細な数値・集計根拠・保存済み記録のCSV/JSON等の分析は図鑑の最終結果から確認する。図鑑保存失敗時は同じ結果の再試行やデータ救出を結果領域で提供し、正常保存したと表示しない。新しい観測で未保存履歴を破棄する場合の確認は、CSV未出力ではなく「図鑑へ未保存」を基準にする。表示項目の撤去でデバッグ用の全ターン原値を失わない。

関係線の単位・対象期間・主要数値、相/雌雄/年齢の凡例、円の内外の意味は判読に必要な短い表示として残す。通常画面の長い集計説明をなくすことと、図の意味を読めなくすることを混同しない。

## 5. 3グラフの拡大と常時表示

全期間の個体群推移・集団構成・生態関係の3グラフを、折りたたみやパネル切替なしで同時表示する。見出しの開閉記号と折りたたみ操作を撤去し、保存された開閉状態で再び隠れないようにする。

削除した説明/操作欄の領域を優先して個体群推移と集団構成へ配分する。特に集団構成は相・雌雄・年齢の時間軸グラフ3本を同時に、相互に読める高さと凡例で示す。全期間の個体数積み上げ・実数軸・対象選択・既定の主生物・無性別/非該当の区別を維持する。100%構成比に変えない。生態関係グラフも読める大きさを確保する。

選択した生物の詳細は独立した隣の枠へ出し、3グラフを隠したり生物の上へ重ねたりしない。上部の現在像サマリ（総括/関係面→Bピラミッド→円）は別の役割として維持する。

現行UIの質感とマップ/グラフの一画面把握を標準寸法で目指す。全要素を一律に拡大せず、不要欄の撤去と領域配分を先に行う。狭幅では読めない縮小や横はみ出しを避け、折りたたみの代わりに縦配置を使う。具体寸法は後続の実画面照合で確定する。

## 6. 円グラフの拡大と二重リングの説明

現行の円グラフを拡大する。元の小さな円をCSSで引き伸ばすだけにせず、描画領域/解像度・リング幅・文字/凡例を合わせて調整する。

- 内側の見出しは「生物グループ」。生産者・一次消費者・主生物・分解者・一次/高次寄生の代表分類を示す。
- 外側の見出しは「系統」。各グループの扇形を草本・水游虫・深殻などの系統へ細分した内訳を示す。
- 見出しから対象のリングへ引き出し線を付け、凡例もグループと系統の対応が分かるようにする。細い扇形へ長い名前を詰め込まず、盤面の記号・既存の固有色を維持する。

両リングとも同じ全生物の個体/群体数を同じ分母で表す。外側の角度は全体に対する系統の割合で、各グループ内だけを100%に拡大しない。外側の系統合計と内側のグループ値を一致させる。同じ対象を二重計数しない。主生物は製品上の分類であり、一律に高次消費者を意味しないため、内側を「栄養階層」と表示しない。

中央は現在構成を示し、生物量Bは既存ピラミッドの役割とする。「個体・群体数の割合」という短い注記を残す。総数0/一系統のみ/多数の細い区分/長い系統名でも両リングの意味を判読できるようにする。

## 7. 作成画面と観測画面の分離

| 画面 | 3グラフ |
| --- | --- |
| 起動直後・マップ作成・初期条件の編集 | 非表示。隠した領域の空欄も残さない |
| 世界の作成後・観測中・手動停止中 | 常時表示 |
| 設定取消で同じ世界へ復帰 | 保持した全期間グラフと対象選択を再表示 |
| 図鑑の保存済み結果分析 | その記録の3グラフを表示。ライブ世界の値を混ぜない |

作成画面から図鑑結果を開いて分析する操作は許容する。これは作成画面の背後へライブの3グラフを出すことを意味しない。図鑑を閉じたときも、元の作成画面ならライブグラフを隠したままにする。

非表示は描画領域の切替であり、保持中の世界・観測履歴・選択を破棄する操作ではない。新世界の作成成功時にだけ、その世界の0Tから初期化する。取消/入力不備/生成失敗で旧履歴を消さない。

## 8. 後続の確認条件

- 右上の開始/停止、準備中/計算待ち/各段階途中/区間終了/終了/異常で、状態表示・ボタン・実進行を一致させる。
- 生物一覧の名称/記号/個体数/強調を連続選択し、個体数変化で行が更新されても別ボタンへ誤伝播しない。安定ID/順序/フォーカスを維持する。ボタンがフォーム送信として働かないことも確認する。
- 地図/詳細/追跡/表示/グラフ対象操作で観測を止めない。説明・図鑑・設定では停止し、復帰前の手動停止と進行意図を保持する。新世界へ古い再開要求を流さない。
- 描画だけの例外と確定時UI例外を分け、復旧/再試行しても確定ターンや集計を重複/欠落させない。「観測中」のまま進行予約や描画が消える状態を検出する。
- 通常画面のCSV/長い集計説明と折りたたみの撤去、全期間集計/図鑑保存/未保存確認、対象選択の維持を照合する。
- 個体群/集団構成の拡大、相/雌雄/年齢の同時表示、独立詳細列、円の内外見出し・凡例と比率合計、作成画面の非表示を標準/狭幅で確認する。

これらは後続の受入条件であり、製品での合格を報告するものではない。停止調査での通常操作と障害注入の結果を区別し、利用者の症状の原因を断定しない。
