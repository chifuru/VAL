# 第3組：群落の更新と独立四相植物

仕様版 `producer-renewal/1`。利用者が採用した第3組の現在正本。基底生産者の群落更新、独立した四相植物の進化/年齢成熟による繁殖、陸水別の生産基盤と情報/寄生/集計をまとめる。[群落・生存目標](balance-restoration-v1.md)、[独立植物/年齢](ab-life-age-plant-v1.7.md)、[陸水基盤](trophic-foundation-v2.6.md)、[供給基盤](producer-pyramid-v2.7.md)、[採用造形](ab-visual-reference-v1.md)の明示的な置換範囲を優先する。第1・第2組、通常植物の非捕食、固定地形、有限収支、R1〜R6を維持する。今回A/B文書のみで、ゲーム実装/画像/新モデル実測はない。

現在の具体化は[境界規則・比較開始値/1](initial-comparison-v1.md)へ採用済み。同ID群落の実績/抵抗維持、新ID再成立の非継承、部分採食の感染量保存、陸水占有率/容量/在庫/再生上限と独立植物経験12/36/80は同書を優先する。植物の別系統/生産者配置/本体と可食部/局所移動/採用造形は[造形対応/1](appearance-correspondence-v1.md)を優先する。本書の未選定記述から両正本の選定済み範囲を除く。ゲーム実装/実測は未完。

## 1. 群落・個体・混合栄養を分ける

| 対象 | 計算上の単位 |
| --- | --- |
| 草本/苔/藻/植物プランクトン等の基底生産者 | 同セル・同系統の群落。有限の基部/可食部/蓄え/生物量を持ち、内部の株ごとに計算しない |
| 独立した四相植物/大型光合成系統 | 森冠/星冠/淡水光合成体は本体一個体＋有限可食量。独自の年齢/相/繁殖/死亡を持ち、通常被食は可食部から減らして本体を維持する |
| 植物共生体 | 既存の混合栄養生物。通常植物へ統合しない |

動く一次消費者/主生物の一枠一個体、P/Q群体、分解者の既定単位は維持する。群落が同セルの動物を消したり、離れた群落と無条件に栄養を共有したりしない。複数の採食分を持つことは内部の全株/全幼体を計算する意味ではない。

## 2. 成立・採食・再生・消失・再成立

| 遷移 | 成立条件と扱い |
| --- | --- |
| 成立 | 適地/空き枠/材料を通り、親からの新規定着か設定で許された環境由来定着かを区別してID/由来/成立時刻を記録 |
| 採食 | 可食部から実際の摂取分だけ減らす。複数消費者は同じ在庫で競合し、可食部0だけで基部まで消さない |
| 再生 | 光/水分/有限養分と基部活性を使い、容量以内で可食部/蓄えを回復する。実在入力/移転/支出を一度ずつ台帳へ記録 |
| 衰退/消失 | 長期の基礎栄養不足・更新不能等で基部活性/蓄えが失われた場合。基礎条件が正常なら通常の被食だけで容易に途絶えない |
| 再成立 | 残存基部の回復、実在する種子等からの定着、設定で許された環境由来定着を分ける。完全消失後の再成立は新ID/新しい実績とする |

基部を失わず可食部だけが回復した場合は同じ群落IDを維持する。完全消失した死亡IDを復活させたり、旧実績/年齢/情報保持資格を新群落へ渡したりしない。部分採食は群落の死亡ではなく、新しい葉の再生も新群落の出生ではない。群落消失時だけ死亡判定/情報候補を一回処理する。

供給なしでは既存の合法な光入力/材料循環/蓄えの範囲、供給ありでは明示した外部入力を別台帳に記録する。消費者の絶滅を見て隠れて補充しない。既存の環境由来更新が許される条件でも、定着に必要な材料/適地やモードの約束を迂回しない。

局所/全体の基礎栄養変動は既定のモード条件で扱い、極めて稀な途絶も理由と経過を伴わせる。乱数だけで生産者を全削除したり、固定地形そのものを変えたりしない。攪乱と実際の消失を分ける。

## 3. 同マスの増量と分布拡大

群落容量/初期蓄え/再生速度/分布密度を別パラメータにする。同マスでの増量と、隣接セルへの新規定着を別予算/空き判定にし、高生産化だけで全面を群落にしない。少ない占有マスで複数採食分を支えつつ、消費者が到達できる配置を評価する。

陸上は光/水分/土壌養分、水中は届く光/水域・底質養分/成立条件を中心にし、容量/再生/疎密を個別設定できる。基底の微藻/水生植物と独立した大型淡水光合成体を混同しない。動物プランクトン相当の一次消費者に光合成を付けない。種子等の分散は既存の局所範囲/費用で扱い、未定義の風/流れや全域への無償播種を追加しない。

## 4. 群落の経過・成長相・更新実績

群落は成立後経過と代表的な成長状態、基部活性/再生/衰退を持つ。成立後経過を内部の全株の年齢へ読み替えて一斉老化死させない。内部の年齢/雌雄分布は推定生成しない。基底群落は従来の少数成長段階を維持し、四相・III三枝/IV六枝を一律に付けない。

更新の成果は実在入力に裏付けられた生産/被食後再生/基部維持/新規定着として記録する。量の変化/群落数/占有面積/独立した実経験数を別にし、微小な再生処理を刻んで無限実績にしない。本人経験/保持資格/死亡情報は第1組の意味・由来・時刻・上限を通す。

## 5. 独立四相植物の年齢・繁殖・進化

独立植物の子は第一相・年齢0・幼体から始まり、親の相/枝/獲得経験を丸ごと継承しない。年齢は出生時の固定基準で判定し、進化/回復によって若返らせない。[年齢能力](ab-age-abilities-v1.8.md)の既存係数を維持する。

繁殖資格は年齢成熟を基準とし、古い第三相以上の条件を置換する。成熟していれば第一/第二相でも、親の有限予算/待機/適地/空き枠/出生調停を満たして無性繁殖できる。幼体の高位相だけで繁殖させず、老齢も既存の費用/健康条件を通す。相/年齢/繁殖待機は別である。

進化は一定量の純生産/被食後再生/栄養維持/新規定着など、植物に実在する成果の蓄積で進める。移動/捕食/攻撃実績を流用しない。移動する淡水系統も位置を変えただけで経験を生成しない。III到達後にしかできない行動だけをIII到達条件に要求する循環条件を作らず、生産/維持から進める経路を持つ。閾値/実績換算/役割別評価基準量はこちらが初期比較表を用意する。

同じ年齢/環境/栄養条件では高位相の生産/容量/回復等の基本能力を強め、維持/成長/繁殖費も増やす。全枝/全環境で無条件に有利にせず、通常植物の攻撃力0/非捕食を維持する。大型植物も通常被食では可食部を減らし、本体の再生費/容量/ID/年齢を維持する。本体損傷/長期の基礎栄養不足/寿命による死亡は残し、不死や隠れた供給にはしない。

## 6. 第三相三枝・第四相各二枝

以下は採用した機能分岐。造形への割当は[現在正本](appearance-correspondence-v1.md)と保存画像を参照する。正式な機械ID/枝IDと専用数値表は実装接続前に用意し、画像枚数から新系統数を増やさない。

| 第三相 | 第四相の二方向 | 有利さと費用の違い |
| --- | --- | --- |
| 生産型 | 好条件の高生産／低栄養の省資源維持 | 高生産は入力要求が高い。省資源は乏しい場所で維持しやすいが好条件での最大生産は控えめ |
| 繁殖拡散型 | 少数の大きな繁殖体／多数の小さな繁殖体 | 大型は一回の親負担が重く、初期蓄えを持つ。小型は定着機会が多いが一つずつの初期蓄えが少ない。量/材料を複製しない |
| 耐食型 | 被食されにくい組織／被食後の再生 | 硬い組織の形成費と再生への投資を分ける。無償防御/即時全回復/捕食者への新しい攻撃は付けない |

陸生の森冠は重厚な幹/根/層状樹冠、星冠は編み幹/放射葉/種子嚢で表す。別の淡水系統は完全浮遊する環状体と受光膜を用い、根/接続枝/泳法を付けない。機能名が似ても全系統を同じ輪郭/飾りの付替えにしない。[採用資料](ab-visual-reference-v1.md)の材質/描線/生命感へ合わせる。旧海生02は今回の淡水系統へ使用しない。採用画像の保存を枝スプライト/全年齢差の完成としない。

## 7. 情報・寄生・食物網

植物の情報は実際の生産/再生/定着/被害に由来し、実在する資源配分/定着先評価へ作用する。情報は非栄養で、受容/場所刺激を養分供給や移動/攻撃能力へ変えない。群落更新や低根拠情報も第1組の本人経験/一死亡一回/時刻/容量規則に従う。

寄生は植物/群落を宿主として使える経路/段階だけを第2組へ接続する。可食部の部分移転、同じ群落内の再生、宿主間移行/新しいP群体感染を区別し、採食/再生だけで感染窓や宿主ID/抵抗をリセットしない。情報を読むだけで寄生を成立させない。

陸水それぞれで生産→一次消費者の採食/出生→上位への移転→死骸/植物遺体→分解/有限材料還元が機能しているか観測する。群落の維持が全消費者の満腹を保証する意味ではない。混合栄養・屍肉食・分解者・P/Qを単一の植物ピラミッドへ押し込めない。

## 8. 初期条件・集計・保存・観察

初期設定には陸水別の群落容量/初期蓄え/再生/疎密、独立植物の初期数/相/年齢/栄養と、供給/優遇/固定0の実効条件を保存する。地形の装飾植生と生きた群落/大型植物を区別する。内部seed表示や実行中の初期条件編集を復活させない。

グラフの記録数は個体/群落/群体、ピラミッドは実在する生物量Bとし、可食量/占有率/生産・再生・消費量を別診断にする。群落の相/年齢を出す場合は代表状態/成立後経過と明記し、非適用/未観測を成体や0で埋めない。全確定ターン原値、既存3グラフ/一体サマリ/横詳細の役割を維持し、表示の詳細対応は第4組の状態対応正本へ採用済み。

定義/係数版、全実効値、群落ID/由来/成立時刻、基部/可食部/活性/蓄え/更新/消失/新規定着、独立植物の相/枝/年齢/出生実績、情報/寄生の由来と関係、入力/移転/散逸を保存する。旧個体モデル/旧第三相繁殖を新モデルと同じ署名で再生せず、旧欠測を補完しない。内部全株の全行動履歴や全群落対探索は追加しない。

後続の比較は、描画なし同条件の基準一致→群落化の単独差分→陸水別の入力/再生/採食/出生→独立植物の成熟/進化/分岐→情報/寄生結合→固定条件のR1〜R6→Worker/保存再生/画面照合へ接続する。容量/在庫の重複消費、可食部0と消失、同ID回復と新ID再成立、少数群落での到達可能な採食、年齢/相独立とI成熟繁殖、被食/老化の描画混同を確認する。未達例を後から除外せず、実際の生存/循環で調整する。

第3組の構造/機能分岐、境界規則・比較開始値の提示済み値、植物/P/Qの造形対応はA/B採用済み。専用寿命/費用/実績換算/枝への詳細配分/機械ID/配置容量は比較接続へ残す。意味/上限/再現性を変える場合だけ利用者へ確認する。次は実装差分/データ対応・C/D接続要否の整理。採用画像は保存資料であり、3core・C/D/E・src/tests・実行用素材・製品4.2.32・配布物は今回変更しない。
