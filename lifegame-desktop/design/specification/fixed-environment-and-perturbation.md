# 環境固定・餌量調整・撹乱情報（最新A/B方針）

ユーザーからの4点の回答に基づき、以前の環境変動案とレビューを修正する。今回も仕様文書のみで、実装・画像生成・動作検証は行わない。

## 1. 餌の役割と、未確定なのはどこか

役割の方向は既に整理できている。「餌の役割が分からない」という以前の書き方は広すぎた。

- 有機系の餌：生命維持・回復・成長に使う。種類・環境による違いを持つ。
- 鉱物系の餌：身体の成長や維持に使う鉱物成分。
- 代謝因子：食べる入力で、成長への作用・調整を持つ。
- 情報エネルギー：食べることで本人の6行動傾向を修正し、経験を系統間で伝える。

残るのは主に数値と配分。例えば「残量1の摂取でエネルギー/HP/成長がいくつ変わるか」「代謝因子が直接エネルギーを回復するか、主に成長を調整するか」「第三相/繁殖に必要な蓄積量」。既存資料でこの部分を具体値として確定していない。役割を一から再設計する必要があるという意味ではない。

## 2. 生存・成長・繁殖は主に餌量で調整する

初期の餌セル密度、一セル当たりの残量と上限、誕生時の量、摂取で減る量を主な調整対象とする。時間だけの無条件回復は追加せず、餌の出現/維持/消失は近傍則を通す。

餌が増えれば必ず繁殖するとは限らず、雌雄・双方第三相・局所出生・待機等の条件は残る。まず既存の消費/成長/繁殖条件と餌量を合わせ、餌を十分にしたのに構造的に出生できない条件があれば別に直す。生存保障の隠れた自動補充は行わない。

## 3. 環境は初期値で決定し、固定する

各マスの環境、地形、障害物は初期生成時に決まり、通常進行では変化しない。8環境は固定された世界の多様性として表す。複合作用がある設定なら、その組合せ/強度も初期値で固定し、合成方法は別途定義する。

ライフゲームによって変動するのは餌と生物の状態。環境をB3/S23で活性化/消滅させる旧案、環境の更新間隔や環境変化への追随を課題にした案は取り下げる。個体が移動すれば受ける環境補正と餌の外見は変わるが、そのマスの環境が変わったわけではない。

環境適性は移動・攻防・餌成立の条件として参照する。固定された8区画に分ける意味ではなく、一続きの地形にマスごとに分布する。得意/苦手だけで系統を隔離しない。

## 4. 情報の餌へ撹乱要素を入れる

経験から生じる情報に加え、ランダムな内容を持つ「撹乱情報」を設ける。通常情報と同じ情報エネルギー資源の内容区分とし、別の生物や大域イベントを追加しない。

- 情報の餌が近傍則で誕生した時、その内容の一部を低率で撹乱情報にする案。発生率は未確定。
- 撹乱情報は実際の成功/生還の記録を必要とせず、ランダムな行動傾向への刺激を持つ。経験情報を装った実績として記録しない。
- 同じ初期値と設定で再現するよう、初期値・座標・誕生ターン等から内容を決め、成立時に固定する。見るたび/食べるたびに引き直さない。
- 摂取時に本人の8パラメータの少数成分を小幅に増減させる案。DNA・身体能力・相・進化枝は変えず、空腹/負傷/通行不可等の条件も無効化しない。
- 情報の内容をランダムにしても、空マスに餌を無条件生成しない。通常の資源B3/S23、成立環境、残量/消費の規則を通す。
- 詳細では経験情報と撹乱情報を区別し、どの傾向へ作用したかを示す。攪乱を食べたことだけを新しい成功情報として再発行しない。

情報量の多さが撹乱の強さと自動的に同じになる仕様にはしない。発生率・変動幅・作用対象数・通常情報との混合は未確定。新しい管理層や群れ全体の計算を追加せず、局所判定・上限付き内容のまま扱う。
