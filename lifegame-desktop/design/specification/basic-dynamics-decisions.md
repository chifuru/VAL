# 基本動作の未確定部分を具体化

A/B草案。ユーザーから委ねられた既存責務内の決定で、実装・ゲーム動作・数値バランスは未検証。本書は下記テーマについて旧資料の曖昧な記述より優先する。[拡張候補](simulation-expansion-candidates.md)は現行仕様とは区別する。

## 1. 餌の持続と競争

餌は同種B3/S23・種類別周期・固定環境適合を維持する。採食で近傍形が崩れ、局所的な枯渇や完全消失が起こることを許容する。現在の近傍に種が残っていなければ、時間経過だけでは復活しない。初期の静止形/振動形は持続の保証ではない。

継続性を調整する順は初期残量→初期配置の近傍形と種類構成→種類別更新周期。B/S変更は別の実験設定として扱い、観測途中に密かに変更しない。現在は補充・全滅救済・死骸の無条件資源化を追加しない。全系統は同じ餌へ接触でき、食性/環境適性の差で利用効率が異なる。

## 2. 繁殖と初期配置

出生先B3と両親の資格を両方必要とする現在の条件を維持する。両親2体だけでは出生できず、第三個体は別系統でも近傍数へ含む。餌生物は含めない。敵が近くても出生先B3の数には含むが、当該ターンに被害があればその親は不適格。親の資源→同系統異性との近接→空き出生先/境界→B3→競合の順に、成立条件を説明する。

初期配置は[初期配置モード](initial-placement-modes.md)に従う。4体組の局所通行条件は維持するが、参加系統数・人数の偏り・空間分布・資源接触保証は設定で制御する。資源接触や異系統との連結を一律に保証する以前の条件は撤回する。

標準のE/HP/M・相・待機・B3を緩和する自動救済は設けない。実装後に出生ゼロが続く場合は、どの条件で止まるかを根拠に調整する。

## 3. 戦闘の意味と実際の軽減

現行の戦闘は餌場・通路・空間の競争へ作用する。撃破によるE奪取・戦利品・死骸餌は加えない。攻撃しただけの報酬はなく、有効損害と生存を既存条件で評価する。同系統を攻撃せず、仲間がいるだけで防御値を上げない。

有効損害は対象の攻撃前HPを超えない実際のHP減少。複数攻撃で超過した時は各攻撃の算定損害の比率で配分し、各個体の撃破時の過大評価を防ぐ。進化・経験の集計は実数で比較し、表示丸めを使わない。

防御/遮蔽の有効軽減は、実際に命中した同一攻撃について「姿勢/遮蔽だけを外した算定損害−実際の算定損害」の正の差。環境・DNA・相・攻撃値は固定し、双方とも既存の最低損害/丸め/倍率上限を適用する。攻撃を受けなければ軽減0。各差は攻撃前HPを上限とし、複数攻撃の合計軽減も攻撃前HPまで。別の未来や敵の行動を再シミュレーションしない。

本人が軽減2以上を得て生存した時だけ防御成果にできる。仲間が近いという相関だけで仲間親和へ軽減経験を加えない。旧「仲間の近くで有効軽減」の自動加点記述は撤回し、次の接触学習で仲間の影響を表す。

## 4. 生還の判定

実際の被害を受けた時、本人へ直近の攻撃者ID/被害ターン/その時の位置を一件だけ記録する。同時に複数なら有効損害最大、同点は初期値で選ぶ。その次のターンに移動し、移動後に当該攻撃者が生存して隣接外になり、移動ターンとその翌ターンに追加被害なく生存した時、一度だけ生還成果とする。判定後は記録を消す。途中で被害があれば最新の記録へ置き換え、元の試行は取り消す。

攻撃者が死亡/不明、移動失敗、停止、追撃範囲内ならこの成果を与えない。生還成立は安全の証明ではなく、限定した実結果の分類。被害を受けずに危険を避けた行動は選択として可能だが、この経験点は付かない。攻撃者の照合はID参照一件で、全個体探索はしない。

## 5. 接触学習と情報発信

同系統の8近傍で、そのターンに本人の実成果が成立した個体だけを接触学習の発信候補とする。受け手は候補を初期値/受け手ID/ターンで一体選び、発信者の実成果に対応する増減の最大絶対値の一成分だけ、符号と同じ向きへ1修正する。同点成分も再現可能に選ぶ。単に発信者の高い値へ追随しない。相互模倣は全員の学習前スナップショットから同時適用し、学んだ結果を同ターンに再転送しない。

接触取込みは個体ごと4ターンに1回。本人の実成果による変化へ接触分を加え、各値±2/ターンの既存上限内に収める。その後に情報摂取の既存上限と0〜100制限を適用する。接触によって相/枝/進化成果数は増えない。別系統からの伝達は情報餌を通す。仲間がいないことによる罰や、大域的な系統共有はない。

情報の経験候補は本人の実成果による修正だけから作る。継承・接触学習・情報摂取・基準値への減衰だけでは作らない。各マスに最新候補一件を8ターン保持し、同時候補は絶対変化量の大きさ→初期値で選ぶ。情報誕生時は所在/8近傍の候補から最新→変化量→初期値で一件を選び、そのうち最大2成分を格納する。格納内容は成立時固定で、情報同士のS23維持では更新しない。内容期限20ターン/取込み待機5/撹乱10%は継続する。

## 6. 進化と計算量

第三相の分類優先は戦闘→機動→採食を維持する。重複計上を避けるための分類で、戦闘優位のバランスが確認されたわけではない。閾値や優先順を自動変更しない。情報/接触による修正は行動傾向にのみ作用し、相別成果は本人が新たに得る。

追加記録は個体ごとの生還一件/接触待機一個、マスごとの経験候補一件。固定近傍とID参照でO(N+I)を目標とする。A1.1/A1.2/A1.3/A1.4とB4/B4.1の既存責務内で具体化し、新Nodeは作成しない。新たな観測・保存機能の拡張は今回扱わない。
