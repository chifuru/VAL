# おまかせで多様な観察条件を生成する

[持続する情報/4](persistent-information-v1.md)の定義版と実効係数を保存する。情報の学習/場所作用に対する倍率0・手動ロックを尊重し、初期状態に架空の経験/親子/養育関係を生成しない。保持資格等のC02暫定値は[情報評価/3](information-evaluation-v1.md)を参照し、定義版と全実効値を保存する。内容別半減期25/50/100Tと痕跡基本100/最大200Tは[情報鮮度/2](information-freshness-v1.md)を参照し、実効条件と版を保存する。通常候補3件/2ターン・残余最大5%/半重みは[情報生成/1](information-generation-v1.md)の暫定値として実効条件/版を保存し、候補のない初期世界へ架空の死亡情報を配置しない。集中/反復の上限や正規化/確率写像・残存写像等は比較選定待ちとし、未提示の数値を自動生成へ追加しない。 追加はA/B反映段階、製品4.2.32は未変更。

## 1. 適用と操作

仕様版 `diverse-world-generation/2`。既定の生成方式に「おまかせ・多様生成」を用意し、数値を一つずつ入力しなくても異なる観察条件を生成できるようにする。現在の製品4.2.32は自由/河畔/湖沼等の既存条件を持つが、本方式はA/B反映段階で未実装。新しい原画/地形テンプレート群の作成を前提にしない。

生成画面では「おまかせ」「条件を指定」の基本選択を少数に保ち、詳細欄で項目ごとの自動/固定を操作する。固定0は空欄/自動と区別する。情報影響度の基準は1倍で、明示固定した値は変えない。実行中は初期条件を直接編集せず、新世界作成時だけ適用する。

供給ON/OFF、自由・供給なし等のモードの約束、手動指定の系統/地形/数値はロックとして尊重する。詳細値を表示しない通常画面でも、実効条件を短い説明で読めるようにする。ユーザーへ内部seed値を入力させるUIは復活させない。

## 2. 関連する条件を組で変える

| 条件群 | 自動項目の候補 |
| --- | --- |
| 地形/環境 | 既存テンプレート、合法な地物分岐、陸水比率/連結/障害物の異なる候補。地形を変えない固定指定は維持 |
| 生産基盤 | 群落の支持量/可食量/再生、初期土壌/水分、群落の疎密/空白。占有面積だけで供給を増やさない |
| 生物構成 | 適合する参加系統、初期数/偏り/配置距離。各系統の生存可能性を一律の勝率に揃えない |
| 寄生 | 宿主数に対応するP初期数/段階、Pに対応するQ初期数、初期経路適応の分布。架空の宿主や自動救済は作らない |
| 情報 | 死亡情報の出現/保持、同層/全層比率、行動影響度等の許容された自動項目。情報に栄養はなく、架空の死亡者による初期情報を作らない |

独立一様乱数を全変数へ掛けるのではなく、水域豊富/陸域豊富/資源局在/高生産で競争が強い/情報が残りやすい等の条件プロファイルを候補にし、関連係数を範囲内で一緒に選ぶ。例は設計方向であり、具体確率/範囲/候補数を今回固定しない。供給なしを選んでいる場合に高生産候補を選んでも、途中の人工供給へ切り替えない。

非自動の固定モード/手動指定は従来どおり使える。情報倍率0を指定しているのにおまかせが上書きする、P/Q無効なのに寄生重視プロファイルが勝手に有効にする、指定種不足を別種で埋めるといった操作は行わない。

## 3. 適合判定と再現

抽選後は地形通行/適地/配置容量、参加生物の必要資源、P/Qを有効にした条件での宿主/感染窓への到達可能性を開始前に静的確認する。固定条件が矛盾すれば理由を示して修正できるようにし、黙って値やモードを変更しない。自動候補の選択は有限回・決定的な順序とし、長い無限再抽選を防ぐ。

生成前に500Tを走らせて成功世界だけを選別しない。開始後の絶滅や行き止まりは競争/適応の結果として記録し、都合の悪い初期値を後から除外しない。多様生成は全系統の存続保証でも、難しい条件だけのランダム生成でもない。

生成方式/プロファイル/定義版、固定項目、自動項目、抽選後の全実効値、地形/障害物、参加系統/初期実配置、計算/乱数方式の版と、情報の層定義/適用範囲/非栄養という意味を保存する。再生時はおまかせを再抽選せず、保存済み条件をそのまま使う。同一条件のやり直しと、新しい条件の生成を区別する。

新世界作成は未保存/CSV破棄警告なしで生成へ進み、生成成功時だけ旧世界を置き換える。失敗/配置不能/遅延応答では旧世界・観測・図鑑を保護する。作成画面の3グラフ非表示、通常画面の停止一本化等は [観測UI仕様](observation-ui-v1.md)を維持する。

## 4. バランス検証・後続

基準のR1〜R6は [群落と生存目標](balance-restoration-v1.md)を維持する。多様生成で異なるプロファイル/地形/構成を混ぜて10件へ数えず、試験群ごとに条件を固定する。同じ系統を十分な条件で確認し、未参加や生成不能を生存成功にしない。供給/優遇/情報倍率の違いは明示して比較する。

後続では手動ロック/明示0/自動の区別、実効値保存、再生での再抽選禁止、有限候補/生成失敗の回復、偏り/同じ組合せへの固定、小中大の性能を確認する。係数の許容範囲は少数試行から選び、未使用条件へ広げる。開始画面をスライダーだらけにせず、現行UIの質感と少数操作を維持する。

情報層は [死亡情報/4](death-information-v1.md)のピラミッド役割＋分解者/P/Qで確定。役割定義版・発信/受信の役割集合を保存し、主生物という表示分類で置換しない。
