# 生態シミュレーション A/B v1.1：実行条件の確定

本書は[A/B正本](ab-specification-v1.md)と[30系統定義表](ab-catalogue-v1.md)の不足条件を埋める**規範的な補遺**。本書が明示的に更新した条件は本書、それ以外は正本・系統表を使う。旧検討資料を補完ルールとして暗黙に読まない。数値は実装前の初期設計値であり、生存率・均衡・実行速度の実測ではない。

対象は既存A1〜A1.7/B4〜B4.4/B5〜B5.3の仕様・機能。新Node分割、C/D/E、ゲームコード、テスト、承認状態変更は含まない。[仕様全体の図解資料](atlas-v1.1/README.md)は本書の図解で、実行画面や実測例ではない。

## 1. 値・時刻・再現性の共通契約

- 単位はセル、ターン、E、B、M、HP、G。距離はチェビシェフ距離。座標は左上(0,0)、右へx、下へy。近傍は自己を除く8近傍、端の外は不在。半径rは最大(2r+1)²−1セル。
- `S_t`はtターン終了状態。初期状態は`S_0`。ターンt+1の途中状態を表示や次の意図へ漏らさない。光供給後・移動前の判断用状態を`V_t`と呼ぶ。
- E/B/M/HP/G、重み、特徴、得点は内部小数で保持。判定前に丸めない。各確定書込みを小数点以下6桁へ四捨五入（正値の0.5は上へ、負値は絶対値で同様）。HP/E/M/B/Gは0未満にしない。被害整数だけ`floor(x+0.5)`。表示は別に丸める。
- 初期値はUTF-8文字列（空白も値）。独立な疑似乱数値`u`は「仕様版、初期値、用途、ターン、ID、候補キー、軸番号」を順序固定のJSON配列としてUTF-8化し、SHA-256の先頭32bitを符号なしbig-endian整数hとして`u=h/2^32`。不要引数はnull。用途名はworld/env、world/terrain、world/edge、world/light、init/group、init/position、birth/dna、birth/sex、birth/role、behavior/jitter、arbitration等で分離。連番乱数の消費順に依存しない。
- 無作為区間[a,b)は`a+(b−a)u`。確率pはu<p。同点は独立用途のhが小さい候補、さらに正規化候補キーの辞書順。候補キーは動作種、主体ID、対象ID、経路、セルを順に含む。観測・描画・画像出力は乱数用途を持たない。
- 生物IDは初期`i:枠:y:x:系統`、子`b:出生ターン:枠:y:x`。一枠一出生なので一意。P/Qは`p:出生元ID:ターン`/`q:出生元ID:ターン`。移行でIDを再発行しない。イベントIDは`ターン:主体ID:種類:同種通番`、通番は確定した対象キー順。過去IDは再利用しない。

## 3. 固定世界の生成と初期配置

### 3.1 環境・地形・光

環境を四つの背景領域へ分けない。盤面を一辺8セルの粗格子に区切り、各粗格子内にu由来の種点一つを置く。環境8種をy/x順の種点へ循環割当（初期値で開始順を回転）。セルは二乗距離最小の種点の環境、同距離は種点キーで決める。自然な環境の塊/境界を持つが、各セルが固定属性を持つ。環境面積の均等化や各系統の隔離は行わない。

### 3.2 配置と初期投入

同一枠の配置候補は適合→位置優先値→キー順で有限に列挙し、足りなければ開始前エラー。主の環境適合は得意2/標準1/苦手0で、苦手も配置可能。草本/小型等の生息適合は系統表の制約を守る。

植物35%は微藻/岩苔/草本を1:1:1、菌3%、小型10%は水游虫/草棲虫1:1の目標。各比率の個体数は通行可能セル数×比率を四捨五入、同群内は最大剰余法。同群で配置不足なら同群の他系統へ再配分し、それでも群目標に届かなければ不足表示して開始しない。各初期餌はI/年齢0、系統表の予算を持つ。主と餌は独立枠なので重ねてよい。

主の少数モードは初期値の系統優先順先頭5。手動は有効主系統1〜21。最低四体ずつを配り、残り四体組を重み最大剰余法で配分。自然は各系統の適合×近隣食用餌（半径2、一体+0.1/上限0.8）の高いセルを優先、同点初期値。散開は既配置主との最短距離が最大、集中は系統ごとの初期値由来中心から最短、同点は適合/初期値。これらは開始時だけの配置処理であり、通常ターンの全個体探索には使わない。

資源保証ONは各四体組の代表点半径2に食用植物/小型一件と鉱物一件への接触可能性を要求する。既存で満たせば追加なし。不足時は空き餌枠/資源枠に初期投入として一件ずつ追加、対象系統は食性最適/生息可能なもの。同点初期値。場所がなければ保証不成立を表示し、地形や他個体を消さない。

各セルR_M5を最初に投入。鉱物片は岩セル20%/その他通行可能3%、鉱液滴は浅瀬/泥20%/その他2%の確率でq2、必要MをR_Mから支払う。初期情報媒体は通行可能セル2%でq2/内容なし/E予算0.1を別途初期投入として記録。種実/胞子/卵/有機粒/因子/死骸は初期0。資源枠3種を超える初期候補は鉱物片→鉱液→情報の順。P/Qは最後に系統表の確率で配置する。

初期媒体を孤立点だけにして初回S23でほぼ全て消すことを避けるため、上の確率で得た種類別候補数を目標数とし、配置は2×2通行可能ブロックを初期値順に先に埋め、端数1〜3だけ単点へ置く。ブロック候補は平均適合度→hで選択、重複なし/枠とM予算を予約する。目標数に届かない場合は単点配置へ戻して不足分を埋める。それでも予算不足なら開始前に不足を表示する。光・資源の初期投入を記録し、毎ターンこのパターンを再投入しない。

## 4. 資源・餌の完全な分類

| 対象 | 特徴/実体 | 一単位の供給 | 更新・期限 |
|---|---|---|---|
| 微藻/岩苔/草本 | 動かず光生産、多いが一口は小さい | 生体Bから最大2、同割合のM | 刈取り後B0は死亡。独立個体の無性出生 |
| 菌膜 | 光なし、有機物/死骸を分解 | 同上。回復適性1.2 | 局所分解後EをBへ。無償補充なし |
| 水游虫/草棲虫 | 高繁殖・A0・低HP、回避して移動 | 生体を直接吸収せず、攻撃→死骸→翌ターン採食 | 水游虫は偶数ターン移動可、草棲虫は毎回 |
| 種実/失活胞子/栄養卵/有機粒 | 移動しない有限脱落物 | 親から引いたE相当B/q、M/q、Gは取得有機E由来 | 生成後12、B3で増殖しない |
| 鉱物片/鉱液滴 | 主にM。食べてもEを作らない | 片M2/滴M1、R_Mから予約済み | 周期4/3のB3/S23、qは保持 |
| 代謝因子 | 低/中/高活性の成長触媒 | E予算≤0.1/q、次の有機取得へG+1/2/3 | 媒体12、取得効果3。活性はuの各1/3 |
| 情報 | 滞留・浮遊するエネルギー媒体 | E予算≤0.05/q、行動9値への二成分 | 毎回B3/S23、内容20、鮮度減衰 |
| 主/餌の死骸 | 有限BE/BM/BG。生前の残予算で価値が違う | 各残予算/残q | 12、感染は追加条件/短期限 |

有機脱落一件はq1、成熟草本→種実、菌→失活胞子、水游虫→栄養卵、その他の許可された成熟生産者→有機粒。8ターン周期は個体ID由来の位相を用い、全員が同じターンに出さない。草本/菌の候補だけ10%で代謝因子へ置換。通常有機はB2/M0.1を全額払える場合だけ、因子はB0.2を払いE予算0.1。脱落に必要なMがない時は通常有機候補を出さない。生物へ戻る卵/種子ではなく**非孵化性の可食物**。

植物・菌の刈取りMは`残M×取得B/刈取り前B`を同時に供給元から引く。小型の栄養価は有限身体/死骸由来であり、動物だから毎回一定Eを吐き出さない。餌種類ごとの固定効果と、実際の残予算を説明表示で分ける。

資源外見は残q/上限比の≤1/3・≤2/3・それ以上で疎/中/密を使い、植物はB/容量で芽/葉群/繁茂。環境は色だけでなく水膜/霜/菌糸/乾いた殻等の輪郭を加える。情報は環境に応じた漂う点/渦、鮮度は光の輪の濃さ、Q媒介は観測レイヤーにのみ印。見た目だけで栄養種や感染性を増やさない。

## 5. CAと有限予算の組合せ

各対象種は**採食前のS_tの同種占有**を数え、周期該当時だけB3/S23判定。死骸/生物を鉱物近傍数へ加えない。S23外の既存鉱物は消失して残Mを所在R_Mへ返し、情報は残E散逸/内容消失。S23内はq/内容/時刻を保ち、採食でq0になったものを同じ更新で再生しない。非周期ターンも期限切れ/実消費は有効。

空セルの鉱物誕生qは2、必要Mは片4/滴2。情報誕生q2は所在/8近傍の期限内実成果候補、発信者生存、E0.2支払と本人E5留保を必要とする。栄養予算は0.1、残る支払E0.1は分泌費。情報のS23保持は発信者死亡後も内容期限まで可能。CA誕生判定を満たしても資源枠/予算不足なら誕生なし。

誕生候補の適合度は鉱物片=岩2/他1、鉱液=浅瀬/泥2/他1、情報=発信環境一致2/他1。有機脱落は同じ条件付き周期で適合1。既存の未失効3枠は追い出さず、空きだけを候補適合度→供給元の予約後残予算→h→キーで一括予約する。供給元が共通する複数セル候補も同じ台帳を使う。情報は周期候補を前段で決め、ターン後半の最新成果/残予算で発信可否を確定する。採食で空いた枠は次ターンからCA誕生に使う。有機脱落だけは後段の空きを使える。

候補の無限再試行はしない。予算や枠の競合では全額成立/0、採食だけ単位内の部分取得を許す。新媒体は次ターンから近傍数/採食対象になり、同ターン連鎖誕生はない。情報の空間的広がりは、情報を受けた個体の**新しい実成果による再発信**と局所CAによる媒体の分布で生じる。発信源なしの内容コピーや、媒体が盤面全域へ物理拡散する処理はない。

## 6. 一ターンの支払順と確定点

| 段階 | 参照・確定すること | 後段への制約 |
|---|---|---|
| 1 期限/CA候補 | t+1で期限に達する旧媒体/死骸/P候補を失効、M還元。S_tからCA保持/消失/誕生候補を作る | 期限切れの情報をこのターンに使わない |
| 2 光/判断 | 旧生存個体へ光E、維持/密度/P負担を見積り留保、V_tで各一基本動作 | 将来食べるEを動作費へ前借りしない |
| 3 移動 | 旧枠の経路/2段階予約で同時確定 | 落選は旧位置、費用0、停止割引なし |
| 4 戦闘 | 移動後位置で対象/射線を再判定、攻撃費を留保し同時被害 | HP0は以後の実行者/受入者にならない |
| 5 移転/採食 | 育児→刈取り→所在の通常二単位を一台帳で調停。実取得から感染移行候補 | 死亡予定でもHP>0なら採食可。感染は移行一回 |
| 6 精算/死亡 | 動作費、基礎維持、密度、旧P徴収を精算。既存個体年齢+1、未払HP/寿命死/刈取死。死骸生成 | 戦闘死の個体も成立済み費用を精算してから残予算を死骸化。二重徴収なし |
| 7 学習/感染成熟 | 生存者の本人・接触・情報・減衰、段階開始時からいたP/Qの実取得と成熟 | 新感染は操作/徴収/成熟とも次回。新III/IV能力も次回判断から |
| 8 成長/出生 | 光G、最大一相、相による待機短縮。出生候補/親/セル予約、出生/材料還元 | このターンIIIに到達した親は初回待機4で繁殖不可 |
| 9 生産/発信 | 既存生存者のB投資→脱落→情報誕生/Q操作→P/Q子放出 | 新生児は参加しない。CA出生候補の源が死んでいれば失敗 |
| 10 出力 | 新規付与以外の待機を減算、状態/失敗理由/イベントを確定 | 出生はI/年齢0。演出は確定状態を変えない |

段階2の動作予算は`max(0,E光後−割引前基礎維持−密度−既存P徴収0.2)`。予約は支払を二重に引かない。通常固定費は採食後Eで払えるが、動作費だけはこの動作予算内に限定。実際の段階6では動作→割引適用した基礎維持→密度→Pの順に支払、残額不足1EでHP2。Pへ渡るのは実際に支払えた分だけ。攻撃後死亡でも留保した攻撃費は残Eから引く。P徴収不足はHP損失のみでPへ無料Eを渡さない。

## 7. 採食・回復・物質収支の調停

## 8. 移動予約・射線・同時戦闘

歩ごとの移動Eは基準1×進入地形倍率×進入環境倍率×固有×枝。地形は平地/浅瀬1、岩1.3、深水1.4、泥1.5。水生対象の深水、植物共生/群体の泥は1。倒木/茂み×1.2、地形部分上限1.8。地形適応枝は`1+0.75×(地形倍率−1)`。二歩は両歩を加算し全額留保する。攻防は攻撃者の所在環境/防御者の所在環境を別に使う。

移動候補は旧状態で全経路が同枠空、かつ可視のセルだけ。したがって交換/前の個体がどくことを前提とする追随は不可。候補は通過/終点をまとめた予約集合を持つ。第1段階で各予約セルのh最小候補を選び、第2段階で自分の全セルに勝った候補だけ実行。負けた候補が明けたセルへ繰上げない。二つの斜め経路がセル中心間で交差しても共有セルがなければ許可し、移動演出だけ上下をずらす。生物同士の接触判定は到達セル/近傍で行う。

攻撃は移動と別の基本動作なので、同一主体は移動後攻撃をしない。攻撃対象の移動に合わせて追尾移動もしない。旧可視IDが移動後も射程/射線内なら成立。遠隔遮断は線が触れる途中セルの主/小型両枠（植物/菌を除く動く生物）が対象、味方も遮る。隣接攻撃は大岩/崖/角抜け制約を共用。同セル小型は射線不要。

同時損害はターン開始相/枝から計算しHPへ一括適用。実与損害は相手の損害前HPを各攻撃者の予定損害比で按分し、合計をHP以内にする。実軽減は同じ攻撃の`D=0損害−実D損害`を非負で計算し、実HP被害の上限処理前の値を使う。学習用軽減は一ターン合計2以上で一回のみ、被害0/空振りを防御成功にしない。全員の生存確認は同時損害後。

例：HP6へ予定損害8と4が同時成立なら実与損害は4と2。双方が撃破全量を経験にできない。攻撃側が同時死亡しても攻撃は成立、死亡者はその後学習しない。死骸は段階6生成なので、攻撃した瞬間にその死骸を食べない。

群体節足は繁殖雌候補=腹部二重輪、働育雌=前肢の育児斑、雄=長めの触角。幼体にも判別可能な縮小印を持つが、繁殖可能印はIII/条件成立後のみ。colony_idを常時全個体へ文字表示せず選択/集団由来表示で確認する。階級は外形の差であり、別種/群体合体ではない。

微藻は小粒の葉状群、岩苔は低いクッションと短い葉、草本は背の高い葉束、菌膜は網状菌糸と胞子斑、水游虫は水滴状体と短い尾、草棲虫は横長体と短脚で区別する。早成甲殻はIから殻板と短い付肢を持ち、IIで側殻、IIIで背殻の縁が発達する。これらは部位ごとに成長計算する新機能ではなく、相/系統から決まる代表形。

P潮環は粒状付着→尾状中間→環状終成体、P葉環は糸状付着→鉤状中間→葉状終成体。追加中間Bは中間形の二重縁として示す。QはPに接する小粒I/帯状II/分岐印を持つIII。宿主と段階で表示を選び、外見から新しい能力や感染経路を生やさない。全20系統の最終造形は既存系統樹の名称・構造を維持し、今回の図は代表見本とする。

IIIへ達した繁殖雌候補は自IDへcolony_idを変更する。初期繁殖雌候補も同じ扱いだが、以下の開始組だけは一回の所属引継ぎを行う。初期四体組のcolony_idは`founder:組ID`、最初の繁殖雌候補がIII到達した場合だけ、同組の**初期働育型**は同時にそのIDへ所属を引き継ぐ。この開始時例外は一回で、通常出生の働育型を別colonyへ全域移籍しない。孤立創設が失敗する可能性や女王不在を救済しない。

## 14. 表示・モーションの静止絵コンテ

一ターンの結果から、各個体最多4表示レコード。優先は死亡→出生/進化→感染移行→攻撃→実採食/育児→移動→防御→光。採食は二口を一レコードへまとめ供給元/実量最多二件を保持。4件を超える下位演出は省略数表示、個体数/損害/統計からは省かない。選択された個体→表示範囲中央近い順→IDで最多128体を詳細演出、他は簡略。128は生物数上限ではない。

| 確定イベント | 一区間内の見せ方 | 禁止する誤表示 |
|---|---|---|
| 移動 | 0%旧位置→50%通過点→100%到達。1歩は線形 | 競合敗北の移動、通過点での採食 |
| 攻撃 | 0〜30%予備動作→30〜60%到達線/咬合→100%戻る。遠隔は射程線 | 空振りで被害表示、描画時の再計算 |
| 捕食/刈取り | 実取得時だけ供給元から口へ最大2粒/一口、残量形態を更新 | 攻撃直後の死骸先取り、源を減らさない粒 |
| 防御/育児 | 輪郭を締める/実受入幼体へ一本の移転線 | 受入取消なのにE移転を描く |
| 出生/成長 | 子Iの小輪郭出現/同IDの相輪郭を置換 | 子を親相で描く、進化を無料全快の光として描く |
| P/Q/情報 | 選択時に宿主内階層/媒介タグ、情報の鮮度輪 | 寄生を自由歩行個体、情報を遺伝子獲得として描く |

補間時間は実時間ターン区間の80%/最大300ms、残り静止。10Hzなら80ms、1Hzなら300ms。停止/一歩送りは確定位置で止まり、リプレイ演出は同じ結果を示すだけ。動き軽減は補間なし/輪郭一回。点表示では移動先/相色/選択輪のみ、詳細な雌雄/感染を無理に描かず選択資料で読めるようにする。

## 15. 不成立理由と観測項目

開始前エラーは`SETTINGS_INVALID / PLACEMENT_SHORTAGE / GUARANTEE_FAILED`。通常の不成立は`BUDGET / SLOT_BUSY / RESERVATION_LOST / PATH_BLOCKED / OUT_OF_SIGHT / OUT_OF_RANGE / TARGET_LOST / COOLDOWN / IMMATURE / HOST_MISMATCH / INFECTION_OCCUPIED / EXPIRED / DUPLICATE_INFO / CAPACITY`。同候補に複数理由があれば設定→対象/経路→成熟/待機→予算→枠/競合の順で代表一つ、観測者が詳細を展開可能。

観測の全状態は生物の感知とは別。例：観測者はQの型を見られるが、個体は可視外の餌も隣の相手Eも知らない。表示は現在セル内の全枠を選択可能にし、「餌の下に個体が消えた」ように見せない。

集計は有効系統の生存/出生/死亡原因/相/枝、E獲得源、M投入/土/生体/死骸/散逸、感染の段階/移行成功/失敗理由、情報の発信/新規取得/重複拒否/Q操作、階級/colony別の生存/出生を固定チェックポイントで記録する。全家系履歴や毎ターン全個体録画は初回外。選択個体の説明は直近一ターンの候補最多3件と得点内訳を**選択中だけ**保持し、全個体の全履歴は残さない。
