# 食物網・寄生・独立栄養・モーションの接続案

ユーザーの追加要望を具体化したA/B草案。ユーザーはA/Bのみの継続とA1.5/A1.6/B4.2/B4.3/B5.3の分割を確認した。関連Nodeを草案で登録し、数値の承認済み化やコード実装は行わない。以前の仕様と異なるテーマは本書を最新の追加草案とする。

## 1. 食う/食われる以外の関係

採食、競争、庇護、寄生、相利共生、独立栄養を別々の関係として扱う。同系統は仲間という基本は維持するが、異系統の近接が常に損失になる設計には限定しない。全20×20の相性表ではなく、宿主適性/生産能力等の少数タグを使う。

候補の寄生生物を既存20系統の一部へ強制的に割り当てるより、**主役20系統とは別に寄生生物2系統を設ける案**を推奨する。主役の図鑑/四相/3→6を維持し、寄生系統は生活環を別の図で説明する。主役の系統数設定とは別に寄生要素ON/OFFと系統選択を持つ。

## 2. 食物網の最小案

草葉/微藻群→小型餌生物→主役、という局所的な関係から始める。草葉/微藻群は従来の同種B3/S23で更新。餌生物の誕生は同種B3に加えて隣接植物があることを条件とする。餌生物の資源単位qは引き続き餌量で、主役の独立した個体数へ数えない。

2ターンごとの餌生物更新で所在/隣接から植物qを最大1消費し、餌生物qを無条件に増やさず維持条件へ使う案。維持に必要な植物がなければ餌生物qを1減らす。誕生と維持で同じ植物qを二重消費しない。複数餌セルの競合は初期値/セル/ターンで一括調停する。

植物qから餌生物qへの変換率と基礎栄養のEは同じ単位とは限らない。単にqを差し引いただけで物質/エネルギー保存を満たすとは扱わない。現行CA誕生での外部供給と、捕食による移転を区別する仕様が必要。寄生を足す前にこの供給経路を確定する。

## 3. 小型個体の群れと庇護

小型の主役はI/II、庇護し得る大型はIII/IVを初期の説明上の区分とする。これは物理的体格の最終定義ではなく、後で系統のbody差を加味できる。

小型側は仲間親和/危険回避により近傍の大型同系統へ接近しやすくなる。大型側は小型同系統の近くで敵が見えると、既存の攻撃/親和/場所愛着の評価からその付近に残りやすくする案。専用の庇護モード、守る対象の全盤面追跡は作らない。

最初は位置占有、敵への反応、近傍同族の既存補正による間接防衛のみ。近くにいるだけの無条件無敵化・損害肩代わりは入れない。寄り過ぎれば密度負荷と餌の奪い合いがある。餌を横取りされる/大型ごと攻撃される場合もあるので、庇護は必ず成功する保証ではない。

異系統庇護は共生タグを用いた将来案に分ける。全個体が異系統小型を守るようにはしない。寄生により生じた接近と、通常の親和による接近を説明上区別する。

## 4. 文脈・鮮度情報を小さく実現する案

既存の情報内容2成分へ発生環境ID一個と誕生ターンを付ける。自然言語の推論、長文記憶、ニューラルネットは不要。鮮度は別の毎ターン値を増やさず、現在ターン−誕生ターンから求める。

最小例は内容効果×鮮度係数×文脈係数。鮮度は0〜4ターン1、5〜9は0.75、10〜14は0.5、15〜19は0.25、20以降0。環境一致1、不一致0.5とする調整前案。内部に小数を保持し、見た目の整数丸めで効果を消さない。撹乱内容も同じ鮮度で減衰し、食べる前に誤情報だと自動認識する能力は付けない。

情報q/Eと内容効果は別。現行の取込み待機5、系統横断、原体験以外の転載禁止を維持する。環境不一致でも受信を遮断せず、共有の可能性を残す。タグ一個と既存期限から計算できるため、大きな学習機構より実装範囲を抑えられる。

## 5. 寄生系統の生活環

以下の2系統はゲーム用の仮名で、実在の種をそのまま再現したものではない。

| 系統案 | 第一宿主/保持先 | 中間宿主 | 終宿主 | 特徴 |
|---|---|---|---|---|
| 潮環寄生体 | 生きた微藻群セル | 小型餌生物 | 水域適性を持つ主役 | 水辺へ戻る傾向が再伝播に結び付く |
| 葉環寄生体 | 生きた草葉セル | 小型餌生物 | 植物食/汎食の主役 | 採食域に留まる傾向が再伝播に結び付く |

草葉/微藻群は栄養資源としての抽象表現であり、生きた宿主としての保持と、非生物の餌に付いた汚染は用語上区別する。鉱物/代謝因子/情報を第一宿主とはしない。

状態は「第一宿主内→中間宿主内→終宿主内→第一宿主への繁殖体」という有限の生活環。各段階に宿主条件と最低滞在期間を設定する。初期案は4/6/8ターン、寿命は宿主外候補8ターン。宿主が変わっただけで終宿主段階へ飛ばさない。

伝播は、感染植物を小型餌生物が実際に摂取→感染した小型餌生物を主役が実際に摂取、のイベントでだけ進める。主役が感染植物を直接食べた場合は生活環不適合としてその系統の感染は成立しない。終宿主適性を満たさない主役では途中で停止し、期限で消える。単なる近接から全宿主へ感染させない。

終宿主で成熟すると、所在/8近傍にある適合した第一宿主への繁殖体候補を最大一件、4ターンに一回だけ作る。適合資源がすでにあれば寄生状態だけを付ける。空なら期限付き候補として保持し、第一宿主が通常B3で誕生した時だけ付着可能とする。寄生のために餌を新規生成しない。候補が期限切れなら再伝播失敗。食物網と同様、寄生体の生活環も局所の成立条件が必要。

## 6. 宿主依存の分岐と行動への影響

寄生系統そのものと、宿主内で発現する型は分ける。宿主の基本系統に二歩解放が定義されていれば「移動型宿主向け」、なければ「定着型宿主向け」の二型を選ぶ案。現在の相/一時的な行動では再分類しない。宿主に入った時に固定し、毎ターン揺らいだり別系統へ変わったりしない。独立した寄生遺伝子の進化まで最初から実装しない。

宿主操作は意志を完全に奪う命令ではなく、本人の9値に対する一時的な評価補正。最大二成分、各±5以内を初期案とする。元の値を上書きせず、有効値＝本人値＋寄生補正（0〜100）で使う。離脱/死滅時に補正は消え、取得済みの経験/相/枝/DNAは書き換えない。

潮環は水域方向の候補評価と危険回避、葉環は資源欲求/場所愛着へ限定する。水域方向は見える範囲のセルだけから評価し、未知の水辺まで経路探索しない。小型餌生物は9値を持たないので、既存の逃避/移動候補評価へ一つの有界補正を付ける。植物宿主は移動しないため操作対象にしない。

寄生体は主役から毎ターンE0.2を宿主負担として得る初期案。支払不能なら成熟が止まり、宿主Eの負値や寄生側の無制限増殖を作らない。宿主の死亡で内部の生活環は終了し、死亡だけで次宿主へワープしない。初期版は親から子への感染と寄生体同士の競争を入れない。

感染した時点では寄生体が有利でも、宿主が捕食されやすくなり生活環が進むことがある。すべての寄生効果を宿主の損失だけに固定しないが、利益を持たせる場合は共生に近い別関係として明記する。

### 多数個体とセル占有

主役は引き続き一セル一体。寄生体は別の主役スプライトとして同居させず、宿主に付く上限付きの生活環状態として保持する案。これは「複数の主役を一個体に集約する」方式ではないが、宿主体内の生物を独立したセル個体として数えないという追加の表現規則になる。

初期版は主役一体/餌種セル一つにつき寄生状態一件、セル外繁殖体候補もセル一件。二系統が同時候補になったら初期値で一つを選び、重複重症化や増殖配列は作らない。寄生系統数と宿主数の全組合せ走査、全伝播経路の履歴保存は避ける。主役人口と寄生状態件数は別に数える。

## 7. 光合成型と特殊な生物

| 生態 | ゲームへ取り入れられる関係 | 初期の扱い |
|---|---|---|
| 光合成型 | 固定の光条件からEを得る生産者 | 植物共生を第一候補。別途増やすより既存系統の個性へ接続 |
| 混合栄養型 | 光でも採食でもEを得る | 光合成型の拡張。両方で無制限に得をしない上限が必要 |
| 化学合成型 | 固定地形の化学資源を消費してEを得る | 腐食域/熱域と接続できる将来候補。環境名だけで無限Eを生成しない |
| 光合成共生 | 宿主へ光由来Eを渡し、その代わり栄養を受け取る | 寄生とは別の相利共生候補 |
| 分解者 | 死骸/有機物の分解に関わる | 既存の有機粒/菌膜へ接続。死骸の無条件生成はしない |
| 捕食寄生者 | 成長後に宿主を死なせる生活史 | 後順位。通常寄生と同じものとして扱わない |

| 行動操作する菌類 | 宿主内で進行し、固定の放出条件を得る | 別系統候補。寄生虫と真菌の生物学上の分類は区別 |
| ウイルス様の感染体 | 宿主内でのみ増え、接触で伝わる | 複数宿主生活環とは異なるモデル。初期の寄生2系統と混ぜない |

これらは実在の生態から得られる着想の分類で、実際の生物全てが宿主操作/複数宿主を持つという意味ではない。複数宿主を渡る寄生、捕食寄生、相利共生を区別する。

### 光合成の最小案

植物共生のE供給を採食なしで維持できる形へ変更する案。固定セルの光量0〜1からE＝1.5×光量×相係数を得る（係数I1/II1.1/III1.2/IV1.3）。初期光量は環境/固定障害物から決め、日照の時間変化や毎ターンの影計算は入れない。

光からEは得られても鉱物Mは作れない。必要なMは所在セルの鉱物資源から受動吸収しqを消費する案で、採食の最大2単位と合わせて一ターンの資源取得上限を守る。Gは光由来のE余剰と鉱物の両条件で得る必要があり、無料でE/G/M全てを増やさない。最小草案は、当該ターンに光由来Eを実際に得た場合に限り、採食後/費用支払後にE≥60かつM≥0.1ならE1/M0.1を消費してG1、1ターン一回までとする。相のG/M閾値や繁殖材料は別に必要。光による容量超過Eは貯めない。

「餌不要」は有機餌を食べなくてもE維持ができる意味で、光も物質も不要という意味ではない。移動/戦闘/密度負荷で消費が供給を上回れば採食が有利になる混合栄養は別設定にする。現行の植物食効率/繁殖特性との重ね掛けは再調整する。

## 8. 確定イベントから作るモーション

| イベント | 表現案 | 誤解を避ける条件 |
|---|---|---|
| 移動 | セル間の短い滑走、系統に応じた揺れ/伸縮 | 二歩は通過点を経由。演出の途中位置を生態計算へ戻さない |
| 攻撃 | 対象方向へ突き出す/放つ予兆と、損害が出た時の反応 | 実際の対象・成立・損害を使用。未採用の遠隔攻撃を見た目だけで追加しない |
| 捕食/採食 | 餌への伸び縮み、粒の取り込み、消費量に応じた短い明滅 | 最大二単位の採食を一イベントにまとめ、実際の餌消費だけ表示 |
| 防御 | 輪郭を閉じる/殻や光膜を強調 | 防御姿勢と実軽減を区別し、無敵に見せない |
| 繁殖/出生 | 両親と空き出生先に短い発光 | 成立した出生だけ表示。親の重なりや一セル複数主役は描かない |
| 進化 | 同じセル内で形を切り替える | 生態上の強化はターン確定時。長い演出で他個体の時間を止めない |

| 光合成 | 低頻度の小さな光粒/発光 | 実際に得たEがある時だけ。常時高負荷な粒子は不要 |

各個体の直近一ターンの確定イベントを固定数で持ち、移動/攻撃/採食/出生等をまとめ最大4件の表示レコードとする案。余分な履歴は保存しない。描画のために生態の乱数を引き直さない。

遠景は点の位置変化/短い明暗、中景は簡略変形、近景だけ詳細動作。詳細モーションは選択個体と画面内の一部へ優先し、例として同時上限128体から計測する。これは表示上限案で人口制限ではない。上限外の個体も動き/採食/戦闘の計算は同じ。

進行が描画より速い時は古い演出を間引き最新の確定状態を表示する。一時停止/倍率変更/設定によって結果を変えない。動きを抑える表示設定も候補。アニメーションに合わせたターン停止や、攻撃モーションを再生しただけの損害発生は禁止する。

## 10. 追加の確定条件

### 食物網の調停と資源の扱い

餌生物の2ターンごとの局所採食は主役の意図選択より前に確定。成立中の餌生物セルは消失/移動の調停を経て一セルにつき植物q一単位まで取得する。新規B3誕生候補も同じ一単位予約を必要とし、取得できなければ誕生しない。誕生セルを同ターンの維持対象に再び数えない。複数候補は一つの植物単位に初期値由来優先値を付けて競合を解決し、消費後の植物を主役の入力へ渡す。植食によって植物セルqが0になれば次ターンのCAでは空となる。

これは抽象的なCA供給＋局所採食モデルであり厳密な閉鎖系ではない。生物学的な収支保存を検証済みとはしない。

### 寄生の開始・分岐・負担

初期感染は適合する既存第一宿主セルの5%を目標として初期値で選ぶ草案。寄生OFFなら一切付けない。割合不足でも餌を生成しない。初期感染も滞在0から始まり、成熟を前借りしない。第一宿主/中間宿主の最低期間を満たさず食べられた場合、その摂取では寄生移行不成立。伝播時は次宿主の滞在0へ戻し、同じ確定イベントを二度使わない。第一宿主の資源が失われればその感染状態も消える。

感染は資源セル全体の有界な負荷状態であり、実際の寄生虫一匹ずつの個体数モデルではない。残る感染資源から複数回の感染が起き得るが、受け手の一件上限は維持する。寄生系統を画面上で一匹ずつ数えた実装とは扱わない。

移動型分岐の宿主補正は探索性+3/危険回避−3、定着型は資源欲求+3/場所愛着+3を初期案とする。主役にだけ9値の補正を使う。潮環の水辺選好は見える水域への移動候補に最大+0.1、葉環は所在セルの植物資源候補評価に最大+0.1。小型餌生物では同じ局所セル項だけを最大+0.1追加し、基本の逃避条件を無効化しない。寄生があるだけで不正な通行や相手の攻撃を命令しない。

宿主負担E0.2は一度だけ主役の維持負荷へ加え、支払えなければ既存の不足HP規則を適用する。終宿主の成熟時間は負担を支払えたターンだけ進む。植物/餌生物には主役Eを新設せず、寄生負担の個別代謝は初期版で抽象化する。寄生が終われば有効値への一時補正を除き、寄生を受けたこと自体の恒久学習は行わない。

### 光合成と受動材料取得

光によるEは維持費の前に一ターン一回だけ加算し、全体の確定順へ追加する。E上限を適用してから支払い可能額を評価する。光量は固定の入力であり、外部からのエネルギー供給として明示する。光合成係数と既存固有食性補正を二重に乗算しない。

材料の受動取得は所在セルの鉱物片/鉱液滴を一単位まで、採食確定段階で消費する。通常採食と共有する二単位上限のうち一枠を使い、既存M吸収を適用する。同じ単位を採食と受動取得で二度使わない。有機餌なしでE維持/成長の道を持つが、暗所/材料不足で停止する。植物共生は必要なら従来の採食も利用できる光合成主体の混合栄養を初期案とし、採食完全禁止の独立栄養専用型は別候補にする。

### 追加処理の順序

餌CA/餌生物の採食・移動/餌経由寄生移行→光E供給→主役の意図・移動・戦闘→通常採食/受動材料取得・主役への感染→維持等の支払い・死亡→感染負担の支払い結果による成熟/宿主分岐・本人の実成果/学習・光成長・進化→出生→終宿主の伝播候補→ターン確定/表示イベント、を追加草案の順序とする。

新規感染の負担/操作/成熟は次ターンから適用し、付いたそのターンに遡って宿主の行動や費用を変えない。宿主が死亡した場合は内部寄生を破棄し伝播候補を作らない。寄生による一時的な行動補正は親から子へ継承せず、情報内容には元の9値を書き換えたものとして転載しない。宿主自身が実際に得た行動成果の学習は通常通り。

成長は一ターン一相、繁殖は双方III以上、1マス1主役、画面内外同則、固定環境を維持する。全項目が未実装であり、生活環成立率/過剰伝播/光合成の優位/描画性能は未検証。
