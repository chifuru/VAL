# 第2組：寄生の生活環・宿主選択・遺伝適応・抵抗

現在の具体化は[境界規則・比較開始値/1](initial-comparison-v1.md)へ採用済み。宿主移行/Q随伴・同ターン死亡/羽化の優先順位、適応/変異/抵抗、羽化費/再準備/成功率、初期Q20%と内訳の比較開始値は同書を優先する。本書の未選定記述から同書の選定済み範囲を除く。Pの二系統×A/B/C形態×I〜III、QのI〜III/最終IVの造形は[造形対応/1](appearance-correspondence-v1.md)へ採用済み。形態/本人の相/宿主段階を別軸とし、形から感染経路や飛翔を追加しない。ゲーム実装/実測は未完。

## 1. 結合と感染の段階

物理的結合は生物H→一次寄生P→高次寄生Q。直接の宿主はPにとってH、QにとってPであり、情報発信元Hと混同しない。一宿主一P群体、一P一Q群体を維持し、同セルの別生物は別の宿主として扱う。宿主/群体IDを移行で再発行せず、移行と新しい子群体の感染を区別する。

Pの処理は曝露→経路適合→侵入→定着→発育→伝播/繁殖。曝露量0や不適合なら感染抽選へ進まない。適合後も侵入/定着/発育は別条件で、単一の感染成功確率へ潰さない。宿主は寄生系統/経路/段階との組合せにより、発育可能・運搬のみ・行き止まり・非宿主に分かれる。定着を成熟/次世代成功として数えない。

接触/捕食/死骸/水媒介の適合、感染力、防御/抵抗、有限栄養/量/時間を通す。同じ感染体を複数経路で重複使用せず、新規感染が同ターンに再放出する連鎖を認めない。

## 2. 宿主選択と実際の適合

| 状態 | 選択に使える仕組み |
| --- | --- |
| 宿主内P | Hの実在する移動/採食/接触判断へ有限の一時誘導を加え、次宿主へ移る機会を偏らせる。P自身が自由歩行して宿主を乗り換える仕組みは追加しない |
| 水中感染体/死骸内P | 基本は受動的。届いた相手との経路/宿主適合で判定し、全盤面の好適宿主を探索しない |
| 自立Q | 実際に感知できる宿主系統/状態/接触経験/局所的手掛かりから探索・接近・産卵先を評価する |
| P内Q | 現在のPへの投資/発育を継続する。任意の別Pへ自由に乗り換えない |

宿主の好みは遺伝傾向＋生活環段階＋栄養/危険＋本人経験/受容情報から生じる。好みと遺伝的な適応は別変数で、「選びやすいが感染できない」「感染できても発育できない」「適合するが選びにくい」を認める。Qの歪曲情報も既存の局所受容条件を通って選択へ影響し得る。

計算側の適合表や感染窓の判定は、生物の完全な知識ではない。相手の遺伝子/内部栄養/正確な成熟時刻を透視して選ばせず、未観測を確実な手掛かりへ補完しない。合法行動・感知範囲・予算・競合を通る。

## 3. 寄生先ごとの遺伝的適応と世代強化

| 遺伝形質 | 高適応時の作用 |
| --- | --- |
| 宿主系統への侵入/定着適応 | 適合する相手に対する侵入・定着成功率を高める |
| 感染経路への適応 | 得意な接触/捕食/水媒介等の試行コストを低くする |
| 宿主内発育への適応 | 維持/発育に必要な栄養を減らし、発育完了へ到達しやすくする |

PはH、QはPへの適応を持つ。キーは宿主系統/感染経路/生活環段階であり、特定の宿主個体IDや成功履歴は遺伝しない。選択の好み、体外耐久/放出、誘導/情報加工への配分も別の形質として継承できる。

子は親の適応を基礎に小さな変異を持つ。実際に繁殖/次世代定着へつながった適応が子孫に残ることで世代を通じて強化/特化される。感染成功のたびに全能力を自動加算したり、親の獲得学習/後天抵抗をDNAへ書き戻したりしない。固定DNAは出生後に経験だけで書き換えない。

費用は基本費用×有限な適応係数、成功率は適合後の基礎条件/曝露量/遺伝適応/宿主防御/獲得抵抗から算定し0〜1へ制限する。維持/活動費を0未満や無償へ落とさず、適応値に上限と得意不得意を設ける。万能型を無料生成しない。非宿主、到達不能な経路、Qの窓外を高い適応値で迂回しない。初期形質表、係数の下限/上限、変異幅/率はこちらが比較用に用意し、観察調整する。

## 4. 再寄生への獲得抵抗

HがPへの対処/排除を実際に経験すると、その系統・近い感染経路に対する後天的な抵抗を得る。PがQを排除した場合も、直接宿主Pの抵抗として扱う。単なる接触/不適合/情報読取だけで排除成功を捏造しない。

抵抗は再侵入/再定着/宿主内発育を難しくする。近い相手への交差抵抗は有限とし、無関係な全系統への完全免疫にはしない。時間で弱まり、維持/排除には実在する有限栄養を使う。生得的な防御や寄生側の遺伝適応と別に保持し、排除直後に寄生し直すだけで毎回容易に再成立しないよう比較する。正確な減衰/交差範囲/費用は観察調整対象。

排除後の再曝露も侵入/定着の新判定を通す。感染済み対象への追加曝露を無制限な別群体へ変えない。抵抗獲得や宿主移動/栄養停滞でQの感染窓を延長・再開しない。後天抵抗を子へ直接コピーせず、子の生得防御は既存の遺伝規則に従う。

## 5. 捕食・死骸・川辺を通る連鎖

感染生物/感染死骸の捕食→感染可能量の取り込み→経路/宿主/段階適合→侵入/定着→発育/次段階→放出/再感染をつなぐ。食べた量/死骸の量と感染性は別で、部分採食や複数捕食者へ同じ感染量を複製しない。

川辺では、適した生活環段階の宿主死亡/成熟放出から感染体が水へ移り、滞留/局所拡散/取り込みへつながる。死亡/産卵/放出/感染は別の成立条件と費用を持つ。川辺へ必ず移動する、死亡すれば必ず放出する、水に触れれば必ず感染するという命令にはしない。水媒介を利用しない生活型へ同じ能力を付けない。

体外感染体はセル×寄生系統/形質型の有限量/感染性/期限へ集約できる。個体・寄生中群体・情報量と別集計にし、移送は同期更新して量/期限を複製しない。未定義の川の流れを捏造しない。死骸の残存と感染性の残存を分け、旧4T/12Tは比較開始値であって新適応全体の固定寿命ではない。

## 6. Qの四相とPを殺す羽化

基本環は自立成体の探索/産卵→適合P内の卵/幼生→寄生成長→羽化準備→P死亡と離脱→第四相の自立成体。新しい子群体は第一相から始まり、親の第四相/成熟年齢を継承しない。Pの三相を比較開始案として維持し、Qは四相とする。相を増やしても一般主生物の3→6分岐をQへ機械的に付けない。

| Qの相/状態 | 条件・意味 |
| --- | --- |
| 第一〜第三相 | P内の成長/作用の発達。卵/幼生/羽化準備という生活状態と別に持つ |
| 羽化開始条件 | 第三相到達、Q自身の年齢による成熟、発育完了、必要栄養蓄積、Pの抵抗への対処を満たす |
| 羽化失敗 | 活動費を消費し、停滞/再準備。次の試行にも時間/栄養/再成立条件が必要で、毎ターンの無償抽選にしない |
| 羽化成功/第四相 | 直接宿主Pを殺し、同じQが離脱して自立成体になる。生物Hを直接殺さない |

通常生物の進化相と年齢は別という原則を維持するが、Qの第四相だけは成熟＋羽化を必要とする例外。相の成長実績・年齢成熟・発育進捗/栄養を別変数にし、ひとつのカウンタへ潰さない。羽化しても出生時刻/年齢/固定寿命基準をリセットせず、長い寄生期間は残る自由生活期間を短くし得る。

新規Q感染は、適合Pが終宿主内で初めて成熟したTに対してT+1〜T+3の既存窓を維持する。窓は新規侵入の条件で、定着済みQの発育は窓終了後も続けられる。成熟時刻を再発行せず、P娘群体は別IDで自分の生活環を通る。

成功した羽化ではP死亡/付随関係解除/Qの第四相・所在更新を一つの確定遷移として扱う。通常のP死亡に伴う付随処理が、羽化に成功したQを同時に死亡扱いしないよう区別する。一方、羽化成功前のH/P死亡を自動的な救済羽化にしない。P消失時はHへの直接誘導/徴収を終えるが、過去の損失を即時全回復させない。Pの死亡/情報候補等は一回だけ処理し、成功羽化によるH死亡や二重生成を追加しない。

離脱時点までにH/Pへ残ったQ痕跡と、Hの既存学習は第1組の時計/上限で存続する。Pを殺すこと自体をHの情報生成と数えず、Qが離脱後に新しい遠隔加工を続ける能力にはしない。

## 7. 栄養・作用・相互競争

HはPの維持/発育/繁殖の負担を、PはQの維持/発育/羽化準備の負担を負う。相が進めば作用上限と必要維持栄養が増え、強い誘導/情報加工/感染体放出/羽化試行は追加活動費を要する。遺伝適応/現在栄養/抵抗/負荷で実効費用と作用が変わり、同じ費用を二重請求しない。

PはHへの比較的強い一時的なメタ誘導、QはPへの小補正と死亡情報の出現促進/歪曲を主とするメタメタ操作。直接補正/受取学習/場所刺激/情報痕跡を区別し、恒久能力/DNA/世界ルールを上書きしない。情報の作用範囲/根拠/時計は第1組を維持する。

Pが早く死ねばQも羽化前に失敗し得る。抵抗を維持するH/Pにも負担があり、強い排除が常に無条件の最適解ではない。Pは次宿主/繁殖機会、Qは適合P/産卵機会を巡って競争し、全員の適度な生存は保証しない。Q羽化でPが減ることが、Hの負担軽減に間接的につながり得る。

第四相Qは局所移動/採食/回避/被食/産卵を行う。食性は既存の有限な微量有機物利用型を比較開始案とし、実在する資源と収支へ対応させる。情報は全生物に非栄養で、情報摂食や無料維持を復活させない。主生物の攻防/有性生殖を一律に付けず、既存の無雌雄・群体単位を維持する。生活状態ごとの所在/容量/費用等の細部はこちらが比較で選ぶ。

## 8. 初期配置・観測・保存

Pは適合する中間宿主内/終宿主内/成熟前後へ分散し、Qは寄生中と第四相の自立成体を分ける。初期Q数は実在する適合Pと生活環を支えられる条件へ対応させた少数とし、固定の大量探索群体を一律投入しない。宿主不足を強制追加や進行中の無親補充で隠さず、固定0/無効指定も尊重する。

初期の相/年齢/発育/栄養/成熟時刻/感染窓/所在を整合させ、初期状態と開始後の達成イベントを分ける。開始時に置いた第四相を実測した羽化成功へ数えない。生成不能な条件を黙って変更せず、全実効値と初期配置を保存する。正確な比率/相別閾値/費用/感知手掛かりの表は未選定で、こちらが候補を用意し実際の動きで調整する。

観測は曝露/不適合/侵入失敗/定着/排除/再感染/発育停滞/宿主間移行/放出、Q羽化試行/失敗/成功・P死亡・第四相生存/産卵/子の再定着を経路/系統/相別に区別する。宿主の好み、遺伝適応、獲得抵抗とその実費、直接誘導/情報作用を混同しない。初期数・寄生中・自立成体・体外感染量を分け、Q総数を常時P以下へ強制して羽化成功を消す処理は行わない。

定義/係数版と実効値、形質型/親由来/変異、抵抗の対象/残存、生活環段階/相/年齢/発育/成熟時刻、H/P/Q参照/所在、羽化結果/費用、感染体の量/期限を保存する。現状態と確定ターン集計/少数由来を用い、全個体の全行動履歴や全宿主対探索を追加しない。再生/保存で抽選/変異/成熟窓を再抽選せず、旧欠測を補完しない。
