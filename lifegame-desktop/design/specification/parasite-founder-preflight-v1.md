# 寄生群体の初期配置と宿主数の整合 / 1

現行primary/1では、直接指定したPは第一宿主へ1群体ずつ配置する。群落の栄養量や小集団の内部人数を宿主枠数へ換算しない。既存の宿主表を参照し、UIに別の宿主定義を複製しない。

- 生産者群が無効なら、直接指定Pの配置可能第一宿主は0。全対応宿主が数指定済みなら、その合計を必要条件の上限とする。
- 自動配置の宿主が含まれる場合は正確な枠数を推定しない。既知の直接指定数を超えるだけで拒否しない。
- 不整合は設定内に説明し、作成ボタンを無効にする。0/空欄、群の再有効化、宿主数修正で解除する。値は保持し、自動で寄生数/宿主数/生態条件を変更しない。
- 地形生成後にだけ分かるP不足は、既存生成の反例を利用して対象欄へ案内する。自動の宿主数が候補ごとに変わるため、直前の実数を普遍的上限として固定しない。
- Qの自立成体をP数0だけで禁止しない。通常の感染率・初期配置・乱数・保存形式は不変。

範囲は既存B5/C8/D9/E6。新Node/分割・A変更・正式状態変更なし。全地形容量の事前保証ではない。中断中の速度変更は対象外。
