# 第1組：情報の生成から消失まで

> 現在状態への集約は [current-state/1](current-state-aggregation-v1.md) を優先する。由来ごと一度/2由来枠・長い経験列/受信列・残存100〜200T・Qの旧残留保持を置換する。生成時の実績/非栄養/開始受容→末尾生成→次T作用の境界は維持する。 本文の旧条件はこの明示範囲を除いて適用する。新正本はA/B反映のみ・未実装/未実測。

仕様版 `information-cycle/1`。利用者が一括案と近傍集中の修正を採用した暫定仕様。C01〜C05を維持し、C02/C03の計算方法、C06のQ痕跡、C10/C11の利用/局所更新をまとめる。既存の[持続情報](persistent-information-v1.md)・[評価](information-evaluation-v1.md)・[鮮度](information-freshness-v1.md)・[生成](information-generation-v1.md)・[Q歪曲](q-information-bias-v1.md)のうち、本書が明示的に具体化した部分を優先する。細かな値は実際の動きで調整する。今回は文書反映だけで、新モデルのゲーム実測はない。

## 1. 実績評価と死亡時の生成

各軸は本人の確認済み実績を系統/生活様式/役割の基準量で割り、0〜1に制限する。生存維持A、役割成果B、関係継続/世代更新Cとして、S=0.4A+0.4B+0.2C（0〜1）とする。集団内順位や将来の勝者から評価しない。実在しない捕食/出産等を要求せず、未観測を成功/失敗に補完しない。役割別の基準量/対応表はこちらが第2・第3組と合わせて初期表を用意し、比較観察で調整する。

通常候補は同内容の本人実経験3件以上/異なる2ターン以上、保持伝達資格は6件/3ターン。通常候補の基礎出現率はpBase=0.10+0.60S。確認済み被害痕跡は下限0.40を維持し、歪曲内容や老衰/原因不明はこの根拠にしない。Qの費用/上限付き補正は別要因とする。候補がなければ基礎確率を割り当てない。

通常確率pNを優先し、根拠不足候補がある場合のみpL=min(0.05,1−pN)、なければ0とする。一死亡最大1件/一回抽選、被害下限を使った生成は実被害痕跡を含める。根拠不足の初期判断重みは通常の半分。低根拠・本人実績・Q加工・真偽を別にし、無作為反転/架空経験は追加しない。

環境痕跡の残存期間はL=100+100Sターン（整数ターンへ四捨五入）とし、生成時に期限を固定する。S=0.6なら基礎出現率46%、残存160ターン。高実績は出現/残存を優遇するが、内容を常に正しい/最大作用へ変えない。容量/局所失活で早く消えることはあり、最低100ターンの残存保証ではない。

## 2. 鮮度と個体の学習

鮮度係数はF=2^(-a/H)。aは元経験からの経過ターン、Hは変動の速い内容25T/関係や危険50T/場所に根付く傾向100T。同じ時計へ別名で重複減衰させず、量の散逸/容量失活は別にする。死亡/読取/伝達/Q加工で元経験を若返らせない。

鮮度は新たな受容と場所刺激へ使う。既に学んだ重み全体を毎ターンこの係数で縮小したり、環境痕跡の消失だけで本人の記憶を消したりしない。本人の現地経験/既存の回帰・忘却で判断が変わる。情報は非栄養で、DNAや基礎能力を直接上書きしない。

## 3. ターン内の順序

1. 開始時：前ターンまでの環境情報の期限/量/局所更新と近傍集計を確定する。同じ開始時スナップショットから受容し、そのターンの判断へ使う。
2. 行動：既存の移動・戦闘・採食等の条件別機会と共有予算を維持する。場所刺激は候補評価の一時作用であり、毎ターンの新しい学習とは数えない。
3. 末尾：本人の実経験・死亡・Q痕跡等の確定結果と、新しい死亡情報を反映する。新情報は次ターンから作用し、同ターンの生成→再受容→追加生成の連鎖を許さない。

情報受容は移動/戦闘/採食を置き換える排他的な一行動にはしない。描画/操作/保存によってこの順序や抽選を進めない。

## 4. 受容の量・伝達比率・費用

新たに学習するのは1個体/群落/群体につき1ターン最大2由来。環境/通常個体/親養育者を合算した上限であり、5成分や複数役割へ適合した同じ由来/内容を重複適用しない。同じ情報の再読取は本人実経験や新しい学習量を増やさない。

| 伝達元 | 相対的な作用倍率 |
| --- | ---: |
| 環境情報 | 1 |
| 通常個体 | 0.25 |
| 親/実際の養育者から幼体 | 1 |

比率は成立した受容に使い、親から遠隔で伝達しない。伝達資格/実接触/養育/年齢条件、受け手の適性/感度/文脈、鮮度、低根拠の半重み、影響度kと既存受信上限を通す。通常生物すべてへ主生物の九値/攻撃/移動を機械的に付けない。学習と場所評価へ同じ補正を二重加算しない。

新しい1由来の受容費は、当該生活様式の通常維持費の1%相当を既存の有限栄養台帳で支払う。最大2由来なら2%相当が追加の目安。栄養不足なら予算条件を通し、将来の採食から前借りしない。同じ表示/再読取ごとに再請求/再学習せず、情報から栄養を取得しない。維持費の尺度は実在する生活状態へ対応させ、Q加工費等と二重計上しない。

本人経験は内容別の少数要約で保持し、受取内容と分ける。重複防止は有効期間を通じた有限キャッシュで扱う。容量不足時も、まだ有効な重複排除記録を捨てて同じ由来を新情報として再学習させない。必要なら新規学習を制限する。容量/受容候補の優先度は実装比較/観察で調整し、全履歴保存や全個体対検索は追加しない。

## 5. 局所拡散と保存容量

1ターンの移送は隣接1マスまで、情報量の最大20%を近傍へ移す。移送前の量を元に同期更新し、由来・元経験時刻・生成時刻・確定期限を保持する。分割/移動で量や独立根拠を複製せず、未定義の風/川の流れを捏造しない。媒体/地形の適合、有限容量、失活等の細部は比較調整対象とする。

1マス最大4由来、1由来最大2内容とする。5成分は排他的な内容枠ではなく適用関係であり、区分ごとに同じ経験を複製しない。容量不足では保持の優先度/失活を明示し、別発信元の実績/時計を混ぜて架空の優良情報を作らない。微小量失活や保持優先度の具体値はこちらが観察で調整する。

## 6. 近傍一帯での集中

集中は同マス＋周囲2マス（最大5×5、斜めも含むマス距離）を対象にする。

| 中心からの距離 | 集中への重み |
| --- | ---: |
| 同マス | 1 |
| 隣接1マス | 0.5 |
| 周囲2マス | 0.25 |

情報量・鮮度・意味/文脈/適用条件の一致と距離重みを使い、由来ごとに集約してから局所集中を評価する。同一由来の断片は量として合算できるが独立した根拠は一つ。異なる実経験が近隣で重なれば、同じ意味/文脈の根拠として強まる。読取/コピー/Q加工件数を新しい根拠へ数えない。

集中による場所刺激の増幅上限2倍は、近傍全体の集計後に一度適用する。セルごとに上限を掛けてから足し合わせ、全体上限を超えない。具体的な単調増加/飽和曲線は観察調整対象。1マス4由来の保存上限と、近傍から参照する由来の数を混同しない。

誘引/警戒や異なる意味の内容は別々に集計する。「豊富だが危険」を単一の正負値で相殺しない。近傍集中を感じることと、個々の内容を読み取って学習することは別で、学習の最大2由来/Tや到達/受容条件を迂回しない。場所作用は根拠のある元の場所/近傍に結び付け、拡散先の餌/安全/危険を自動的に証明しない。

情報更新時に影響範囲の局所集計を作り、個体は参照する。毎個体で全盤面/全情報を再探索せず、変更セルと近傍の差分/索引を使う。表示軽減やカメラ操作は計算定義を変えない。

## 7. 複数Qの痕跡

情報発信元1体に最大2つのQ由来痕跡を保持する。直接P/発信元/加工Qを別に記録し、一P一Qという同時容量や既存の感染適合/成熟窓は変えない。順次寄生はそれらの条件を通った場合だけ成立し、痕跡を残す規則から再感染窓を延命/再開しない。

同じQの有償更新は一つへ集約して飽和させる。3つ目が来たときは、支払った活動費に裏付けられた実効強度が高い2つを残す。単に新しいだけで旧痕跡を無条件に消さず、強度の算定/同値時の安定した優先度はQの相別表と合わせて観察調整する。

同じ内容への加工は上限付きの加重平均とし、痕跡数で2倍/無限に加算しない。逆方向なら同じ評価の歪曲は相殺し得るが、別内容の誘引と警戒を混ぜない。出現促進と内容歪曲も別に合成し、元の実績/被害/親子/scope/時計を書き換えない。具体のQ上限/相別費用は第2組で設定する。

Qの離脱/死亡時の残存強度を基点に、その後は半減期50Tで弱まり、100Tで失活する。寄生中の更新は活動費を支払い、離脱/死亡後に新しい遠隔加工はしない。発信元の死亡で情報生成に成功した際、その時点の歪曲を生成情報へ固定する。生成後は通常の情報鮮度で減衰し、離脱後の痕跡減衰を同じ効果へ再度掛けない。元経験の時刻/生成情報の期限は更新しない。

## 8. 観測・保存と次工程

定義/係数版と全実効値、役割別基準量/S/確率/期限、受容数/伝達元/費用/重複抑止、拡散量/失活/容量、近傍の由来/集中と個別受容、学習/場所刺激、Q痕跡/合成/時刻/実費を区別して記録する。旧記録の欠測を新定義で補完せず、保存再生で抽選/時間/加工を進めない。既存3グラフ/一体サマリ・全確定ターン原値を維持し、新常設グラフを増やさない。

実装/観察では同初期条件を使い、通常/情報作用なし/Q加工なし等の既存比較へ接続する。出現率/密度/寿命、再読学習の抑止、近傍反復と同由来拡散の違い、誘引/警戒、親養育者/通常伝達、Qの競合/離脱後残存、受容費と生存/世代更新、処理負荷/保存再生を確認する。単一の結果や情報量だけで利益/創発/因果を認定せず、R1〜R6と既存の固定比較を維持する。今回は観察計画の記録だけで製品実測はない。

第1組は暫定採用済み。系統/役割別の基準量、集中曲線/微小量失活/容量競合、有限キャッシュ等はこちらが実装比較/観察で調整する。意味/上限/再現性を変える必要がある場合だけ利用者へ確認する。第2組の寄生生活環/遺伝適応/抵抗/Q第四相は[第2組・寄生生活環/1](parasite-lifecycle-v1.md)へ採用済み。第3組の群落更新/独立四相植物は採用済み。第4組の状態/計数/表示/保存対応は採用済み。次は初期比較表と実装差分/データ対応・C/D接続要否の整理。今回は3core・C/D/E・src/tests・画像/配布物・製品4.2.32を変更しない。
