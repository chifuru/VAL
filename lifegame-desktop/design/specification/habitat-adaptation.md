# 系統別の環境適性・地形・障害物（A1.2 / B4 / B5）

ユーザー指定：環境により戦闘力・防御力・移動のしやすさが系統ごとに変わる。得意・苦手環境を設け、4環境以外の地形・障害物も扱う。以下の割当・計算方法はA/Bの提案であり、実装済みの規則ではない。

## 各マスが持つもの

| 項目 | 役割 | 例 |
|---|---|---|
| 環境 | 生息条件と餌の成立条件 | 水域・熱域・情報域・静域 |
| 地形 | 足場・水深・勾配などの移動条件 | 平地・岩場・浅瀬・深水・ぬかるみ・崖 |
| 障害物 | 進入・経路・遮蔽に作用 | 大岩・倒木・茂み |
| 資源 | 採食可能な餌と成長調整入力 | 生命・鉱物・情報・数字。四つとも消費対象で、作用は基盤仕様で検討 |
| 個体 | そのマスを占めるFizzBuzz生物 | 最大1体。系統・相・枝・雌雄・DNA・現在状態 |

環境作用も近傍セルで更新する案とし、[最新基盤仕様](life-rule-foundation.md)で地形との関係を定義する。四つの背景領域へ固定分割しない。一続きの背景上にマス単位で持つ。岩場は熱域にも静域にも存在でき、情報域のぬかるみ等も表現できる。ただし深水は水域など生成時の整合条件を設け、成立しない組合せを無作為に作らない。4環境の追加を自動的に決めた仕様ではなく、その上に地形・障害物を設ける。

## 攻撃・防御・移動を独立に扱う

- 基礎DNAと相・分岐から求める能力を基準とし、現在の環境と系統の組合せで攻撃・防御にそれぞれ補正を掛ける案。得意環境でも全能力が一律に上がるとは限らない。
- 攻撃は攻撃者の所在マス、防御は対象の所在マスを使う案。同じ環境へ攻防両者を置き換えて計算しない。射程・遮蔽は両者の間の地形も参照する。
- 移動は進入先の環境適性、地形、経路上の障害を使う。移動のしやすさはまず消費エネルギー・移動コストで表す案。速さや移動回数を同時に重複強化しない。
- 「得意」は補正、「進入不可」は制約。環境適応を積むだけで大岩をすり抜けたり、崖を飛び越えたりできることにはしない。
- 同系統でもDNA・成長・枝で程度は変わるが、基礎DNAは書き換えない。機動・適応の経験は苦手環境での消耗を緩和する方向を候補にし、際限なく全環境が得意になる仕様にしない。
- 雌雄で一律に環境適性の優劣を設けない。

概念式：実効攻撃＝成長後の攻撃×系統と環境の攻撃補正。実効防御＝成長後の防御×系統と環境の防御補正＋方向に対応した遮蔽効果。移動消費＝基準消費×系統と環境の移動コスト×地形コスト。通行可否を先に判定し、不可を単なる高コストへ置き換えない。係数・上下限・遮蔽との合成は未確定。

## 地形と障害物のルール案

| 要素 | 移動 | 戦闘・観測 |
|---|---|---|
| 平地 | 基準 | 遮蔽なし |
| 岩場 | 系統ごとに足場コストが異なる | 岩陰がある方向だけ防御に寄与 |
| 浅瀬 / 深水 | 水生系と陸上系でコスト差。深水への進入資格は要検討 | 水深への適性を攻防の理由として表示 |
| ぬかるみ | 重い体と湿地適応系で差 | 防御を自動強化しない |
| 崖 | 高低差のある境界を通行不可とする案 | 高所攻撃の追加は未決定 |
| 大岩 | 占有セルへ進入不可、迂回 | 直線上の攻撃・視認を遮る案 |
| 倒木 | 低い障害として移動コスト増 | 完全遮蔽にはしない案 |
| 茂み | 系統により移動コスト増減 | 視認と遮蔽に作用。射程攻撃の扱いは未確定 |

斜め移動で接する二つの通行不可セルの間をすり抜けない案。複数マス先に移動できる場合も中間経路を確認する。出生先も地形と障害物による進入・生存条件を満たす空きマスに限定する案。

## 分岐と表示への接続

機動・適応の「地形適応」は特定の地形・環境での移動、採食、生存の成果を使う。「広域探索」は通行可能な新しい場所への移動成果を使う。歩数だけ、移動失敗だけ、苦手地形に居続けるだけで進化しない。戦闘の経験は補正後に実際に成立した攻防を記録する。

B4：移動前の通行可否、移動先コスト、攻防双方の所在環境・遮蔽を判定し、結果を記録する機能案。

B5：全体マップ中心の画面を維持し、環境・地形・障害物・餌・個体を見分けられるようにする。選択マスの環境、地形、障害と、選択個体の攻撃・防御・移動の有利/標準/苦手、その理由を表示する。同じマスで別系統を選ぶと結果が変わることを参照できる案。

B5.2：環境適性の説明を既存シートへ追加。生まれ持った適性、後天的な適応、今いる場所の一時補正を区別し、系統樹の分岐理由へ戻れる。

[全体マップ静止画](habitat-overview-mock.png)は表示提案。数値・配置・経路・補正は実測ではない。画像中の細部より本仕様を優先する。具体係数、進入資格、視線・射程、環境遷移は未確定。

## 環境隔離を避ける最新案

[局所戦略仕様](local-strategy.md)により、苦手環境そのものは進入禁止・即死条件にしない。上表の深水等はコストの差とし、地形による絶対的な生息隔離は初期案へ追加しない。大岩・崖などの通行制約は別に保つ。数字・情報などの共有資源を巡る接触を可能にする。
