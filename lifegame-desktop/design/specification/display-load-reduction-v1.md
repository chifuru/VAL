# 処理軽減欄：見た目と生態を保つ表示設定

## 適用

仕様版 `display-load-reduction/1`。A2/B5/B5.3/B5.5の既存責務内で扱う。製品4.2.32の既存最適化は維持し、本書の設定欄・プリセットはA/B反映段階、未実装とする。新Node/分割/正式状態変更なし。生物をまとめる集団化・個体数の自動削減は採用しない。

## 1. 操作と設定

既存の表示チェック欄の近くに「処理軽減」を設ける。名称/状態/モーション等の既存設定と同じ値を操作し、矛盾する二重のチェック状態を作らない。通常・最大軽減・個別設定の実効状態を短く示す。個別に変更したら「個別設定」とし、通常へ戻せるようにする。

| 省略/更新項目 | 個別設定 | 最大軽減時 |
| --- | --- | --- |
| 移動補間・身体のモーション | 省略可能 | 省略。確定位置の詳細画を表示 |
| 粒子・軌跡・発光等の追加演出 | 省略可能 | 省略 |
| 成立した行動のマーク | モーションと独立してON/OFF | 簡潔な静止マークはON |
| 主生物以外の名称札 | 既存の分類別ON/OFFと同期 | OFF |
| 追加の常時状態札 | ON/OFF。選択詳細の値は維持 | OFF |
| グラフ・関係図の描画更新 | 通常/低頻度 | 最大1回/秒、最新値へまとめて更新 |

最大軽減でも主生物の識別に必要な記号/造形、対象位置、選択中の情報と所在強調は維持する。行動マークも不要なら個別にOFF可能。手動停止/終了/選択時は最後の確定値を表示し、グラフの表示遅延を取り残さない。設定変更だけで観察を停止しない。

## 2. 省略しないもの

- 近景の生物原画・相/枝/雌雄/年齢差、地形の質感と奥行き。最大軽減だけを理由に近景を記号化しない。
- 遠景の既存記号形式と全位置の把握。遠景での強制記号化と、近景で利用者が選ぶ簡略表示は既存の独立設定を維持する。
- 生態計算の個体数・行動・収支・出生・死亡・寄生・情報作用・乱数・ターン。生態を間引かない。
- 全ターンの観測原値と保存/CSV/JSON。描画更新頻度と収集頻度を分離する。
- 盤面・一覧からの選択、個体説明、ヒット判定、同居の識別。名称札を隠しても対象を消さない。

## 3. 陰影・再利用

背景と接地の陰影は既存素材/事前生成画像/キャッシュで保持し、毎フレーム盤面全体へ暗色マスクを重ねる方式へ戻さない。既存の基本背景＋候補地物/接続部材、固定区画、縮尺別画像、位置索引、事前準備を再利用する。表示切替やカメラ操作で生態乱数を消費しない。

## 4. 後続の確認条件

同じ初期条件・同じ確定ターンで、通常/最大軽減/個別設定の世界指紋・全ターン原値が一致すること。近景原画の維持、遠景記号の維持、名称/モーション/マークの独立性、通常への復帰、停止/終了時の最新表示、別設定からの同期を確認する。小中大・遠近でフレーム時間と長い停止を比較し、効果は実測値で報告する。全PCでの改善や無停止を未実測のまま保証しない。
