# 初期配置モードと参加系統

ユーザー指定：初期配置の偏りは許容し、偏りなしモード・系統少なめモード等の設定で制御する。A/B草案で、実装・配置成立率・バランスは未検証。本書を初期配置の最新仕様とし、全20系統の同数参加・資源隣接保証・異系統接触保証を一律に課す旧記述を置き換える。

## 1. 独立して設定する項目

| 設定 | 草案 |
|---|---|
| 盤面規模 | 40×28 / 80×56 / 160×112。面積と描画の既存仕様を継続 |
| 初期総個体数 | 規模の推奨値80 / 320 / 1280。4体単位で変更可能。通行可能数を超える値は入力不可 |
| 参加系統 | 全20 / 少数5 / 指定1〜20。少数は初期値で重複なく選び、手動選択も可能 |
| 系統別の初期数 | 均等 / 偏りあり。参加系統の全てを最低4体で含める |
| 空間配置 | 散開 / 自然分布 / 集中。個体数の偏りとは独立 |
| 初期資源の接触保証 | OFF / ON。ONは各初期個体の所在/8近傍の通行可能セルに基礎有機食と鉱物系が各一種以上必要 |

標準は80×56/320体、全20系統、初期数は均等、空間は自然分布、資源接触保証OFFとする。自然な餌の偏りや不利な初期位置を許容する。性別は既存の4体単位で雄2/雌2を維持し、今回新たな性比設定は設けない。参加系統が少なくても総個体数は自動で減らさず、一系統あたりへ配分する。

## 2. 組合せ済みモード

| モード | 参加系統 | 系統別初期数 | 空間 | 資源保証 |
|---|---|---|---|---|
| 標準・自然配置 | 全20 | 均等 | 自然分布 | OFF |
| 偏りなし・比較用 | 全20 | 均等 | 散開 | ON |
| 偏りあり | 全20 | 偏りあり | 自然分布 | OFF |
| 系統少なめ | 5 | 均等 | 自然分布 | OFF |
| 集中配置 | 全20 | 均等 | 集中 | OFF |
| カスタム | 指定 | 選択 | 選択 | 選択 |

モードは初期設定の組合せであり、運行中の戦略モードではない。変更後はカスタム扱いにする。「偏りなし」は系統数配分と配置手順の偏りを抑える意味で、地形・餌・雌雄接触・将来の勝率まで等しいことを保証しない。環境を均す/有利な餌を追加する処理はしない。

## 3. 個体数配分

4体を一組とし、総組数G＝初期総個体数/4、参加系統数K。G≥Kが必要で、不足時は設定不成立として説明し自動で参加系統を除外しない。

均等では各系統へfloor(G/K)組、残りを初期値による系統優先順へ一組ずつ配る。系統間の初期数差は最大4体。例：320体/5系統なら各64体、320体/20系統なら各16体。

偏りありでは最初に各系統へ一組を配り、残りG−K組を系統ごとの固定重み1〜4で比例配分する。整数部分を配った後、端数の大きい順で残りを配り、同点は初期値で決める。重みが違っても個体数が少なければ差が出ない場合がある。重みは初期人数にだけ作用し、戦略/能力/餌の発生率を強化しない。

参加しない系統は初期0体として区別し、絶滅した系統に数えない。繁殖では親と同系統のため、今回の通常則で未参加系統は途中出現しない。系統少数でも同系統は仲間で、一系統だけなら異系統戦闘は発生しない。

## 4. 空間配置

4体組は初期配置の手順だけで、永続的な群れ/一族戦略の単位ではない。各組は通行可能な3×3内に四つの位置を取り、崖境界等で相互通行が切られないことを確認する。異なる組は初期値で混ぜた配置順とし、系統ID順の場所取りを避ける。

- 散開：盤面をG個の矩形区画へ長辺方向の二分割で分ける。各区画へ一組を割り当て、区画内中心候補を初期値で選ぶ。区画内に有効候補がなければ未使用の全体候補へ移る。代替配置は開始条件の説明に残し、均等分散を保証したとは表示しない。
- 自然分布：固定環境/地形に存在する全有効中心候補を初期値で順序付け、空き条件を満たす場所へ置く。環境適性による優遇や資源隣接を必須にせず、偏りを許容する。
- 集中：通行可能な候補から初期値で3拠点を選び、各組を割り当てた拠点から近い有効候補へ優先配置する。拠点候補が3未満なら存在する数、組数が3未満なら組数を使う。系統専用拠点にはせず、異系統の組も同じ拠点へ置ける。

全モードで1マス1個体・盤面内・通行可能・初期重複なしは必須。資源保証ONだけ追加の餌条件を確認する。異系統が同じ連結領域にいること、得意環境へ配置すること、全組が近接することは共通必須にしない。地形による隔離や餌不足で早期に不利になる初期状態も許容する。環境自体の種別で移動を禁止する旧方式には戻さない。

候補を一巡し必要数を置けなければ設定不成立で停止。初期値の自動引き直し、個体数削減、資源/地形の書換えはしない。資源保証をOFFにしても、通行条件や重複禁止は緩めない。

## 5. B機能との接続

B4は規模/総数/参加系統/人数配分/空間方式/資源保証から初期配置を決定する。組配置の順序は均等配分と偏りあり配分に共通で、配分とは別の再現可能な順序を使う。初期生成の位置候補探索は開始時のみで、通常ターンの個体判断の大域探索には使わない。初期値と全設定が同じなら同じ世界となり、表示倍率/表示頻度には依存しない。

B5はモード名、参加系統、系統別初期数、空間方式、資源保証、散開代替の有無を開始条件として区別する。これは初期配置形式の設定機能で、保存/高度な比較等の新機能を今回追加するものではない。開始後に設定だけ変更して個体を再配置せず、変更時は新しい世界として開始する。

餌/環境の生成則、各個体の初期相/状態、繁殖・進化、画面内外の同じ更新は維持する。設定は初期条件にだけ作用し、少数系統を常時保護する処理や人口の均等維持は設けない。
