# ゲーム内の説明シート（B5.2）

A/Bと静止画による機能仕様。ゲームへの組込みは未実施。

## 開き方と内容

系統樹の相・枝から「なぜこの分岐？」を開く。個体詳細、餌・環境の詳細、繁殖の案内からも同じ説明へ移動できる。戻ると元の系統・相・枝の選択を保つ。

| 説明の区分 | 表示すること |
|---|---|
| 分岐の仕組み | 第三相3枝→第四相6経路、各枝の理由、基本系統とDNAの保持 |
| 経験の読み方 | 餌の実吸収、環境適応、有効な移動、敵との戦闘。評価する成果と除外する行為 |
| 雌雄の見分け | 同じ系統・相・枝の雄/雌を並べ、小さな模様・発光差と♂/♀を説明 |
| 繁殖条件 | 第三相から候補になること、同系統異性、状態・待機・距離・空きマスの条件 |

## ルールと個体の実際を分ける

- 一般の説明シートはルールと代表例を示す。個体を選択した場合のみ、その個体の経験と進捗を重ねる。
- 条件ごとに「必要な経験」「記録された成果」「不足・候補未成立の理由」を示す。将来数値が確定した項目だけ、必要値・現在値・差を表示する。
- 食べた回数・歩数・攻撃回数を成果と混同しない。戦闘経験なしの場合は「実交戦の記録がない」と表示し、別の経路が残ることも伝える。
- 第三相で繁殖可能な相になっても、相手・栄養・空きマスなどを満たすまでは「今すぐ繁殖できる」と表示しない。
- 見本画像・未確定の閾値・実際に到達した経路を明示的に区別する。色だけでなく文字・図・記号を使う。

## 説明用の文例

「栄養を多く見つけたからではなく、実際に吸収し、その環境で生命を維持できた経験が採食の特化へつながります。」

「同じ場所を往復しただけでは広域探索の経験になりません。移動が新しい資源や生存につながったかを見ます。」

「第三相になったので繁殖の候補です。第四相への覚醒は必要ありません。相手・栄養・待機・空きマスの条件を確認してください。」
