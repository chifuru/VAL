# 群体節足の後継群れ・分業調整 / 4.2.54

群体節足だけ、繁殖型の娘が生まれ、働育個体の支援を受け、次世代の群れを作れる経路を強める。新規世界の `socialRenewalModel: successor/1` でのみ有効とし、保存済みの無指定世界には適用しない。出生時は一個体・第一相・年齢0で、女王・雄・働育雌も独立個体のまま扱う。

- 同じ群れに生存する別の繁殖型が近い場合、雌の子が繁殖型候補になる確率を `.08` から `.55` へ変更。繁殖型が近くにいない場合の `.6` は維持する。出生・性別判定は決定的な初期乱数を使う。
- 群体節足の維持費を従来の `.45` 倍にする。移動・採食・死亡は有償で、寿命と場所の占有上限は維持する。
- 栄養蓄えが20E以上の個体だけ、同じ群れの仲間から2マス以内へ近づく移動候補を少し優先する。仲間へ瞬間移動せず、採食や危険回避の候補を残す。
- 実交配で有限貯精を得た女王の単親負担は40Eから30Eへ下げる。親が払ったEだけを子のE/Bへ分け、子の出生時資源を増やさない。貯精回数・鉱物支払・出生待機・空きセルを維持する。
- 働育個体は2Eを払う育児給餌で、同じ群れの女王・幼体へ最大1.5Eを渡す。旧設定の約0.7Eより有効な世話となるが、差額は失活し、無償の給餌にしない。

神鳥・多頭蛇・深淵触手・深淵頭足・量機には既存記録で少なくとも一つの存続経路があり、今回の係数変更は行わない。最終係数の長期生存は未測定であり、全条件の安定生存は認定しない。
