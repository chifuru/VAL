# 長期グラフの重複走査軽減 / 1

全確定ターンの観測原値と全描画点を保持する。個体数・相/雌雄/年齢の積み上げ順、縦横軸、色、画素、対象切替と保存解析を維持する。生態規則、乱数、記録/保存形式、関係指標の意味は変更しない。

既存paintStackの横座標を一描画につき各時点一度だけ計算し、全系統で共有する。下辺を逆順に描く走査で積み上げ基準値を更新し、別途の更新走査をなくす。加算順序・頂点順序・描画命令は維持し、減算による基準値復元、間引き、丸め、平均化を行わない。

作業配列は描画呼出内の横座標と基準値だけとする。観測行を書き換えず、系列/系統ごとの全履歴複製や永続キャッシュは増やさない。履歴長Tに対し一時領域はO(T)、描画自体は全点保持のためO(T×系列数)を残す。

検証は基点e8f36adの実paintStackと比較する。Canvas命令/画素/ラベル一致、空/1点/新系統/欠値/微小値/大きな値/共通最大値/短い枠/高DPI、再描画/追記/短縮/別系列を限定確認する。長期合成履歴で横座標用のturn参照を数え、実Canvasで限定計時する。アプリ全体や実長期生態の倍率へ拡大解釈しない。
