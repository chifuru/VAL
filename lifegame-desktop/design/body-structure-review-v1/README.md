# 群体節足・多頭蛇：身体構造の比較

レビュー用の基本形候補。各画像の左からA/B/C、上段は全身、下段は同案の前面・身体のつながりの詳細です。3案は進化枝ではなく、同じ成体のデザイン方向の比較。製品の原画/分岐/生態ルールは変更していません。

## 群体節足
[比較画像](01-swarm.png)

|案|形|見る点|
|---|---|---|
|A：環殻・腹膜型|環状の外骨格の内側を、柔らかい胴と腹膜で満たす|従来の環状形を残しながら、一個の胴・腹面・脚の付け根がつながる|
|B：分節胴型|前後に長い胴を、分節した殻が覆う|前後方向と脚の動きが読みやすく、まとまった動物として見える|
|C：包殻胴型|厚い胴を、重なった殻が低く包む|殻と筋肉の対比、重心、腹面の連続性で生命感を出す|

利用者指定によりCを基本形として採用。A/Bは採用対象にしない。殻/脚/感覚部は同じ身体に生える構造として扱い、装備の追加や機械の脚に見せない。

## 多頭蛇（現行名称）
[比較画像](02-serpent.png)

|案|形|見る点|
|---|---|---|
|A：収納口器型|共通の感覚部の下に、太く短い口器がまとまる|口器の付け根を一つの喉へ接続。閉じればまとまり、開けば異形の迫力が出る|
|B：展開口器型|流線の胴の前下方へ、複数の口器が扇状に展開|個別の目や顔を持たない口器を、共通の身体から伸ばす|
|C：花弁口器型|口器と筋肉質な口縁が、一つの摂食部の周囲に折り重なる|全開時の多口と、閉鎖時の鋭い一体輪郭を両立する|

口器型A/B/Cは利用者の指摘により不採用。以後の作画根拠として使わない。口器を独立した蛇の首や顔として作らず、一体の摂食組織として見せやすい。Bは展開時の迫力が強い別方向。**口器数は3に限定しない。画像で見える数も仕様として固定しない。**数だけの差ではなく、収納/展開/折り重なりと胴への接続を比較する。名称変更・攻撃回数・射程・食性・能力変更は今回の造形から導入しない。
