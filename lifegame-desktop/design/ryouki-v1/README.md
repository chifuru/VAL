通常型の分岐は[採用した第三相3枝・第四相6枝](../ryouki-branches-v2/README.md)を正とする。利用者の「これでいきましょう」により、この2枚の身体造形と対応を採用した。前後比/横幅/殻と支持構造の差を保持し、上の通常I/II・相変異2区分も維持する。旧9区画図は未採用の参考で、その接続線/矢印は親子の根拠にしない。[台帳](registry.json)は採用5・未採用提案1・原案5。ファイル名のproposalは作成時の名称で、現在の採否とは分ける。

上段の図は身体形状。通常型の移動は相ごとに1/2/3/4マス、相変異中は全相3マス。複数同居は相変異型2〜3体を独立個体として扱う。通常型の第四相を黒くする案、相変異の全身黒一色案、筒状案は現在参照にしない。相変異4の繁殖目的を、繁殖力の追加上昇や他相の繁殖禁止へ変換しない。

相変異は可逆な相状態の変化。低密度が一定ターン続き、通常型の占有へ戻れる場合に解除し、本人の進化相/枝/年齢は維持する。一度の密度低下だけで通常型へ切り替えない。密度や継続Tの具体値は仕様の比較開始案に分ける。
