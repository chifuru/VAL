# P/Qの採用造形と実行素材 / I10

正本は[造形対応](../specification/appearance-correspondence-v1.md)と[採用台帳](../appearance-baseline-v1/registry.json)。新造形の案出しや系統数の変更は行っていない。潮環・葉環の各A/B/C×I/II/III＝18形態、QのI/II/IIIと別採用IV＝4形態を実行用RGBA atlasへ接続する。

`registry.json`は採用原画4枚の元path/SHA256と同一コピー、image_genによる背景・宿主・文字・枠の除去編集4枚の保持先/SHA256、元区画・編集成分・atlas区画の対応、静的派生PNGのSHA256を記録する。原画自体は変更していない。`edits/`は生成出力の同一コピーで、造形の新正本へ昇格させない。

最初のQ四相編集はI〜IIIの紫の珠/連結珠/網状組織を採用する一方、IVは旧比較図の小型巻殻・大きい爪へ寄ったため不採用。採用06だけを参照した`hyperparasite-adult.png`へ差し替え、大きな左への重層保護板・右側の高い背面・短い接地器官2本を保持した。元比較図05のIVと、Qの背景になっている橙P組織も実行Qへ含めない。Q自身のIV内部の橙網状組織は採用06の身体の一部として残す。

再現は`python3 tools/prepare-parasite-assets.py`（Pillow/NumPy/SciPy）。保持した透過編集のalpha80超の既存本体を独立成分として識別し、その本体に近い既存の柔らかい縁を静的に帰属させる。最大352pxへ縦横比保持で縮小し、384pxセル内へ16px以上の透明余白で配置する。RGBの再描画や実行時の背景除去は行わない。Pは各1152×1152、Qは1536×384。静的pack後に近景で毎回`cleanFrame`の最大成分除去を行わず、細い糸や接続嚢を保持したセルをキャッシュして描くだけとする。

新Pは保存済み`primary-state/1`＋`primary-form/1`のA/B/Cと本人相、新Qは`hyper-state/1`の本人相から素材を選ぶ。感染の経路/宿主段階や宿主の年齢を相へ読み替えない。flag/stateがない旧記録は従来のlife-f経路を維持する。肖像は採用元の区画そのものを使い、説明用背景を盤面のカードとして重ねない。

齢の変化は本人の記録を参照する。Pは繁殖成熟と区別した老齢の表面差、Qは本人の幼体/成体/老齢を同一相の縮尺・表面差で表す。方向は保存された向きがある場合の反転だけで、泳法・飛翔・新しい器官を追加しない。これは全年齢/全方向の新しい描き起こしや最終外観承認ではない。

素材予熱も新P18/Q4へ対応する。生態の状態・乱数・費用・出生・計算署名・保存形式は変更しない。実画面/形態選択/原画肖像/透明余白/旧経路/入力不変の限定検査は`tests/i10-parasite-materials.cjs`、結果は`operations/evidence/i10-rendering-materials-v1/materials/`へ記録する。
