# 量機：通常型の分岐造形・第2提案

[量機/1](../specification/ryouki-v1.md)の第三相3枝・第四相6枝を、通常型の菱形外殻/多脚/青緑と金の描写で比較する。いずれも**利用者未確認の造形提案**で、採用済みの[通常I/II・相変異2区分](../ryouki-v1/README.md)は維持する。

## 第三相：3方向

[第三相比較画像](01-third-phase-proposal.png)。左から広域探索・周辺探索・障害踏破。

| 区分 | 造形の狙い |
| --- | --- |
| III-1 広域探索 | 前後へ伸びる低い菱形。前後軸に沿う殻と脚の列 |
| III-2 周辺探索 | 横へ広がるまとまった菱形。側角の下へ広がる脚 |
| III-3 障害踏破 | 斜めに重なる殻と段差のある輪郭。前後と中央で支える接地構造 |

## 第四相：各方向から2枝

[第四相比較画像](02-fourth-phase-proposal.png)。3列×2段で、同じ列の上下が第三相の同じ親から分かれる。上下の第四相同士が順番に進化する意味ではない。

| 位置 | 第三相の親 | 第四相 | 造形の狙い |
| --- | --- | --- | --- |
| 左上 | III-1 広域探索 | IV-1 広域探索・直進 | 直線的な細長い槍菱形と、身体に沿う脚の列 |
| 左下 | III-1 広域探索 | IV-2 広域探索・ランダム | 短く丸みのある菱形と、四隅へ分かれる支持 |
| 中央上 | III-2 周辺探索 | IV-3 周辺探索・近め | 内へくびれた辺を持つ小さな菱形と、中央に集まる脚 |
| 中央下 | III-2 周辺探索 | IV-4 周辺探索・広め | 側角が張り出す横広の菱形と、側方まで広がる支持 |
| 右上 | III-3 障害踏破 | IV-5 障害踏破・水域 | 曲線的に絞る薄いレンズ形と、滑らかな殻の重なり |
| 右下 | III-3 障害踏破 | IV-6 障害踏破・火山 | 厚い斜めの殻が噛み合う段状の菱形と、低く踏ん張る支持 |

前後比だけで近づきやすい直進/水域は直線と曲線、ランダム/近めは膨らんだ辺と内へ絞る辺、広め/火山は横幅と殻の段差を比較する。色替えだけに頼らず、同じ系統の骨格から違いを出すための提案である。図中の比率は能力値/実寸/占有セル数を指定しない。

## 今回の目視確認

第三相は細長い低い外殻/横広の中央集約/段差の大きい殻と支持脚に分かれた。第四相も直進の細長さ、ランダムの丸い広がり、近めのくびれ、広めの側角、水域の滑らかな外周、火山の斜めに重なる殻を比較できる。親の系統名/枝番号/上下の配置に誤対応はない。全体の青緑/金と多脚を維持し、通常型へ相変異の黒い背面を割り当てていない。

第四相図のIV-1見出しは「広域探・直進」と「索」が欠けている。正式名は上表の「広域探索・直進」で、画像の欠け表記を系統名の変更にしない。

近め/広めは共通する菱形が強く残り、水域の俯瞰は細長い直進との比較が必要。図の大きさで判別できることと、実際の1マスで読めることは別なので、実装時の縮小表示は後続確認とする。今回の画像だけで全6枝の最終採用や判読性の合格を認定しない。

## 採用と実装の境界

- 画像は造形の比較用。通常IIIの移動3/IVの移動4と、相変異全相3/同居2〜3/色区分/低密度継続による解除は正本を維持する。
- 通常型に黒い背面/黒と深緑の相変異配色を割り当てない。脚/殻の形から飛翔/泳法/新感染経路/溶岩無効等を追加しない。
- 火山枝の厚く重なる殻を、攻防値の追加強化を採用した根拠にしない。
- 年齢/性別/全方向/実行アトラス/モーション/盤面縮小時の判読性はこの2画像だけで完成としない。既存遠景記号/近景絵柄の方針も維持する。
- 元生成画像を保持してコピー保存し、[量機の画像台帳](../ryouki-v1/registry.json)へ元ファイル名/ハッシュ/提案区分を記載する。[実行契約](../../operations/plans/ryouki-branches-v2.md)と作業記録で実体差分を照合する。
