## 雌雄・階級と成長を混同しない

第三相・同じ枝で比較する。既存の表示仕様は雌の腹部幅+5%と輪郭の小突起一つ、雄の触角または縁突起+5%だが、この小差では分かりづらいという利用者の指摘を受け、比較画像では差を強めた造形案を示す。

日輪の雄は長く鋭い冠と縁の突起、雌は丸みのある胴と短い冠。浮遊傘の雄は細めの傘と長い縁突起、雌は幅広く丸い傘と短い縁を使う。作画指示の目安は雄の冠/縁突起を約20%強調、雌の胴/傘を約15%広げることで、画像の計測済み比率や確定した能力差ではない。基本の系統色・身体構成・相・枝は共通にし、色だけで区別しない。遠景では無理に細部を描かず、選択資料でも確認できる設計とする。

これは外見の比較案であり、core・A/B正本・製品コードは変更しない。採用時には正本の表示仕様と数値を揃える。繁殖条件や能力への性差は追加しない。

群体節足は繁殖雌候補の腹部二重輪、働育雌の前肢の育児斑、繁殖雄の長めの触角を比較する。階級は出生時の母体条件と投資で決まり、後から情報で変更しない。各図は一個体であり、複数個体の合体ではない。

全ての子は第一相から始まり、繁殖は第三相以降かつ各条件成立後。働育雌は不妊。寄生群に雌雄は設定しない。日輪と浮遊傘の絵を有性繁殖以外の新規ルールの根拠にしない。
