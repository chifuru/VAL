# 生存多様性・寄生経路：確認用試作 v1

利用者確認前の比較実験。製品src/・Windows版・正式な採用仕様は変更していない。既存A1.5/B4.2等へ接続する候補として読み、製品の実装済み機能と混同しない。

## 現状の原因

- 製品の標準初期値は、植物の先行配置で水域の餌枠が埋まり、水游虫が初期0。寄生の中間宿主も最初から欠ける。
- 微藻/岩苔は出生がほぼなく、同齢の初期個体が寿命120/180付近で消える。菌は低密度なのに同種近傍3が必要で、無光合成の初期栄養を使い切りやすい。
- 非光合成の主生物は、維持・移動・孤立費が日々の食物吸収へ近く、植物共生だけが長期に残る例がある。単純な総個体数では多様性を評価できない。
- 製品の死骸感染は、成熟した中間/追加中間の寄生体・感染期限4ターンに限定。接触感染はなく、終宿主に到達しないと新しい第一宿主へ増殖できない。

## 比較する最小限のスイッチ

| 条件 | 変更する部分 |
|---|---|
| baseline | 製品と同じ計算。読取専用の観測だけ追加 |
| food | 餌の初期配置をセルごとの同時選択へ変更。植物が他群を締め出さず、空き枠も残す。餌の初期年齢を寿命の0〜60%へ分散。菌だけ近傍1〜3で有償繁殖 |
| budget | foodに加え、非光合成主の維持を食性別0.70〜0.85倍、移動費（動く餌を含む）0.8倍、孤立費0.5→0.1。有機吸収の係数0.5→0.6、植物共生の光入力1.5→0.8 |
| routes | budgetに、反復接触・感染性死骸の拡張・宿主内の成熟移行を追加 |

初期配置は、合法候補ごとに微藻0.28/岩苔0.22/草本0.20（浅瀬等0.035）/菌0.035（湿潤・腐食0.07）/水游虫0.12/草棲虫0.075の重みを積み上げ、セルの一回の初期値乱数で一つだけ選ぶ。余りは空き枠。初期の生体数・栄養予算は製品とは変わり、各条件のターン0に記録する。地形と主生物数/系統/初期DNA規則は維持。途中の強制補充はしない。

草本・微藻・岩苔のB3、有性出生の二親/B2/3、子I相、有限E/M、捕食・地形・情報作用は共通。値を変えた後も毎ターンE/M保存・占有・IDを検査する。全系統が永続する保証や、最終バランスではない。

## 寄生は「宿主内コロニー」

宿主内の微小個体群を一レコードにまとめる。Pは宿主ごと1コロニー、QはPごと1コロニー。個々の虫の雌雄・個体数・交配は追わない。現行P/Qにも性別フィールドはなく、その近似を明示する案。主生物の雌雄は維持する。

- **反復接触**：近傍1の見通しがある相手へ、同じコロニーとの3回の接触が8ターン以内に積み重なると感染候補。受け手の曝露記憶は最大4コロニー。終宿主前は同じ宿主段階への局所増殖が可能で、成熟済み・親のE0.12実支払い・子E0.04/散逸0.08・親は6ターン待機。一日一コロニーまで。
- **最終段階の増幅**：成熟した適合終宿主では半径2、3ターン待機、最大3件の有償接触感染。新しい宿主では段階に応じて成熟をやり直す。待機・E不足・既感染・遮断・競合なら失敗し、同日に新感染から再拡散しない。従来の放出経路は併存する。
- **死骸感染**：感染宿主の全段階を感染性死骸に残し、感染性16ターン/死骸20ターン。栄養は有限、P/Qは既存レコードの移転で複製しない。植物/対応する小型/菌/主などの受け手で第一・中間・追加中間を決める。未成熟・非適合の主は追加中間として保持し、適合する成体へ育てば6回の支払い後に終宿主へ移行できる。これは比較用の生活環緩和案で、現実の全寄生種へ一般化しない。
- **高次寄生**：死骸移転ではPに付随。成熟Qは接触によるPの子へも実支払いで移り得る（親QのE0.06→子QのE0.02＋散逸0.04）。高次寄生の情報操作は既存の延長された表現型モデルを使う。

## 実行・評価

`node design/survival-trial/observe.cjs baseline,food,budget,routes 300`

基準初期値に加え、`survival-holdout-1`〜8の初期配置だけを調べ、Qが初期存在した8を別の経路確認条件に用いる。これはQの確認を目的に選んだ条件で、無作為な未使用初期値での一般性能証明ではない。初期0と、存在していた種の絶滅を分ける。

主の存続系統数・餌の存続系統数・P/Q・出生/死因・一体一ターン平均の吸収と費用を比較する。食物の初期配置と予算、維持/吸収、感染経路を段階的に分け、感染経路自体の効果はbudgetとroutes間で比較する。実測後の報告を参照し、未改善の種や過剰な感染も残課題として示す。
