# 独立植物の採用原画と暫定実行素材 / I03

森冠・星冠・淡水光合成体の3系統を、それぞれI・II・III三枝・IV六枝の11形態へ接続した。画像数やセル数は新たな種数ではない。現在の採用正本は [造形対応](../specification/appearance-correspondence-v1.md) と [採用画像台帳](../appearance-baseline-v1/registry.json)。初期案・不採用案・旧海生02は使用していない。

`registry.json` は原画5枚の元path・SHA256・同一の実行用コピー、33区画の元画参照、透過編集の保持先・SHA256・静的切出し位置、派生atlasのSHA256を記録する。元の採用PNGは変更していない。原画のI/IIと各分岐図は画像内の文字・寸法・比較シルエットも含む資料で、`Art.producerPortrait` は正しい原画区画を直接描画する。枝の順序は `I, II, III-1, III-2, III-3, IV-1a, IV-1b, IV-2a, IV-2b, IV-3a, IV-3b`。

`edits/` は image_gen の透過背景編集を保持したもの。新しい案出しではなく、採用参照の背景・文字・枠・寸法・比較シルエット・航跡を除く編集として依頼した。最初の星冠IV-1aでは二段の受光冠、淡水IV-2aでは後方の受光膜が省略されていたため、その2区画だけ追加の参照編集へ差し替えた。淡水の編集シート内では、大型繁殖組織を持つ膜なしの区画をIII-2へ対応させ、修正後の膜付き区画をIV-2aへ対応させる。全体の形態と区画数を原画に照合し、編集画像を自動で原画の新正本へ昇格させていない。

静的な再現は `python3 tools/prepare-independent-plant-assets.py`。Pillow・NumPy・SciPyを使用し、保持した透過編集を切出し・縦横比保持で配置する。淡水の余白へ混入した隣接区画の非連結片だけを、事前に除く。生体の受光膜を削る処理や、新しい身体組織の生成はしない。実行中は生成済みRGBA atlasを描くだけで、背景除去・盤面へ重ねる上マスク・囲みカードは追加していない。

I03の近景は採用した輪郭・材質への暫定接続。森冠・星冠の広い発光縁、細い組織のマット、原画と完全一致する切抜き、全方向・全年齢の専用素材、実寸判読性と遮蔽の最終調整はI10へ残る。透過編集は画素単位の原画コピーではなく、造形再採用や最終外観の認定でもない。幼体の小縮尺と老齢の小縮尺・低彩度は同じ相/枝の表示差として適用し、可食量の減少で本体や葉へ穴を追加しない。淡水の膜を羽ばたかせず、泳法・航跡・根を追加しない。

編集元の生成出力は `/workspace/generated_images` にも保持した。森冠 `exec-03eb9fd4-1180-414b-80b1-ff25233ed03c.png`、星冠 `exec-726f82e9-f98e-41eb-8a64-569abe5c3601.png`、淡水 `exec-c0ddf140-1926-4b15-ad36-9502e5c37058.png`、星冠IV-1a修正 `exec-7ed6c7e1-bb1b-4195-bd98-dd28a06adc98.png`、淡水IV-2a修正 `exec-488edea8-87f3-480c-bc56-e490791ba1ff.png`。これらの可搬な同一コピーが `edits/`。
