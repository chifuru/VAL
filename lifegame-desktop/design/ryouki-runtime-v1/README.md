# 量機の採用原画と暫定実行素材 / I04

正本は [量機/3](../specification/ryouki-v1.md)、[採用5枚の台帳](../ryouki-v1/registry.json)、[通常型III/IVの採用対応](../ryouki-branches-v2/README.md)。通常I/IIとIII三枝・IV六枝の11形態、相変異I〜IIIの共通1形態とIVの1形態を描画へ接続する。13区画は一つの量機系統の表示区分で、新種や新しい進化枝を追加しない。旧9区画提案と、相変異図の右上にある通常型の小見本は使用していない。

`registry.json` は採用原画5枚の元path/SHA256と同一の実行用コピー、各原画の採用区画、透過編集2枚の保持先/SHA256、派生atlasの区画/SHA256を記録する。元の採用原画は変更していない。`Art.ryoukiPortrait` は正確な元画cropを直接描画し、通常の11形態と相変異2区分を正しく参照する。

`edits/normal-eleven.png` と `edits/mutated-two.png` は、採用原画を参照して背景・文字・枠・注釈線だけを除く目的で image_gen の透過編集を行った出力。新しい造形案の生成ではない。通常は青緑/青の玉虫色と金の縁、相変異I〜IIIは背面だけ黒で他は元色、相変異IVは黒と深緑を維持した。黒い部分は閉じた浅い窪みで、穴/傷/割れ目ではない。通常11形態の輪郭・脚の支持と、相変異2形態の色区分を原画へ照合した。編集画像を造形の新正本へ昇格させていない。

元出力は `/workspace/generated_images/exec-92553bbe-5d83-454d-8f74-f23071ece7d0.png` と `exec-8e57e6cd-007c-43e8-a3f7-13b3d81df367.png` に保持し、`edits/` はその同一コピー。追加の生成は行っていない。

静的packは `python3 tools/prepare-ryouki-assets.py`（Pillow/NumPy/SciPy）。透過編集のalpha80以上の独立した身体11/2成分を検出し、接触した柔らかい発光縁だけを近い身体へ帰属させ、元のRGBを再描画せず切出し・縦横比保持で配置する。全13セルの全周と四隅はalpha0。毎フレームの背景除去、黒い背面を後から覆うマスク、囲みカードは使用しない。

atlasの順は `I, II, III-1, III-2, III-3, IV-1, IV-2, IV-3, IV-4, IV-5, IV-6, mutated-I-III, mutated-IV`。`o.ryouki.mutated` と本人のphaseを読み、相変異表示のために進化相/枝/年齢を変更しない。同じ相/枝の幼体は小縮尺、老齢は小縮尺・低彩度を用いる。全方向・全年齢/雌雄の専用原画、細い触角/脚のマットと発光縁、実寸判読性/遮蔽の最終調整はI10へ残る。透過編集は元画の画素コピーや最終外観の合格を意味しない。

同居する相変異量機2〜3体は、IDの安定順で主枠内の位置を分け、各自の原画/命中判定/名札/状態札/P・Qの付随位置を持つ。遠景は同じ専用記号を個体ごとに描き、同居数を補助表示する。生産者/基底群落/一次消費者を合体させない。歩行表示は確定moveイベントの `from → path各歩 → to` を使用し、失敗した歩や追加の泳法/飛翔/溶岩無効を描画で作らない。

限定検査は `tests/ryouki-graphics.cjs` と `tests/display-plane.test.cjs`。前者は13表示区分/元画肖像一致/alpha/年齢、合法な量機3体同居＋陸生独立植物/草本群落/草棲虫と付随P・Qの表示fixtureを扱う。自然に同居が成立した証拠や生存率の試験ではない。
