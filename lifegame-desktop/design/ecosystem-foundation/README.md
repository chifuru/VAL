# 生態系の土台・自然地形・重複識別 v2

利用者の「生物が広く生存・行動・競争でき、その結果として寄生が維持される」を評価する分離モデル。製品2.2.0は未変更。既存C7.1〜5/C8.1内の候補を具体化し、採用前の観測を行う。coreとNode承認状態は変更しない。

## 評価の優先順

1. 生産者と動く餌が出生で更新されること。
2. 主生物が採食・移動・防御・攻撃・成熟・次世代出生を行えること。
3. 複数の初期値/配分で残る系統と、早期に失われる系統を分けること。
4. 宿主が維持される上で寄生P/Qの生活環・接触・死骸移転が続くこと。

単に最終個体が残るだけ、寿命を伸ばしただけ、途中で初期個体を補充しただけを安定化とは呼ばない。初期0は絶滅に数えない。恒久的な全系統共存は保証せず、観測期間と条件を明記する。

## 初期配置

主は既存の同系統4体の局所小組と指定総数を維持。標準では比較用の偏りなし、追加条件では初期値から1〜4の配分重みを生成し、小組数を変える。全種16体固定を生存対策にしない。配置の偏り、近傍での競争、初期DNA差を残す。

餌の初期配置はv1試作のセル単位一回の抽選を使う。微藻.28/岩苔.22/草本.20（非平地・泥地.035）/菌.035（湿潤・腐食.07）/水游虫.12/草棲虫.075を合法候補だけ累積し、残りは空き。初期餌年齢は寿命の0〜60%に分散。初期E/B/Mの違いは台帳と観測に残す。途中の救済補充はない。

## 固定された連続地形

8環境の中心を初期値で配置し、低周波の滑らかな変位で境界を曲げる。地形はスケール7と3の連続した高低差を合成し、環境ごとの既存累積閾値で浅瀬/深水/平地/岩場/泥地を決定する。独立セル抽選で生じた細切れ模様を減らす。遮蔽物は岩1.2%・倒木2.3%・草むら5.5%、辺障害は既存2%。これらは初期値で固定され、生物による環境の書換えは追加しない。

草本/草棲虫は水域・湿潤域の浅瀬へ初期配置・出生しない。微藻と水游虫の水生ニッチを草本が埋め尽くすのを避ける。小型の移動も自身の合法生息地を守る。主生物は環境で隔離せず、既存の環境適応と移動費で共有生息地を使う。

## 生産者と消費者の収支

- 微藻/岩苔/菌は同種近傍1〜3から有償出生。草本はB3、小型はB1〜3。空き餌枠、合法生息地、親E8・M/B・待機の条件は維持。植物の投資処理も同じ近傍条件で繁殖用E8を残す。疎らな繁殖条件だけ緩め、蓄えが旧B3のままだった不整合を修正する。
- 菌は維持.07、光合成なし。有限土壌からのM吸収を植物と同じ合法源に追加する。土からEは得ず、Eは従来の局所の残骸・有機源から得る。
- 主の非光合成維持は元の値へ食性係数（動物/菌.70、鉱物.75、汎食.80、植物.85）×.65。移動費は小型を含め元の.48。孤立費.1。有機吸収係数.6、植物共生の光入力.8。実吸収・要求費・未払によるHP損失を分ける。
- 主の寿命は系統固有値の1.5倍、小型も1.5倍で小型の出生待機も1.5倍。出生適格の主Eは45、親からの実投資と子I相/年齢0/G0、相III以降の繁殖は維持。
- 見通しのある半径4以内の同系統・異性を認識した際、幼若期は.5、成熟した双方では.8の親和特徴。成熟前の分散で配偶機会を失うのを抑え、親和重みと組み合わせた局所評価へ加える。これは通常の視覚とは別の局所的な配偶相手の感知であり、全域探索や壁越しの情報共有は行わない。動物食系統は接近した小型餌への攻撃に採食上の価値を加え、他の主生物への無差別な攻撃と分ける。行動名や出生を強制せず、空腹・危険・資源・ランダム性と比較して選ぶ。

## 宿主を使い切らない寄生候補

Pは宿主内コロニー、QはP内コロニーで、微小個体の性別・全虫数は追わない。主生物の雌雄は維持。

- 親の成熟・見通し・同じコロニーへの反復接触が必要。終宿主前は8ターン窓の6接触・半径1・1件/48ターン、成熟終宿主は4接触・半径2・最大2件/16ターン。
- 親E.3の実支払いから子E.1と散逸.2。Q同伴は親Qの追加実支払い。感染直後の同日連鎖を禁止し、新宿主で成熟をやり直す。
- 維持の宿主負担は主.15、小型・生産者.04。Qの取り分は支払額の25%を上限.05で分ける。満額を払えたターンだけ成熟し、不足は宿主のHP負担となる。宿主サイズ差を無視した一律.2による弱い餌側への過剰負担を減らす。
- 全段階の感染性死骸は16ターン、死骸は20ターン。摂取時は既存P/QのIDを移し、栄養や寄生個体を無限複製しない。
- 成熟前の横方向伝播、適合成体への成熟、終宿主での増幅はv1候補を保つ。全寄生虫に共通する現実の生物学的主張ではない。

## モックに接続する描画

既存の生物原画と地表原画を利用。固定地形をキャッシュし、連続した材料色へ地表テクスチャを薄く重ねる。岸辺・岩・倒木・草むらは実際のセルから描く。格子は初期非表示。背景の彩度/明度を抑え、独立した生物の輪郭を暗い下地で確保する。

同一マスに主と餌が共存すると、主を右上・餌を左下へずらして小さく表示。Pの橙点とQの紫輪は各宿主に付随する。資源は左上、死骸は右下の小印で区別する。選択地点の全生物/資源/寄生と拡大地図を併記する。低倍率で全形態を読ませず、全体観測と48/64pxの拡大で識別する。表示は生態状態を変更しない。

## 別評価：群体節足のコロニー繁殖候補

通常のfoundation条件とは分け、`colony`条件で評価する。創始小組は雄1・女王1・雌の働き個体2。働き個体は局所の同コロニーへ親和し、E25以上なら幼若個体に加えE65未満の成体女王にも自身のE2と余剰M（最大.2、M2は保持）を栄養として渡せる。受け手の通常の有機吸収処理を通し、吸収分を回復・蓄え・成長G・材料へ配分し、非吸収分は散逸/土壌へ戻す。材料や成長を伴わない単なるE加算とは区別する。雌の出生時、母以外の同コロニー女王が半径2にいると女王分化確率8%、いなければ60%。女王候補の存在による局所的な抑制とし、母Eの追加閾値で全ての候補が働き個体になる不整合を避ける。出生自体のE/M/待機/空間・交尾条件は満たす必要があり、女王の強制補充は行わない。

給餌だけでは群体節足が600ターンで消失した。このため、毎回隣に雄がいなければ産卵できない条件を、実際の交尾後の有限貯精へ分ける候補を設けた。

相III以上・健康な女王が隣の相III以上の雄と合法な近接状態になったとき、双方E2を支払い、一つの父性記録（固定DNA・出生重み・父ID・世代）と12回分の貯精を保持する。雄は同ターン一女王まで。母は通常の栄養/HP/待機・空き主枠・近傍B2/3を満たして、一腹につき自身のE40/M4を実支払いする。子はI相/年齢0/G0で、母と保存した父のDNAを継承する。実際の出生時だけ残数を1減らす。残数0なら貯精経由の出生には再交尾が必要で、雄不要の無限出生や単為生殖ではない。既存の隣接した二親による有償出生は併存する。貯精は女王ごと一記録のみで、保存した父性記録を生存個体として数えない。

`node design/ecosystem-foundation/observe.cjs colony 600 ECOSYSTEM-2026 operations/evidence/ecosystem-foundation-v2/colony`
