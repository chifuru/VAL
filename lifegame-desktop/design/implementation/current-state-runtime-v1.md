# CS08一次：状態量の測定と接触集計

起点6349562。current-state/1の意味、マス/固定枠、既存配置/素材/一般の既定モード/製品4.2.77を維持する。既存C7/C8.2・D7/D8/D9・E5/E6の範囲。

## 接触の意味を変えずに数える

従来は実在する生体/自立IVのQについて、近傍の個体ペアを作り、実IDの組で重複排除して系統ペアの整数件数へ集約していた。現在の生態はその個体ペア履歴を保持せず、観測だけが系統別件数を必要とする。

`CurrentEcology.contacts`は、所在マスごとに系統別の生体数を数える。同マスの同系統はn(n−1)/2、異系統はnm。異なるマスは、隣接する占有マス対を一度だけ処理してnmを加える。元のどちらかの方向で接触できる場合だけ成立させ、一方向の壁、斜め移動、障害物、死亡体除外、自立IVのQという既存資格を維持する。小集団の内部人数を接触主体数へ乗算しない。

実IDの重複がある診断入力では従来の個体ペア方式へ戻す。通常の一意な実IDを持つ世界では、個体ペアのSet/JSONキーを大量生成しない。系統ペアの出力キーと並びを維持し、観測値/生態の行動/乱数消費は変えない。

## 署名と記録

生成物と生態署名を更新。新署名57332f90…から、直前の同じ生態規則7808c454…への厳密な計数等価を宣言する。新しい情報/土壌規則を、それ以前の別規則へ同値扱いするものではない。従来の未選択経路の条件付き互換も維持する。

同マス・隣接/障害/片方向の壁・自立Q/死亡体・重複診断ID・密集/順序入替を個体ペアの独立な全列挙と比較した。保持したT0/T133世界からの実1Tは、観測を含む全世界が変更前と一致した。7808c454…の形式4記録は原bytesを変えず再生でき、未選択の従来マス境界も一致した。等価なのは今回の計数変更であり、過去の生態ルール変更への互換保証を増やさない。

## 測定範囲と残る負荷

[限定証跡](../../operations/evidence/current-state-runtime-v1/README.md)。代表1条件は自然133Tまで、壁時計4分の上限で終了。500T完走ではない。過去の別規則のT500世界を新方式へ流用しない。

旧経験/学習の列は0、加算分は9成分、残骸の個別レコードはT133で0。現在の生体数に応じた世界の増加と、別管理の全T観測を分けて把握した。実在物質の残る土壌在庫や、必要な全T原値は消去しない。

保持T133で接触集計の暖機中央値は739.56→4.56ms。全1Tは単回2955.92→2157.83msで、安定した全体改善率を認定する測定ではない。共有配分、情報受信、世界複製/一時割当とGCは残る。ブラウザの暖機描画とグラフ単体は別計測で、計算時間へ加算しない。残る負荷の優先度を確認してから次の局所改善へ進む。
