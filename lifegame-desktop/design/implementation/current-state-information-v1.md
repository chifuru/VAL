# CS02：情報の現在状態と接合

実装契約 `current-state-information/1`。正本は [current-state/1](../specification/current-state-aggregation-v1.md)、実行範囲は [CS02計画](../../operations/plans/current-state-information-v1.md)。C7/C7.1/C7.3/C7.5が所有し、新しいNodeは作らない。

## 有効範囲

内部比較指定 `config.currentStateModel === 'current-state/1'` のみ。`cell-reorganization/1` と `persistent/1` を必要とする。通常フォームへは公開せず、既定の生成条件を切り替えない。不明版/旧informationStateを黙って変換しない。

`src/ecology/current-information.js` をstateが束縛し、通常の3段階ターンへ接合する。生成元と23共有モジュールを含む生成物の両方が同じ処理を使用する。Workerの生ソースfallbackにも依存ファイルを追加するが、新方式の全T観測・転送・画面・図鑑形式の完成を意味しない。

## 状態と操作

| 所有者 | 正本/操作 | 境界 |
| --- | --- | --- |
| 主生物 | 出生時 `birthWeights` がb、`informationState.change` がa | 旧`weights`は保持しない。`behaviorWeights`/`weights`で現在値を派生し、`adjust`が実効差分だけ更新する |
| その他の情報主体 | `informationState.base` と `change` | bは9軸の0。既存の行動/配分/宿主選好の参照へ接続する |
| P/Qの宿主選好 | `hostLearning.base=0`、既知の宿主種別ごとの`change` | 宿主適合DNAと分離。許された宿主だけ、既存±20の選好範囲で学習する |
| 発信 | `outgoing.components` | 意味7種・適用範囲・既知の相手系統に限定した固定分類。正負の9軸量、実績数/異なるT数、当該場所の文脈。個体/出来事IDを保存キーへ埋め込まない |
| 受信 | `incoming` | 正負刺激・各方向の慣れ・最終刺激Tと更新T。同Tに束ねて一度学習/支払し、受信元列を持たない |
| 環境場 | `informationField` | マス×適用範囲×源/相手の既知分類×意味×根拠×正負×期限区間。量・強度9軸・根拠量を移送し、死亡者IDや元の全属性を持ち越さない |
| Q作用 | `qInformation.active/residual` | 現寄生は実リンク1件。終了後は期限ごとの量/方向へ集約し、元QのID列を残さない。最大30Tなので未来の残留期限も有限 |

同Tの同一作用の判定はWeakMapの一時Set、受信候補と場所評価索引は当該ターンのcontextへ置く。次の世界JSON/保存へ受信候補や重複判定列を戻さない。現在の実績カウンタ、直接の親/養育、最新の受信結果は保持する。

## 時計・実行順

1. 既存ターンの準備で、実主体を追跡し、場の前T分を同期移送/減衰/失効させる。発信30T、受信10T、Q残留30T/半減10Tを処理する。
2. 発信内容を開始時点で複製した読取索引を作る。受信者同士の処理順が新しい本人実績を伝播させない。
3. 適合/文脈/親子/感度/影響度を通した正負刺激からaを更新する。同方向に刺激が続くTは慣れを増し、刺激がなかった方向だけ時間減衰する。基礎維持Eの1%をT内一回支払い、予算不足/影響度0なら受信しない。
4. 行動候補の場所刺激は一時の誘引/警告とする。候補を読むだけではaやEを更新しない。
5. 既存の実際の採食/被害/生産/支援/生殖/寄生を、同じ確定段階で本人の発信要約へ渡す。移動後の新経験は新しい場所の要約へ切り替え、旧場所の実績を新場所の死亡情報へ写さない。
6. 死亡情報の評価/通常・低根拠/確認被害/Q促進・歪曲を判定し、当該マスの期限区分へ渡す。初期量1は内容/正負へ分割し、総量を増やさない。読み取りや新流入で古い期限を延長しない。

環境の有効強度は一度だけ半減15T、期限は30〜60Tを10T区間へ下丸め、量0.01未満は失活台帳へ渡す。同期拡散は最大20%。環境の根拠量は分割移送し、隣接先ごとに独立実績を複製しない。

本人経験による既存学習と10Tごとの出生傾向への弱い復帰も、主生物のaへ接続する。情報失効ではaを消さず、子は自身の出生時bとa=0から始まる。後天的な親のaは遺伝式へ渡さない。

## 観測と版

内部要約は `current-information-observed/1`、作用量は `current-information-flow/1`。発信/受信の集約主体数と場の区分数/量を数える。集約場を独立発信者数と呼ばない。実際の死亡/受信時だけ、利用できる発信者や分類の情報をcontextの観測イベントへ渡す。

新状態の図鑑保存/読取は `CURRENT_STATE_ARCHIVE_UNCONNECTED` で明示拒否する。CS07で新形式を接続するまで旧列形式へ偽装しない。新方式を旧結果の互換署名へ登録しない。変更していない従来経路は、起点との短期比較後に `currentStateModel` 未指定という条件を付けて旧署名の再生へ接続する。

## 検査・残件

検査は `tests/current-information.test.cjs`。従来経路の起点比較は `tests/current-information-legacy-parity.cjs`。実測と対象ハッシュは [証跡](../../operations/evidence/current-state-information-v1/README.md)。未実行の長期自然循環/500T、性能改善率、UI・Windowsを成功へ含めない。

土壌/個別死骸と要求の集約はCS03、関係/摂取構成はCS04、環境卵はCS05、活動更新はCS06、観測/Worker/画面/保存の全接合はCS07。これらが残るため、この比較経路だけで肥大化全体が解消したとは扱わない。
