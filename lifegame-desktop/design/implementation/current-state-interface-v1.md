# CS07後半：現在状態と通常の観測画面

起点5006c1b。上位はcurrent-state/1の9節、既存責務はC8/C8.1/C8.2・D9。Core/A/B、正式61Nodeの状態/階層/層間参照は変更しない。

## 生態と表示の境界

`current-presentation.js`がネイティブ全T観測を既存画面へ投影する。新しく作る「多層のマス構造（比較用）」だけに`currentStateModel:current-state/1`を付ける。通常の既定モードを変更せず、保存記録の再生には保存した実効条件を直接渡す。

毎Tの人口・相/年齢/雌雄・実作用・同化・世代差分・収支はネイティブ観測を正とする。既存画面の行はその原値を参照し、同じ全期間の原値を複製しない。画面に必要な実B/占有/在庫だけを`current-view-facts/1`として追加し、最終状態とは別に全T集計へ保存する。世界や個体の過去リストを復活させない。

- 全Tの個体数と相/雌雄/年齢、実作用の3観点を維持する。CSVもすべての確定行を保持する。
- ネイティブの栄養段階4成分＋不明は、画面の食性5分類と別である。食性5分類のBは、系統別の直近50Tの実同化構成で配分する。植物/低次動物は既存の役割に置き、主生物の未観測・不明供給源は未分類に置く。個体ごとの過去食事リストは作らず、個体の食性を確定した表示にも用いない。ピラミッドのtitleへ導出法を記載する。
- 関係面は、実際の同化・損害・支援/除去・新規定着/現存付随・情報適用を既存関係図の単位へ投影する。現在のP/Q付随は群体T、感染/情報は実件数。接触だけでは実作用にしない。原値にない死亡個体の系統やQの反実仮想的な功績を推定しない。防御等の関係面が対応しない作用も、全期間の実作用指標とCSVには残る。
- 生物量/役割のない旧ネイティブ記録では未記録を示し、現在の世界から補わない。旧1〜3形式は従来の読取処理を維持する。

## 手動詳細と盤面

既存の手動更新を維持し、選択した瞬間の情報を固定する。初期値とa、発信1集約内の意味区分、受信1集約の正/負、直近適用・費用、現在のQ痕跡を読む。表示操作で受信/期限更新/経験追加は行わない。

場所の情報は由来個体数に読み替えず、集約区分と現在量/期限/作用として示す。残骸は同マスの新鮮在庫・分解済み有機物・還元待ちMの量を示す。盤面では所在マスへ小さな残骸の量の印を置き、死亡個体やDNAを再生成しない。感染運搬だけ残る旧死骸オブジェクトは既存の表示を維持する。

情報の説明は新方式の30T発信/10T受信/30〜60T場所情報/Q残留30Tへ分岐し、旧由来履歴の説明を流用しない。既存配置・遠景記号・近景の生体/地形素材を維持する。

## CSV・結果と再生

CSVはネイティブ原値を分割出力し、Worker/代替経路で同じ内容を作る。表示行を旧観測の可変rowsへ逆挿入しない。相の不明、B、土壌・情報・占有も別の単位で出力する。

図鑑の通常画面が形式4を開き、同じ全T原値からグラフを作る。保存時には表示集計を除いた生態原値と確定世界の一致を検査する。初期条件照合は形式4専用へ分岐する。再生だけでは保存せず、再保存は既存の明示操作/新IDを維持する。
