# CS04：現在の関係・摂取構成・観測統計

接合対象 `current-state-relations/1`。起点 `884e2a0`。上位は [current-state/1](../specification/current-state-aggregation-v1.md) 6節、既存のマス内有限取得とCS02/03。既存C7系/C8/C8.2、D7/D8/D8.2/D9内の接合であり、新Node・正式状態変更はない。

## 生態が保持する現在値

`currentStateModel: "current-state/1"` の内部比較経路だけに適用する。従来経路・UI配置・画像・既定条件・製品4.2.77・配布は維持する。

- `current-ecology.js` は各対象の `uptake` に更新Tと5成分の現在量だけを保持する。過去の食事・源個体ID列は保持しない。
- 成分は栄養段階4成分＋不明。同化した実Eを加算し、既存量は半減期20Tで減衰する。合計0.000001以下は不明へ戻る。光合成は生産者成分、採食は源の現在構成を一段上へ移し、最上段は上限に留める。不明は不明のまま。
- 源の構成は同時取得の要求を組む時点で固定する。同T中に源が光合成しても、その前に成立した要求の構成を書き換えない。物理的なE/Mの配分・収支は既存処理が一度だけ行い、構成更新から栄養を生成しない。
- 身体・捕獲・土壌への移転と実採食、宿主→P→Qの実支払額へ同じ構成境界を接続する。小集団分割では現在量を比例分割する。土壌に混ざった後の死者ID・系統は復元しない。
- 構成の参照だけでは時計や世界を更新しない。これは摂取の現在証拠であり、分子追跡でも食性/情報の役割分類の代用品でもない。

## 接触と成立した作用

個体ペアの過去レジストリ `contactPairs` は新方式に持たない。当該Tの実在同居者・到達可能な隣接者を数え、T内だけ実IDペアを重複除外する。全占有層と自律第四相Qを扱い、代表1体だけに置き換えない。系統ペアへ集約した接触回数を渡し、次Tは新たな接触機会として数える。「生涯で初めて出会った回数」とは呼ばない。

採食・寄生栄養は実同化E、戦闘は実損傷、防衛は実軽減、支援は実移転、感染/除去は実成立、情報は実効変化を成立作用とする。接触・命令・短時間演出だけでは成立関係や作用の多様性を増やさない。現存する宿主/P/Qの付随関係も実作用とは別に渡す。同Tで死亡した寄生者の実作用は、当該Tの実在参照から集計する。

源系統を知る実作用はその系統へ結ぶ。集約土壌・資源・不明な情報は分類ノードへ結び、実在しない生物や失われた源系統を補完しない。分類ノードを関与系統数へ加算しない。

## 世代統計と全ターン観測

生態の累積 `demography` は廃止する。現在の世代・直接の親子/養育・成熟・繁殖待ちは維持する。生態からは当該Tの出生・成熟・初繁殖・幼体死亡・環境成立の差分だけを渡す。死亡時の齢/世代がイベントにない場合は同Tの実体または開始時の事実を使い、不明値を世代0にしない。混在する低次動物小集団は単一世代へ捏造せず、構成と成員フローで記録する。

`current-observations.js` が世界の外で全Tの個体数・相/齢/雌雄/階級構成・接触・成立作用・栄養・出生阻害・収支と栄養段階Bを保持する。累積世代表と系統ペア接触総数は観測側だけに持ち、毎Tの生態複製や行へ累積表全体を戻さない。直近50Tの成立作用と、完了した連続10T区間二つにまたがる関係の継続を観測行から導く。接触だけは作用種類に含めない。

CSVと読取専用スナップショット `current-observation-snapshot/1` を用意する。T0から連続した行と同じ条件を要求し、復元は記録データから集計を再構成するだけで生態を進めない。現在行だけの参照で全期間をコピーしない。生物量は現在Bを5成分で配分し、未観測部分を役割から推定しない。分解者/P/Qと残骸は別枠にする。

## 互換・確認範囲

新形式の通常画面・Worker・図鑑への全接続はCS07。本補助観測形式は通常図鑑の保存形式ではなく、既存の新状態保存拒否を解除しない。変更していない `currentStateModel` 未指定の経路だけ起点比較後に旧再生へ接続する。新しい生態規則の旧結果互換は登録しない。

[限定証跡](../../operations/evidence/current-state-relations-v1/README.md) に対象版と結果を残す。新方式16項目、CS02/03関連32、通常ターン7、既存観測12と従来3条件の短期比較を確認する。自然500T、総合性能、画面操作、Windows、配布は対象外。次はCS05の卵/感染体と残留状態の整理。
