# CS08二次：情報受信の照会再利用

起点fb859a0。現在状態/1の生態ルール、初期値＋a、発信/受信/場所情報の時計、親子/役割/寄生の意味を維持する。既存C7.5/C8.2・D7/D8.2/E5内で接合する。共有配分、世界複製/転送、UI/素材、数値の変更は含まない。

## 再利用するものと本人ごとに判定するもの

`CurrentInformation.buildIndex`は、ターン開始時の発信スナップショットを従来どおり作る。公開内容は複製して固定し、先に受信した個体の変化が同ターンの後続受信へ新しい発信として波及しない。

- 同じ受信マスから見える発信候補は、近傍/通行/地形の見通しが共通なので一度だけ列挙する。列挙順と候補の重複処理順を維持する。
- 本人の除外、親子/実養育者、系統/役割/寄生の適合、文脈、影響度、費用、慣れ、宿主選好の反映は受信者ごとに判定する。共通候補の利用を、同じ学習結果の一括適用へ変えない。
- 本人の成熟/親子/有効な養育者は、その受信処理内で必要になったとき一度だけ照会する。期限切れの養育者を再利用しない。
- 発信量の分母と鮮度は、同じターンの同じ発信スナップショットについて再利用する。除算→受信者の尺度→鮮度という数値演算順を維持し、係数を先に合成して丸め方を変えない。
- キャッシュはターンの計算コンテキストだけに置く。世界・保存・Worker転送の状態を増やさず、次のターンには新しい発信と所在から作り直す。場所作用のキャッシュとは別で、表示が計算を進める仕組みにしない。

## 版と限定照合

生成物/署名を更新した。新署名9631330d…から直前の同規則57332f90…へ、今回の照会再利用の等価を接続する。情報/土壌規則を変更した以前の別生態規則との同値扱いは追加しない。元記録の署名/原bytesを保持する。

新規3項目は、同マスでの見通し再利用と親子判定の分離、系統/役割の独立した適合、次ターンの発信元除去と費用の不再適用を確認する。既存の情報15項目と、実Worker/記録を含む接合12項目も成功した。

保持済みのT0/T133から各1Tを計算し、観測を含む全世界が変更前と一致した。旧形式4記録の初期条件再生と原bytes、未選択の従来マス経路も保持した。[証跡](../../operations/evidence/current-state-reception-v1/README.md)。

T133境界の単回計測では情報受信開始が453.03→307.25ms。全体は2468.50→1986.28msだったが、JIT/キャッシュ/GC等を含む一回の比較で、安定した全体改善率とはしない。自然133Tを再走せず、500T/全条件/Windowsの認定を増やさない。共有配分、複製/一時割当/転送、情報受信の残る処理は後続対象。
