# CS05：環境感染量と共有遺伝型

接合対象 `current-state-infections/1`。起点c373ceb。上位は [current-state/1](../specification/current-state-aggregation-v1.md) 7節。既存C7/C7.1/C7.5/C8.2、D7/D8.2/D9内へ接合し、新Node・正式状態変更はない。

## 適用範囲と現在状態

明示 `currentStateModel: "current-state/1"` の内部比較に限る。通常画面の既定条件・造形・UI配置・製品4.2.77・配布は変更しない。新方式の通常画面/Worker/図鑑への全接合はCS07。

`current-infections.js` が世界の `currentInfections` に版・実ID/型IDの採番値と、現在参照されている遺伝型だけを保持する。確定した環境感染体は `genotype` 参照・感染量E/標準量換算・所在・経路・段階・期限・直接参照を持つ。

- Pの型は宿主/経路/段階の遺伝適応と宿主選好、Qの型は遺伝子・選好・歪曲方向を共有する。同一の実定義を照合し、遺伝適応を平均化しない。
- 現在の環境レコードから参照がなくなった型を確定時に解放する。宿主内の実P/Qは自身の可変な生活状態を持ち、型共有を理由に混ぜたり複製したりしない。
- P/QとP感染体は短い実IDを採番する。直接の親/宿主は別フィールドで保持し、祖先の全IDを子のIDへ連結しない。
- 型を読むための索引は世界の外に置く。既存の感染処理中だけ必要な遺伝定義を展開し、確定前に参照形式へ戻す。侵入のたびに全感染体を展開し直さず、その対象の型だけを参照する。

## 集約するもの・分けるもの

同じマス・系統・遺伝型・経路・生活/成熟段階・作成T/感染期限・必要な直接親/発信元/担体等が一致する環境感染体を量でまとめる。自由卵では投与量の単位も区別する。新しい流入と古い流入をまとめて期限を伸ばさない。

付着済み卵、宿主へ侵入したP/Q、実P/Qの生活状態、一匹移行を表す感染体は合算しない。遺伝型の定義を共有できても、宿主・感染窓の証拠・翌Tの定着時刻・成熟・移行の単一保持は別の状態である。環境中の量を、生存する寄生群体数へ読み替えない。

準備時に型を展開し、既存の期限処理・付着/孵化/侵入/定着・栄養/発育を実行する。水中分散の後と確定前に同条件量を再集約する。索引や一時展開の対象も現在の在庫に限定し、過去の放出列を残さない。

## 卵と感染量の移転

自由卵の在庫が複数の適合宿主へ届く場合、各宿主へ実在量だけを取り出して、宿主別の付着状態を作る。一回の付着量は元の投与単位・残量・標準感染量の最小値。残量は元在庫へ残し、在庫全量を宿主ごとにコピーしない。同じ宿主への重複付着を避ける。

付着後は宿主へ追随し、既存の孵化待ちを経て曝露/侵入を試す。適合・防御・抵抗・最低量・失敗・侵入翌Tの定着を維持する。既存の外部期限前に侵入したものへだけ、既存条件どおり一度の翌T判定を認める。失敗や宿主消失ではその実量を散逸させる。

水系自由卵の集約規則では、既存の `waterMoveChance` を各Tに分散する在庫割合として使い、連結した既存到達範囲の水域へ分ける。既定25%なら現在量の25%を移し、75%を残す。確率25%の判定後にさらに25%を移す二重低下は行わない。水域経路・障害・設定された1/2マス範囲と元の期限を維持する。この量での分散/付着は明示的な新集約規則であり、旧一レコード一卵の個別抽選との一致は求めない。通常方式の抽選は変更しない。

通常の水中感染量も有限量を隣接水域へ分け、移送後に再合算する。移動先IDへ過去の移動履歴を連結しない。一般の曝露も既存の実量消費を通し、同じ量を複数宿主へ使わない。卵の寿命・初期量やP/Q維持費を新たに短縮・優遇していない。

## 抵抗と残留の終了

Pの系統/経路別抵抗とQへの抵抗は、既存の獲得・上限・半減・維持費を保つ。新方式では内部の現在量を毎Tで丸めずに減衰させ、0.000001以下で作用と空の保持欄を終了する。2×10^-6が毎回の丸めで永久に残ることを防ぐ。支払と有効値の扱いは既存境界を維持する。

Qの活動中の実参照、終了後最大30T/半減期10Tの現在ベクトルはCS02を維持する。読取や表示では延命せず、過去Qごとの列は作らない。本工程では期限終了を再確認し、メタ/メタメタ作用・感染窓/羽化条件を改変しない。

## 観測・版と限定確認

`currentInfectionSummary` は現在の環境レコード/量在庫/遺伝型数と保持Eを示す。レコード数は感染体の個体数ではない。卵フローも集約された付着/移送等の処理成立として扱い、実量はE/標準量換算で確認する。

新状態の通常図鑑保存拒否を維持する。変更していない `currentStateModel` 未指定の経路だけ起点比較後に旧再生へ接続し、新しい集約規則の旧互換は作らない。
