# 実装開始値と判定条件の具体案

案の版 `implementation-start/2`。利用者の「設計の具体化を詰めたら実装へ進めるか、内容を具体化して教えて」を入力とする。[現在の採用仕様](../specification/README.md)を維持し、未選定の数値/条件だけを実装開始案へ落とした。**量機の攻撃0.45/防御0.60/最大HP0.80だけは利用者採用済みで、[量機/3](../specification/ryouki-v1.md)を正とする。その他は未採用・未実測の設計案で、正本を自動で上書きしない。** 数値を比較する際は本版と全実効値を固定し、後から成功した初期値だけを選ばない。

## 1. 範囲・尺度・開始条件

実装前に独立して残るのは、この数値/判定条件の具体化。C/Dの更新・素材化・ゲームコード・検査・調整・配布は実装工程に含める。本案が扱う責務は既存A/Bの範囲内で、系統/枝/能力の新設を目的にしない。本書の提案と、採用済み条件の正本を分離する。戦闘3倍率の採用反映は[現在の実行契約](../../operations/plans/completion-roadmap-v1.md#今回の整理範囲)のFLOW-04で扱い、既存A/BとManifestの現在要約へ接続する。core/C/D/E/src/tests/画像/製品4.2.32は変更しない。

- Tは確定ターン。Eは利用可能な栄養エネルギー、Bは有機体量、Mは有限材料。現行の会計に合わせ、E→B変換は同量のEを減らし、余剰分は散逸へ記帳する。E+BとMを別に保存し、HPを栄養の追加在庫にしない。
- 表の維持費は**成体・第一相・DNA中央値における実効値**。既存の主生物維持費0.60倍を重ねて適用しない。年齢/相/DNA/環境補正は定義した経路で各一回だけ適用する。
- 年齢は出生時L0で固定した基準を使う。通常主生物/新四相植物の成熟ceil(0.1L0)、老齢floor(0.75L0)を維持する。相変異/羽化/宿主移行で年齢を初期化しない。
- 攻防/HPの比較倍率は同じ相/年齢/DNAの既存標準主生物に対する値。強くなった相を低い相へ戻さず、進化の基礎成長も残す。
- 調整順は基盤生産→維持/移動負担→繁殖費/待機→捕食/排除→情報作用。固定10条件/未使用3条件とR1〜R6は変更せず、実測の失敗も記録する。

### 2.1 進化と分岐

経験は累積II=20、III=60、IV=140を開始値にする。材料の保持条件はIIIで2M、IVで4M。維持を支払ってHP70%以上を保ったTに0.5、実吸収2Eにつき1、合法な実移動1歩につき0.1（歩行分最大0.4/T）、合計最大2/Tを加算する。表示/移動失敗/接触だけでは加算せず、獲得Mを経験としてさらに複製しない。

分岐用の観測窓は直近32T。新規セルの判定だけは直近16Tの通過セルを最大64件で保持し、全移動履歴へ広げない。

| 分岐 | 判定の開始案 |
| --- | --- |
| III-1 広域探索 | 未訪問だった合法セルへの実到達数/16を0〜1へ制限 |
| III-2 周辺探索 | 窓冒頭の位置から2マス以内で成立した採食T数/8を0〜1へ制限 |
| III-3 障害踏破 | 水域/岩/泥/高温等、通常より移動負担の大きいセルの実通過歩数/8を0〜1へ制限。少なくとも3歩の実績が必要 |
| IIIの選択 | 上記の最大。実績同点は出生DNAの探索/場所愛着/踏破傾向、さらに同点なら保存seed＋ID＋相の固定hash。障害実績不足ならIII-3は選ばない |
| IV-1/2 直進/ランダム | 成立した移動Tを8T以上観測し、前回移動からの方向差45度以内の割合が65%以上なら直進、それ以外はランダム |
| IV-3/4 近め/広め | 成立した採食を8T以上観測し、窓冒頭位置からのマス距離平均が1.5以下なら近め、それ以外は広め |
| IV-5/6 水域/火山 | 水域と高温/火山性地形の合法通過を合計8歩以上観測し、多い方。地形の不存在を成功経験へ補わない。同点は固定hash |

経験が十分でも必要な実績がなければ相IIIで待つ。移動/採食/難所へ進む別の合法経路は維持し、上位枝でしか入れない場所を進化の必須条件にしない。

枝は命令ではなく候補得点/費用の補正とする。広域は未訪問候補1.2倍、周辺は既知の局所可食候補1.2倍、踏破は地形の追加移動費を0.8倍。IVの直進は方向維持候補1.3倍、ランダムは方向変化候補1.2倍、近めは1マス以内/広めは2〜3マスの採食候補1.25倍。水域/火山は対応地形の追加移動費を0.65倍とし、IIIの0.8倍と重ねない。通行禁止や死亡を無効化せず、火山枝のためだけに新しい地形/海を作らない。

### 2.2 可逆な相変異

[量機/2](../specification/ryouki-v1.md)の比較案を開始値にする。

- ターン開始時の同セル＋周囲8セルの同系統の他個体が6体以上で3T連続なら成立。
- 2体以下が6T連続し、自セルが本人一体になった場合に解除。中間密度では状態を保ち、継続条件から外れた側のカウンタは0へ戻す。
- 相変異中は最大3独立個体/セル。移動先/出生先の予約、攻撃/捕食/寄生/選択/計数を実IDごとに調停する。解除待ちで削除/無償移動をしない。
- 相変異4の合法な繁殖準備候補の評価重みは1.5倍。繁殖率/出生数/待機への倍率に転用しない。空腹/危険を無視せず、不足条件の改善へ動く。
- 1〜3は背中だけ黒、4は黒と深緑。解除で進化相/枝/年齢/IDは変えず、移動距離だけ通常相の上限へ戻る。

## 3. 群落と独立植物

標準採食量qを2Bと定義する開始案。採用済みの群落容量10q/初期70%/最大再生10%/T、陸20%・水15%の適地占有率は維持する。可食部の再生1BにつきE1.2を減らしてB1へ移し、E0.2を散逸する。有限土壌M0.02を個体内へ移して組織へ割り当て、同じMを二度減らさない。消費/死亡時の材料移転へ追従させる。

三系統は生産者の独立個体で、基底群落とは別。大型生産者は三系統合計1体/セル、基底群落は別枠に1群落/セル、主生物枠との共存を許可する。同じセルの光入力予算/土壌Mをまとめて調停し、枠を増やしただけで入力を複製しない。光の合計上限はそのセルで最も大きい個別上限を一回だけ適用し、光配分は実在する受光面積比、同面積なら固定hashの順で割当てる。初版の受光面積は基底群落1、大型I/II/III/IV=1/1.15/1.35/1.6とする。

大型の非可食本体は2B、可食容量I/II/III/IV=8/10/12/16q。維持と光入力の相倍率は1/1.15/1.35/1.6、年齢係数は採用済みのものを使う。可食0だけで死なず、維持未払いによる健康悪化は残す。実再生は容量10%/T、E/有限M/基部活性の支払可能量の最小値。

大型の第一相E容量は森冠40/星冠40/淡水36、M容量は各4、最大HPは40/36/28を開始値とする。E容量にも相倍率を適用する。初期本体は2B、可食量は当相容量70%、Eは容量50%、Mは1、健康は本人上限で、初期台帳へ全量を記載する。出生子は下記の支払量だけを持ち、幼体のHP/光/維持は既存の年齢係数へ接続する。基底群落と大型個体の少ない初期本体量を、内部株数へ換算して個体数を水増ししない。

通常出生は親10E/0.2M→子E6+B2/M0.2＋散逸2E。出生後に維持4T分のEを残し、子はI/年齢0/可食部0。適地/近傍8セル/空き枠/費用/待機を満たす。IVの大型繁殖体は親14E→子E10+B2＋散逸2E、待機1.5倍。小型繁殖体は親8E→子E4+B2＋散逸2E、待機0.75倍（切上げ）とし、一回の出生機会につき一子を維持。M0.2は共通。親の相/経験を子へコピーしない。

経験II/III/IV=12/36/80を維持する。維持を払い健康な本体を保った2Tにつき1、純新生産4Bにつき1、被食後再生4Bにつき1、子が4T生存した初回に1、合計最大1/T。生産/再生は同じBを排他的に帰属し、T内合算後の端数を保持する。単なる移動/試行/処理分割では加点しない。

分岐は直近32Tの実際のE配分。IIIは生産/繁殖拡散/被食対処の最大、同点は既存DNA傾向→固定hash。IVは同じ親枝内で高生産/省資源、少数大型/小型、耐食/再生の実配分を比較する。全額支払った生産・繁殖準備・対処の配分を実績へ残し、未来の能力を先に得たと仮定しない。IVの開始効果は高生産=光上限1.2倍/維持1.1倍、省資源=維持0.8倍、耐食=一回可食上限0.8倍、再生=再生上限1.2倍。光/容量/在庫/費用を通す。

感染体生産は親0.12E→感染体のE相当備蓄0.06＋散逸0.06。標準感染量1はこの有効備蓄0.06E相当とする。成功時に備蓄から新PのE.04+B.02へ割当てる（ここで初めて新しい生体Pとして計数）。部分曝露では実際に移転した備蓄rを使い、定着には最低r=.03を要求する。新PはB.02とE=(min(r,.06)−.02)だけを持ち、半量曝露r=.03ならE.01+B.02。下限未満は定着不能、上限超過分は元期限の感染量へ残す。接触しただけで標準一個分の栄養を補わない。定着判定までは体外/侵入中感染量として扱い、生体Pの維持を重複請求しない。失敗時は残量を失活/散逸し、死んだPの無償再生成はしない。成熟Pの有償生産は全経路合計6Tに1感染量を上限にし、同じ体外量の局所接触/水媒介と、同じPの捕食移行を別処理にする。Q産卵は親0.10E→子E.08+B.01＋散逸.01。いずれも生成/感染/移行の同ターン連鎖を禁じ、途中状態を二重計数しない。

P→Hのメタ誘導は候補評価への相I/II/III最大±10/20/30%、追加費.005/.010/.020E/T。Q→Pの小補正は最大±3/5/8%、追加費.001/.002/.004E/T。実投資比率に比例し、維持/発育を先払いした残りの予算内に制限する。支払えない作用は弱まり、恒久的な基礎能力やDNAを上書きしない。Qの主な投資先は後述の情報痕跡で、IVで新しい直接補正は行わない。

### 4.1 Qの羽化と自立

- 自身の年齢成熟12T、寿命80T。実維持成功0.25＋実発育成功0.75、最大1経験/T。II=4/III=12経験、発育は別に12進捗。
- III到達＋成熟＋発育＋栄養/抵抗/再準備を満たして羽化。試行の追加費=試行時の実効維持費6T分（表の基準なら.09E）、成功率=0.60×(1−Pの実効対Q抵抗)、失敗再準備4Tを維持する。通常支払後に試行費とIVへの追加B.01を作るE.01の両方を残せる場合だけ試行する（基準残高.10E）。試行費は成否にかかわらず支出し、Bへの変換は成功時のみ。成功時はPだけ死亡、同QがIVへ離脱する。
- 自立IVは隣接1マス移動0.002E/歩、同セルの既存有機資源/死骸から最大0.10E/Tを採り、50%を吸収する。食べなかった在庫を消さず、吸収されない分は既存の残渣/散逸へ記帳。情報は食べない。
- 成熟/栄養/待機を満たせば産卵、基準待機12T。新QはIで、許可された実接触先と限定窓を通る。既に窓を過ぎたPを感染させるための窓再開は行わない。
- IVは既存情報を新規加工しない。P寄生中にH/Pへ残した痕跡だけが死亡時の出現促進/歪曲へつながる。

QのI/II/IIIの情報促進上限は出現率へ+0.02/+0.05/+0.10、内容歪曲上限は定義域幅の5/10/20%。実支出/相別投資上限を0〜1へ制限し、促進/歪曲への配分合計を1以下にする。遺伝する投資配分も標準0.5、採用した小変異と相/費用の上限を通す。元経験/根拠不足/真偽を区別し、架空経験や期限の若返りを作らない。
