# 全系統の専用差分 / 4.2.2

完成対象は全系統です。[全31系統の制作台帳](coverage.md)に、系統別の分岐・雌雄・年齢・階級・生活環・下層の状態差を記載しました。

今回、主21系統すべてに専用分岐原画を接続。通常20系統×9枝＋早成型3枝＝183枠。既存の日輪/浮遊傘18枠を維持し、残り19系統165枠を10シートとして制作。色替え/幅変形だけだった枝を、器官配置と輪郭が異なる原画へ置換しました。雌雄・年齢の系統固有原画と階級/寄生/下層は引き続き制作対象です。
