# 小型サマリの位置を訂正した全画面案

未採用・未実装の静止画。今回の画像資料のみ保存し、ゲームコード・A/B・Node・Manifest・coreは変更しない。

サマリは既存Index.htmlのmetrics内trend-card（個体群の推移）の位置、すなわちマップ上の個体数カード列の末尾に置く。右側には個体数推移・集団構成・生態関係の基本3グラフを縦配置。マップ下部に大きなサマリは新設しない。個体数推移は全て/主生物/餌生物/植物/一次/高次、集団構成も対象切替可能。相/雌雄/年齢は個体数の時系列。

小型サマリの3線は増減を比較するため初期値100へ指数化する案であり、異単位の実数を共通軸へ直接重ねる意味ではない。初期0の指標は指数化できないため、その扱いは未確定。これを採用済み集計式として扱わない。

画像の数値・曲線は説明用。相/雌雄/年齢の総数曲線の不一致、寄生虫カードで星晶の記号を流用している点、一次/高次の記号が似ている点、サマリ線が初期100から始まっていない点は生成画像の不整合で仕様ではない。最終実装では3構成グラフの同対象総数を揃え、寄生虫は固有記号を使う。モックは配置と画面密度の確認用である。
