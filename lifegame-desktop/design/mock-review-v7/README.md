## 今回受領した集計方針

初期表示は主生物。「全て」は表示中の拡大範囲によらず盤面全体の生物を対象とし、植物・餌生物・寄生虫も各記録個体を1個体として合算する。生物別も選択可能。相はI〜IVで集計し、IIIが上限の系統もIIIへ含める。無性別は独立区分。特殊な性/階級の内訳は対象別の補足とする。説明欄に、個体数の割合であり生物量や生態的重要度の割合ではない旨を記す。

## 資料の限界・確認観点

数値・曲線は説明用であり実測値ではない。静止画の細かい文言や付加的な造形から、新しい能力・感染条件・性別決定則を採用しない。密集画面での宿主付随表示、色が重なる選択範囲、実際の1マスサイズ、縮小/ズームの位置連続性、動画としての行動識別は製品で別途確認する。年齢と進化相は独立。行動欄のローマ数字は図の項番であり進化相ではない。相・分岐・年齢を揃えた雌雄比較を意図するが、造形差が別相に見えないかもレビュー対象。

画像は説明資料として分割配置しており、最終UIの固定レイアウトを決定するものではない。既存の採用モックは置換しない。生物名は深淵触手/星晶/植物共生、餌生物の例は水遊虫。高次寄生虫は一次寄生虫に付随する。
