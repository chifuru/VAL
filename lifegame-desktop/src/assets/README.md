# LIFE LAB 描画資産

`creatures.png` は旧実行モックと同じ素材・描画器から書き出した20系統×四相の透明アトラス。`tools/export-visual-assets.cjs` が製造する。旧エンジン/部位成長のテンプレートは製造時だけ使用し、ゲームの計算へ読み込まない。原素材は同じVALリポジトリの既存プロジェクトから読み取り、変更しない。

`food.png` は同素材群の動く餌・鉱物・情報画像24枠。実行時の情報は結晶の別名称にせず、鮮度付きの浮遊光輪として描画する。植物/菌/卵/粒/滴/因子/P/Qは描画プリミティブを併用する。

`terrain.png` は今回新規に生成した真上視点の8環境の地表アトラス（4列×2行）。左上から水/熱/情報/静、下段は寒冷/湿潤/強風/腐食。単一背景やモックUI画像ではなく、固定環境/地形の確定セルへ対応させる。通行を変える岩塊・倒木・茂み・崖はモデル実体から別描画する。

`visual-manifest.json` が枠位置と由来、同内容の `.js` がローカルfile用の静的読込定義。実行時のネットワークや元プロジェクトへの依存はない。描画は生態のDNA/相/枝/雌雄/階級/資源残量だけを読み取る。

枝は光輪・弧・色、雌雄は小さな冠/側面斑で区別する。部位の個別進化は再導入しない。早成甲殻の外形は深殻の三相を暫定共有し、能力・相数・生態は独立したまま。植物の基部だけの個体は小さな芽。専用造形の追加や枝ごとの大きなシルエット差は今後の認識合わせ対象。
