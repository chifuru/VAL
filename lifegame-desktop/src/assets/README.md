# Production artwork / painted-world 3

現行素材は `visual-manifest.json` の10枚だけ。旧実行用アトラス6枚と旧地表manifestは除去した。参照用の採用モックと過去の検証画像はdesign/とoperations/に保持する。

| 原画 | 対応 |
|---|---|
| life-a〜e | 主生物20系統×四相。1行1系統、列はI〜IV |
| life-f | 早成甲殻のI〜III、寄生2系統・高次寄生1系統の各3造形。第4列は未使用 |
| food-atlas | 微藻/蘚苔/草本/菌膜/水棲小虫/陸棲小虫の各二相 |
| habitat-props | 樹木/茂み/岩塊/倒木/葦/泡/崖など16区画。実際の地物と装飾を区別して描画 |
| solar-branches / jelly-branches | 各III三枝＋IV六枝。IIIは先頭行、IVは続く6枠 |

新しい量産原画を採用モックから参照生成した。原画PNGは生成結果からそのまま保存し、SHA・寸法・参照矩形をmanifestに記録する。JS定義は同じ内容をfile://で読むための静的形式。`node tools/export-visual-assets.cjs` はSHA・領域・両manifestの一致を検査し、旧描画器から再生成しない。

`art.js` は実行時にセル内の微小な隣接画の断片を除外し、年齢/雌雄の比率・表面差とDNAの寸法差を表示変換する。個体の相・枝・年齢・性別を変更しない。日輪と浮遊傘以外の枝は体形比率による区別で、全分岐専用画の完成とは扱わない。P/Qは宿主の印と説明欄へ表示し、新たな自由個体にしない。

地表は画像の反復タイルを廃止し、固定された実セルから連続材質を生成して表示起伏に貼る。装飾の花草・水際の泡は食用生物や物理的障害物を意味しない。遠景で装飾を岩の記号に変換しない。

造形の対応・原画SHA・実画面の条件と限界は `operations/evidence/graphics-rebuild-v3/README.md`。独立四相植物・海洋光合成系統は今回追加しない。
