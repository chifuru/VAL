新しい量産原画を採用モックから参照生成した。原画PNGは生成結果からそのまま保存し、SHA・寸法・参照矩形をmanifestに記録する。JS定義は同じ内容をfile://で読むための静的形式。`node tools/export-visual-assets.cjs` はSHA・領域・両manifestの一致を検査し、旧描画器から再生成しない。

`art.js` は実行時にセル内の微小な隣接画の断片を除外し、年齢/雌雄の比率・表面差とDNAの寸法差を表示変換する。個体の相・枝・年齢・性別を変更しない。4.2.2で全21主系統の専用枝183枠へ接続。新しい19系統165枠はdedicated-branches-01〜10に収録。新原画は身体ごとの領域と縦横比を使用。雌雄/年齢は共通変形が残り、全差分完成とは扱わない。P/Qは宿主の印と説明欄へ表示し、新たな自由個体にしない。

地表は画像の反復タイルを廃止し、固定された実セルから連続材質を生成して表示起伏に貼る。装飾の花草・水際の泡は食用生物や物理的障害物を意味しない。遠景で装飾を岩の記号に変換しない。

造形の対応・原画SHA・実画面の条件と限界は `operations/evidence/graphics-rebuild-v3/README.md`。独立四相植物・海洋光合成系統は今回追加しない。

## 背景景観 / painted-habitat 3.1

`habitat.js` が専用の地表・水面11素材を合成する。草原/林床/岩/砂礫/浅水/白波/深水/雪/熱域/情報域/腐食域。8環境は実タイルからマスクを作り、色だけで代用しない。深水には底の見えない専用画を使い、岩地や情報域へ水路を描き足さない。

地表の小石・細かな草花は装飾で、実際の餌や障害物を新設しない。実際の水域・地物・壁の所在は既存タイルと照合する。近景の見えている領域だけ128〜256texel/セルで合成し、素材の端を重ねて継ぎ目を抑える。遠景は地勢を残して細部・彩度を抑え、個体記号の読みやすさを優先する。

地物の影は元の輪郭から作る。泡や低い草花に大きな楕円影を付けない。遮蔽は個体の周辺だけを局所的に解除し、それ以外の森林を不透明に保つ。

採用モック・前回3.0・今回3.1の比較は `operations/evidence/habitat-visual-v3.1/comparison.html` と同PNG。原画・対象SHA・実測条件は同ディレクトリのREADME。生物原画10枚と生態計算は3.0から変更していない。
